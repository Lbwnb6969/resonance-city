# 精制河湾生产资产

运行 `python tools/build_refined_valley_art.py` 可重建本目录的 PNG、编辑 SVG、几何投影阴影、接地遮罩、manifest、接触表与 `validation.json`。生成器使用项目既有 45°/30° 正交投影和 BSP 遮挡排序；新建筑包含窗框、窗台、门阶、檐口、石墙接缝、逐片瓦面、露台构件、庭院或店铺层次。两类树使用独立树冠与枝叶团簇几何。

`scripts/visual/building_variant_catalog.gd` 默认使用本 manifest：住宅按现有稳定建筑 ID 选择露台、坡瓦、庭院；商业使用商铺。`preview_entry(expression)` 与真实作者根共用深流石蓝露台、织机陶瓦商铺、暖庭绿灰庭院。`prop_entry(kind,tone)` 提供文化馆和两类树。显式美术对照模式继续保留既有资产入口。

全部地脚均为模型 `(0,0,0)`，与对应 cast/contact 遮罩共用；manifest 的 origin 与 pixels_per_world 直接进入既有生产 sprite、阴影和 alpha 命中流程。建筑仍使用原有 `0.8` 落地显示比例，World 用途、朝向、实际占地、声音、RNG、规划保留地和存档字段由既有系统管理。PNG 导入启用 mipmap 和 alpha 边缘修复。
