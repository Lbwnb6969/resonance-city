# P1 · 可持续塑造的小城市

在 P0 的接合效果上增加表达范围，不先扩成大城。

| 工作 | 可玩结果 |
|---|---|
| 特殊建筑 | 自由选址，台基/入口/柱廊自动适配；可移动、改造和撤销 |
| 功能区 | 连续画笔/轮廓指定住宅、商业、文化或自然倾向，影响后续点击 |
| 植被 | 树群/林带/草石自动避让道路、入口和保留地 |
| 玩家街坊 | 逐栋选择、命名、回访；保留跨 CID 成员 |
| 声音反馈 | 视野内为主、远处偶发、特殊合奏、区域风格和连接 |
| 编辑/UI | 常用工具清楚、小窗口可用、键盘输入隔离、撤销统一 |
| 中型扩展 | 80–150 栋检查局部缓存、区域差异与音乐组织 |

从已有公园、文化馆、留地、作者音源和逐栋命名实现迁移。制作两种同河湾布局，比较风格、操作次数、继续建设意愿和听感；技术日志与真人结论分别记录。
