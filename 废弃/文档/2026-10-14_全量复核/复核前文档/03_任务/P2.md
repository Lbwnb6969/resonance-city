# P2 · 强力建筑、时代与大城

| 工作 | 交付 |
|---|---|
| 首批强力建筑 | 布局预设/批量模块、剧场台阶广场或大跨度公共空间；能在现有城市演示 |
| 古典→中世纪 | 新材料和立体建造机会，新旧街区共存；玩家选择进入 |
| 历史保留 | 明确选区保持旧外观、名字、作者和声音来源 |
| 时代扩展 | 文艺复兴/工业/现代按内容价值增加工具与地标，旧 27 座为候选池 |
| 大城编辑 | 400–600 栋的批量工具、空间分块、LOD、完整供音与编辑测量 |
| 作品导出 | 摄影/壁纸、可读 DNA 与音频作品；可继续编辑原城市 |

先验证一座强力建筑的能力，再扩大目录。3,000–5,000 栋为后期扩展目标，按真实帧时与用户作品规模推进。复杂经济、票制和高自由度实时作曲等内容按实际价值决定，不设成必需里程碑。
