# 全量复核来源

`原始文档/` 是首次修改前的 31 份原稿，逐字节保留；`复核前文档/` 是本次复核前的整套文档，`PROJECT_复核前.md` 保留当时状态。两套都只供追溯，不提供现行玩法规则。
