# 地形与自然执行规格

> **当前权威裁定 · 2026-10-11**：三层模型保留，但“规则层”只承担已经能被玩家理解的关系。河流对唱保留为首个地形音乐合同：无桥仍可听见一次有来源的两拍应答，桥只改变物理耦合；位置距离和音程由玩家安排。对唱不写入 `V`，不产生自动奖励。湖泊镜面、林地局部高频质感、山地主动梯田编曲、海岸/山顶传播先不进入全局公式；山坡不强制把建筑音高升阶，地形不替玩家选音。旧 T1/T3 的固定数值保留作候选与历史记录，不能据此实现自动增益、自动居中、自动改 MIDI 或全局 `T/σ`。

> 2026-10-09 重构版 · **权威规格**。旧文档中地形无任何生成规则（只有固定四点岛台 + 配色参数）。

> **2026-10-09 二次修订**：表 T3 拆成三层（规则 / 声学 / 玩法），去掉"跨河 = 完全隔绝"的说法；

## 层的划分（与 spec.space §0 一致，必须先读）

地形对声音的作用分三层，任何一条地形规则必须明确属于哪一层：

| 层 | 地形做什么 | 依据 |
|---|---|---|
| **规则层** | 改 `O`、`T`、`σ` —— 改的是"算不算有关系、关系多强" | 表 SP2 / SP7 |
| **声学层** | 改 PCM —— 延迟、滤波、增益、额外声源 | 表 T3 的"声学层"列 |
| **玩法层** | 给玩家什么动词、什么形态、什么奖励 | 表 T4；表 T3 的"玩法层"列 |

**禁止**用规则层的结论（`c = 0`）去断言声学层的结果（"听不见"）。
**跨河的两个建筑在规则上无耦合，但在混音里仍可能互相听见**——
后者由 AUDIO-009 的监听 / 编曲隔离决定，不由 `O = 0` 决定。

## 表 T1 · 地形类型

| 类型 | 可建 | 规则层 O | 规则层 T | σ 倍率 | 声学层 | 数量 |
|---|---|---|---|---|---|---|
| 海 sea | ❌ | 0 | — | — | 开放空间，最低声床；远处低频回荡 | 地图外缘 |
| 河 river | ❌ | 0 | — | — | 流动噪声；**对唱**（事件应答） | 1–3 条 |
| 湖 lake | ❌ | **0** | — | — | 镜面延迟副本（0.15 s，−12 dB） | 0–3 个 |
| 山 mountain | 缓坡可建 | 陡坡 0 / 缓坡 0.7 | 1.0 | **1 + h/8** | 风声；高海拔高频更清 | 0–2 座 |
| 林 forest | ✅ | 0.7 | 0.85 | 1.0 | 吸高频（带通常通） | 0–n 片 |
| 平原 plain | ✅ | 1.0 | 1.0 | 1.0 | — | 默认 |
| 滩涂 beach | ✅ | 1.0 | 1.0 | **1.15** | — | 海岸过渡 |

**两处旧误已改**：
① 湖的 T 列原写"镜面延迟"——T 是**乘在 c 上的系数**，不能填效果；湖的规则层是 `O = 0`，镜面属声学层。
② 海岸的"开阔"原被写成 `T = 1.15`——开阔影响**传多远**，属 σ，不是 T。写在错误的列会让实现把两件事乘在一起。

## 表 T2 · 地形生成（terrain 子流）

| 步 | 规则 |
|---|---|
| **1 高度场** | 种子驱动的 FastNoiseLite Value 噪声，4 层分形，`1/f` 权重；噪声归一化到 `[0,1]`，再映射为以海平面0为基准的有符号高程h；噪声值与高程不混用，映射参数在通用生成器实施时写入规格 |
| **2 海** | 高度 < 0 → 海；海岸线是 0 等高线 |
| **3 填洼** | **priority-flood**：把无出口洼地填平；**记录哪些洼地变成湖**（盆地 = 被更高高程包围的连通低区） |
| **4 流向** | 在**填充后**的高程场上算 D8 最陡下降；**原高程用于地貌与渲染，填充面用于排水**（两者不得混用） |
| **5 平地** | 填充面上的平地保留 **priority-flood 父图**的确定指向；**不得对平地再套用裸梯度**（会死循环或随机游走） |
| **6 流量** | 累积上游流量；流量 > 阈值的水道 → 河；**河宽 ∝ `sqrt(流量)`** |
| **7 河终止** | 河**必须终止于海或湖**；不允许终止于平地 |
| **8 缓冲带** | 河两岸留缓冲带，宽度 ∝ 河宽；缓冲带内不可建 |
| **9 可建性** | 可建面积 ≥ 地图总面积 **45%**，否则重采样 |
| **10 重采样** | 最多 **8 次**；尝试由**根种子 + 尝试序号**确定；耗尽则使用**有记录的河谷模板**，**不得悄悄更换每日根种子** |
| **11 R 保护** | 生成后检查存在一块可建区其 `R_initial ≥ 65`（沿用旧裁定） |
| **12 首片** | 第一切片用**受控河谷模板**（表 T6），先解决城水配合，不追求通用水文 |

**地形族**（种子决定）：河流谷地 / 海岸 / 山地 / 三角洲 / 湖泊群。

**排水约束**：旧稿写"河从最高点按梯度流向海"，这在平地与局部洼地会**停住**。
必须走 priority-flood 父图 + 逆序流量，否则平地上不会产生河，且湖无法正确成形。

## 表 T3 · 地形声学调制（三层分离）

**每一行必须能回答"哪一层"**。三列同时成立不是冗余，是分工。

### T3-a 河

| 层 | 内容 |
|---|---|
| **规则层** | 默认 `O = 0` → 两岸**不产生耦合边**，不参与 R。有桥处 `O = 1.0` |
| **声学层** | 两岸建筑**并非互相听不见**。若两岸都在全城混音中发声，仍会有拍频与掩蔽——由编曲（AUDIO-009）决定谁在什么时候真的发声 |
| **玩法层** | **对唱**：两岸建筑直线距离 < 8 且音程 `s ≥ 0.85` → 由来源事件生成一次应答，**延迟 2 拍**复述前者；不写入 `V`，不产生自动成长奖励。 |

**对唱是"有来源的事件应答"，不是规则耦合**：单向一次复述，**双方不得互相再次复制**（防递归）。
它不产生 R 边，也不因 `O = 0` 被取消。**这是"河让城市更音乐"的机制，不是"河把城市切断"的机制。**

### T3-b 湖

| 层 | 内容 |
|---|---|
| **规则层** | `O = 0` → 不产生耦合边 |
| **声学层** | 湖面回声为后续试听候选，当前不自动插入固定延迟、增益或反馈支路。 |
| **玩法层** | 湖心岛不自动增益或居中；玩家可主动安排独奏与留白。 |

### T3-c 山

| 层 | 内容 |
|---|---|
| **规则层** | 山脊两侧 `O = 0`；缓坡的物理可达性由地形判定。当前不启用自动 `σ` 放大。 |
| **声学层** | 高海拔高频更清（空气感）；风声环境层 |
| **玩法层** | 不强制改音高；玩家未来可主动选择梯田上行编曲。 |

### T3-d 林

| 层 | 内容 |
|---|---|
| **规则层** | 林地不新增全局 `T` 倍率；局部听感候选后置。 |
| **声学层** | 高频吸收——**低频保留**，听感是"闷"而不是"断" |
| **玩法层** | 植树降密度，可作留白手段 |

### T3-e 海

| 层 | 内容 |
|---|---|
| **规则层** | `O = 0`（外缘，无对岸）；海岸传播加成后置。 |
| **声学层** | 环境声床来源：低频脉动，速度随时代（航海慢 / 现代快） |
| **玩法层** | 海岸线是最有价值的建材：视野好 + "开阔"加成（σ × 1.15） |

### T3-f 河谷

| 层 | 内容 |
|---|---|
| **规则层** | 当前不启用额外河谷 `σ` 倍率。 |
| **玩法层** | 河谷低音社区更容易形成"深流"形态 |

## 表 T4 · 玩家地形动词

| 动词 | 操作 | 效果 | 代价 | 频率 | 提交 |
|---|---|---|---|---|---|
| **引水** | 从水源拖出路径 | 生成河道 | 不可撤销；占地 | 每乐章 1 次 | WorldDelta |
| **植树** | 点一下 | 小片林地（半径 2） | 占地；降低局部密度上限 | 每乐句 1 次 | 介入槽 |
| **挖湖** | 在低洼处点 | 小湖（半径 2–3） | 不可撤销；占地 | 每乐章 1 次 | WorldDelta |
| **平整土地** | 在山坡拖一片 | 降为缓坡（可建） | 不可撤销 | 每乐章 1 次 | WorldDelta |
| **建桥** | 在河上拖过 | 该处 `O` 由 0→1.0，允许跨河耦合 | 占用介入槽 | 每乐句 1 次 | 介入槽 |

**统一提交规则**（回答"独立额度是否绕过乐句边界"）：

- **全部地形动词的落定都锚在乐句边界**，即使它们不共用介入槽。
- **独立额度动作同样通过同一个 `WorldDelta` 提交**——额度决定"每乐章几次"，`WorldDelta` 决定"何时生效"。两者不冲突。字段和失败回滚规则见 [19·城市生成管线 §8.3](../19_城市生成管线.md)。
- **预览必须显示**：相邻建筑的耦合变化、可能失去的命名形态、会被覆盖的建筑。

**覆盖既有建筑的水域改动必须拒绝**——不能自动删除、移位或让建筑浮空。
迁移是另一个明确动作，不由地形改动触发。

**建桥的几何约束**：桥是**真实的边**，必须同时满足 ① 两岸落脚点存在 ② 跨度合理 ③ 桥头能接路。
玩家划过一条河**不自动成桥**，只是提出候选，仍需几何成立（19 §2②）。

## [TERRAIN-001] 地形生成与可建性

状态：受控河谷模板已接；河谷、湖盆、林岭、海湾平原四类可切换首片，高地峡谷第五类首片，共享连续世界合同并分别改变水面宽度、山势、声学因子与视觉色调；通用高程映射/水文/可建面积与回退验收仍待完成。

意图：让山海湖河成为一等系统，且生成结果必然可玩。

规则：表 T1 / T2；地形由 **terrain 子流**生成，可复现；可建面积 ≥ 45%；最多重采样 8 次；`R_initial ≥ 65` 保护；
排水走 priority-flood 父图。

数据：表 T1 / T2 / T6；spec.run.md 表 R2（terrain 子流）；spec.space.md 表 SP1。

验收：`tests/terrain_contract.gd -- --case generation`
- 同种子同地形
- 可建面积断言（≥ 45%）
- 水域/陡脊按遮挡规则判 `O=0`；保留地、岸线缓冲等不可建区不自动成为隔声墙
- 5 种地形族各生成一次并记录
- 平地上**确实产生河**（priority-flood 回归）
- 每个湖都由"被高程包围的盆地"产生

反例：
- 不得生成全山或全水的地图
- 不得让地形破坏 `R ≥ 65`
- 不得使用非 terrain 子流的随机
- 不得用裸梯度在平地上找流向
- 不得在重采样耗尽时悄悄更换根种子

## 连续地形的迁移边界

| 项 | 旧 | 新 |
|---|---|---|
| 跨河 | "隔声（O = 0，除非有桥）" + 对唱加成写在同一行 | 表 T3-a 三层分离；**对唱不是耦合** |

| 海岸 | `T = 1.15`（写在 T 列） | σ 倍率 1.15（表 T1 新增 σ 列） |

| 湖泊 | "低洼处积水" | 被高程包围的盆地（填洼时判定） |
