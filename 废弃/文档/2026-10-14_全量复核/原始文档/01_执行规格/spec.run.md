# 单局、随机、祝福与城市记忆执行规格

> 时长、种子、祝福、时代与三种模式的现行规则。剩余产品缺口见 ../待裁定与依赖.md；工程细节按已批准边界自主补齐。

## 表 R1 · 时长（沿用）

| 单位 | 长度 |
|---|---|
| 小节 | 2 s |
| 乐句 | 8 小节 = **16 s** |
| 乐章 | 12 乐句 ≈ **3.2 min** |
| 一局 | **7 乐章 ≈ 22 min**（含祝福与结算停顿，实际 25–35 min） |
| 祝福选择 | **每乐章开始 1 次 → 一局 7 次**（包含首章，非章末再发一次） |

## 表 R2 · 种子与City DNA（沿用裁定内容）

```
City DNA = { seed: uint64, mode: string, charter_id: string,
             decisions: [{bar:int, proposal_id, target, choice}] }
所有随机来自 hash(seed, 子流名)
子流固定：terrain / mode / boons / form / events
seed = hash("daily:" + UTC日期 + 版本号)
```

禁止无子流来源的`randi()`。地形及初始布局使用terrain；调式/音源/宪章使用mode；祝福用boons；命名形态用form；提案及城市记忆事件用events。2026-10-08用户批准P0 U02方案，执行定义见R2a；每日一城无后端，不暗含排行榜、账户或云存档。

## 表 R2a · P0种子执行方案（用户批准U02）

| 项 | 规则 |
|---|---|
| 根种子 | 16位小写hex文本，表示原uint64位串，避免JSON整数精度/有符号转换损失 |
| 子流派生 | SHA256(根seedhex+":"+子流名)，UTF-8，五条命名子流各自独立 |
| 随机字 | SHA256(子流hashhex+":"+计数器十进制)前8位hex作为uint32；计数器从0递增 |
| 有界取样 | uint32拒绝采样，丢弃≥floor(2^32/上界)×上界的字，再取模，不引入模偏差 |
| 快照 | 根seed与五子流计数器；试听只深拷贝不推进真子流 |
| daily | SHA256("daily:"+UTC YYYY-MM-DD+ProjectSettings application/config/version)前16位hex |
| P0版本 | p0-2（改变合法选址/连片成长，写project.godot；旧作品保留身份）；改变生成/子流语义必须升版本 |
| P0决策 | 保留原bar/proposal_id/target/choice；追加verb、district_id、输入requested_audio_frame与commit_phrase_frame；音级/格子来自系统选项，不丢失输入时刻 |

P0只实现种子/生成/选择可追溯接口；完整Run、祝福、图鉴重放内容仍不进入P0。daily失败保留根种子并记录回退，见CITY-002/T2；旧P0九街区安全坐标只属于固定测试fixture。

### 河谷作品保存与继续

当前自由河谷支持Ctrl+S存一版、F9继续最新完整版本、重新启动自动继续；城市出生/升级/公共规划落定后自动留检查点，正常退出时保存。存档保留完整规划几何、稳定ID、随机流、待落定操作、决策时刻、PCM渲染游标/相位/交接节点与镜头/移动体进度。保存不推进随机流和城市时间。

每份作品为独立本地文件，写完并校验后才成为可读版本；旧版本保留。最新文件损坏时恢复前一完整版本，损坏文件保留。重启从保存的下一未渲染样本继续，旧音频设备队列不跨进程保留，至多跳过原0.12秒缓冲；新输出80ms渐入。Demo 另可导出包含 `resonance_audio_plan_v1` 与 `runtime.model` 的 City DNA JSON，携带事件时间基准、声音事件和可恢复模型；菜单可继续最近一份 DNA。这仍不替代完整 City DNA 跨版本迁移/作品画廊。

### 表 R2b · 存档与回放实现合同

存档是版本化的 `WorldSnapshot`，不是若干数组的截图。至少保存：

| 类别 | 字段 |
|---|---|
| 版本 | `schema_version`、生成器版本、规格哈希、资产 manifest 哈希 |
| 随机 | 根 seed、五条命名子流计数器；试听/悬停不推进正式子流 |
| 世界 | 连续坐标、原始地形/排水信息、道路拓扑与几何、地块/建筑/社区稳定 ID |
| 玩家规划（已有切片） | `planning_reservations` 及留地/释放/用途转换事件，字段与旧档默认值见 [spec.proposal P10](spec.proposal.md#表-p10--留地与后续兑现)；纳入 WorldSnapshot、DNA 与后台结算副本，不能仅存 UI 轮廓 |
| 玩家街坊作者记录 | 作品级 `authorship={schema:1,next_neighborhood_id,neighborhoods}`，独立于 World；记录 `id/name/revision/member_ids/selection_kind:explicit_buildings/created_audio_frame/modified_audio_frame`。二进制存 `city.authorship`，DNA 以 `runtime.authorship` 恢复、顶层同名字段供阅读；旧档缺失为空，未知 schema 或无效字段拒绝。成员为已确认真实建筑稳定 ID，可跨 CID，不随出生/分裂扩张；编辑保留历史失效成员。字段详见 [19 §8.2/8.5](../19_城市生成管线.md#82-世界数据边界)，不证明精确范围听音或调音完成 |
| 渐进时代（待实施） | R10 的 `era_transition`、正式入代事件及城市乐句新锚点；当前正式时代与局部音色/外观进度分别保存，不按数组顺序重建传播 |
| 客流 | `transit_demand`及有序`transit_flow_pending`；生成器版本136，旧档缺观察队列按空恢复。归集时点见spec.city合同；后台任务句柄不进DNA |
| 决策 | 已接受事件、来源操作、请求音频帧、提交乐句帧、待提交 `WorldDelta` |
| 声音 | PCM 渲染游标、相位、交接节点和可回放 `AudioPlan` 引用 |
| 表现 | 镜头、移动体和当前可听快照所需的进度 |

稳定 ID 不得来自数组位置；坐标保存为数值，超出 JSON 安全整数的值保存为字符串。写盘顺序固定为：临时文件写入 → 关闭 → 回读并验证 schema/哈希/关键字段 → 保留上一份有效档 → 原子替换。替换失败不能损坏上一份有效档，损坏的临时文件保留供诊断。

回放按稳定事件 ID、`commit_frame` 和同版本随机子流重建同一模型；音频事件的字段、排序和“不得回写已渲染 PCM”规则见 [12 · 声音架构 §10](../12_声音架构.md)。旧格子档只能显式迁移或拒绝，不能直接当连续世界档读取。

### 2.1 五个时代（v4-ERA-01）

| # | 时代 | 副题 | 最快路径所在乐章 | 城市 | 新增的声音 | 可用音级（ERA-04） | 本时代的典型新张力 |

| Ⅴ | 现代 | 电与律动 → 光与合成 | 第 6–7 乐章 | 公寓、玻璃、公园、体育场 | 电钢琴、合成器、鼓机；摇摆→电子 | 不再新增；地标可局部改写协和观 | 大城的多声部交织；终章 |

为什么是五个、而且首尾各两乐章：七个乐章放五个时代，中间三个时代各一乐章（约 3.2 分钟，够听清一种新声音、做成 1–2 座地标）；第一个时代要承担序曲与上手，最后一个时代要承担高潮与终章，各给两乐章。时代再多，每个时代只剩一闪而过；再少，就失去"一部城市史"的跨度。

### 2.2 赢得的跨越（v4-ERA-02）

**规则**

- 每乐章固定 12 乐句：不提前结束，也不无限延长（建议同时作为 U08 的答案之一）。
- 乐章末结算终止式。跨越资格按表 R7 三路径任一 + 末乐句 R≥70；修复者同一无向边每乐章最多计1次。下表原修复者的半/阻碍终止对应其他路径的完整映射尚未定义（GAP-RUN），不私自改奖励。

| 终止式 | 条件 | 结果 |
|---|---|---|
| 完满终止 | 两条都满足 | 若本时代已满最短停留 → **跨越**；否则"辉煌"：本时代多揭示 1 座地标候选 |
| 半终止 | 只满足一条 | 不跨越；下一乐章为"悬"：该乐章首次协和解决计 2 次 |
| 阻碍终止 | 都不满足（且未崩盘） | 不跨越；下一乐章为"小调乐章"（关系小调色彩，§2.2.1）；若小调乐章以完满终止收尾 → **皮卡第跨越**：跨越并获得额外奖励 |

- 最短停留：时代Ⅰ 2 乐章，其余 1 乐章。
- 保底跨越：时代Ⅰ的第 3 个乐章末、时代Ⅱ–Ⅳ的第 2 个乐章末，若仍未跨越，则无论终止式如何都跨越（"平淡跨越"，无额外奖励，仪式照常）。即时代Ⅰ最长 3 乐章，Ⅱ–Ⅳ最长 2 乐章。
- 路径范围：最快 Ⅰ(1–2)→Ⅱ(3)→Ⅲ(4)→Ⅳ(5)→Ⅴ(6–7)，4 次跨越；最慢 Ⅰ(1–3)→Ⅱ(4–5)→Ⅲ(6–7)，2 次跨越。
- 第 7 乐章永远是终章，无论身处哪个时代。终章的终止式决定结尾：完满 = 圆满终章（全城齐奏）；半 = 开放结尾（停在属和弦上，"未完待续"）；阻碍 = 余音（落在小调）。三种结尾都要好听。
- 结算第一行是"本局抵达：××时代"——像 roguelike 的"到达层数"，是再来一局的直接理由。
- 第一个切片只做"完满 / 非完满"两档与保底；"悬"和小调乐章作为 **v4-ERA-02b** 随后加入。

**为什么这样设计**

- 跨越由玩家赢得；先让城市逐步发生变化，完成后的正式提示才确认“你做到了”，不在触发时用全屏卡片提前宣布。
- 失败不是死胡同：半终止给"差一点"的玩家一个加速；阻碍终止给低谷一个最动人的翻盘——从小调走向大调，是音乐里最古老的情绪弧线（对应《文明6》的英雄时代）。
- 保底保证每个玩家至少看到两次大跨越；技术好的玩家走得更远、看到更多时代。
- 不需要新的胜负条件：唯一的失败仍是既有的 R<40 连续 3 乐句崩盘。

#### 2.2.1 小调乐章（v4-ERA-02b 的一部分）

五声 C D E G A 与 A 小调五声 A C D E G 是同一组音，C 大调七声与 A 自然小调也同音。所以"小调乐章"不改任何街区音高、不改诊断：只把环境声床、装饰与终止式和声的中心移到 A，画面换到稍冷的薄暮色调。这正好符合美学规格"转调必须走共同和弦桥"——关系大小调本身就是最宽的共同和弦桥。

### 2.3 渐进时代过渡（v4-ERA-03，2026-10-10 用户更新）

跨越资格在乐章末按 R7 判定，随后进入“时代正在蔓延”的城中演出。首版时长、传播排序、建筑沉降/重生、正式入代与祝福时点统一取表 R10；旧16秒全屏庆典与开场时代卡已由本次用户要求替代，原文移到[旧规格归档](../../废弃/文档/2026-10-10_时代渐进过渡前/16秒过门与提前时代卡_旧规格.md)。

保持既有双时钟：音乐及与可听帧同步的过渡持续推进；城市结算、生长、崩盘累计、提案刷新和介入提交保持，旧乐章已经结算，不把过渡当作额外五个城市乐句。进入前已有 pending 按正常末边界先落定。镜头/聚焦/Solo/Mute/黑屏继续可用，不以全屏遮挡让玩家等待；新的建造与调音提交在正式入代后的祝福流程结束时恢复。

跨越中 `era` 仍表示已正式进入的旧时代；`era_transition.target_era` 表示将进入的时代，建筑的表现与音色按局部进度使用新旧混合。新音级、工具、地标候选与交通时代规则在过渡完成帧统一解锁，不能在听见第一个新音色时提前切整城规则。暂停/选择等待仍沿 ERA-09，昼夜相位不重置。

### 2.4 音阶随时代生长（v4-ERA-04）

| 时代 | 新增可用音级（释放/调音白名单，第三八度 MIDI） | 第一次出现的关系 | 玩家感受 |
|---|---|---|---|
| Ⅰ | C D E G A（48/50/52/55/57） | 大二「痒」、小三中性；三全音只来自工坊 F♯ | 五声怎么摆都不难听，入门友好 |
| Ⅱ | + F（53）、B（59） | 小二「抖」（E–F）、C–B 大七失谐（第三八度内 B 在 C 上方 11 个半音，基频差约 116 Hz，按表 U10 不算"抖"）、F–B「刺」 | 第一次在自然音里听到"抖" |
| Ⅲ | + F♯（54）、B♭（58） | 更多半音关系 | 调色变丰富 |
| Ⅳ | + C♯（49）、E♭（51）、G♯（56） | 十二音齐 | 专家区间 |
| Ⅴ | 不再新增；地标可局部改写协和观（如爵士"色彩音"） | — | 自由与复杂并存 |

- 表 B 协和分不变；调音仍须与至少一个邻居协和（PROPOSAL-001 规则不变）。
- 现行表 B/CITY-001 中"小二仅由叛离产生""三全音仅工业固有"是时代Ⅰ（五声）范围内的陈述；时代Ⅱ起按本表新增音级解释；时代规则已批准，不再等待重复裁定。
- 为什么：①新的张力有了稳定来源——现行 Demo 截图里 R 常在 99–100：自动生长只挑协和位置，孤立的工业没有邻接、不计入 R，诊断循环容易"断粮"；②难度曲线由历史自然给出：五声→七声→半音；③玩家可用的音越来越多，"创造和改变声音"的余地随时代变大；④五声在中国就是宫商角徵羽，这条主线与本作的五声核心天然契合（另见 §7 文化变体）。

### 2.5 时代来客（v4-ERA-05）

- 每次跨越，在新升起的土地上出现 2 处 "来客"街区，距当前城市边缘 2–3 地块（连续世界距离）；类型为住宅/商业（时代Ⅳ其中 1 处为工业）；时代Ⅱ–Ⅳ音级取本时代新增音，时代Ⅴ取已开放现代音级（Ⅴ无新增音）；位置与音级由 terrain 子流按种子与时代确定（可复现）。
- 来客就像 P0 的工业：不是坏，是新；把它们接纳进和声，就是新时代的第一道题。玩家可以迁移、调音、用街道隔开，或让城市长过去和它们相遇。
- 来客是完整街区（长音 + 律动 + 装饰），用本时代音色。

### 2.6 遗产与时代混音（v4-ERA-06）

- 普通建筑按 R10 的局部传播进度换成新时代外观与音色，不在跨越触发帧一起更换。
- 地标保持落成时代的外观与声部，成为遗产；详情卡注明"遗产·古典"等。
- 结果：一座有神殿和大教堂的现代城市，会在电子织体里同时听到古典合唱与中世纪钟声——用户要的"后期仍有古典、中期音乐与混合"由城市自己的历史实现，而不是菜单选项。
- 可选（P3）：时代Ⅲ"规划"（LMK-06）可把一个家族指定为"历史街区"，保留旧外观与旧音色。

**矩阵的四条硬约束**

1. **形状恒定，音色换代。** 连续（住宅长音）/分段（商业律动）/锯齿（工业）/包络拍频（失谐邻接）四种形状是游戏语言，每个时代都由该时代的乐器来扮演。**锯齿类音色只给工业族**；现代时代也不给住宅/商业用超级锯齿主音，否则"锯齿 = 需要处理"的诊断直觉会被冲淡。
2. **时代长音音色必须通过既有 A6 声学协议**（C3–C♯3 的 7.78 Hz 峰 ≥6 dB、C3–F♯3 无慢峰、协和 RMS 波动 <1.5 dB）。谐波更丰富的音色会在三全音上产生慢差频（事实核查：7×C3 与 5×F♯3 约差 9.3 Hz），所以时代音色的谐波权重有上限。律动与装饰层可以自由换乐器（可用已登记 CC0 采样库，具体乐器以包内实际清单为准）。
3. **渐强来自织体，不来自响度。** 一局越往后越丰富，靠的是声部密度、亮度、律动驱动与音域展开；−16 LUFS 初始校准、固定公共增益与真峰值余量规则不因时代改变（续作导航已指出 v3"音量天花板随时代升高"只是假设）。
4. **终章欣快而不刺耳。** 现代时代的高潮走旋律性电子：不用刺耳失真，侧链轻柔——宁神与生动同时成立。

**色板架构**（2026-10-09已按建议批准）：每个时代一套 24 槽基础色板；现行"4 时段 × 4 季节 = 16 张"改为作用在基础色板上的变换 LUT；R 连续轴照旧叠加。这会改变 spec.ui 表 U3 中"16 张表"的含义，本次全体裁定授权覆盖此具体架构，实际色值与变换曲线随切片制作。

### 2.9 双时钟语义（v4-ERA-09）

| 时钟 | 定义 | 能否保持 |
|---|---|---|
| 音乐时钟 | PCM 样本帧；游戏运行时永不停止；驱动全部声音与音乐同步画面（生长揭示、拍点动画） | 不保持 |
| 城市时钟 | 计乐句：R/V 结算、生长解析、崩盘计数、提案刷新、待提交介入落定 | 可在过门乐句、祝福选择、暂停时保持 |

- 保持期间音乐继续：时代过渡按 R10 的完整传播时间轴；选择等待时演奏"等候小节"（以当前城市长音为底、1 小节循环的织体），像乐队在等独唱者。长音持续，所以等待时诊断信息仍可听。
- 保持结束：城市乐句锚点在下一条小节线重设。拍与小节连续不跳，只有乐句起点按整小节平移。
- 暂停 = 延留：城市时钟保持，音乐退到柔和的等候小节（可选完全静音）。暂停中允许试听与查看条件，不允许落定（沿用 v3-U25e 的本意）。
- **不做 2× 倍速**：音乐即时钟，加速会改变音乐本身；16 秒乐句本已很短。
- 保持状态与乐句锚点进入快照；City DNA 以音乐帧记录锚点，回放可重现。
- 这一条同时回答续作导航对 v3-U25e 的质疑："不能只停画面/改墙钟 delta"。

### 2.10 祝福时点（v4-ERA-10）

- 祝福在每个乐章**开始**时选择，第 1 次在开局——一局 7 次，正好对应 7 个乐章（建议作为 U08"第 7 次祝福的用途"的答案）。

## 表 R7 · 三条跨越路径（取代表 R3 的单一条件）

**任一满足即可跨越**（三条**独立判定**，不得要求全满足）：

| 路径 | 条件 | 适合 |
|---|---|---|
| 修复者 | 本乐章 ≥3 次协和解决 + 末乐句 R ≥ 70 | 处理失谐的玩家 |
| 建造者 | 本乐章新增建筑数 ≥ **`max(6, ceil(0.04 × N))`**（N = 当前全城建筑数）+ 末乐句 R ≥ 70 | 和谐扩张的玩家 |
| 配器师 | 本乐章填上 ≥2 个**不同 ID** 的声景缺口 + 末乐句 R ≥ 70 | 做配器的玩家 |

**建造者阈值为什么随规模变化**：旧稿写死"≥6 栋"。在 9 栋的小城里 6 栋是 67% 增长；
在 600 栋的大城里 6 栋是 1%——**大城里这条路径变成白送**。`ceil(4% × N)` 使它在各规模下等价：

| N | 阈值 |
|---|---|
| 9–150 | 6 |
| 200 | 8 |
| 300 | 12 |
| 400 | 16 |
| 600 | 24 |

**防刷规则**：
- **修复者**：三全音的修复**不得默认计入**（限定音程集合沿 R7；新增时代中玩家也能主动选择形成三全音）
- **配器师**：缺口有**稳定 ID**，被填上后记录；**来回调音不得反复计入**
- **建造者**：只计新增建筑数，迁移与重建不计

**声景缺口判定**（见 `12_声音架构` / `spec.audio`）：低音缺失 / 节奏缺失 / 协和缺失 / 留白缺失 / 应答缺失。

| 机制 | 交响曲 | 自由共鸣 | 聆听 |
|---|---|---|---|
| 崩盘（R<40 连续 3 乐句） | **结束本乐章进程**（之后可转继续经营） | **不结束、不计数**。R<40 只触发灰噪化（可逆，R>48 退出） | 不结算 |
| 跨越条件（表 R7） | 有；第 7 乐章为终章 | **无乐章、无跨越压力**；时代由玩家主动推进（满足表 R7 任一路径后可选择跨越，不满足不催促） | 无 |
| 保底跨越 | 有（表 R6） | 不需要 | — |
| 锈蚀（`11_核心循环.md` §6.3） | 有（局部、可逆、慢） | 有（同左） | 不结算 |
| 介入槽 / 额度 | 有 | 有（同左） | 无操作 |

**交响曲的压力服务什么**：一局有起伏的**叙事弧**——七个乐章、跨越仪式、终止式（完满 / 半 / 阻碍 / 皮卡第）。
压力让"这一章收得好不好"有分量，让 22–35 分钟有开头、展开、高潮与终章。
**它不服务于"惩罚失误"**：崩盘只在 R<40 持续 3 个乐句（48 秒）后发生，且之后作品保留、可继续经营。

**自由共鸣的承诺**：玩家可以无压力地经营与试验，**没有任何机制会结束这座城**。
锈蚀与灰噪化仍在——它们是"声音变干"的反馈，不是失败。

验收（并入 RUN-G2）：自由共鸣模式下构造 R<40 连续 5 乐句 → 断言**未结束**、灰噪化生效、R>48 后退出。

反例：不得在自由共鸣模式下因崩盘结束游戏；不得在自由共鸣模式下用倒计时催促跨越。

## 表 R10 · 渐进时代过渡

状态：2026-10-10 用户批准方向；首版具体节拍方案已定，待实施与实听/实看。替代旧16秒过门、3小节扫城和提前宣布时代；当前整城4拍音色切片不是本表验收。

| 阶段 | 音乐与画面 | 时序 |
|---|---|---|
| 萌发 | 起点普通建筑先出现新时代音色；原城仍演奏，起点沉入地下，再长出新时代建筑。不开时代卡，不统一换全城色板 | 第0–2小节 |
| 蔓延 | 从起点向外，按稳定空间顺序在小节线上触发下一批建筑；旧城与新城并存，局部音色/外观/灯具逐步转代，道路铺装按相邻已转换建筑渐变 | 第2–38小节 |
| 收尾 | 最远建筑完成沉降、重生与音色交叉；整城环境与色板落定。地标/历史街区留作遗产 | 第38–40小节 |
| 正式入代 | 所有应转代对象完成后，才提交新时代规则并显示“正式进入××时代”；新候选/来客揭示，章首祝福沿原次数 | 满40小节的完成帧起 |

**时间权威**：120 BPM 下首版 `duration_bars=40`、总160拍，即80秒；是音乐过渡的5个乐句长度，不是增加5次城市结算。每栋 `cue_beats=1`、`sink_beats=2`、`rise_beats=4`、`settle_beats=1`，共2小节；到达拍先开始4拍音色交叉，下一拍开始沉降，音色先让玩家发现变化，随后旧屋入地、新屋长出。全部时点由可听音频绝对帧推导，不能用墙钟或若干独立 Tween 计时；不把80秒缩为整城同时慢淡化。首版节奏可按实听调整，但正文和测试同步更新，用户要求的一分多钟与先局部后整城保留。

**起点与空间传播**：默认取最早有效共鸣点对应的普通建筑；若该建筑为遗产/历史街区成员，则按距源点近→稳定ID选择最近可转代建筑，再无则从最早可转代建筑开始。起点只负责局部音色萌发，不能改变主音/MIDI。触发时冻结可转代对象名单与坐标；按到起点的欧氏距离归一化 `u=d/max_distance`，起点到达帧为0，其余对象到达小节 `2+floor(36*u)`（范围2–38），同距离按稳定ID排序。每栋有独立局部进度，不依赖镜头或屏幕距离，不因河流/孤岛/远端不连路而漏换；这是时代传播，不是声学耦合或道路传播。所有可转代对象都须在第40小节完成，只有一个对象时仍保留整段城市混合演奏与结尾时点；无可转代对象时演奏环境与既有遗产，不伪造新建筑。

**建筑与作品保护**：沉降/重生只替换表现资产与时代音色。地基锚点、占地、入口、ID、音级/相位、家族/社区、活力、阶段、主题来源、道路耦合与留地均保持；不删对象重建、不计算建造者新增。采用地面裁切让建筑沉入地下并在原地长出；路网与交通路径不消失。地标、明确保留的历史街区及其原音色不参加普通建筑换代，仍受全城昼夜亮度控制。

**声音与视觉的一致性**：每栋的旧/新音色进度进入路由/分组签名，不能用全局 `era` 一次改所有声部。未到达对象继续旧音色；已到达对象按真实位置和相位交叉，长音不中断，节奏/主题沿原音级与排程改演奏音色。新旧交叉声部合计仍受 A21/A26 的70个RenderVoice上限，固定公共增益/A6声学协议不变；超预算复用已批准的预算内合成/轮换，不临时翻倍。远景可合批绘制，但保留真实传播前沿和局部进度，不能把远景简化成全城一次换色。音色权重配方仍取 A17/各时代音源；旧A17的固定过门动机拍号只属历史切片。

**入代与等待**：累计满40小节且全部对象完成时，在可听播放游标到达完成帧时，以同一事件提交 `era=target_era`、新白名单/工具/候选/交通时代和正式通知，一次且可回放；PCM预渲染游标越过此帧不提前宣布或解锁。新土地与两处来客沿 R9/ERA-05 在此边界揭示。正式提示用短横幅与时代纹样、真实城声的收束，不卡全屏、不新增系统庆祝音。下一乐章祝福从此时出现；选择未结束则进入原等候小节，结束后在下一小节线开新城市乐句，仍是一局7次。过渡不占用下一乐章12句，也不改变最短停留、保底或终章；无跨越的章间不插此演出。

**快照与可访问性**：WorldSnapshot/DNA保存 `era_transition={from_era,target_era,start_audio_frame,duration_bars,origin_id,origin_position,ordered_members,arrival_bars,phase,completion_event_id}`；每栋音色/资产进度由同一时间轴恢复，保存/加载不得从头重播或提前宣布，完成事件防止重复解锁/发祝福。音乐绝对帧与入代后的新城市乐句锚点分别保存。旧档无过渡字段表示未在过渡中。减弱运动采用相同传播顺序、相同时长的原地交叉，取消沉降/重生与自动运镜；B黑屏只隐藏画面/通知，声音与入代时点一致。可手动接管镜头，返回城市不重置传播；不自动追逐每栋建筑。

验收归 P2任务6 / RUN-006：新增 `era_spread` case（待实现），核对起点/中途/最远点到达顺序、同帧新旧并存、最后音色/重生收尾及唯一正式入代；快照中途往返和B黑屏/减弱运动结果一致；至少覆盖小城与动态大城，70声部交叉不超预算、真实供音无下溢。真人看/听同一段，能先发现局部变化、跟随蔓延、在最终提示时确认入代；老的16秒PASS与整城4拍交叉都不覆盖。
