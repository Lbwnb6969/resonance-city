# 现有 Demo 快速开始

本指南描述当前代码，不宣称新文档中的墙格/拉路工具已经实现。新版实现差距见 [PROJECT](../PROJECT.md)。

## 运行

双击根目录 `启动Demo.cmd` 打开隔离的新古典河湾。Godot 正常 F5/作品入口继续保存；主场景为 `scenes/continuous_valley.tscn`。独立 ZIP 使用打包时版本，画面和操作以包内说明为准。

当前默认 24 栋年轻房屋、三片背景街段，已有暖石/陶瓦四向资产、橄榄/柏、石街、文化馆、夜光、地表细节和联合屋顶。仍包含旧章程/声音选择和自然成长流程；改文档不会改变它。

## 常用操作

| 操作 | 当前代码行为 |
|---|---|
| 滚轮、中键拖动 | 缩放与移动镜头 |
| P | 旧规划引导：章程→卡牌→范围→公共建筑/留地→声音 |
| 点击作者房屋 | 改音/下一段/留地/命名入口；普通房屋保留旧菜单 |
| K | 逐栋选择并命名街坊，可跨内部 CID，确认后保存 |
| C | 旧规划分组辅助；独听作用于内部 CID，不是任意选房范围 |
| Tab/M/F/H/B | 地图状态的独听/静音/聚焦/全景/黑屏；面板状态由原生焦点优先处理 |
| Ctrl+S、F9 | 保存作品、读取最新作品 |
| Shift+R | 先保存再开始隔离新局 |
| Ctrl+Shift+E | 导出可读 City DNA |

命名不会自动加入同 CID、新生或共墙房屋。输入名字时城市字母快捷键隔离；Esc/地图右键先收起当前草稿/面板。

## 其他已有入口

公共空间可比较不建/留地/公园/文化馆，支持局部兑现、搬迁和原位改用。G 为当前合法桥位；公交沿真实路网选择站点。N/T/Y/E/Shift+E 有空城、地形和大城样例入口。它们属于已实现功能，迁移时保留数据与接口。

完整旧操作、测试数量和截图路径留在 [迁移前 Demo 说明](../废弃/文档/2026-10-14_综合优化前/文档/Demo快速开始.md)。新的点击社区扩展、自由拉路、区域/植被画笔和视野声场以新切片验收为准。

## 现有公共/交通流程速查

下面只描述旧代码已有功能，迁移时保留对象和作品格式，不能把其乐句等待套在新版墙格工具上。

| 功能 | 当前操作/边界 |
|---|---|
| 首段表达 | 深流/织机/暖庭点击听同源四秒；停止/再听或 Space 保留，Enter 才提交 |
| 公共空间比较 | Space 听不建/留地/公园/文化馆三秒；改位置/城市或关闭使旧比较失效 |
| 自由留地 | 左键至少三点，Backspace 撤点，Enter 提交，Esc/右键取消草稿 |
| 分块/内院 | Tab 收束组件或外环后继续画；组件/孔洞必须合法，剩余留地可继续规划 |
| 公建设施 | 点击后搬迁/原位改用；保留 ID/等级，同用途不自动升级 |
| 公交线路 | 至少两站，Backspace 撤站，Space 试听，Enter 排队；共享站换乘 |
| 作者线改站 | 点击站点“改站 · 线路名”，重画至少两站；同线保留只撤关联待播编辑 |
| 地形样例 | N空城，T多社区，Y五地形，E扩展城，Shift+E现代大城；不代表新工具完成 |
| 美术对照 | 根 `启动美术对照.cmd` 展示同源城市多套风格；仍是候选，正常编辑可用 |

当前时代地标仍使用两乐句条件与 Enter 确认，建设仍有旧音乐排程。这些是待迁移行为。实际可听帧的夜光、公共活动、作者回访与保存继续可复用；旧短窗技术成绩与用户最终审美分别记录。
