## 当前目标

把《共鸣之城》做成一座**会演奏的城市**：玩家在地形上播种声音，城市按和声长成几十个社区的大城，听起来是一支乐队。

用户 2026-10-09 的六条硬要求（全部已在文档中落地）：

1. **去格子**，更柔和偏直觉的放置 → [世界模型](文档/10_世界模型.md)
2. **极简 UI**，信息只在悬停时出现 → [界面与反馈](文档/16_界面与反馈.md)
3. **视听正反馈**，每一步都有即时奖励 → [界面与反馈](文档/16_界面与反馈.md) §4
4. **声音与城市深度结合** → [声音架构](文档/12_声音架构.md)
5. **大城市规模**（几十个社区） → [城市规模](文档/18_城市规模.md)
6. **自然地形**（山/海/湖/河） → [地形与自然](文档/13_地形与自然.md)

**价值排序**：好玩易玩 > 视听正反馈 > 视觉效果好 > 新意。

## 七项核心改动（相对旧设计）

1. **格子 → 连续空间**：耦合系数 `c = A(距离)×O(遮挡)×T(地形)×I(工业)` 取代 `w = 1+0.15(n−1)`
2. **27 上限 → 声部组**：建筑无上限；同时发声封顶 70（`{社区, 音级, 阶段}` 合并）
3. **诊断驱动 → 配器驱动**：缺口系统取代"修失谐"；三路径跨越取代单一条件
4. **地形从名词 → 一等系统**：山海湖河林影响声学耦合
5. **常驻面板 → 近乎全空**：悬停出卡 + 环形菜单 + 节拍条
6. **单模式 → 三模式**：交响曲 / 自由共鸣 / 聆听；结束可继续经营
7. **撒点 → 六层管线**：地形→骨架→社区→街坊→地块→建筑
