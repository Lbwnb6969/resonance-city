# P0真人听测

协议锁定在`01_执行规格/spec.audio.md` A11。这里是操作说明；当前没有真人成绩，自动验证不算听觉通过。

1. 在Godot按F5，点击“正式黑屏听测（6练习 + 10正式）”。填写测试者编号、实际设备型号/连接方式，选择“耳机标准”或“内置扬声器标准”。正式组辅助OFF；整个组保持音量，关闭系统通知等会发声的软件。
2. 每题8秒播放时屏幕全黑、鼠标隐藏，不重放或solo。声音结束后选左/中/右，再选抖/刺，提交两项答案。练习有正确反馈；正式题只记录、直到本组完成。
3. 每个设备条件分别找3人，每人完成6练习+10正式。窄带辅助ON是单独补充组，不能混入标准组。Esc会中止，缺题不能通过。
4. 会话结束页面显示CSV绝对路径；Windows默认位置是`C:/Users/Administrator/AppData/Roaming/Godot/app_userdata/共鸣之城/人测结果/`。同一条件的3份完整真人CSV用下面命令统计；方位和类型同时对才计1，每人至少7/10，不用三人总分替代。

```powershell
python tools/grade_listening.py '第一份真人.csv' '第二份真人.csv' '第三份真人.csv' --condition headphones_standard --output '验证记录/P0/耳机统计.json'
# 内置扬声器改用 --condition speaker_standard；窄带补充改用 speaker_narrowband
```

统计器核对锁定的种子/布局、完整练习与正式题、每题无下溢、辅助与设备条件、来源human；automation、重复会话、混条件与缺答会被拒绝。不能改自动记录的来源来填人测，也不能凭听测工具PASS宣布HUMAN-AUDIO或HUMAN-SPEAKER通过。

已完成技术检查：固定9街区声部/唯一失谐声部、10正式题抖刺各5/方位4-3-3、176400帧每题、standard辅助OFF、实际窗口1440×900每个RGB像素均0、隐藏鼠标。题库文件`数据/listening_fixtures.json`含真值，仅供执行人/统计工具；测试者答题前不要查看。
