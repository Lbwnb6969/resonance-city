## 0. 一句话

**你在一片地形上播下声音的种子。城市按和声长出来，长成一座会演奏的城。**

玩家不是逐栋摆房子的建筑师，而是**城市规划者兼指挥者**。城市自己长，但玩家决定社区如何组织、关键公共建筑放在哪里，再用播种、音级与调音决定这座城怎样发声。

---

## 1. 定位

**听见城市 → 想这里该成为什么 → 选有表达差异的候选 → 播种或调音 → 听见选择的结果 → 发现新的创作机会。** 缺口是其中一种机会，不能变成必须处理的任务。

这不是"修复失谐"的游戏，是**"补齐配器"**的游戏。失谐只是缺口的一种。

> 反支柱对照：旧定位是"城市先响着，你听出哪里不对，然后作一次介入"。新定位是"城市先响着，你听出**少了什么**，然后给它加上"。前者是维修，后者是创作。这个转变是本次重构的核心。

## 2. 核心支柱

### 支柱 A · 声音即地形
**地形本身就是声学结构。** 水面与山脊阻断规则耦合，林地吸高频，平原通透。把工业放在河对岸会改变规则关系与编曲组织；两岸仍可同时发声，不能由 `O=0` 推出真实混音中没有拍频（见 A25）。

配套：城市的每一栋建筑都是一个发声体，它的音级写在它的位置上，位置写在它的声音里。

### 支柱 B · 配器即玩法
城市演奏时**会缺东西**——缺低音、缺节奏、缺一个五度、缺一段留白。缺口不是错误提示，是**邀请**。玩家的工作是判断"这里该放什么"，而不是"这里哪里错了"。

反例（明确不做）：不投放噪声逼玩家维修；不用倒计时逼玩家处理。

### 支柱 C · 生长即谱写
城市与音乐来自**同一组事件**。你播下 C，后代属于音级 C 的源点家族；你在河对岸播下 G，两岸在满足 T3-a 的距离、协和与来源条件后可形成五度对唱。城市形态与音乐结构是同一个东西的两面。

City DNA 的目标是完整复现形态和声音；当前恢复范围与尚未验证的跨版本重渲染见 PROJECT，不把可继续的存档等同于完整重渲染证明。

### 支柱 D · 大城即乐队
大城阶段切片有 **36–48 个初始规划社区**、400–600 栋建筑；后期目标为 **3,000–5,000 栋**，社区随成长分裂（见 `18_城市规模.md`）。它听起来**不是 600 条音轨在吵**，而是一支乐队：**只有少数声部同时唱旋律，其余是垫、是脉动、是留白**。规模靠组织，不靠削减。

**规模按四个验证层次推进。** 小景先验证选择因果，大城验证组织与性能；独立工程可继续扩展，未通过真人验证的层次不得宣称玩法已成立：

| 阶段 | 规模 | 验证什么 |
|---|---|---|
| 核心切片 | 20–30 栋、≥3 个可辨认区域 | **完整因果链** + 两条值得选的路线 |
| 中型验证 | 80–150 栋、8–14 社区 | 多社区轮换/应答、音乐角色分配 |
| 大城切片 | 400–600 栋、36–48 初始规划社区 | 大城音乐组织与实时供音 |
| 后期目标 | 3,000–5,000 栋、社区随成长分裂 | 分尺度城市表现与持续音乐创作 |

**每个阶段必须说明"新增了什么真实玩法"**，不能只有数字增长（见 `18_城市规模.md` §5.1）。

**涌现不是新系统，是既有规则的组合**（2026-10-10 裁定）：
本方现有的材料（地形、社区、音级、用途、编曲槽）足以产生组合，
缺的是**让组合成立的空间**。四条回路见 `10_世界模型.md` §9。
**扩大组合关系先于扩大目录**——不靠加牌组、加地形族、加模式来换新鲜感。

### 支柱 E · 柔和直觉
**没有格子。** 你在连续的地形上放置，系统给你柔和的落点吸附。所有操作都有即时的手感反馈：音高滑动、地面涟漪、色温呼吸。

界面默认几乎是空的——城市和节拍。信息在你把鼠标移上去的时候才出现。

### 支柱 F · 长到一起
**房子会长到一起。** 相邻的、沿同一条街的房子自动共享山墙、屋顶连成一片、围合出庭院——
一座城市应该读作**一片连续的建筑**，不是一堆各自为政的方块。

**但"长到一起"只发生在眼睛看见的层面。** 每一栋仍然是独立的一栋：独立的音级、独立的 ID、独立的一票。
共享山墙不会把两个音合成一个音，也不会让两栋变成一个数值单位。

**玩家在哪里落点，决定它会长成什么。** 任意合法陆地都能点；沿街的位置能升级，空地按每 2 乐句最多出生 1 栋、阶段最多到群的规则慢生长。
系统不拒绝你，只是让位置自己说话（见 `01_执行规格/spec.fabric.md` 表 FB1/FB2）。

**这是"好看"的主要引擎**：留白与对比靠地形与不建的地方，层次与城市感靠连片。

### 支柱 G · 时间是第二种地形

地形决定城市**在哪里响**，时间决定它**在何时呼吸**。昼夜不是一层装饰滤镜，也不是逼玩家赶工的倒计时；它让同一座城在一局里经历天空、影子、窗光、树木、行人和环境声床的连续变化。

- 第一阶段先做**昼夜**：从音频绝对帧派生连续的晨光、白昼、黄昏和夜间。它改变表现与环境层，不改变落点、R/V、成长候选、音级、交通拓扑、随机流或跨越条件。
- 后期再做**季节**：把自然的色彩、树冠、地面细节、微动效和环境声床拉到更慢的时间尺度。季节不把本作变成生存或经济模拟，也不收回玩家已经建成的城市。
- 时间必须让旧社区更有历史感，让新声部更有出场时刻；**城市结构仍由玩家选择，时间只让选择被看见、被听见**。

第一版设计参数见 `17_美术规格.md` §7.1–§7.2；声音边界见 `12_声音架构.md` §6.1。先用昼夜验证动态基调，再引入季节，避免同时增加两条难以辨认的变化来源。

## 3. 反支柱（明确不做）

1. **玩家不自由输入音符，不直接作曲。** 音级来自系统给定的音阶集合，且必须与周围形成可听关系。
2. **不做格子、不做 tile 摆放。** 建筑位置在连续空间。
3. **不做完整交通与经济模拟。** 保留真实道路、轻量站点/换乘/容量、目的地与需求反馈；它们参与城市成长和既有音乐角色，不引入完整经济系统。
4. **不做数值碾压。** 元进程只解锁可能性（音源、形态、地形、图鉴），不给永久"R+2"。
5. **不用系统提示音。** 所有 UI 反馈音都是当前调式内的乐器音。
6. **不使用写实渲染、霓虹高饱和、夸张喜剧动效。**
7. **失谐不扭曲几何。** 只用色温偏移、对比微变、阴影变硬、微动效熄灭。
8. **不为"看着热闹"堆常驻 UI。** 信息按需出现。
9. **任意合法陆地都可落点。** 水面、陡坡、重叠占地、保留地和成路仍按合法性拒绝；合法空地上也允许建（长不好是后果，不是错误提示）。

## 4. 体验目标（三个词，可测试）

| 词 | 测试 |
|---|---|
| **宁神** | 截任何一帧：色相 ≤3 族、对比柔和、无高频闪烁；放置 30 秒画面仍在缓慢呼吸 |
| **生动** | 任意 10 秒窗口 ≥5 处微小运动；每社区 ≥3 个循环微动效（锁 BPM 整数分频）；城市状态变化全部有视觉对应 |
| **丝滑** | 任何可见变化经过缓动；P0普通视角稳定 60fps；3,000–5,000 栋后期目标为 120fps 及以上（见 `18_城市规模.md` §6） |

**声音总标准**：任意时刻录 30 秒音频，盲听像一段**作品**，不像游戏音效在循环播放。

## 5. 与旧设计的关键改变

| 项 | 旧设计 | 新设计 | 理由 |
|---|---|---|---|
| 空间 | 16–32 格棋盘，一格一栋，四向共享边 | **连续地形，浮点坐标，距离核耦合** | 用户要求去格子；且地形必须是空间连续体 |
| 邻接权重 | `w = 1 + 0.15×(n−1)`，n = 共享边界格数 | `c = A(距离)×O(遮挡)×T(地形)×I(工业)×M(音乐性)` | 无格子可用；且让地形真正影响声学 |
| 实体上限 | 27 声音实体，到顶停长 | **建筑无上限；实际合成声部封顶 70**（含背景 drone、环境、装饰与交叉） | 27 是"一栋一声部"的产物；按声部组承载后可放开 |
| 邻居计数 | 四向共享边，典型 4–9 个邻居 | **全对集合 `E`（R/V 用）与近邻集合 `N₁₂`（生长/阶段/碴用）** | 密集区实测可达 108 个 `c>0` 邻居，混用会让密集区整体冻结 |
| 社区身份 | 同家族声学连通群 | **稳定规划社区**（ID 不随音级/成熟变化）+ 家族 + 每乐句重算的音乐簇 | 三者服务不同目的，混用会让"社区"指代不清 |
| 核心循环 | 听 → solo/mute 定位 → 判断张力 → 介入 → 再听 | **听 → 想这里该成为什么 → 选有表达差异的候选 → 播下 → 听见它变** | 从维修转向创作 |
| 跨章条件 | 修够 3 条指定失谐边 + R≥70 | **三条路径任一**：修复者 / 建造者 / 配器师 | 奖励建设，不只奖励修理 |
| 多样性 | 靠停谐最优被"不好听"劝阻 | **音乐性权重 `M`**：同音占据率 >40% 时邻接ΔV减半；降回 ≤40% 即恢复，R全同音仍100 | 直接、可计算、不惩罚 |
| 失谐后果 | 全城 R<40 崩盘 | **局部锈蚀簇 + 交响曲模式全城 R 崩盘双轨** | 全城平均仍会稀释局部问题，局部状态须单独呈现 |
| **落点**（新） | 生长硬锁在临街地块；空地不可建 | **任意合法陆地可点，L1/L2/L3 由后果分层**（沿街长大、空地孤屋） | 用户要求"能随便造房子"；且拒绝落点是手感杀手 |
| **建筑形态**（新） | 无任何形态关系规则，建筑是独立方块 | **有机连片**：共享山墙 / 连排 / 围合庭院，街道读作一片 | 用户要求"房子长到一起变成社区"；此前只有听感关系与行政关系 |
| 地形 | 名词级提及 | **山/海/湖/河/林/平原为一等系统**；规则层（耦合）与声学层（延迟/滤波）分开 | 用户要求；且"规则上无关"≠"听不见" |
| UI | 常驻右栏 31% 宽 + 底部条件卡 | **默认近乎全空；悬停出卡；单推荐焦点** | 用户要求 |
| 时序 | 一切真实变化等 16 秒乐句边界 | **分层落定**：输入即时 / 声音等 1 拍 / 结构等 16 秒 / 时代从局部音色与建筑重生逐步蔓延，完成后才正式提示（首版节拍见 R10） | 不能让每次调音都变成 16 秒等待；时代长演出不延长普通调音 |
| 章节 | 固定 7 乐章 @16 秒乐句 | 保留（22–35 分钟中城），新增**自由共鸣长局**达到大城 | 大城需要时间 |

## 6. 必然保留的已批准资产

以下是被反复验证、且不依赖格子模型的资产，**原样继承**：

- **表 B 协和分**：同度/八度 s=1.00 ΔV+8；纯五/纯四 0.90 +5；大三/大六 0.85 +5；小三/小六 0.60 0；大二/小七 0.30 −3；小二/大七 0.05 −8；三全音 0.00 −8。
- **三层声部**：drone（持续，承载和声与拍频）/ 律动（身份与节奏）/ 装饰（偶发彩蛋）。
- **音乐时钟为主**：120 BPM、4/4、小节 2 秒、乐句 8 小节 16 秒。视觉与音乐同步必须用音频帧，不用 Tween 秒数。
- **混音标准**：−16 LUFS 基准、真峰值余量 3 dB、drone RMS ≥ 总混音 25%、equal-power 交叉 2–4 拍。
- **声学测量协议**：小二 7.78±0.5 Hz 峰 ≥6 dB；三全音 3–16 Hz 无慢峰；协和包络波动 <1.5 dB。
- **五时代与音阶生长**：Ⅰ C D E G A → Ⅱ +F,B → Ⅲ +F♯,B♭ → Ⅳ +C♯,E♭,G♯ → Ⅴ 不新增。
- **失谐的视觉表达**：不扭曲几何。
- **无后端**：种子、每日一城、回放全部本地。

## 9. 城市规划与音乐的统一（2026-10-10）

本作的玩家身份由两个互补层组成：

- **规划者**：为一片社区选择发展章程，决定公共设施、交通节点、公园和重要建筑的位置，给自动生长留下方向。
- **指挥者**：从实际长出的城市中选择音级、调音、聚焦和编曲关系，让空间结果成为可听的作品。

这不等于逐栋摆房子。普通建筑仍由连续空间生长规则自动生成；玩家控制的是区域意图与关键锚点。规划章程不锁死建筑用途，深流/织机等声音路线也不替代规划章程。

三种首批规划章程：

| 章程 | 自动生长的倾向 | 主要取舍 |
|---|---|---|
| **紧凑核心** | 围绕公共设施和主街形成连续街坊 | 更快形成中心，也更快产生密度与设施容量压力 |
| **走廊连接** | 沿道路、桥头和交通节点形成多个社区 | 需要提前安排连接顺序，桥和节点的机会成本更高 |
| **蓝绿文化网络** | 保留公园、庭院、绿廊和文化节点，让建筑围绕公共空间生长 | 可建面积和成长速度降低，但获得留白与主题轮换空间 |

关键建筑的关系不是万能范围加分，而是改变后续的合法机会、服务分配、容量压力、角色资格、留白和声音组织。规划影响不直接改写 c/R/V；声学耦合仍服从 spec.space，服务仍服从真实道路，编曲仍服从 spec.audio 的角色槽与70声部预算。

随机卡牌沿用章首祝福/奖励窗口，改变一个已存在的规划关系或其持续时间。卡牌不提供基础设施，不以全城固定加分取代布局判断。城市战略来自集中与分散、现在兑现与留地、设施容量与中心数量、关系重叠与角色槽竞争、当前时代与历史保留之间的取舍。

首个完整验证场景应包含同一河谷、两个社区、一座文化设施、一块公园候选地和一个桥位。比较不同章程、锚点位置和声音路线，记录普通成长、服务覆盖、社区形态、角色分配、30秒盲听和下一步机会。

## 10. 从严密工程到极致心流

外部评审提出了一个有价值的方向：工程规则应当保护表达，而不是让玩家先理解防御机制。这里吸收方向，不照搬附件中的固定数值和新系统。

现行心流收束为：听见空间韵律 → 选择表达意图 → 立即看到可撤回的预影与关系 → 在最近拍点听见声音变化 → 在乐句边界看到结构落成 → 观察街坊、地标或声部关系继续生长。

已吸收的设计原则：

- 视觉预影和轻量声音反馈必须快速回应输入；结构、R/V、道路和存档仍按现行提交边界落定。
- 连片预览要让玩家预感共享山墙、街墙、庭院和地形高差的结果，但预影不能冒充已建对象。
