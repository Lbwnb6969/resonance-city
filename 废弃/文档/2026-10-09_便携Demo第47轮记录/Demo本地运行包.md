# Demo本地运行包

第47轮提供本地Windows x86_64可携带版本：解压`交付/共鸣之城Demo_2026-10-09_轮47.zip`，双击其中的`启动Demo.cmd`。同目录另有风格小景与古典小景启动器。约94 MB压缩包，保持`运行环境`文件夹完整；启动器只使用相对路径，不需要安装Godot或复制开发工程。

本机未安装导出模板，因此这版附带现有Godot 4.7.2二进制与实际导出的资源ZIP；明确作为本地体验包，不称模板生成的正式发行EXE。没有上传、公开发布或安装新引擎。

资源包排除原素材、生产库、工具、测试、文档、验证记录与MCP插件。44件清单纹理逐件比对源文件和实际导入ctex SHA；Demo、风格小景与古典SVG均使用当前资源。许可目录保留Godot MIT、该引擎实际第三方许可/版权数据、四包CC0原许可及项目原创说明；引擎许可不等于整个游戏的许可。

重建在项目根目录运行，输出和证据目录必须是尚不存在的新目录，旧包不会被覆盖：

```powershell
python tools/build_demo_bundle.py --engine 'D:/GODOT/Godot_v4.7.2-stable_win64.exe' --output '交付/共鸣之城Demo_新版本' --evidence '验证记录/Demo/运行包_新版本'
```

构建器会导出资源、检查SHA与排除项、复制引擎、运行空目录隔离检查、直接启动真实主入口和风格入口、收集许可，再生成压缩包。运行检查脚本是包外测试工具，不进入游戏包；相同引擎从空目录只挂载资源ZIP。构建记录登记源基线提交、实际输入与脚本SHA，避免把工作区构建误标为旧提交的纯净产物。

本轮11项隔离检查通过，包含实际主场景、音频singleton、最新工具、释放落定/显示生长、聚焦只读和古典小景；直接主入口及风格入口成功。两张运行包GPU图已查看。采用Dummy与有限模拟边界，不代替用户之后组织的真人听测或长期压力。正常主入口用`--quit-after`强制结束时出现1个AudioStreamGeneratorPlayback退出残留警告；verbose日志已定位并记录，没有当成无警告退出或完整发行验收。

启动器沿用当前应用名称，因此`user://`听测结果与同机开发版共用应用数据位置，不迁移或删除旧结果。玩法仍是已批准的生长Demo；历史建筑只是独立小景候选，时代音乐及自动成形卡片没有在打包时新增。
