# 共鸣之城 · 当前设计裁定（2026-10-13）

本文是旧版详细规格之上的统一裁定。旧文档的公式、数据字段、验收命令和历史验证继续保留；遇到与本文冲突的玩法、美术或空间表述，以本文为准。实现尚未完成的内容必须标为目标，不得把旧验证记录当成新方向已完成。

## 1. 核心体验

玩家在连续自然地形上塑造城市的形状和气质。玩家表达大形状，系统补齐小细节：道路、特殊建筑、功能区和植被使用连续空间；点击社区房子后，房屋墙面、屋顶、门洞和露台使用一个只存在于该房屋内部的局部格子生成器。

城市不会因为时间流逝、人口或后台模拟自动扩张。玩家确认一次意图后，系统可以用短暂的生长演出生成细节，但不会替玩家做下一次规划决定。

## 2. 双层空间裁定

### 2.1 房屋局部层：Townscaper 式

点击一栋已有社区房子或房屋小组，进入房屋编辑焦点。生成器在房屋外轮廓上建立不规则四边形格；格子只服务于墙体、屋顶、露台、庭院边和门洞的邻接组合，不铺到城市地面，也不作为道路、声音、功能区或全局存档的占用表。

玩家点击相邻边、角或上层锚点表达“向这里长”。系统按邻接标签补齐墙段、转角、檐口、门洞、柱、支撑、屋顶和露台。围合空间优先成为庭院或露台；路径穿过房屋优先形成门洞；抬高局部优先补支撑和台阶。大形状可预测，小装饰在固定种子内变化。首个切片局部逻辑格上限为 12×12，超出时分片。

### 2.2 城市连续层：Tiny Glade 式

道路使用连续样条；桥、特殊建筑使用占地轮廓、朝向和入口意图；功能区使用画笔、中心点或闭合轮廓形成权重场；植被使用地形、遮挡和密度散布。它们不吸附到房屋局部格，也不为“对齐”而把道路拉直。

道路可以在建筑旁生成入口、台阶或矮墙；特殊建筑可以根据道路和地形自动补台基、柱廊、平台和灯光；功能区改变材质、装饰、生成权重和声音风格，不自动生成任务或人口；植被避让道路、入口、房屋占地和确认的公共空间。

### 2.3 关系与身份

房屋局部格的身份与城市连续坐标分开保存。真实几何关系可以触发共享檐口、连排屋顶、庭院或入口，但视觉联合不合并建筑 ID、音级、阶段或玩家作者记录。任何系统都不得把局部格索引当作全城邻接、道路节点或声音分组依据。

## 3. 玩家循环与社区生长

现行循环是：**观察 → 表达意图 → 可撤回预览 → 确认 → 分段生成 → 视觉/声音反馈 → 撤销或继续**。

“社区自己长”只表示玩家点中房屋并确认扩展后，房屋局部会自动补齐墙、露台、门洞和装饰；它不表示社区在无人操作时自动增殖。道路、功能区、特殊建筑和植被同样遵循“玩家先画/放，系统后补细节”。

预览不写 World、存档、正式随机流或永久音频；确认写入带稳定 ID 的操作记录；撤销按操作记录回滚；过期后台结果丢弃，不能覆盖新操作。

## 4. 声音裁定

声音不参与资源循环、胜负、任务门槛或建筑合法性。关闭声音后，玩家仍能完成所有玩法。声音的作用是空间提示、操作确认、氛围和正反馈。

- 主要播放视野内城市：道路、房屋、功能区和自然以低密度环境层、短动机和拟音回应。
- 每个乐句只允许少量远处偶发回应，不能抢走当前操作焦点。
- 新区域完成、地标落成、昼夜切换或玩家主动请求时，暂时提升为全城合奏，随后回到局部声场。
- 空地、未确认预览和玩家静音区域保留留白。
- 玩家可以把区域加入同一音乐网络，也可以为不同区域指定不同音乐风格。连接改变调性、音色、节奏密度和过渡，不改变几何合法性；连接可试听、保存、撤销。

旧规格中关于拍频、声部合并、音频帧和 PCM 的合同仍然有效，但它们是实现与诊断工具，不再把“修复失谐”当作玩家主循环，也不允许以音频正确率阻止建造。

## 5. 美术与性能裁定

风格目标是 Tiny Glade 的暖、软、自动补细节，加上纪念碑谷的简化几何、清楚轮廓、有限色板和模型盒构图。使用自己的古典童话城市资产，不复制参考游戏素材或源码。

优先级：美术辨识度 > 操作直接性 > 生成稳定性 > 音乐丰富度 > 城市数量。

第一切片性能起点：60 FPS；主线程生成预算 ≤2 ms/帧；近景详细实例 ≤300；可见植被实例 ≤2,000；活跃音乐声部目标 ≤32；单房屋局部逻辑格最多 12×12。任何扩大上限的改动都必须附带同场景帧时间、生成延迟、内存和声部数量对比。

## 6. 实施优先级

1. 先完成一栋房屋的局部格子生成：墙、门洞、屋顶、露台、撤销。
2. 再完成连续样条道路、一个特殊建筑、一个功能区画笔和一簇植被。
3. 接入视野内/远处/全城三档声音反馈和区域音乐连接。
4. 用旧规格的存档、音频、地形和性能合同验证新切片；旧合同与本裁定冲突时，玩法语义以本裁定为准，数值和数据完整性合同继续保留。
