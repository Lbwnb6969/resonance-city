# 01 · 世界模型：空间、距离与声学耦合

> 2026-10-09 重构版。本文定义**取代格子模型**的新地基。这是整个重构最重要的一份文档——它决定了玩法、声音、地形、规模能否同时成立。
> 数值权威在 `01_执行规格/spec.space.md`；本文解释为什么这样设计。

---

## 1. 为什么要去掉格子

旧设计的全部空间逻辑建立在一句话上：**"四向共享边是邻接权重的物理基础"**（旧 v2 §9 明确把"无网格建造"列为不吸收）。

后果是三重的：

1. **操作上**：玩家点格子，格子吸附，一栋一格。这天然是"摆棋子"，不是"经营一片土地"。
2. **声音上**：两个街区的关系由"是否共享一条边"和"共享几条边"决定。于是几何上隔着一条街、实际只隔 5 米的两栋房子，声学上完全没有关系——**耳朵听到的拍频和系统计算的 R 脱节**（旧问题单 Q06）。
3. **地形上**：山海湖河无法存在。河要么是"不可通行的格子"，要么不存在。

用户要求"更柔和、更偏直觉、不要分格子"，这不是美术偏好，是在要求**把地基换成连续空间**。

## 2. 核心设计：距离核耦合

### 2.1 建筑是点，不是格子

每栋建筑有**连续的浮点位置** `(x, y)`，单位是"地块"（1.0 地块 ≈ 旧设计里 1 格的长度，用于兼容既有资产尺度）。

- 建筑有**占地半径** `r`（普通民居 ≈ 0.45，大型公共建筑按占地尺寸）。
- 建筑有**高度** `h`（影响遮挡与视觉，见 §4）。
- 建筑有**朝向** ψ（影响遮挡扇区，可选，P1）。

**不存在格。** 不存在"这格被占用"。存在的是"这个位置与最近的建筑距离 0.82 地块，可以放"。

### 2.2 耦合强度取代共享边计数

旧公式：`w = 1 + 0.15×(n−1)`，n = 共享边界格数，封顶 2.0。

新公式：两个建筑 i、j 之间的**耦合系数**

```
c(i,j) = A(d) × O(i,j) × T(i,j) × I(i,j) × M(i,j)        c ≥ 0
```

乘算顺序是规格的一部分：`A`（自身封顶 2.0）→ `O` → `T` → `I`（工业 1.3）→ `M`（音乐性，见表 SP4）。

- **距离衰减 A(d)**：`d` = 两建筑中心的距离（减去各自占地半径）。
  - `d ≤ 0`（贴在一起）：`A = 2.0`（对齐旧公式封顶）
  - `A(d) = 2.0 × exp(−(d / σ)²)`，`σ = 1.8` 地块
  - `d > 4.0`：`A = 0`（**有效邻接半径**，超出不产生规则关系）
  - 这个形状给出：紧贴 = 2.0，一地块 ≈ 1.47，两地块 ≈ 0.58，三地块 ≈ 0.12，四地块 ≈ 0.014 → 断。

**关于上限（修正旧稿）**：旧稿写 `c ∈ [0, 2.0]`，与同段的"平原工业最大 2.6"自相矛盾，两者都不完整。
真实范围：平原非工业 **2.00**；任一端工业 **2.60**；有桥跨水 + 工业 **2.99**。
**`A ≤ 2.0` 单独成立，`c` 不另设封顶**（见 `spec.space.md` 表 SP2 §2.1）。

**关于"连续"（修正旧稿）**：旧稿同时说"c 是连续函数"和"d > 4 硬截断"。正确表述是：
**c 在 `0 < d < 4` 上连续**；`d = 4` 处 A 已衰减到峰值的 **0.72%**，这一跳在 R 上的最大影响是 **0.71 个百分点**，
故截断视为连续。**不要说"c 处处连续"。**

- **遮挡 O(i,j)**：两者之间是否有实体阻挡（山体、水体、成路的街道、大体量建筑）。
  - 无阻挡：`O = 1.0`
  - 部分遮挡（穿过林地/矮墙）：`O = 0.7`
  - 完全遮挡（山脊、河流、成路的街道）：`O = 0`
  - 实现：在两者连线上按距离查询地形/道路阻挡采样（见 `spec.space.md`）

- **地形调制 T(i,j)**：地形对这段耦合的额外作用（见 `13_地形与自然.md`）。
  - 平原/无地形：`T = 1.0`
  - 水面跨越：`T = 1.15`（有桥时水面成为**声学镜面**——但注意：**这不是"隔声的反面"**，见下）
  - 林地跨越：`T = 0.85`（植被吸收高频，但保留低频）
  - **σ 的地形倍率单列**：山上传声远、河谷聚声、海岸开阔都是 **σ 的倍率，不是 T**。
    两端取**最大值**（`max` 而非平均），保证 `c(i,j) = c(j,i)`。

- **音乐性 M(i,j)**（表 SP4）：当一方所在音级在其**近邻集合**中的占据率 `occ > 0.40` 时，`M = 0.7`，否则 1.0。
  这是让"全城调成 C"不再是数值最优的机制——**乘法而非惩罚**，加一个不同音级即刻恢复。

### 2.2.1 规则层 ≠ 声学层（这一条必须先读）

**`c = 0` 只表示"不参与规则结算"，不表示"听不见"。**

两栋隔着河的 C3 建筑，规则上不产生耦合边（不进入 R），但若两者都在全城混音里以 drone 持续发声，
**PCM 里仍然有 7.8 Hz 的拍频**。这是物理事实，删一条规则边不能消除它。

所以：**任何"听感"的断言必须以混音层为准，不能以规则层为准。**
水体在**规则层是墙**（`O = 0`，不参与 R），在**声学层是镜子**（湖面延迟、河岸对唱、海面回荡）。
任何文档、UI、提示不得把这两件事写成同一件事。见 `spec.space.md` §0 与 AUDIO-009。

### 2.3 R 谐振度公式（形状不变，权重分层）

```
R = 100 × Σ_k ( W_k × ( Σ_{i,j∈k} c_ij·s_ij ) / ( Σ_{i,j∈k} c_ij ) )
W_k = ( Σ_{i,j∈k} c_ij ) / ( Σ_all c_ij)
```

即：**先按社区算加权平均，再按社区耦合总量加权**。

- `s_ij` = 该音程的协和分（**表 B，原样保留**）
- 权重从离散的 `w` 变成连续的 `c`
- 仍为**纯函数**，每乐句边界重算，不保留历史
- 无配对时 `R = 100`（保留旧裁定）
- 工业系数：任一方为工业时 `c × 1.3`，**先封顶 2.0 再乘**（保留旧裁定）

**为什么分层**：全城平均会让一片锈蚀社区被 40 个健康社区稀释（旧问题 Q10）。分层后，
一片社区真的坏掉时 R 会明显下降，玩家能看到、听到具体哪里出了问题。

**R 的职责边界**：R 是**布局的和谐度指标**，不是"好不好听"的指标。好听由编曲负责
（见 `12_声音架构.md` §4）。除崩盘阈值外，**没有任何跨章条件、缺口、奖励以 R 为唯一判据**。

**V 活力公式不变**：`V_next = clamp(V + ΣΔV_pair + 1.0 − decay, 0, 100)`，`decay = 0.5` 当 `R < 60`，单乐句净变化上限 ±12，`V₀ = 50`。

| 情形 | 旧 | 新 | 一致？ |

| 两栋紧贴 C3–E3 | R=85, V 各 56 | R=85, V 各 56 | ✅ |

## 3. 有效邻居图

### 3.1 每个建筑的邻居（两个集合，不是一个）

旧稿写"典型邻居数 4–9"，同时又写"密集方阵可有 68 个邻居"。**两句都低估了。** 实测（`r = 0.45`）：

| 排布 | 间距 | `c > 0` 的邻居数 |
|---|---|---|
| 六方最密堆积 | 0.90 | **108** |
| 方格 | 1.00 | 68 |
| 六方堆积 | 1.20 | 60 |

所以必须区分两个集合，各有各的用途：

| 集合 | 定义 | 用途 |
|---|---|---|
| **全对集合** `E` | 所有 `c > 0` 的无向对 | R 的分子分母、V 的 ΔV 求和 |
| **近邻集合** `N₁₂(i)` | 按 `c` 降序取前 **12** 个邻居 | 生长判据、阶段升级、碴冻结、音乐性权重 |

**为什么必须分开**：若阶段升级与碴冻结用全对集合，密集区每栋建筑都有 70+ 个邻居，
"≥2 邻居 s ≥ 0.85"和"任一邻居 s ≤ 0.05"两边都极易命中——
**结果是密集区所有建筑同时冻结、同时不再升级，城市在密集处停止生长**。这是旧稿里的一个隐藏问题。

**稀疏性是特征不是 bug**：一座只有 2–3 个区域的小镇应该听起来稀疏。这是"城市早期"的声音。

### 3.2 社区（Community）

**规划社区 = 从一个锚点沿可建邻接图加权扩张得到的发展区域。**
- 扩张种子：城市中心 / 地标 / 玩家播种点
- 扩张代价：道路穿越 + 坡度 + 岸线 + 边界（**不用欧氏 Voronoi**——会把隔河两岸划成同一片）
- 边界：主路 / 河岸 / 山脊（可见边界，玩家看得见）
- 最小 4 栋，最大 40 栋（超出先分裂，保留父 ID）
- 社区是**音乐声部聚合的基本单位**（见 `12_声音架构.md`）与**界面的基本单位**（悬停一栋 → 显示它属于哪个社区）

**必须与另外两个概念分开**（旧稿把三者混成一个"社区"，见 `18_城市规模.md` §1）：

| 概念 | 定义 | 稳定性 |
|---|---|---|
| **源点家族** | 一个共鸣点源出的全部建筑 | 随生长变化；只用于溯源与显示 |
| **规划社区** | 上面定义的稳定发展区域 | **稳定 ID**，不随音级/成熟/调音变化 |
| **音乐连通簇** | 每乐句按声学耦合图 `c > 0` 重算的连通分量 | **每乐句重算**，编曲的临时输入 |

**三条硬规则**：
1. **一座建筑恰好属于 1 个规划社区**。家族与音乐簇是另两套标注，不改变归属。
2. **改音级不改变规划社区 ID**。玩家调音不会把房子"调出社区"。
3. **起始 3 个区域 ≠ 3 个成熟社区**。开局只有 9 栋，按最小 4 栋规则至多 2 个区域够格成为社区，其余是萌芽区域。

### 3.3 声景缺口（Soundscape Gap）

这是**核心循环的驱动力**，定义在世界模型里因为它是一个空间+声学事实：

**缺口 = 城市当前演奏中，某个声部角色在某个位置缺失。**

缺口有 5 类（对应五种声部角色）：

| 缺口类型 | 判定 | 玩家该做什么 |
|---|---|---|
| **缺低音** | 城市总混音中低音区（< 130 Hz）drone 能量占比 < 15% | 播一个低八度的共鸣点 |
| **缺节奏** | 某片区域（半径 6 内）无商业律动建筑 | 播一个商业共鸣点 |
| **缺协和音** | 某社区存在 s ≤ 0.30 的配对，且该社区没有提供解法音 | 调音或播一个第三音 |
| **缺留白** | 某区域的建筑密度 > 阈值且无公园/水面间隔 | 不建，或引水/种树 |
| **缺应答** | 存在两片分离社区（距离 5–10），音程关系是协和但未形成呼应 | 调整其中一片的音级形成五度/八度 |

**缺口在界面上是柔和的视觉+听觉提示**（见 `16_界面与反馈.md`），不是错误标记。

**缺口是机会，不是任务**（这一条决定整个玩法的性质）：

1. **缺口不强制、不计分、不阻塞**。没有任何关卡要求"处理完所有缺口"，缺口也不会累加成一个待办清单。
2. **玩家可以选择不填**。留白与未解决的张力是正当的创作选择——一个未解决的和弦在下一乐章解决，是本作最好的时刻之一。
3. **缺口不是唯一的目标来源**。玩家可以纯粹为了"我想让这一片听起来像低音"而不建，系统不评价。
4. **缺口会自然变化**。填上一个缺口后，别处会出现新的——不是系统在派活，而是城市的和声结构变了。

**缺口与音乐性权重（表 SP4）的分工**：音乐性权重是**布局层的连续激励**（随时生效、无 UI、无提示）；
缺口是**音乐层的创作机会**（乐句边界结算、有听觉先行提示）。两者不可互相替代，
**不得把音乐性权重做成缺口提示，也不得把缺口做成惩罚**。

## 4. 高度与遮挡

- 山体、大型地标有**高度** `h`。高度 ≥ 2 地块的实体在投影上遮挡其"阴影扇区"。
- 遮挡方向由光源决定（世界约西偏南 20°，高度角 45°，沿用已批准光影）。
- **声学遮挡用山体轮廓线，不用视觉阴影**——但两者方向一致，让玩家能直觉推断。
- 高地上的建筑**传播更远**：`σ` 按 `(1 + h/8)` 放大（山上的钟声传得远）。这是"山地层级生长"的物理基础。
- 洼地/河谷的建筑**耦合更紧**：`σ × 0.85`（河谷聚声）。

## 5. 时序：分层落定（修正"一切都要等 16 秒"）

旧稿写"**所有**真实变化在乐句边界（16 秒）落定"。这让每一次试听、每一次拖动都变成漫长等待，
把"创造"变成了"排队"。修正为**四层时间**：

| 层 | 边界 | 什么变化 | 为什么 |
|---|---|---|---|
| **L0 即时** | 0–50 ms | 输入响应、悬停高亮、预影、预测文案 | 手感，与音乐时钟无关 |
| **L1 试听** | 按住即响 | 候选音、未来快照试听、单独聆听 | **不改变真实城市**，随时可听 |
| **L2 下一拍** | 0.5 s | **本乐句内的局部声音变化**：单栋调音、Solo/Mute、装饰层 | 一个音的改动不需要等 16 秒 |
| **L3 乐句边界** | 16 s | 建筑生长、社区形态、地形动词落定、缺口结算、R/V 重算 | 城市结构与和声的确定性结算 |
| **L4 小节/乐句** | 2 s / 16 s | 跨越仪式（3 小节）、时代更替 | 大型演出需要完整时间 |

**关键裁定：L2 的存在**。玩家调一个音、按一次 Solo，在**下一个合法拍点**（0.5 s）就听得到，
不必等到乐句边界。实现方式是"从生效拍点重渲染该声部的后续 PCM"——
合成器本来就要逐块生成，从拍点切分是可行的，且不破坏确定性（拍点是固定网格）。

**为什么仍然保留 L3 给生长**：City DNA 的可复现性要求**城市结构**的结算锚在乐句边界。
玩家可以随时打断声音，但不能随时打断城市——否则"城市自己在演奏"这件事不成立。
**结构等 16 秒，声音只等 1 拍**，这是两者的分界。

**音乐时钟永不停**（保留）：L3/L4 期间音乐继续，视觉按音频帧同步，不用 Tween 秒数。

**即时反馈在哪**：见 `16_界面与反馈.md` §2。关键是输入层与变化层分离，输入层必须**极其跟手**。

## 6. 坐标系与投影

- **世界坐标**：连续浮点 `(x, y)`，单位"地块"。地形生成在 `[-8, +40]²` 量级（含海面）。
- **投影**：保留等距 2D 硬编码仿射（现有实现可复用）：
  ```
  screen = origin + ((x − y) × 28, (x + y) × 14) × zoom
  ```
  其中 (28, 14) 是半个地块的屏幕尺寸（沿用现行实现）。
- **反向**：`cell_at` 的逆变换继续可用，但现在返回**连续坐标**而非整数格。
- **不引入 3D**。高度通过投影偏移 `−h × 14 × zoom` 表现，遮挡用绘制顺序 + 山体多边形。

## 7. 与旧代码的迁移

**旧稿此表的 API 名称已过时**（指向重构前的实现）。迁移以 `19_城市生成管线.md` §5 为准，那里列的是现行系统的迁移边界。
这里只保留变化的方向：

| 变化方向 | 说明 | 工作量 |
|---|---|---|
| 空间类型 | `Vector2i` → `Vector2`，且**不再有任何"格"的概念** | 小 |
| 邻居查询 | 共享边枚举 → 距离核 + 空间索引（支持"取前 12 强"） | 中 |
| 生长候选 | 四向邻格 → 合法地块（不是环带撒点） | 大 |
| 道路 | 只阻断邻接 → 完整路网、交点、路宽、桥、临街面 | 大 |
| 社区 | 同家族连通群 → 稳定规划社区 | 中 |
| 声像 | 三段量化 → 连续等功率 | 小 |
| 地形 | 无 → 全新地形层 | 大 |

**迁移原则**：先让**耦合函数**与**连续坐标**上线（空间层），保持其他系统不变，跑通 `spec.space.md` 表 SP9 的 fixture；
