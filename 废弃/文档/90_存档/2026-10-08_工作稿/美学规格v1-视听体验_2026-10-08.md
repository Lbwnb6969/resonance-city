# 《共鸣之城》美学规格 v1 — 视听体验标准（宁神 · 生动 · 丝滑 · 尽善声）

> 工作稿 · 2026-10-08 · v0.1
> 把"好看、宁人心神、丝滑、声音尽善尽美"从感觉翻译成**可执行、可验收的规格**。
> 权威位置：与策划案 v3.1、执行方案 v1 同列 `共鸣之城\文档\`；美术/音频的最终评判以本文规格为准。

---

## 0. 三个词的可测试定义

| 感觉 | 定义（能通过/不通过来判定） |
|---|---|
| **宁神** | 截任何一帧，色相 ≤ 3 族、对比柔和、无高频闪烁；放置 30 秒无操作，画面仍在缓慢呼吸，让人不想关 |
| **生动** | 任意 10 秒窗口内，屏幕上 ≥ 5 处微小运动；每个街区有 ≥ 3 个循环微动效；城市状态变化全部有视觉对应 |
| **丝滑** | 任何可见变化都经过补间与缓动，无瞬变、无硬切；转场不被中途打断出破绽；稳定 60fps |

声音的总标准一句话：**任何时刻录下 30 秒音频，盲听都像一段"作品"，不像"游戏音效在放"。**

## 1. 视觉参照坐标（学谁、学什么、不学什么）

| 参照 | 它为何被赞誉 | 我们取哪一条 |
|---|---|---|
| **纪念碑谷** | 神圣几何 + 粉彩色阶 + 大量留白，"无意义的美"直击心灵 | **色彩纪律**：每屏一主色族，辅色同类色，点缀色只有一个（[主创访谈](https://m.sohu.com/a/195265689_99994828/?pvid=000115_3w_a)、[色彩分析](https://m.sohu.com/a/151931984_487912/)） |
| **Townscaper** | 每次点击都有玩具般的微动画与鸟鸣回应，建筑自己"长"出可爱的不规则 | **即时愉悦**：任何生成/生长都必须带 squash & stretch + 环境小彩蛋（飞鸟、晾衣绳、猫） |
| **Dorfromantik** | 手绘温度，暖秋色系，像一本可以玩的绘本 | **材质温度**：扁平但不"塑料"——给纯色加 2–3% 的纸感噪点，边缘不做绝对平直 |
| **Islanders** | 极简干净，信息零噪音 | **克制**：装饰物密度有上限，宁可空，不可乱 |
| **Mini Motorways** | 极简到抽象，却百看不腻 | **可读性**：远看先读"形与色块"，近看才读细节 |
| **Alto's Odyssey** | 天空渐变是一天的诗 | **天色系统**：我们的昼夜色板=天空渐变表，换色板时天空先行、城市随后（错峰 1 拍，产生"光扫过城市"感） |
| **GRIS** | 水彩晕染式场景过渡 | **过渡美学**：场景级变化用晕染/雾扫，不用淡入淡出黑场 |

不学的：Two Point 式的夸张喜剧动效（破坏宁神）、任何霓虹高饱和赛博色（与色板纪律冲突）、写实渲染。

## 2. 宁神：画面规格

1. **色板纪律**：全局 ≤ 24 色（执行方案 §5），单屏色相 ≤ 3 族；饱和度的"天花板"随谐振度浮动——和谐的城市才配拥有最饱和的颜色，这本身就是联觉表达。
2. **对比度上限**：任意相邻色块明度差 ≤ 30%（夜景窗光除外，它是唯一的"高对比特许"）。
3. **无闪烁红线**：禁止任何 < 0.5Hz 的明度跳变；粒子与动效的 alpha 变化必须带淡入淡出。
4. **形态自然**：资产保持自然几何——屋顶就该是尖的，烟囱就是直的，不强行圆角化。画面的"柔和感"由色彩、低对比、光影和缓动效负责，而不是由形状负责。（v0.1 原"圆角优先"条款作废：它不现实，也会让资产变得怪异。）
5. **失谐的视觉信号（不扭曲几何）**：失谐街区不添加尖刺、不变形，而是用潜意识级的信号表达——色温轻微偏移（偏冷或偏品）、对比度悄悄拉高、阴影边缘变硬、微动效逐一熄灭。玩家"说不出哪里不对，但感觉不对劲"，这与听觉上的拍频粗糙感同构：都是意识之下的警报。
6. **留白**：任意缩放档位下，纯地面/水面/天空占比 ≥ 25%；程序生成器摆装饰物时执行密度上限。

## 3. 生动：城市呼吸清单

**原则：每秒都有东西在动，但幅度都很小。**

- 每街区 ≥ 3 个循环微动效，全部锁定 BPM 整数分频（如旗帜 2 拍一摆、烟囱 4 拍一团烟）——**视觉节拍器**，看城市就像看音乐。
- 密度绑定活力 V：活力高的街区行人多、晾衣绳满、鸽子成群；灰噪化街区动效逐个"熄灭"（先是鸟没了，然后旗不飘了——比直接变灰更揪心）。
- 环境彩蛋池（程序随机播撒）：飞鸟掠过、猫穿屋顶、纸飞机、晾衣绳、窗台花盆。彩蛋的分布也随街区声部类型不同（工业区没有猫，有蒸汽）。
- 水面/河流：恒定缓动波光（正弦位移贴图），流速 = 环境声床的"声部"。

## 4. 丝滑：工程纪律（写进 Definition of Done）

1. **一切变化走 Tween**：位置/缩放/透明度/颜色，禁止直接赋值瞬变（生成器代码评审时查这条）。
2. **缓动标准**：入场 `ease-out cubic`；状态切换 `ease-in-out sine`；回弹类（生长、彩蛋）`ease-out back`（overshoot ≤ 1.1）。
3. **时长表**：微交互 150–300ms；UI 300–450ms；镜头移动 600–900ms；建筑生长 = 精确 1 拍；场景级过渡 = 1 小节。
4. **过渡不可打断出破绽**：所有过渡支持"接力"（新过渡从当前插值状态无缝接管，而非重置）——用户在过渡中连续操作也不露馅。
5. **性能预算**：60fps；单屏 Sprite ≤ 800；粒子系统 ≤ 12 个；YSort 节点树深度 ≤ 6。
6. **镜头手感**：平移带惯性（摩擦系数调"滑但不漂"），缩放到档位时吸附 + 一次 200ms 的 ease-out 落定，配合一声极轻的木质"嗒"（L0 触感音）。

## 5. 声音：尽善尽美规格

> 承接策划案支柱 A/B/C 与铁律（小节边界切换），此处给出"做到什么程度才算尽善尽美"的明细。

### 5.1 衔接（Smooth Transitions）

- 结构变化只在**小节边界**生效；声部进/出用 **equal-power 交叉淡化**，时长 2–4 拍，绝不用线性淡变（响度中点凹陷可闻）。
- 转调必须走**共同和弦桥**（先落到新旧调共有的和弦，再进入新调），禁止直接 key change。
- 情绪大跳（如灰噪→救回）用"织体桥"：先抽掉鼓组留 pad，再逐层重建——**先减后加**，比直接切更震撼。
- 参照：[Tetris Effect 音频分析（GameDeveloper）](https://www.gamedeveloper.com/audio/game-audio-analysis---tetris-effect)——操作音全部调谐到当前调式、爆发段前的"抽离"手法；[自适应音乐实例整理（奶牛关）](https://cowlevel.net/article/1948101)。

### 5.2 形象化（Sound You Can See）

- 每个街区的声部音色与其视觉签名**一一对应且可反向猜**：听到锯齿脉冲必能找到工业区，听到木琴 4/4 必是住宅。验收时做"听音指图"测试。
- **环境声与音乐共调**：市场喧闹、工厂轰鸣、风、水、鸟鸣这些 diegetic 声层，其节奏/音高向当前调式与 BPM 靠拢（机器轰鸣的音高调到五度内，风声做带通扫频与和弦根音共鸣）——世界本身在演奏。
- 全部 UI/反馈音 = 当前调式内的乐器音，无一个"系统提示音"。

### 5.3 混音与空间

- 总线：Master → 音乐（分声部 bus）/ 环境 / 介入反馈 / UI。
- **Sidechain ducking**：提案试听、定音、形态演出时，音乐 bus 自动 −6dB、300ms 回弹——主角声音永远让位给"当下最重要的声音"。
- 混响即空间：河谷/峡谷大混响、广场中混响、室内小混响；镜头推拉时混响参数连续跟随（这也是"丝滑"）。
- 响度目标：整体 −16 LUFS，峰值留 3dB 余量；宁神的前提是不吵。

### 5.4 愉悦声的红线

- **每个音都有尾巴**：任何发声不得"干"——最小混响或自然衰减 200ms+。
- **防重复**：同一事件音 ≥ 4 个 round-robin 采样 + ±3% 音高抖动。
- **卡拍奖励音的"酥麻"配方**：基音 + 纯五泛音 + 高八度 shimmer（+10ms 延迟），瞬态要"脆"（5ms 内起振）。
- **灰噪化也要"美"**：衰败不是噪音污染，而是声音"褪色"——低通 + 降采样轻颗粒，像旧磁带。让玩家心疼而非烦躁。

## 6. 验收测试（每个里程碑都要过）

| 测试 | 方法 | 通过标准 |
|---|---|---|
| **壁纸测试** | 任意时刻截屏 | 色相 ≤3 族、构图有留白、可直接当壁纸 |
| **30 秒放置测试** | 不操作静观 30s | ≥5 处微运动、无一处突兀、不想关窗口 |
| **闭眼定位测试**（P0 已有） | 黑屏听 30s | 指出失谐方位与类型 |
| **听音指图测试** | 单独放一条声部 | 能指认它属于哪个街区 |
| **过渡猎手测试** | 故意在每次过渡中疯狂操作 | 抓不到任何瞬变/硬切/音量跳 |
| **作品测试** | 任意 30s 录音 | 盲听像"一段音乐"，不像"游戏在放音效" |
