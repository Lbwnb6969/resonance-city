# 04 · 地形与自然：山、海、湖、河、林

> **2026-10-11 选择性恢复（当前有效）**：地形继续影响音乐，但地形提供空间机会，玩家决定声部、音级与位置。河流对唱是第一条可玩的地形音乐关系：同岸/对岸位置与音程共同决定是否产生一次、延迟两拍的应答；它不再自动增加活力，也不要求建桥。湖泊的回声与独奏岛、林地的局部听感、山地的玩家主动梯田编曲、海岸/山顶传播属于后续试听候选，当前不自动改音高、全局滤波、声像或成长收益。河流之外的地形仍可只承担构图、留白、区域辨识与可建性。本文旧表中的固定增益、固定延迟、强制升阶和全局地形倍率均按此段解释，保留为历史方案而非当前运行合同。

## 1. 设计原则

**地形不是背景，是乐器。**

每一条设计都必须回答："这个地形让玩家听到什么？"如果只是好看，就不做。

**四条铁律**（第 4 条是本轮新增的，它决定了整个地形系统能否自圆其说）：

1. **地形影响声学耦合**（`c = A × O × T × I × M`，见 `10_世界模型.md` §2.2）——这是地形参与**规则**的途径。
2. **地形不扭曲几何**（沿用美学红线）——山是山，水是水，不为了"表现声学"把地形做成波形。
3. **地形可被玩家改变**（有限度）——引水、植树、挖湖是玩家的动词；山与海是给定的。
4. **规则层与声学层必须分开说**（新增）。`O = 0` 表示"不参与和声结算"，**不表示"听不见"**。
   水体在**规则层是墙**（不进 R），在**声学层是镜子**（湖面延迟、河岸对唱、海面回荡）。
   **任何文档、UI、提示不得把这两件事写成同一件事**（详见 `spec.space.md` §0 与 AUDIO-009）。

## 2. 六种地形

下表的"规则层"与"声学层"两列**不是重复，是分工**——实现时落在不同系统里。

| 地形 | 生成 | 可建 | **规则层**（进不进 R、σ 怎么变） | **声学层**（PCM 里是什么） | 视觉 |
|---|---|---|---|---|---|
| **海** | 固定边界（地图外缘） | ❌ | `O = 0` | 开放空间，最低声床；远处低频回荡 | 大面积，波光，水平线 |
| **河** | 从山地流向海/湖 | ❌ | `O = 0`；有桥处 `O = 1.0` | 流动噪声；**两岸对唱**（有来源的事件应答，非规则耦合） | 流动波光，流速 = 环境声床节奏 |
| **湖** | 低洼盆地积水 | ❌ | `O = 0` | **镜面延迟副本**（0.15 s，−12 dB，关闭反馈）；湖心岛独奏 | 静止或极缓波光 |
| **山** | 高度场山峰 | 缓坡可建 | 陡坡 `O = 0` / 缓坡 `0.7`；**σ × (1+h/8)**，两端取最大值 | 风声；高海拔高频更清 | 等高线、阴影、多层 |
| **林** | 山地/平原交界，或玩家种植 | ✅（但降密度） | `O = 0.7`；`T = 0.85` | **吸高频，保留低频**（"闷"而不是"断"） | 树冠层，随风摆动 |
| **平原** | 默认 | ✅ | `O = 1.0`，`T = 1.0` | 无调制 | 草地、纸感纹理 |

## 3. 地形的声学意义（核心）

### 3.1 河：对唱

**这是本作最重要的地形机制。**

一条河把城市分成两岸。水体在**规则层**是墙：`O = 0`，两岸**不产生耦合边**——R 不计算它们。

**但请注意这一句的准确含义**（这是最容易写错的地方）：
`c = 0` 只表示"不参与和声结算"，**不表示两岸互相听不见**。
若两岸都在全城混音里以 drone 持续发声，**PCM 里仍然会有拍频**——这是物理事实，删一条规则边不能消除它。
系统能做、也必须做的是：**按 A25/AUDIO-009 组织两岸的槽位与聚焦电平，并实测拍频听感**；分组不构成持续拍频已消除的证明。

而**跨河的同音/协和建筑形成"对唱"**——这是设计出来的、有来源的事件应答：

- 判定：a、b 分居河两岸，直线距离 < 8 地块，音程关系为协和（`s ≥ 0.85`）
- 效果：
  - **不再提供活力奖励**：双方只产生一次有来源、延迟两拍的应答；成长仍由常规耦合和玩家行动决定。
  - 音频上，后者的律动**延迟 2 拍**复述前者（卡农式应答）——这是真的可听的
  - **单向，不递归**：B 复述 A 之后，A 不得再复述 B
  - 视觉上，河面出现一次从一岸到另一岸的**波光传送**（1 拍）
  - 命名形态：**双子港**
- **对唱不是耦合**：它不产生 R 边，也不因 `O = 0` 被取消。**河是让城市更音乐的机制，不是切断城市的机制。**

**为什么好**：它让玩家主动想"我该在河对岸放什么"，而不是把河当成障碍。地理创造了音乐结构。

### 3.2 海：地平线

- 海是**声床的来源**：海浪的节奏 = 环境层的低频脉动，速度随时代变（旧航海时代慢、现代快）
- 海不可建；海岸主要提供视野、留白与构图，传播加成暂不启用。
- **注意**：开阔影响的是 σ（传多远），**不是 T**（T 是乘在 c 上的系数）。旧稿把它写进 T 列是错的
- 海**没有对岸**（除非地图另一侧也有海），所以不产生对唱

### 3.3 湖：镜面与岛

- 规则层：`O = 0`，不产生耦合边
- 声学层：湖面回声是后续试听候选，当前不自动插入固定延迟副本。
- 湖心岛不自动增益或居中；玩家可用独奏、留白和公共空间主动组织突出声部。
- 这是"留白"的极致形态：湖是天然的留白

### 3.4 山：层次与瞭望

- **等高线生长**（对应旧形态"梯田赋格镇"）：
  - 山坡不强制改音高；未来可做玩家主动选择的梯田上行编曲。
  - 效果：山坡上的城市自然形成"从低到高的音阶排列"——视觉上就是梯田，听觉上就是上行音阶
  - 这是**地形直接决定音乐**的最强例子
- **山上传声远**：**σ × (1 + h/8)**，两端取**最大值**（保证 `c(i,j) = c(j,i)`）。
  山顶的钟声在有效邻接范围内衰减较慢；**d > 4 的规则硬截断不变**。全城可闻由编曲与监听组织实现，不能靠 σ 扩大规则截止距离
- **山体遮挡**：山脊两侧 `O = 0`，**规则上不参与和声结算**。
  与河同理：这**不表示两侧绝对听不见**，而是"不构成设计过的关系"，由编曲分组处理

### 3.5 林：吸音与季节

- 林地的全局高频吸收暂不启用；局部听感保留为后续试听候选。
- 树**锁 BPM 摆动**（旧美学保留）：旗帜 2 拍一摆、树影同步
- 秋色、强拍落叶（旧 U24d 保留）
- **玩家植树**：可以在密集区植树降密度（解决"缺留白"缺口）

### 3.6 时间让地形呼吸

昼夜和后置季节属于**自然表现层**。它们让同一条河、同一片林和同一个山谷在长时间聆听中有生命，但不偷偷改写地形的规则层或玩法层。

| 地形 | 昼夜表现 | 季节表现 | 不改变的东西 |
|---|---|---|---|
| **海** | 白昼读地平线，黄昏出现长条暖反光，夜间保留低亮月色水面 | 只换雾色、岸边植被与远景风感 | 海的边界、不可建性、σ 口径 |
| **河** | 波光随环境声床流动；黄昏沿桥和岸线出现灯带，夜间水面变暗但不断流 | 春夏水岸更丰，秋冬岸色变轻；不改河道拓扑 | 两岸规则隔断、桥的几何、对唱事件 |
| **湖** | 天空和建筑倒影随天色连续变化，夜间只留稀薄的城市反光 | 湖岸草木和雾色变化，湖面仍是留白 | 镜面延迟、湖心岛独奏、`O = 0` |
| **山** | 晨昏强调山脊轮廓，夜间变成可读的深色剪影；云雾低频移动 | 高地先出现霜雪或枯色，低地不被统一铺雪 | 高程、遮挡、σ 放大和等高线生长 |
| **林** | 白昼树冠摆动最完整，夜间只保留稀疏枝影和少量萤光 | 春发芽、夏浓荫、秋落叶、冬裸枝；每种密度资产都保持同一朝向 | `O = 0.7`、`T = 0.85`、植树动词与留白作用 |
| **平原/滩涂** | 通过天空、草地和远雾承担大部分变化，避免额外堆装饰 | 地面纹理、花草和农事小物变化 | 可建性、开阔 σ、街坊与落点规则 |

声音上，地形仍提供原有环境声床；昼夜/季节只改变声床的音色、密度和细小事件，具体声部边界见 `12_声音架构.md` §6.1。任何 `O/T/σ`、R/V 或成长判断都不得从天色和季候反推。

## 4. 地形生成

### 4.1 种子驱动

地形由 `terrain` 子流生成（沿用旧种子系统）：

```
地形种子 → 原始高程（地貌）→ priority-flood 填洼排水面与无环父图 → D8 流向/流量累积 → 河流与海/湖出口（河宽按 √流量）
         → 湖泊（填满局部低洼）
         → 林地（按海拔与湿度分布）
         → 海岸线（高度 < 0 的地方是海）
```

- **可复现**：同种子同地形（City DNA 的一部分）
- **开局地形族**（旧策划案提到）：河流谷地、海岸、山地、三角洲、湖泊群
- **地形必须保证 R_initial ≥ 65 的可建区存在**（旧约束保留）

### 4.2 地形与时代

**时代更替不改原始地形，植被与建筑随时代换；玩家仍可按 T4 改地形**（旧 ERA-08 矩阵的自然行保留）：

| 时代 | 植被 |
|---|---|
| Ⅰ 古典 | 柏树、橄榄、葡萄架 |
| Ⅱ 中世纪 | 橡树、药草园、条田 |
| Ⅲ 文艺复兴 | 几何园林、绿篱、喷泉 |
| Ⅳ 工业 | 维多利亚式公园、行道树 |
| Ⅴ 现代 | 中央公园、屋顶花园 |

## 5. 玩家的地形动词

| 动词 | 操作 | 效果 | 代价 |
|---|---|---|---|
| **引水** | 从水源拖出路径 | 生成河道，提供两岸对唱的空间机会 | 不可撤销，占地，每乐章 1 次 |
| **植树** | 点一下 | 生成小片林地，改变构图与密度；局部听感后置 | 占地，每乐句 1 次 |
| **挖湖** | 在低洼处点 | 生成小湖，镜面 + 留白 | 不可撤销，占地，每乐章 1 次 |
| **平整土地** | 在山坡拖一片 | 降缓坡地可建 | 不可撤销，每乐章 1 次 |

**限制**：引水、挖湖、平整不可撤销；植树可按 P9 移除，桥按 T4/P7 的合法几何与额度提交。UI 必须显示代价和耦合变化预览；独立额度也走同一个 WorldDelta。

## 6. 地形与城市形态（回答 Q18）

**同一套生长规则 + 不同地形 = 完全不同的城市形态。**

| 地形 | 城市会长成 | 音乐特征 |
|---|---|---|
| 河谷 | 沿河两岸的长条城市 | 对唱、卡农 |
| 海岸 | 半圆形沿湾城市 | 开阔、低频厚（海声床） |
| 山地 | 梯田式多层城市 | 上行音阶、层次分明 |
| 三角洲 | 多岛屿城市 | 多声部应答、复杂 |
| 平原 | 同心圆/放射状 | 单旋律突出、清晰 |
| 湖泊 | 环湖城市 | 镜面回声、独奏岛 |

**这是"两种宏观布局"的基础答案**：地形先提供不同的空间机会；玩家再用发展章程、社区范围、道路和公共锚点选择如何利用这些机会。相同地形也能因规划选择长成不同的城市，地形不替玩家做规划决定。

## 7. 视觉规格

- **水体**：恒定缓动波光（正弦位移贴图），流速 = 环境声床的节奏（旧美学保留并升格为规则）
- **河流**：从山到海的连续曲线，宽度随流量变化（上游窄下游宽）
- **海岸**：沙滩渐变 + 浅水透明层
- **山地**：等高线 + 明暗分层（受光面亮、背光面暗，沿用统一光影）
- **森林**：树冠层 + 地面阴影，树高 22/28 px（见 spec.terrain 表 T5）
- **留白**：整城尺度水面/天空/纯地面占比 ≥25%，社区 ≥15%，单栋不设比例（17 §6；**水面算留白**）

## 8. 实现建议

**通用生成与地形动词沿已有连续世界增量实现**；受控河谷与参数化五地形族已接入，具体范围见 PROJECT，不从零重写：

1. **第一阶段**：只做**静态地形**（种子生成高度场 + 河 + 海，可建/不可建判定）。不做引水/植树。
2. **第二阶段**：地形影响耦合（O 与 T 进入 `c` 公式）。
3. **第三阶段**：玩家的地形动词（引水/植树/挖湖）。
4. **第四阶段**：等高线生长（梯田）。

**每阶段都必须有实测**：地形跨过的耦合是否真的变（O=0）；对唱是否真的可听（2 拍延迟）；σ 放大是否真的传得远。

**风险**：地形生成可能产生**不可玩的布局**（全是山、或没有足够平地）。必须：
- 生成后检查可建面积 ≥ 阈值
- 检查 R_initial ≥ 65 可达
- 若失败，最多重采样 8 次（旧 CITY-002 规则保留）
