## 七项核心改动（相对旧设计）

1. **格子 → 连续空间**：耦合系数 `c = A(距离)×O(遮挡)×T(地形)×I(工业)` 取代 `w = 1+0.15(n−1)`
2. **27 上限 → 配器预算**：几十个社区、400–600栋为目标；70约束实际合成声部，逻辑组与波形共享组分开，背景也计入预算。旧主场景仍使用旧额度。
3. **诊断驱动 → 配器驱动**：缺口系统取代"修失谐"；三路径跨越取代单一条件
4. **地形从名词 → 一等系统**：山海湖河林影响声学耦合
5. **常驻面板 → 近乎全空**：悬停出卡 + 环形菜单 + 节拍条
6. **单模式 → 三模式**：交响曲 / 自由共鸣 / 聆听；结束可继续经营
7. **撒点 → 六层管线**：地形→骨架→社区→街坊→地块→建筑
