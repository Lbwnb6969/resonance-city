# 共鸣之城 · 生图参考包

## 目的

为执行 AI 提供**当前可实现阶段**的视觉参考。生成结果必须像一个早期 Godot 2.5D 等距城市原型的下一步，而不是商业宣传片或复杂的成品城市。

## 当前 Demo 的真实基线

- 当前 Demo 只有少量建筑、树、道路和公共空间；主视角是固定等距/轴测视角。
- 建筑是简单的奶白/浅灰墙体、柔和陶瓦屋顶、少量门窗；树是低多边形锥形树冠。
- 地面是浅灰绿色平面或很小的台地，留白很大，阴影柔和，画面近乎无 UI。
- 早期 Demo 的参考图在本目录：当前Demo_风格小景.png、当前Demo_风格小景_推近.png、当前Demo_古典小景.png、当前Demo_柔和岛台房群.png、用户认可_古典小景参考.png。
- `验证记录/连续河谷/` 中的大城图只用于理解河流切开两岸与规模关系，不作为本次美术密度目标；那是压力测试。

## 目标气质

宁神、生动、丝滑；低对比、低饱和、最多三族色相、2–3% 纸感噪点。画面是清楚的可执行游戏参考图，保留空地和简单几何。不要写实、不要霓虹、不要复杂 UI、不要满屏细节。

## 核心玩法转译为画面

玩家在连续地形上播下声音的种子，城市按和声自动生长。玩家控制社区章程、公共锚点、少数建筑音级与调音；普通房屋自动长出并沿街连片。地形就是乐器：河把城市分成两岸，桥是连接点；湖是镜面留白；山是梯田层次；林地是吸收高频的绿荫；平原提供通透留白。画面要能看出“地形决定城市在哪里响”，但不要把音符、波形或复杂 HUD 画成主角。

## 目标视觉规则

- 固定等距/轴测镜头，几何简洁，轮廓清楚。
- 建筑相邻时共享山墙、檐口和屋顶，读作少量连续街墙；仍保留几栋独立房屋的可辨轮廓。
- 留白来自水面、天空、街道、庭院；整城至少约四分之一为空间。
- 光影来自左上方单一太阳，接触阴影软，昼夜只改变影长、色温和窗光。
- 时代以材料和轮廓区别；当前优先古典/早期现代小景，不要一次展示五个时代。
- 画面只需要表达一个可执行场景：4–12 栋建筑、1 个地形主角、1 个公共锚点或一座小桥即可。

## 明确禁止

写实 3D、超高建筑密度、复杂交通经济系统、巨型地标堆叠、赛博霓虹、强烈 HDR、黑色描边、夸张卡通、满屏粒子、满屏 UI、文本水印、Logo、游戏标题字样、过度理想化的“最终成品城市”。

## 本次需要的四类参考图

1. 早期小景全景：少量房屋和树，浅色台地，留白明显。
2. 河谷两岸：一条窄河、一座简单桥、两岸各几栋房屋，强调对唱构图。
3. 古典小景推近：奶白石墙、柔和陶瓦、拱廊/柱廊，仍保持少量建筑和简单材质。
4. 同一早期小景的黄昏/夜间：只增加稀疏暖窗光与较长阴影，结构保持简单。

## 给生图模型的执行要求

把目录中的当前 Demo 图当作风格与复杂度参考图，而不是要求复制其中的 UI 或文字。每一张结果都必须能直接交给 Godot 执行 AI 当作布局、材质、色板和密度参考；优先准确、克制、可做，而不是华丽。

## 用户补充的早期河谷 Demo

新增参考图：用户补充_早期河谷Demo.png。它代表本项目早期的大地图状态：大面积浅色地形与水面，河道是清晰的主构图，白色道路很稀疏，建筑是少量小型重复房屋，树木和空地占大多数，界面信息轻量地贴在边缘。生图结果应保留这种可实现的密度和尺度；可以去掉文字/UI，但不能把它升级成密集、宏大、复杂的城市。
