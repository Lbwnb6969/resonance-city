# 共鸣之城：接续状态

## 当前目标（2026-10-12）

做出好玩、好看、好听、能持续经营的城市音乐游戏。当前只打磨20–30栋河湾试玩的前三分钟：选择发展方向、安排公共空间、亲自试听声音、看房屋沿道路成长、听见选择、改音并组合下一段。后台、公交、大城与后时代作为支撑，暂缓扩张。

用户尚未试玩，但明确认为城市画面不吸引、UI不好；要求大改美术/UI，精细化是第一条件。当前是第一时代古希腊与古罗马，门窗、材料、柱式和灯具必须符合时代；建筑朝向须协调真实道路，可以制作多个真实几何模板。可用Blender Python/MCP，项目内设计、实现、重构、取舍与常规验证已授权。

最新方向：弱化固定“社区”，玩家自行界定自己的街坊；紧密房屋按真实关系自然联合成较大房体。旧CID保留内部服务、编曲与作品兼容职责，不决定玩家归属。不能把选几栋偷换成整CID，不能因命名/同音/同CID自动联合。整CID调音与完整SP6后台扩张不作为当前主线。

**每次进入下一部分前，完整阅读该功能所有相关文档内容，再检查代码与既有工作。** 不只读关键词，不沿被最新要求替代的旧设计推进；按功能读，不每轮重读所有资料。PROJECT只在目标、决策、进度、验证或下一步变化时更新。公式和阈值只维护所属spec；设计批准、代码实现、技术验证、截图检查与真人评价分别记录。

## 当前可玩与实际实现

- 默认24栋年轻房屋、三段背景街道，没有预建公园或赠送成熟。实际序曲五秒后出现“塑造第一段”，P可提前进入。章程→变化卡→现行规划片区→公园/文化馆/留地/暂不建设→可听边界落定→选择声音；收起后P/轻入口继续原草稿。
- 深流为低慢住宅，织机为高短商业，暖庭为中音垫与真实邻近留白。三种声音无默认代选，点击立即听同源四秒，可切换、停止、重听或按住Space；Enter/确认才提交。预影与待播位置来自真实事务，到设备可听边界才交给正式房屋。16秒乐句，下一可写拍改音；作者根屋落成后即可改音并继续下一段，不锁六栋成熟。
- 8类建筑×四向、2类树共34个精制资源；石门洞、凹窗/木百叶、逐片陶瓦、内庭、taberna商铺、20柱环廊文化馆、橄榄树/地中海柏与陶碗油灯。四向先旋转模型几何再投影，不旋转成品贴图。按真实出生era=1替换，后时代保留独立入口；候选clay/garden/paper与原资产仍在。
- 暖石街面、错缝石块、低路沿、公共石院和外台阶石阈跟随真实道路/占地/地形；夜光按真实四向几何遮挡，未来房屋不先亮。表现层不写World/RNG/存档。
- 章程、变化卡、公共选择与声音选择采用356像素暖石原生面板；Tab原生焦点、Enter推进、Space试听。800×600为真实落点/门面保留屏幕像素净空。旧596像素作者菜单仍遮部分目标，待精修。
- 默认隐藏固定社区标签与常驻“街坊C”入口。C或房屋“规划片区工具”按需打开旧分组辅助；只列真实已听成员/音级/主题资格/公建/留白/作者根。独听与恢复沿旧CID规则，不能声称精确自定范围试听。“在此继续规划”预填旧范围，可继续原草稿；作者入口解除临时独听及该CID静音。
- 已接入真实相邻房屋的联合屋顶层：同路同侧、朝向协调、已听且完整揭示的第一时代住宅/商业，按真实共享墙与道路弧长组成2–6栋段，保留单栋类型、作者身份、内庭、ID/MIDI与命中。按模型真实高度延续平顶/瓦坡，以竖直侧墙处理高差；首版斜棚已修正。该切片不代表完整联合建筑全部验收。
- 玩家可按K或房屋“给这片街道起名”，逐栋选择真实已听房屋、跨旧CID命名，并主动保存；地图名/已有名字列表可重新增减成员和改名。800/1440均用356px原生暖石面板，名字输入屏蔽城市快捷键。Esc/地图右键仅撤命名草稿，输入框右键仍为原生文本菜单。只保存明确的稳定ID，不自动吸纳同CID/同家族/后生屋；失效历史ID保留。确认按最后实际成员取景并保存，F9恢复修订、成员与名字；房屋悬停也显示玩家名。精确选区聆听、批量调音和画连续边界尚未实现。

作者家族沿真实道路接排，背景家族各维持8栋用于首作。留地是真实空地，不发声、不赠活力，成长避开它；可保持留白或转公园/文化馆。普通主题仍有成熟/成员/成街/锚点资格；作者主题先唱真实根音。两岸作者可按真实来源/音程/距离建立延两拍Reply，连线只显示已经输出的事件。既有作品保存、City DNA、公共改用/搬迁/局部兑现、道路/桥、公交与时代入口保留，范围见Demo与所属spec。
