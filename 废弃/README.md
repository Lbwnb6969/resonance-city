# 项目统一废弃目录

本目录是整个项目唯一的废弃、旧实现和作废材料入口。默认不作为施工依据；需要追溯指定证据或执行已有基线对照时才读取。

所有路径均相对项目根目录。按原来源保留文件名与内部层级：

| 位置 | 内容 |
|---|---|
| `废弃/文档/` | 旧设计、旧规格、历史研究与正文替代片段；原 `文档/90_存档` 也在此 |
| `废弃/scripts/` | 旧实现与重构前代码 |
| `废弃/tests/` | 测试仍需读取的历史合成器与基线 |
| `废弃/tools/` | 旧生成器、构建或验证工具 |
| `废弃/资产/` | 旧素材、加工前副本与旧授权声明 |
| `废弃/验证记录/` | 失效、失败或被替代的证据；按原 Demo/P0/连续河谷层级保存 |
| `废弃/参考资料/` | 被替代的研究入口与资料 |
| `废弃/交付/` | 旧本地运行包，保留原本的 Git 忽略行为 |
| 已有的轮次目录 | 此前已直接存于根废弃目录的历史实现基线 |

**后续归档规则**：重要内容只移动，不删除；统一放到 `废弃/<来源目录>/<日期或轮次>/`。不得在 `文档`、`scripts`、`资产`、`验证记录` 或其他活动目录中新建第二个 `废弃`/作废存档入口。有效证据仍放 `验证记录/`，正式运行包仍放 `交付/`，Git 恢复备份不属于废弃材料。

移动前保存 Git 备份，确认目标无同名覆盖；移动后更新现行引用、测试基线路径和导出排除项。保留源码基线的 UID 与原文件一起移动；保留资产、验证记录原有的 Godot 扫描排除行为。不要在本目录根增加 `.gdignore`，现有回归测试仍显式读取 `废弃/tests/` 和部分轮次基线。
