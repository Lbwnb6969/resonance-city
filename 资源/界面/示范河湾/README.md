# 示范河湾封面

17张480×300 PNG由本工程实际Godot视口生成，与 `scripts/world/city_creation_examples.gd` 稳定ID对应；未使用生图或外部游戏截图。

生成命令：`Godot_v4.7.2-stable_win64_console.exe --path . --script tools/capture_creation_examples.gd`。工具走正常作品切换路径，在隔离临时作品库中先留存旧城，再加载样例，隐藏UI并暂停居民拍摄。跨河示范打开街坊导引。

封面中的建筑、植被、地景和纹理使用本作既有资源；原Tiny Glade/Foundation适配素材的出处和许可仍以 `资源/自然参考/README.md` 与各素材子目录记录为准。封面随整体美术校准后重新生成。
