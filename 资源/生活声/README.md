# 近景生活声

`step_a/b`、`wood_a/b`、`bread`适配自本地Foundation恢复原件，原文件保持在`参考资料/Foundation逆向成品-2026-10-13/outputs/foundation-audio-recovered/`。脚步对应原事件`3908144014`，木工轻敲对应`1044131224`，放置面包对应`4290601322`。事件到媒体关联及每个原件/加工件SHA256见[来源与处理.json](来源与处理.json)。原始音频版权归原作者，此处不标作CC0或本作原创。

处理为单声道22.05kHz PCM16，去除前沿空白、低通、短淡入淡出、降低峰值。`cup_0/1`为本项目原创的三模态衰减陶瓷接触合成。复现使用音乐工作流Python运行[烘焙工具](../../tools/bake_creation_life_foley.py)。

声音由实际可见动作触发，只有镜头很近时渐入；使用既有短声部空槽。全部变体只读，不修改原件，也不改居民经营状态。
