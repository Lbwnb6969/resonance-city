# 共鸣之城 · Resonance City

融合Tiny Glade自然美术、Townscaper模块化建筑、Foundation街坊生活与Cities: Skylines II城市工程机制的Godot城市音乐游戏。玩家画房屋、小路、林地与池塘，居民真实往来，房屋与街坊共同演奏。

## 开始试玩

使用Godot 4.7.2打开 `project.godot`，按F5；当前Compatibility，1440×900。项目已附完整轻量音色库，首次克隆直接播放；本地原始PCM缓存存在时优先使用。修改音频合成源码后，在项目根依次重新生成两套资源（`Godot`替换为本机引擎路径）：

```powershell
Godot --headless --path . --script tools/bake_creation_music_bank.gd
Godot --headless --path . --script tools/bake_creation_portable_bank.gd
```

普通试玩无需预烘焙；上述命令用于修改合成源码后的资源更新，不打包游戏。原始PCM约276.55MB只留本地，完整QOA轻量库约62.68MB纳管；含全部3907条音频与240种变化。也可双击：

- `启动Demo.cmd`：隔离新城，不写个人继续档。
- `继续我的河湾.cmd`：继续个人作品。
- `打开创作样例.cmd`：隔离创作样例。

其他特色样例入口在 [tools/样例启动器](tools/样例启动器/)。个人作品保存在Godot `user://`，作品收藏Ctrl+O、手记J、账本L；完整操作见 [快速开始](文档/Demo快速开始.md)。
