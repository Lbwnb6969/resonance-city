# 共鸣之城

以 Foundation、Tiny Glade、Townscaper 三个本地研究库为参考，重新构建的 Godot 城市音乐游戏。玩家自由塑造房屋、道路、水岸与植被，街坊沿实际路网生活，房屋与公共演出参与和谐、克制的音乐回应。

美术以 Tiny Glade 为基础；道路有自由曲线与两点直拉。当前是可编辑的古典河湾切片，完整经营、时代扩展、大城性能和最终草地观感仍在开发。

## 运行

使用 Godot **4.7.2** 导入根目录 `project.godot`，按 F5。默认 Compatibility 渲染器，1440×900。仓库包含当前代码、原创运行时几何、已入库资产及 Windows 原生音频模块；编辑器缓存由 Godot 重建。

- [快速开始](文档/Demo快速开始.md)：房屋扩展、露台、自由道路、水岸、植被、保存和街坊演出。
- [PROJECT](PROJECT.md)：当前进度、实际验证、下一步与未完成问题。
- [AI 开发入口](AI_START_HERE.md)：设计/实现 AI 的阅读顺序。
- [三库参考索引](文档/参考索引.md)：按机制选择研究资料。
- [最近的街坊演出与试听](验证记录/街坊演出_2026-10-14/README.md)。

作品保存于 Godot `user://city_creation_v1.json`，旧版本放用户目录 `废弃/城市存档/`。个人作品不上传。仓库内样例与验证夹具和个人作品隔离。
