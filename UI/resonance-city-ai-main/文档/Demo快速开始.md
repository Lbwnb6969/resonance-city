# 共鸣之城 · 快速开始

用Godot 4.7.2打开 `project.godot` 后F5，或双击下方入口。默认3D河湾，Compatibility，1440×900。

| 常用入口 | 行为 |
|---|---|
| [启动Demo](../启动Demo.cmd) | 从默认河湾开始，不读个人作品；隔离试玩 |
| [继续我的河湾](../继续我的河湾.cmd) / F5 | 读取个人继续档，编辑停手后自动保存 |
| [打开创作样例](../打开创作样例.cmd) | 隔离创作样例，直接试房屋、露台与跨河桥 |

## 先玩五分钟

1. 按1点房屋侧墙扩房、点顶面加层；空地点击建新屋，按住拖出一排。按2在屋顶留露台，有净空时自然出现花架与布篷。
2. 按3沿门前画小路，跨河会补桥，连通两岸居民生活。R切自由曲线/直拉，直拉时空格或右键锁段，Esc取消整笔。
3. 按5选房，改名字、配色/样式，或设面包坊、制琴坊、花圃茶座、演奏庭；建成14屋并完成茶聚与跨区问答后可设人文书院。先保留居所并接上道路，观察人真实到岗、采购和回家。
4. 按7画池塘，岸边会留下湿砂和扁石，池中出现有限浮叶/花。按9刷草丘、露岩或平顶台地，默认自然轮廓收放坡肩，关闭勾选可画规整圆丘，Shift临时压低；再按1在高处起屋、按3接路，陡坡自动铺石阶。新屋记住起笔海拔，水平扩房保持同一层地板。
5. 按8刷街坊、选音乐主题；选演奏庭邀请演出，街坊沿路到齐后演奏。J看成长手记，点「下一件事」或各目标按钮，镜头会带到对应位置，并选好工具、显示具体做法；L看生活账本里的库存、工人和停产原因；F1随时翻阅《营造与乐理手札》，Ctrl+O收藏完整作品。

红色预影表示本笔与结构、水域或支撑规则冲突；调整位置再落定。建设立即提交，不等待音乐资格。

## 成长与地标

居民实际买面包、品茶、收到木饰/画作并参加演出，会让各户从1级逐步长成5级名宅；门前花盆与暖灯、窗台花箱、铜铃、连廊、花架、金色风向标和彩绘圆窗随级别出现。已获得的等级会保留。

左上角「地标名胜 · 免费营建」列出里程碑。10屋加跨河桥解锁古钟瞭望塔（步行+15%、聚焦范围+3m）；累计烤出24份面包解锁水车磨坊（所有面包坊每炉+1、烘焙耗时缩短20%）；文艺复兴开启、两个街坊实际完成器乐问答后解锁圆顶音乐院（38m演出与自动接力）。选「免费选址」后点击有效预影放置，Esc取消；工具5选中地标可移动或整体回收，Ctrl+Z可恢复。水车磨坊须沿岸落位，再接路让工人来开炉。

## 九大工具

| 键/工具 | 操作 |
|---|---|
| 1 房屋 | 点墙扩展、点顶加层；拖动同一宿主/楼层建整笔，空地起笔建新屋；邻屋自动贴齐，Alt自由放置 |
| 2 露台 | 点墙伸出、点顶留花园；可连拖同层，系统补栏杆与支撑。工具4点布篷也能移除原露台 |
| 3 道路 | R/UI切自由曲线/直拉，Alt起笔临时直拉；按住左键画，直拉时空格/右键锁段，松开提交；Shift点击擦除整条路 |
| 4 移除 | 点单元，附属失去支撑层一起移除；面板选整栋或Shift点击；撤销恢复 |
| 5 用途/样式 | 点房选中，改名后Enter；选已解锁用途、灰泥/木构/石砌、配色，面包坊/工坊可开停生产，演奏庭可邀请/结束演出 |
| 6 植被 | 选橄榄/柏/灌木与笔刷大小，拖左键画；Shift擦除；自动避开房、路、水，建设冲突时保记录并隐藏 |
| 7 水岸 | 选池塘/引水渠与宽度；池塘空地起笔，引水从已有水边起笔；Shift点击填回自建水，主河保留 |
| 8 街坊 | 拖动划区、点击选区；起名、选五主题，可选已解锁时代风貌并连接两区共鸣，面板可开用途配器/邻里对答；Shift移除整区，后画区域覆盖成员归属 |
| 9 地形 | 抬高/压低/还原/露岩草丘/平顶台地/柔化缓坡，2/3.5/5m笔刷；自然轮廓开关、Shift起笔临时压低，一笔一次撤销 |

Esc取消未落定笔画；切工具也会取消。鼠标在UI上松开不把草稿误建到世界中。

## 镜头与保存

| 快捷键 | 行为 |
|---|---|
| 滚轮 / 右键 / 中键 | 缩放 / 转动 / 平移镜头 |
| H / F | 恢复全景 / 隐藏界面拍照 |
| Ctrl+Z / Ctrl+Shift+Z / Ctrl+Y | 撤销 / 重做 |
| Ctrl+S | 保存当前继续作品 |
| Ctrl+O | 打开作品收藏，保存完整可编辑版本；“示范河湾”页签可切换17座内置样例 |
| J / L / F1 | 河湾手记 / 生活账本 / 营造与乐理手札；Esc返回 |
| P / ♫ 点房试听 | 进入用途与试听视图，逐栋点按弹奏；按住P移动光标或按住左键划过不同屋顶可连续刮奏，不改作品或撤销历史 |
| V / 漫步按钮 | 进入街头透视视角；WASD/方向键行走、右键转头，再按V恢复原镜头 |
| F10 | 保存当前异常截图、城镇、相机与生活现场到 `user://render_diagnostics/`，用于定位画面问题 |
| F12 | 拍下带纸框和日期的明信片，保存在 `user://postcards/`；创作或漫步视角均可使用 |
| 音乐 / 光线按钮 | 静音或开启音乐 / 晴昼→夕照→星夜循环 |

继续档位于Godot `user://city_creation_v1.json`；作品收藏在 `user://city_creation_works/`。收藏可同名留新版本，打开另一作品前先保留当前作品，恢复房路、居民行程、库存、演出进度及镜头光线。关闭窗口保存已有编辑，未落定草稿不写入。从隔离样例启动不自动写个人继续档。游戏内切换示范会先把当前河湾留在“我的作品”，可随时回开；正常继续模式下，选中的示范及后续编辑作为当前继续作品。

工具8的跨区共鸣连线可以隔河连接两片街坊；音乐按双方实际时代与当前乐句一问一答。近处房屋清晰演奏，连线伙伴轻声回应，远方钟声保留方向，其余远处街坊安静。解锁新风貌后，老街坊会保留原来的样子，由你选择哪一片升级。完整 UI 规范与全量游戏内文案可参阅 [UI与全量游戏文案手册](UI与全量游戏文案手册.md)。
