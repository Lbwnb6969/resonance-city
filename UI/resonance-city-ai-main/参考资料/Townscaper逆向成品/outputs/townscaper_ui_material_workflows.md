# Townscaper UI、输入模式、太阳和材质业务链补充

本报告补齐覆盖审计发现的业务流程空白。依据发行 GameAssembly.dll 的 PDB 支持原生函数、IL2CPP 接口/枚举和完整场景组件；结论标记为静态回答，不伪造触屏、手柄、文件对话框实际操作。[方法、字面量与发行组件索引](townscaper_ui_workflow_evidence.json)覆盖 684 个 UI RVA，列出的 direct callees 仅辅助定位，本文行为结论来自函数体控制流。

## 真实场景入口与公共按钮状态

发行场景实际各有一个 UiMaster、SaveMenu、SaveSystem、KeyboardAndMouseControlRemap、InputModeManager、Toucher、SunButton、SunButtonGamepad、GamepadScreenCursor、MaterialMaster、TexturePngMaster。完整2517组件中没有 SaveCardsHandler、ControlBinding、KeyboardControlsMenu、GamepadStepper 的直接序列化实例；这些代码仍属于发行范围，但不能把其存在当作当前场景已启用。这里的“没有实例”指序列化结果，不断言运行时任何路径都不能创建它们。

UiMaster.MaybeSetup 的两次 IUiSetup 遍历、Boot dim/loading 接管见交互报告。AddMenuStateState 订阅的是 UpdateState.onTargetChange：target>=1 设置对应 MenuState bit，target<1 清 bit，变化时发出(old,new)事件。菜单门控因此跟随目标状态，不能等动画完成再解释 bit。CanTakeKeyInput mask=0x78d；GamepadCursorShouldWork 要求恰好64，组合其他菜单位会关游标。[3e50e0](native_application/3e50e0.c:1)；[9c9da0](native_application/9c9da0.c:1)；[3e5580](native_application/3e5580.c:1)；[3e5c00](native_application/3e5c00.c:1)

BaseButton 的 PointerClick 先保存 eventData，再调用事件 Use，选择 disabled/enabled 的音频反馈，最后执行 onClickAction 与 UnityEvent。**disabled 字段在此入口只改变声效类型，没有包住回调执行的 early return**；不能把视觉 disabled 当成统一业务阻断，实际 SaveMenu 等另有自身状态门控。Click() 是供键盘/手柄等调用的同类回调入口。Subscribe 将自身 click delegate 和 UnityEvent 与业务 listener 接起来。[874140](native_application/874140.c:1)；[873f30](native_application/873f30.c:1)；[8740c0](native_application/8740c0.c:1)

## Toucher：建造与手势切换

Toucher.LateUpdate按fingerId维护 Tracker，采样每帧位置/时间/平滑delta，历史Data最多256项；开始触摸时UI Raycast/active tracker选择决定是否参与世界手势。实际State枚举Idle0、Rotating1、Zooming2、Panning4、Pressing16、Dragging7、ZoomingAndPanning6。单指闲置先StopRotation、MasterClicker.TouchDown，进入Pressing；位移超过基于EventSystem.dragThreshold及0.04..0.1秒插值的动态阈值时取消点击(TouchUp false)转旋转。两可拖动指进入6；平均位置/delta做Pan，距离变化经过方向相关权重做PinchZoom。单指Rotating结束使用历史运动设置惯性；没有有效手指时Pressing以TouchUp true释放，其他取消/禁用路径TouchUp false。[306420](native_application/306420.c:1)；[306220](native_application/306220.c:1)；`dump.cs:389150`枚举不是从整数外观猜名字。

TouchDown先hover按actionId定位、记录pressTime并压下voxel反馈；TouchUp(commit=true且pointerPressUsed=false)按持续时间分支：>0.25秒且validRemove删除，否则AddClick；长按取色已由MasterClicker.Update把pointerPressUsed置true，因此TouchUp不会再建造/删除。释放始终停止bob/移除预声效。触控建造入口确实存在，不能由鼠标OnPointerClick忽略pointerId>=0反推不支持触控。[3d4660](native_application/3d4660.c:1)；[3d47b0](native_application/3d47b0.c:1)；[3d5000](native_application/3d5000.c:1)
