# GitHub参考资料发布范围

GitHub仅保留帮助理解和开发当前项目的技术报告、算法重建、GLSL着色器、定向C#/IL代码和许可说明。主设计以 [四库融合蓝图](../文档/code_artifact.md) 为准，按问题查 [参考索引](../文档/参考索引.md)。

完整四库原件仍在本地原路径。批量函数反编译、全量资产/调用图JSON、CSV/TSV大表、压缩证据、图片及原始美术/音频不再跟踪，不删除、不移动本地文件。报告内部列出的这些历史证据须在本地完整资料中查询。

当前游戏代码、实际运行所需的精选模型/纹理/声部库位于 `scripts/`、`资源/` 和 `数据/`，继续随项目提供。离线资源恢复脚本需要本地完整原件；运行现有游戏不依赖那些恢复导出。

`.gitignore` 忽略参考目录内未跟踪的原件；已经跟踪的精选代码与文档仍可正常修改提交。main当前所有文件合计必须小于100,000,000字节，由 `tools/sync_github_main.py` 在准备和推送时检查。
