# 设计参考库的精选发布范围

`ai-sync/resonance-city-ai`保留帮助理解和开发当前项目的精选技术报告、算法重建、GLSL、定向C#/IL与许可说明。`origin/resonance-city`额外保留参考源码，当前源码范围仍不等于四库原始素材全集。主设计以[V7.1施工总案](../文档/54_V7_最终施工改造总案.md)为准，按问题查[参考索引](../文档/参考索引.md)。

完整四库原件仍在本地原路径。批量函数反编译、全量资产/调用图JSON、CSV/TSV大表、压缩证据、图片及原始美术/音频不再跟踪，不删除、不移动本地文件。报告内部列出的这些历史证据须在本地完整资料中查询。

当前游戏代码、实际运行所需的模型/纹理/环境声及示范数据位于 `scripts/`、`资源/` 和 `数据/`，两库均保留；QOA轻量库69,951,895字节供首次克隆直接播放。原始PCM缓存可重建。部分离线提取脚本仍依赖未纳入当前树的Foundation源GLB/WAV、Tiny Glade索引或本机游戏安装；不能因正式资源可运行，就声称原素材提取也能完全离线完成。

`.gitignore` 忽略参考目录内未跟踪的原件；已经跟踪的精选代码与文档仍可正常修改提交。main当前所有文件合计必须小于100,000,000字节，由 `tools/sync_github_main.py` 在准备和推送时检查。

通用研究阅读包的完整`源码/`、Tiny Glade原渲染后端/UI/调试变体与资产纹理大表、Foundation批量原生伪代码、CS2重复`verified-il/`及成员反射导出不随GitHub发布。当前四库报告、恢复算法、Foundation行为树、CS2定向C#及来源说明继续保留。报告中的完整原件/IL/通用阅读包链接用于本地查询。

`资源/音乐/城市同步声部库.res`是本项目代码可重建的PCM缓存，也只保留本地；首次启动直接加载纳管的`城市同步声部库_轻量.res`，无需等待完整合成；改合成源码后按根README依次重建PCM与轻量库。必要贴图、模型、环境声和示范封面继续纳管，保持克隆后场景可运行。
