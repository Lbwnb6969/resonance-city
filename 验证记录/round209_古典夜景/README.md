示范文化馆/公园与两作者根屋来自 `art_direction_sample.gd` 的合法事务，它是用于切城和公建的受控样本；普通新河湾仍无预建公建，不赠送玩家成果。尚无真人审美、好玩或好听反馈，未测试大城/多种子风格。
