# Round 215 · 玩家房屋的古典联合屋顶

## 目的

本切片把“社区”从固定行政标签退到后台：玩家看到的是实际房屋沿同一条道路贴合后形成的连续古典屋顶体块。联合体是从已听见的建筑几何派生的表现缓存，不创建新的建筑、社区、音级或存档对象。

## 现行规则来源

- `文档/01_执行规格/spec.fabric.md` FB2：共享山墙净间隙 ≤0.10，连排按同一街面且最多 6 栋；身份、音级、阶段、Solo/Mute 仍逐栋独立。
- `文档/17_美术规格.md` §3.0：用檐口线融合、山墙贴片或顶面合并表现联合体；不旋转贴图，不把房子切成一个实体。
- `文档/14_城市生长.md` §2.3：自动生长产生的真实共享山墙/连排只改外观。

## 实现范围

`scripts/visual/joined_classical_roofs.gd` 提供 `setup(owner)` / `sync(owner)`。它读取 Demo 的 `shown_world`、`building_geometry`、`sprites`、可听帧和 `fabric_cache.shared_walls`：

1. 只取第一时代、已出生且已完成显示的住宅/商业建筑；公共文化馆永不进入联合。
2. 对真实 `shared_walls` 再检查同一真实道路 `road_id:side`、四向朝向相同、道路/水体没有穿过接缝。
3. 按同一实际道路的弧长排序，真实相邻关系组成 2–6 栋一段；不使用同 CID 全并，也不使用旧 `rows` 的 ID 排序。
4. 在两屋真实外翼与窄缝处延伸各自屋面，保留各自地脚高度、坡向、屋面尺度和异型高差，沿相接处形成连续的瓦面/檐口及石质高差侧墙。原 Sprite 继续独立命中、独立音级与独立屋型。
5. 相机平移/缩放只由父层变换处理；World、RNG、pending、音频和存档不写入。

## 最小验收

`tests/round215_joined_classical_roofs.gd` 使用真实 `build_first_composition_starter()`，Dummy/headless 验证真实首作成员、共享墙候选、同路同侧/朝向过滤、公共馆排除、2–6 段上限、未来出生过滤、道路/水体接缝过滤、相机复用和 World 快照不变。它只证明结构与几何合同，不能代替 Root 的 NVIDIA 实窗审图，也不等于真人“好看”结论。

## 异型接缝精修依据与实现决定

已完整核对 `tools/build_refined_valley_art.py` 的四类屋体/屋顶、`rotated_geometry`、`bake`、相关 manifest 的四向模型边界，并核对 `tools/build_classical_svg.py` 的正交投影与遮挡顺序。以下数值来自当前精制造型，不能用 manifest 的通用 `roof_eave_y` 代替露台真实平顶：

| 屋型 | 真实造型（原始模型单位） |
| --- | --- |
| 露台宅 | 平板宽 1.15、深 1.03、顶 .603；侧石栏顶 .725；帽石顶 .7535；屋内园/凉架保持原 Sprite |
| 瓦宅 | 瓦顶宽 1.20、深 1.10、檐 .574、脊 .834；脊沿模型 z，坡沿模型 x |
| 庭院宅 | 侧翼中心 x=±.39、瓦顶宽 .44、深 .98、檐 .552、脊 .667；只接外翼，院中开口不进入新面 |
| 商铺 | 瓦顶宽 1.20、深 1.01、中心 z=−.03、檐 .607、脊 .777；前棚和招牌仍属原 Sprite |

实际入口为模型 +z，生产贴图以 `180−orientation×90` 旋转后烘焙；运行时接面使用同一个四向基，不沿两屋中心连线任意转坡。模型横向到 World 的比例为 `geometry.scale×pixels_per_world/(28√2)`，模型高度到 World 投影高度为 `geometry.scale×pixels_per_world×√3/(2×14)`。瓦面外缘采用生成器的 .011 模型单位瓦口厚度；各半屋面在各自 Sprite 的地脚高度上计算，不能对每个顶点重采样地形把平顶扭弯。

首版把两种屋型的猜测檐高插值为同一条高瓦脊，实窗因此出现额外斜棚。精修保留相接两侧各自真实屋面：瓦面按原侧坡短延伸，平顶按 .603 水平延伸，二者在接缝处的高度差用石质竖直面封口并作短瓦收边。瓦宅之间形成真正连片的双坡谷；露台之间保留平板与前后帽石，不凭空添加瓦脊。只在两屋外檐实际重叠的进深范围接合，不跨庭院、不跨路水、不改原屋顶/原命中。

实现前的脚本、测试和证据完整备份于 `废弃/美术/round215_异型屋面接缝精修前/`；原实窗目录保持原位。共享关系缓存仍由 World 全量刷新提供；本切片不扩展离线资产管线或合并建筑身份。
