# Round218 古典自然地表

本轮在完整阅读 `17_美术规格`、`13_地形与自然`、`10_世界模型`、`19_城市生成管线`、`spec.space`、`spec.terrain`、`spec.asset` 及声音边界后，精修第一时代河谷的河岸相邻空地。

## 玩家现在看到的变化

- 河谷空地由连续世界坐标的 2048×2048 mipmap 地表纹理表现，暖土、灰绿高地和湿岸过渡跟随真实高度、坡度和岸距。
- 真实陆地内最多 96 组草簇、44 块小石；道路、已听房屋/地块、公共组件和活动留地会被裁掉。
- 水岸几何、道路、占地、留地、World、RNG、声音和存档没有改动；后时代和非河谷不启用第一时代自然细节。

## 验证

- `landscape_contract.json` / `raw.log`：独立 helper **9/9**。2048² 纹理带 mipmap，904 个真实连续地表面，草簇/石块上限，净空，同值 World fork 缓存和后时代门控通过。
- `live_2026-10-12T23-45-47/live.json`：Root 实际 NVIDIA/OpenGL/WASAPI **9/9**。1440 窗口截图、推移/昼光复用、4096 帧冻结 PCM 逐值一致、0 新增欠载。
