# 精致微缩河湾：地面、水与石岸

2026-10-12。用户要求整体美术与 UI 大改，精细化为第一条件。本项负责地图地面，不增加 HUD 或教程文字；建筑、植被与 UI 由本轮其它模块统一接入。

## 表现决策

默认 `river_valley` / `baseline` 使用暖砂低地、橄榄绿坡地、深青河槽、浅青岸水，与暖石墙、陶瓦、石蓝/灰绿作者屋顶和深松树冠共同形成微缩河湾。色板入口为 `scripts/visual/miniature_valley_material.gd`。

精细化通过材质层次完成：32 层线性插值水深过渡全部落在真实河界内；实际岸壁从真实地形高度降至水位，以三道石层、错缝、窄受光顶边和水线接地表现高度。原均匀横向白划线替换成跟随真实河道、错开长度和位置的慢波光。首版实窗暴露七道硬水带及大圆斑式坡地色差，本次加细水层并收敛相邻高程带明度，保留真实地形分层而降低底图感。

道路保留真实宽度、路径与投影，以暖石铺装取代近白平涂；窄接地边在路面下绘制，交叉口由全部真实路面覆盖内部边线。细石缘和交错铺装缝集中在已有人居的真实街段，路口不横穿其它道路绘制。地形保留克制的细粒，不铺满随机装饰。完整暖石街面限定实际可听 `city.era == 1`；后续时代的基础道路回到原表现，仅在真实 `building.era == 1` 的存留建筑周边保留石面，混合街段按附近实际古典建筑比例插值。不新增道路时代字段或改写建筑时代。自然水深与坡地材质不随城市时代整幅切换。

未建公共模板轮廓、抽象中心圆点和庭院金点从默认地图退场。已建公园、文化馆、真实留地和街坊关系继续呈现；规划候选由现有规划预影负责。其它地形族和 `clay/garden/paper` 对照保留原绘制路径。

普通建筑旁的石缘由实际建筑空间索引派生；真实作者家族出生后，下一次显示城市更新已住人街段材质。作者铺地仍保留真实表达色，不把普通家族涂成作者路线。材质不改变建筑纹理身份、地脚、道路拓扑、占地、正式随机流、声音、存档或正式事务。
