# Round152 · 规划路线平衡矩阵

这是 P12/P11 的离线技术证据，不是真人听感结论。

命令：

```text
D:\GODOT\Godot_v4.7.2-stable_win64_console.exe --headless --audio-driver Dummy --path . --script tests/round152_route_balance.gd
```

结果：`ROUND152_ROUTE_BALANCE checks=223 failures=[]`。

夹具从同一个 `river_valley` 种子出发，运行三种发展章程（紧凑核心、走廊连接、蓝绿文化网络）、三张章首变化卡（街墙聚拢、沿路回声、锚点回响），并在每个组合中分别提交“不建 / 公园 / 文化馆”三个公共落点。每个落点都经过生产 `ContinuousWorld` 的乐句结算，记录首个提交后的关系评分、出生时间、位置、道路距离、中心距离、服务对象与卡牌引用；同一组合还用生产 `public_planning_preview` 输出三秒分支元数据。

每个组合的三个公共分支都携带四项真实机会（社区主题、低音表达、商业律动、跨岸应答），并能由 `planning_next_action.gd` 生成 `P11-NEXT-ACTION/v1`，目标社区和角色槽保持一致。夹具还检查章程之间、卡牌之间的成长签名不全相同，避免用单一路线当作固定最优。

本批结果的可验证边界：蓝绿章程在存在公园/文化馆锚点时出现更高的首个关系评分；走廊章程的道路距离信号更低；紧凑章程的中心距离信号更集中。变化卡是条件性的：只有对应邻居、道路/站点或公共锚点关系存在时才改变候选排序/时机；没有资格时保持原路径，未伪造全城 R/V 加成。公共分支的角色资格和下一行动均可达。

该夹具没有输出 30 秒音频，也没有使用 WASAPI；真人盲听、路线审美因果与长期平衡仍待真实试玩确认。
