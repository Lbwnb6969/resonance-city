# Round208 古典街景地面

默认 `river_valley / baseline` 改用原始陆地三角面顶点色插值。顶点色由真实 `height_at` 连续混合暖土与浅橄榄色，并以真实坡向作克制明暗变化；投影高度、岸线与 World 不变。离散高程分色与等高圈只保留在既有候选风格。

第一时代的未建道路保留真实路径与半宽，颜色混入脚下地面，退出整条石边；有真实第一时代建筑的街道前缘才显示暖石底、三排交错细缝和接地边。第二时代起仍使用既有道路底色，只保留实际旧古典建筑周边的石材；新年代建筑不凭空继承古典街面。32 层水深与真实石岸保持原实现。声音、World、拓扑、占地和存档没有写入。

代码直接通过现有 Demo 的 GroundLayer.sync 接入，未改 Demo/UI/资产/scenery。几何与顶点色按地形和道路身份保留；平移、缩放复用已有路面绘制命令，真实建筑出生才刷新石铺前缘。

验证命令：

`D:/GODOT/Godot_v4.7.2-stable_win64_console.exe --headless --audio-driver Dummy --path . --script res://tests/round208_classical_ground.gd --log-file 验证记录/round208_古典街景地面/ground_dummy.log`

结果：退出 0，14/14。904 个连续三角面面积 1475.999950，与真实两岸面积 1475.999999 一致；没有进入水域。沿真实山坡的 1000 个采样色各异，相邻最大 RGB 向量差 0.000237。未建土路与地面最大色差 0.046014；默认已有街面 68 段石铺、134 条接地边、501 条细石缝均在真实道路内。合同覆盖只读快照、真实作者出生、时代/候选/地形家族隔离、相机缓存和候选切回默认。

首版 Dummy 暴露此前非河谷分支的空数组类型赋值错误，已改为类型保持的 assign；失败日志和合同保留于 `废弃/验证记录/round208_古典街景/地面首版Dummy/`。测试脚本初次命名与原生 Material/Expression 冲突，编译时改为 Miniature/PlayerExpression。
