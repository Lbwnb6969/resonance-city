# 第一时代精制河湾与界面集成

2026-10-12。依据用户最新要求直接深化当前可玩的古希腊/罗马第一时代，精细化优先；建筑角度须协调道路，替换旧玻璃格窗。Root 集成，子 Agent 分别交付资产/catalog、地面/水、临街方向、古典灯具并只读审图。没有使用 AI 生图或 Blender；本批资产通过可复现 Python 几何投影产生，Blender 工具仍可用于下一批制作。

## 实际行为

默认河湾已换为8种建筑×四向、2类树，共34个资源。石砌门洞、深窗与木百叶、陶瓦与檐口、内庭柱廊、敞开商铺、六柱山墙文化馆替代旧外观。每个方向独立旋转模型几何、计算光照/遮挡及 cast/contact 遮罩；不是旋转成品图。只读真实道路、地块/设施入口决定门面方向，声音卡、试听预影和正式房屋共用同一模板。第一时代建筑按出生时代保留，后时代取原独立时代入口。

树、暖石街面、石岸接地、32层柔和水深已接入。街灯的第一时代分支是石质方柱与陶制油灯，后时代保留原灯具。UI统一深松绿/暖纸色，章程示意卡与真实房屋声音卡分层；确认区固定在滚动内容外；800×600使用原生像素、按菜单净空移动实际目标镜头。面板打开时收起重复说明，未建公共模板不作为默认景物显眼呈现。World、实际占地、声学/声音规则、玩家作品和保存字段没有改变。

首版导入/并行编译、菜单高度、观察帧与画布缩放问题、报告前退出的次版实窗、菜单补修与探针未启动揭示时的截图完整保留在 `../../废弃/验证记录/round206_精制河湾/`。首版窗格合同及留存范围见 `../../废弃/美术/round206_首版窗格/`；原生产资产和三组候选保留。`run_*/progress.json`是各截图时的中途检查点，最终结论读取同目录`live.json`。
