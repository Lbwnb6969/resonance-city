## 一、 修路系统设计方案：「随手画 / 直路 / 双点曲路」三模合一与「严丝合缝闭合快感」

### 1. 三种修路模式的无感切换与同轨操作流

玩家既可以点击底部道路画具气泡旁的 3 枚极简微印章（快捷键 **`1 自由画` / `2 直路` / `3 曲路`**），也可以在默认模式下直接通过**「按住拖拽 vs 单击点选」**智能触发，完全不增加学习负担：

| 修路模式 | 触发操作方式（直觉无门槛） | 底层几何采样与磁吸规则 | 核心爽感与适用场景 |
| :--- | :--- | :--- | :--- |
| **① 随手自由画**<br>(`MODE_FREEHAND = 0`) | **按住鼠标左键直接拖动**（与现有手感 100% 一致） | 实时采集鼠标轨迹，经 **Ramer-Douglas-Peucker（RDP）稀化 + Catmull-Rom 样条平滑**过滤手抖毛刺。 | 蜿蜒林间小径、贴岸自然羊肠小道。 |
| **② 精准直路**<br>(`MODE_STRAIGHT = 1`) | **单击定起点 $P_0$ → 移动鼠标实时预览笔直虚线与相交夹角 $	heta$ → 再单击定终点 $P_1$** | 生成 $P_0 	o P_1$ 的等距直线段（步长 `2.0m`）；支持**已有道路切线/法线角度吸附（$15^\circ$ 刻度步进，$30^\circ / 45^\circ / 60^\circ / 90^\circ / 180^\circ$ 强磁吸）**。 | 古典神庙中轴大道、规整街坊网格、跨河笔直石拱桥。 |
| **③ 双点丝滑曲路**<br>(`MODE_CURVE = 2`) | **第 1 下点起点 $P_0$ → 移鼠标拉出切线方向点第 2 下定控制点 $P_1$ → 移鼠标预览弯道与弯曲角 $lpha$ 点第 3 下定终点 $P_2$** | 采用 **二次贝塞尔曲线（Quadratic Bézier）** $B(t) = (1-t)^2 P_0 + 2(1-t)t P_1 + t^2 P_2$，按弧长等距重采样为点列写入 `state.roads`（**零存档结构破坏**）。 | 严丝合缝的 $90^\circ$ 街角圆弧、环湖优美弯道、完美正圆环岛。 |

> **智能混合交互细节**：
> - 当鼠标移动距离起点 `< 0.5m` 即松开左键时，判定为**「单击定锚点」**，自动进入直路/曲路尺规预览；若按住左键拖动超过 `0.8m`，则直接作为**「随手自由画」**实时拉出墨迹。
> - 在尺规预览途中，按 **`Tab` 键**可随时在「直路」与「双点曲路」之间无缝切换；按住 **`Alt` 键**可临时关闭角度磁吸进行 `1°` 级无极微调；按 **`右键 / Esc`** 取消当前锚点。

### 2. 看得见的「道路相交夹角 $	heta$」与「道路自身弯曲角度 $lpha$」烫金量角罗盘

为了让修路过程充满“尺规作图般的秩序美感”，在地面预览层（`city_creation_placement_preview.gd`）用 **1 个共享 `ImmediateMesh` + 1 枚悬浮羊皮纸微印章**实时绘制两套视觉反馈：

```
  [A. 道路相交夹角罗盘 (Intersection Angle θ)]       [B. 曲路自身弯曲角与内切圆弧 (Bend Angle α & R)]
  
            已有道路切线 T_road ──►                          P1 (第1次点击: 切线交点/控制锚点)
                         ╱ ╲                                   ╱  ·  ╲  弯曲转角 α = 90°
                        ╱   ╲  ╭──────────╮                   ╱ ╭───╮ ╲ (显示金色内切扇弧)
                       ╱ 90° ╲ │ ✦ 90°正交│                  ╱  │90°│  ╲
                      ╱       ╲╰──────────╯                 ●───┴───┴───●
                     ●═════════●                           P0 (起点)     P2 (第2次点击: 终点)
                    P0(起点)   P1(当前鼠标)                └─── 等臂对称正圆弧 R = 12.0m ───┘
```

1. **道路相交夹角（Intersection Angle，$	heta$）**：
   - 当起点 $P_0$ 吸附在已有道路节点或路段上时，取已有道路在该点的单位切向量 $ec{T}_{	ext{road}}$，与新路起始方向 $ec{D} = (P_1 - P_0).	ext{normalized}()$ 计算夹角：
     $$	heta = 	ext{rad\_to\_deg}(rccos(	ext{clamp}(ec{T}_{	ext{road}} \cdot ec{D}, -1.0, 1.0)))$$
   - 若 $	heta > 90^\circ$，同时计出锐角补角 $	heta_{	ext{acute}} = 180^\circ - 	heta$（便于观察正交与斜交），在交点处贴地绘制半径 `2.2m` 的**暖金刻度虚线扇弧**。
   - **黄金角度磁吸**：当 $	heta$ 接近 $30^\circ, 45^\circ, 60^\circ, 90^\circ, 120^\circ, 135^\circ, 180^\circ$（误差 $\le 2.5^\circ$）时，自动将方向向量 $ec{D}$ 吸附到精确角度，扇弧瞬间由半透明米金转为**高亮鎏金色**，悬浮印章显示 **`✦ 90° 正交`** 或 **`✦ 180° 顺延`**。
2. **曲路自身弯曲角度与曲率半径（Road Bend Angle & Radius，$lpha, R$）**：
   - 在双点曲路模式下，确定起点 $P_0$ 与切线锚点 $P_1$ 后，移动终点 $P_2$ 时，实时计算入口切线 $ec{T}_{	ext{in}} = (P_1 - P_0).	ext{normalized}()$ 与出口切线 $ec{T}_{	ext{out}} = (P_2 - P_1).	ext{normalized}()$ 的**道路弯曲偏转角 $lpha$** 以及控制点内折角 $eta = 180^\circ - lpha$：
     $$lpha = 	ext{rad\_to\_deg}(rccos(	ext{clamp}(ec{T}_{	ext{in}} \cdot ec{T}_{	ext{out}}, -1.0, 1.0)))$$
   - 在控制点 $P_1$ 内侧绘制**金色切线虚线框（$P_0 	o P_1 	o P_2$）与内切弯曲扇弧**，并标出 **`弯度 90° · R 12.0m`**。
   - **等臂对称正圆弧磁吸（Symmetric Arc Snap）**：当两段切线臂长 $L_1 = |P_1 - P_0|$ 与 $L_2 = |P_2 - P_1|$ 差值 `< 0.6m` 时，自动将 $|P_2 - P_1|$ 磁吸锁入 $L_1$，生成一条曲率极其均匀的对称圆弧（此时等效圆弧半径 $R = L_1 / 	an(lpha / 2)$）。

### 3. 「严丝合缝最后闭合（Snap-to-Close Euphoria）」的三重反馈

当玩家将直路或曲路的终点移近已有路网节点、路中段、桥梁端口或自身起点（距离 $\le 1.8	ext{m}$）时：
1. **双端切线咬合（Tangent & Orthogonal Lock）**：终点坐标自动锁入目标道路中心线，若目标点与当前进入切线夹角接近 $180^\circ$（顺接）或 $90^\circ$（丁字正交），曲路控制点会自动微调以保证闭合处**零折角毛刺**；
2. **视觉无缝织合与环岛涌现**：闭合处亮起双层暖金同心圆环（`Closure Halo`），原本断开的路缘鹅卵石瞬间无缝咬合；若本次闭合围成了一个面积在 `28m² ~ 220m²` 之间的闭合街心环路（Loop），环心自动触发 `StreetWonderPlan` 涌现**环岛双层喷泉或街心花坛**；
3. **听觉五度落锁声**：角度磁吸滑过刻度时发出极轻柔的**鲁特琴品丝轻拨音（Tick）**；最终点击完成闭合的瞬间，奏响温润的**五度双音钟琴（Chime P5）**。

## 二、 建筑有机微雕系统：低开销实现「微掰角度 / 圆角 / 外挑伸出 / 半圆阳台」

### 1. 工程与设计取舍：为什么选择「参数化微雕基因 + 静态合批」而非实时 CSG？

在 300 栋建筑同屏的《共鸣之城》中，如果使用实时布尔运算（CSG）或任意自由网格顶点拖拽，每次建房/修路都会引发沉重的法线重算、UV 撕裂与碰撞体耗时。
最契合本项目的成熟方案（参考《Tiny Glade》与《Townscaper》的底层哲学）是：**「4 项参数化有机微雕基因（Parametric Organic Genes）+ 零 CSG 预制扇片/切角柱替换 + `house_merge` 单网格合批」**。

| 有机微雕维度 | 存档轻量字段（兼容旧档默认值） | 玩家的直觉操作与闭合快感 | 底层零 CSG 几何实现方案 | 面数与性能预算 |
| :--- | :--- | :--- | :--- | :--- |
| **1. 建筑组合微掰角度**<br>（有机折角翼楼 / 贴弯路微弯） | `bend_angle_deg: float`<br>（默认 `0.0`，范围 `-30° ~ +30°`） | 当两栋房拼接组合、贴着弯曲道路建造、或拖拽屋脊微调手柄时，侧翼楼体可**有机掰弯 $\pm 15^\circ \sim 30^\circ$**，完美贴合弯道弧线。 | **分段刚体铰链旋转 + 扇形脊瓦楔子（Hinged Wing + Mansard Wedge）**：将多开间或组合房屋拆为主体段与侧翼段，侧翼绕交界轴旋转 $\delta$；屋脊交界缝隙自动插入 1 枚 **`12-tri` 扇形瓦面楔子**严丝合缝封顶。 | **仅 `+12 ~ 24 tris`**<br>0 额外 Draw Call |
| **2. 墙体圆角与柔和导角**<br>（直角石墙变温润圆角） | `corner_bevel: int`<br>（`0` 直角 / `1` 斜导角 / `2` 圆角） | 轻点屋角印章或滚轮切换，锋利的 $90^\circ$ 直角墙瞬间化作**温润的 $45^\circ$ 斜切导角或三段式平滑圆角**，屋檐同步生出扇形圆弧飞檐。 | **3 段式切角柱 + 平滑法线（3-Segment Smooth Chamfer）**：外露墙角顶点向内退让 `0.35m`，用 **3 段折面（各 $30^\circ$）+ 共享平滑法线（Smooth Vertex Normals）** 渲染，在光照下呈现丝滑圆柱高光。 | 每个圆角仅 **`+18 tris`**（四角全圆仅 `+72 tris`） |
| **3. 局部有机伸出（外挑）**<br>（二层悬挑木阁 / 凸肚飘窗） | `extrude_mask: int`<br>（按位标记四面墙外挑/飘窗） | 向外轻拉二层楼板或一层墙面，二层即**向外有机挑出 `0.45m` 形成中世纪斜撑悬挑楼阁（Jettying）**，或在一层鼓出**六角凸肚采光飘窗（Oriel Bay Window）**。 | **法线外推 + 预制木石牛腿斜撑（Corbel Brackets）**：二层墙面顶点沿法线外推 `0.45m`，底部自动挂载 2 根 `8-tri` 木构/石雕斜撑；飘窗采用 `36-tri` 三面梯形凸窗贴墙合批。 | 每次外挑/飘窗仅 **`+28 ~ 48 tris`** |
| **4. 半圆弧形阳台与转角花台**<br>（圆弧锻铁露台 / 半圆观景台） | `balcony_arc: int`<br>（`0` 无 / `1` 正面半圆 $180^\circ$ / `2` 转角圆弧 $270^\circ$） | 在临水、面朝花园或转角二层窗下轻点，墙面长出**半圆形石雕托底阳台（或转角 $270^\circ$ 包裹式圆弧露台）**，配锻铁栏杆与天竺葵花箱，小人会走上圆阳台凭栏听曲。 | **6 段扇形弧板 + 弧形石托 + 极简栏杆（6-Segment Fan Slab）**：半圆阳台由 6 片梯形扇面（`36 tris`）、底部石雕托盘（`16 tris`）与 6 根极简锻铁立柱（`48 tris`）拼成。 | 每座圆阳台仅 **`~100 tris`**（`zoom > 28m` 自动 LOD 隐藏细栏杆） |

### 2. 「修曲路 ↔ 捏有机房」的双向咬合快感（Road-to-Building Organic Snap）

- **贴弯路自动微弯（Auto Curve-Hugging）**：当玩家在一条弯曲道路旁（距离路缘 `<= 4.5m`）放置或扩建房屋时，系统自动采样房屋两端点对应的道路切线夹角差 $\Delta 	heta$；若 $8^\circ \le |\Delta 	heta| \le 30^\circ$，房屋**自动将 `bend_angle_deg` 设为 $\Delta 	heta$ 并开启 `corner_bevel = 2` 圆角**，让建筑像顺着河岸与弯道自然生长出来一样严丝合缝！
- **极简交互入口（不增设臃肿弹窗）**：结合六期减法后的屋顶罗盘，选中房屋时左翼仅保留 `[时代]`、`[原型]` 与一枚 **`[🌿 有机微雕]`** 循环印章（或直接拖拽房屋四角的微光金色控制球），轻点即可在 **「规整直墙 → 温润圆角 → 二层外挑飘窗 → 半圆铁艺阳台 → 随路微折」** 之间丝滑切换。

## 三、 音乐系统深度审视：砍掉什么、完善什么？（打造四层透明又极致和谐的室内乐）

### 1. 音乐系统必须「果断砍掉 / 精简」的 3 处干扰源

| 建议砍掉/精简的机制 | 现有代码位置与听感问题（为什么声部多了会不够清澈？） | 减法与重构方案（Less Mud, More Harmony） |
| :--- | :--- | :--- |
| **1. 砍掉「多街区同时挤在中音区（C4–C5）跑主旋律」的同频段混叠** | `city_creation_music.gd` 中多个活跃街坊主干（Stems）和工坊声部往往在同一八度（MIDI `60 ~ 72`）同时演奏八分音符旋律，导致中频拥挤、缺乏主次。 | **严格执行「唯一领唱者法则（Single Lead Soloist Rule）」**：同一时刻全城只允许镜头焦点所在的 **1 个主街区**演奏第 3 层主旋律，其余相邻街区自动退居第 2 层演奏分解琶音或长音托底。 |
| **2. 砍掉「100% 满密度的机械平行三度/六度伴音」** | `city_creation_harmonic_dyads.gd` 对每个长音都机械叠加同向平行三度/六度，连续听久了像电子风琴自动伴奏，缺乏真人室内乐的呼吸对话。 | **保留 65% 双音 + 引入 30% 呼吸留白与反向/斜向对位**：主旋律密集上行时，伴音保持共同音驻留（斜向）或反向落往低三度/低六度；主旋律长音停顿时，内声部才轻轻补上两个八分音符的应答走句（Call & Response）。 |
| **3. 砍掉「细碎频繁的高频生活抢拍短音」** | 当视野内有多个小人过桥、茶座举杯、工坊运转时，若短槽（Short Slots）频繁随机插入高频叮当声，会打碎长轨建立的宁静心流。 | **收敛为「每小节最多 2 颗高八度星芒泛音点缀」**：每小节（`3.0s`）只取离镜头最近的 1~2 次生活交互（或曲路闭合/走上圆阳台），严格对齐 16 分音符网格并锁入当前和弦的高八度（C5–E6）五度/六度泛音。 |

### 2. 重构后的「四层立体透明室内乐架构（4-Layer Transparent Chamber Architecture）」

在严守现有 `12 长轨 + 4 短槽 + 6 总线 + 2 自然声` 预算的前提下，将全城声部严格锁入 **4 个互不打架的音区（Pitch Register）与职能层**：

| 声部层级 | 专属音区隔离 | 触发来源与代表配器 | 怎么做到既多层次又极致和谐？ |
| :--- | :--- | :--- | :--- |
| **第 4 层：星芒泛音层**<br>(`Sparkle Ornament`) | **高音区 C5–E6**<br>(MIDI `76–88`) | 曲路严丝合缝闭合、过桥、走上半圆阳台、钟表尾拍（竖琴泛音 / 钢片琴 / 微风铜铃） | 只在主旋律长音尾拍或留白处闪烁，每小节最多 2 颗，严格吸附当前和弦的 **5 度 / 大 6 度 / 9 度**。 |
| **第 3 层：唯一领唱层**<br>(`Single Cantabile Lead`) | **中高音区 E4–E5**<br>(MIDI `64–76`) | 镜头当前聚焦主街区的代表乐器（古典长笛 / 中世鲁特琴 / 工业双簧管 / 现代毛毡钢琴） | 全城永远只有 **1 个清晰的主唱声部**；当街区包含曲路或圆角/半圆阳台建筑时，自动延长连音线（Legato）包络。 |
| **第 2 层：对位织体层**<br>(`Counterpoint & Arpeggio`) | **中低音区 E3–E4**<br>(MIDI `52–64`) | 二阶互哺工坊（茶座+面包、书院+制琴）、次焦点街区（原声木吉他琶音 / 中提琴 / 单簧管） | 与第 3 层形成**反向/斜向对位**：第 3 层行进时第 2 层驻留或反向；第 3 层停顿时第 2 层走分解琶音填空。 |

```gdscript
class_name CityCreationRoadCurveSnap
extends RefCounted

## 天际线式三模修路引擎：支持自由画(0)、精准直路(1)、双点二次贝塞尔曲路(2)
## 提供道路相交夹角(theta)、道路自身弯曲角(alpha)、黄金角度磁吸与1.8m终点严丝合缝闭合。

const MODE_FREEHAND := 0
const MODE_STRAIGHT := 1
const MODE_CURVE := 2

const SNAP_ANGLES_DEG := [0.0, 30.0, 45.0, 60.0, 90.0, 120.0, 135.0, 150.0, 180.0]
const ANGLE_SNAP_TOLERANCE_DEG := 2.8
const CLOSURE_SNAP_RADIUS := 1.8
const SYMMETRIC_ARM_TOLERANCE := 0.65
const SAMPLE_STEP := 1.8

## 1. 计算新路起点与已有道路切线的相交夹角与磁吸修正方向
static func compute_intersection_snap(
	start_pos: Vector2,
	target_pos: Vector2,
	ref_tangent: Vector2,
	enable_snap: bool = true
) -> Dictionary:
	var raw_vec := target_pos - start_pos
	var dist := raw_vec.length()
	if dist < 0.001 or ref_tangent.length_squared() < 0.001:
		return {
			"snapped_target": target_pos,
			"angle_deg": 0.0,
			"acute_deg": 0.0,
			"snapped": false,
			"snap_label": ""
		}
	var dir := raw_vec / dist
	var ref := ref_tangent.normalized()
	var dot_val := clampf(ref.dot(dir), -1.0, 1.0)
	var cross_val := ref.x * dir.y - ref.y * dir.x
	var raw_deg := rad_to_deg(acos(dot_val))
	var snapped := false
	var chosen_deg := raw_deg
	if enable_snap:
		for target_deg in SNAP_ANGLES_DEG:
			if absf(raw_deg - target_deg) <= ANGLE_SNAP_TOLERANCE_DEG:
				chosen_deg = target_deg
				snapped = true
				break
	var sign_dir := 1.0 if cross_val >= 0.0 else -1.0
	var final_dir := dir
	if snapped:
		final_dir = ref.rotated(deg_to_rad(chosen_deg * sign_dir)).normalized()
	var acute := chosen_deg if chosen_deg <= 90.0 else 180.0 - chosen_deg
	var label := "%d°" % roundi(acute)
	if snapped:
		if is_equal_approx(acute, 90.0):
			label = "✦ 90° 正交"
		elif is_equal_approx(chosen_deg, 180.0) or is_equal_approx(chosen_deg, 0.0):
			label = "✦ 180° 顺接"
		else:
			label = "✦ %d°" % roundi(acute)
	return {
		"snapped_target": start_pos + final_dir * dist,
		"direction": final_dir,
		"angle_deg": chosen_deg,
		"acute_deg": acute,
		"snapped": snapped,
		"snap_label": label
	}

## 2. 计算双点曲路(P0 -> 控制点P1 -> 终点P2)的自身弯曲角度、等臂正圆弧磁吸与曲率半径
static func compute_curve_metrics(
	p0: Vector2,
	p1_control: Vector2,
	p2_raw: Vector2,
	enable_snap: bool = true
) -> Dictionary:
	var v_in := p1_control - p0
	var v_out := p2_raw - p1_control
	var len_in := v_in.length()
	var len_out := v_out.length()
	if len_in < 0.1 or len_out < 0.1:
		return {
			"p2_snapped": p2_raw,
			"bend_angle_deg": 0.0,
			"interior_angle_deg": 180.0,
			"radius": 0.0,
			"is_symmetric_arc": false,
			"curve_label": "0°"
		}
	var t_in := v_in / len_in
	var t_out := v_out / len_out
	# 用入口切线与出口切线计算弯曲偏转角 alpha
	var snap_info := compute_intersection_snap(p1_control, p2_raw, t_in, enable_snap)
	var out_dir: Vector2 = snap_info.get("direction", t_out)
	var bend_deg: float = snap_info.get("angle_deg", 0.0)
	var is_sym := false
	if enable_snap and absf(len_out - len_in) <= SYMMETRIC_ARM_TOLERANCE:
		len_out = len_in
		is_sym = true
	var p2_final := p1_control + out_dir * len_out
	var interior_deg := 180.0 - bend_deg
	var half_rad := deg_to_rad(clampf(bend_deg * 0.5, 1.0, 89.0))
	var radius := (len_in + len_out) * 0.5 / tan(half_rad)
	var prefix := "✦ 等臂圆弧 " if is_sym else "弯度 "
	var label := "%s%d° · R %.1fm" % [prefix, roundi(bend_deg), radius]
	return {
		"p2_snapped": p2_final,
		"bend_angle_deg": bend_deg,
		"interior_angle_deg": interior_deg,
		"radius": radius,
		"is_symmetric_arc": is_sym,
		"snapped": bool(snap_info.get("snapped", false)) or is_sym,
		"curve_label": label
	}

## 3. 生成精准直路等距点列
static func sample_straight_road(p0: Vector2, p1: Vector2, step: float = SAMPLE_STEP) -> PackedVector2Array:
	var pts := PackedVector2Array()
	var dist := p0.distance_to(p1)
	var count := maxi(2, ceili(dist / maxf(0.5, step)) + 1)
	for i in range(count):
		var t := float(i) / float(count - 1)
		pts.append(p0.lerp(p1, t))
	return pts

## 4. 生成二次贝塞尔曲路等距弧长采样点列
static func sample_quadratic_curve_road(
	p0: Vector2,
	p1_ctrl: Vector2,
	p2: Vector2,
	step: float = SAMPLE_STEP
) -> PackedVector2Array:
	var chord_len := p0.distance_to(p1_ctrl) + p1_ctrl.distance_to(p2)
	var raw_steps := maxi(6, ceili(chord_len / maxf(0.5, step * 0.5)))
	var lut := PackedVector2Array()
	var cum_len := PackedFloat32Array()
	var total := 0.0
	for i in range(raw_steps + 1):
		var t := float(i) / float(raw_steps)
		var omt := 1.0 - t
		var pt := (omt * omt) * p0 + (2.0 * omt * t) * p1_ctrl + (t * t) * p2
		if i > 0:
			total += lut[i - 1].distance_to(pt)
		lut.append(pt)
		cum_len.append(total)
	if total < 0.01:
		return PackedVector2Array([p0, p2])
	var final_count := maxi(3, ceili(total / maxf(0.5, step)) + 1)
	var out := PackedVector2Array()
	var cursor := 0
	for j in range(final_count):
		var target_d := total * (float(j) / float(final_count - 1))
		while cursor < cum_len.size() - 2 and cum_len[cursor + 1] < target_d:
			cursor += 1
		var seg_len := maxf(0.0001, cum_len[cursor + 1] - cum_len[cursor])
		var local_t := clampf((target_d - cum_len[cursor]) / seg_len, 0.0, 1.0)
		out.append(lut[cursor].lerp(lut[cursor + 1], local_t))
	return out

## 5. 检测终点严丝合缝闭合吸附（支持吸附已有道路端点、路段投影点或自身起点形成环岛）
static func find_closure_snap(
	query_pos: Vector2,
	roads: Array,
	current_start: Vector2 = Vector2.INF,
	snap_radius: float = CLOSURE_SNAP_RADIUS
) -> Dictionary:
	var best_pos := query_pos
	var best_tangent := Vector2.RIGHT
	var best_dist_sq := snap_radius * snap_radius
	var found := false
	var is_loop_close := false
	if current_start.is_finite() and query_pos.distance_squared_to(current_start) <= best_dist_sq:
		return {
			"closed": true,
			"is_loop": true,
			"snap_pos": current_start,
			"tangent": Vector2.RIGHT,
			"closure_label": "✦ 环路严丝合缝闭合"
		}
	for road in roads:
		var pts: Array = road.get("points", [])
		for i in range(pts.size()):
			var p: Vector2 = pts[i]
			var d2 := query_pos.distance_squared_to(p)
			if d2 < best_dist_sq:
				best_dist_sq = d2
				best_pos = p
				found = true
				if i + 1 < pts.size():
					best_tangent = (pts[i + 1] - p).normalized()
				elif i > 0:
					best_tangent = (p - pts[i - 1]).normalized()
	return {
		"closed": found,
		"is_loop": is_loop_close,
		"snap_pos": best_pos,
		"tangent": best_tangent,
		"closure_label": "✦ 严丝合缝闭合" if found else ""
	}
```

class_name CityCreationRoadProtractorGizmo
extends RefCounted

## 在修直路/修曲路预览时，绘制地面暖金夹角扇弧(theta)、曲路内切弯曲弧(alpha)与闭合双层金环。

const COLOR_GOLD_NORMAL := Color(0.88, 0.76, 0.48, 0.72)
const COLOR_GOLD_SNAPPED := Color(0.98, 0.85, 0.42, 0.96)
const COLOR_CLOSURE_RING := Color(1.0, 0.88, 0.46, 0.95)

static func draw_intersection_protractor(
	mesh: ImmediateMesh,
	origin: Vector2,
	ref_tangent: Vector2,
	current_dir: Vector2,
	height_fn: Callable,
	snapped: bool = false,
	radius: float = 2.2
) -> void:
	if ref_tangent.length_squared() < 0.01 or current_dir.length_squared() < 0.01:
		return
	var col := COLOR_GOLD_SNAPPED if snapped else COLOR_GOLD_NORMAL
	var a0 := ref_tangent.angle()
	var a1 := current_dir.angle()
	var diff := wrapf(a1 - a0, -PI, PI)
	var steps := 18
	mesh.surface_begin(Mesh.PRIMITIVE_LINE_STRIP)
	for i in range(steps + 1):
		var t := float(i) / float(steps)
		var ang := a0 + diff * t
		var p2 := origin + Vector2.from_angle(ang) * radius
		var y: float = float(height_fn.call(p2)) + 0.06
		mesh.surface_set_color(col)
		mesh.surface_add_vertex(Vector3(p2.x, y, p2.y))
	mesh.surface_end()

static func draw_curve_tangent_cage_and_arc(
	mesh: ImmediateMesh,
	p0: Vector2,
	p1_ctrl: Vector2,
	p2: Vector2,
	height_fn: Callable,
	snapped: bool = false
) -> void:
	var col := COLOR_GOLD_SNAPPED if snapped else COLOR_GOLD_NORMAL
	# 1. 绘制 P0 -> P1 -> P2 切线控制虚线框
	_draw_dashed_segment(mesh, p0, p1_ctrl, height_fn, col, 0.45)
	_draw_dashed_segment(mesh, p1_ctrl, p2, height_fn, col, 0.45)
	# 2. 在控制点 P1 内侧绘制道路弯曲转角扇弧
	var dir_to_p0 := (p0 - p1_ctrl).normalized()
	var dir_to_p2 := (p2 - p1_ctrl).normalized()
	var arc_r := clampf(minf(p0.distance_to(p1_ctrl), p2.distance_to(p1_ctrl)) * 0.32, 0.8, 2.6)
	draw_intersection_protractor(mesh, p1_ctrl, dir_to_p0, dir_to_p2, height_fn, snapped, arc_r)

static func draw_closure_lock_rings(
	mesh: ImmediateMesh,
	snap_pos: Vector2,
	height_fn: Callable,
	pulse_phase: float = 0.0
) -> void:
	var y: float = float(height_fn.call(snap_pos)) + 0.07
	for ring_idx in range(2):
		var r := 0.65 + float(ring_idx) * 0.42 + sin(pulse_phase * TAU) * 0.06
		var steps := 24
		mesh.surface_begin(Mesh.PRIMITIVE_LINE_STRIP)
		for i in range(steps + 1):
			var ang := TAU * float(i) / float(steps)
			var pt := snap_pos + Vector2.from_angle(ang) * r
			mesh.surface_set_color(COLOR_CLOSURE_RING)
			mesh.surface_add_vertex(Vector3(pt.x, y, pt.y))
		mesh.surface_end()

static func _draw_dashed_segment(
	mesh: ImmediateMesh,
	a: Vector2,
	b: Vector2,
	height_fn: Callable,
	col: Color,
	dash_len: float
) -> void:
	var dist := a.distance_to(b)
	if dist < 0.1:
		return
	var count := maxi(2, int(dist / dash_len))
	mesh.surface_begin(Mesh.PRIMITIVE_LINES)
	for i in range(0, count, 2):
		var t0 := float(i) / float(count)
		var t1 := minf(1.0, float(i + 1) / float(count))
		var p0 := a.lerp(b, t0)
		var p1 := a.lerp(b, t1)
		mesh.surface_set_color(col)
		mesh.surface_add_vertex(Vector3(p0.x, float(height_fn.call(p0)) + 0.05, p0.y))
		mesh.surface_set_color(col)
		mesh.surface_add_vertex(Vector3(p1.x, float(height_fn.call(p1)) + 0.05, p1.y))
	mesh.surface_end()

### 参考代码 3：低开销建筑有机微雕（微掰角度 / 平滑圆角 / 二层外挑 / 半圆阳台）
**建议路径**：`scripts/visual/city_creation_organic_morph.gd`

```gdscript
class_name CityCreationOrganicMorph
extends RefCounted

## 零 CSG 布尔运算的建筑有机微雕几何生成器：
## 1) 曲路旁自动微掰角度 (bend_angle_deg) + 12-tri 扇形屋脊封顶楔子
## 2) 3 段式平滑法线圆角导角 (corner_bevel)
## 3) 二层悬挑木阁与斜撑托臂 (extrude_mask)
## 4) 6 段扇形半圆铁艺阳台 (balcony_arc)

const MAX_BEND_DEG := 28.0

## preset 0..4 一键循环预设（供屋顶罗盘「有机微雕」按钮调用）
static func cycle_organic_preset(house: Dictionary) -> Dictionary:
	var next_preset := (int(house.get("organic_preset", 0)) + 1) % 5
	house["organic_preset"] = next_preset
	match next_preset:
		0: # 经典规整
			house["corner_bevel"] = 0
			house["extrude_mask"] = 0
			house["balcony_arc"] = 0
		1: # 温润圆角墙面 + 扇形飞檐
			house["corner_bevel"] = 2
		2: # 二层有机外挑楼阁 + 斜撑木托
			house["corner_bevel"] = 1
			house["extrude_mask"] = 1
		3: # 临街半圆弧形铁艺花台阳台
			house["corner_bevel"] = 2
			house["balcony_arc"] = 1
		4: # 转角 270° 环抱式圆阳台 + 二层外挑 + 随路微弯
			house["corner_bevel"] = 2
			house["extrude_mask"] = 1
			house["balcony_arc"] = 2
	return house

## 当房屋贴近弯曲道路时，自动计算侧翼顺路微掰角度 (-28° ~ +28°)
static func auto_road_hug_bend_deg(house_pos: Vector2, house_yaw: float, roads: Array) -> float:
	var forward := Vector2.from_angle(house_yaw)
	var probe_left := house_pos - forward * 1.8
	var probe_right := house_pos + forward * 1.8
	var tan_l := _nearest_road_tangent(probe_left, roads, 5.2)
	var tan_r := _nearest_road_tangent(probe_right, roads, 5.2)
	if tan_l.length_squared() < 0.01 or tan_r.length_squared() < 0.01:
		return 0.0
	var diff_deg := rad_to_deg(wrapf(tan_r.angle() - tan_l.angle(), -PI, PI))
	if absf(diff_deg) < 6.0 or absf(diff_deg) > 35.0:
		return 0.0
	return clampf(diff_deg, -MAX_BEND_DEG, MAX_BEND_DEG)

## 生成 3 段式平滑法线圆角导角墙柱（每个圆角仅 6 个矩形面 = 12~18 tris）
static func append_rounded_corner_pillar(
	st: SurfaceTool,
	corner_center: Vector3,
	start_angle: float,
	radius: float,
	height: float,
	color: Color,
	segments: int = 3
) -> void:
	for i in range(segments):
		var t0 := float(i) / float(segments)
		var t1 := float(i + 1) / float(segments)
		var a0 := start_angle + (PI * 0.5) * t0
		var a1 := start_angle + (PI * 0.5) * t1
		var n0 := Vector3(cos(a0), 0.0, sin(a0))
		var n1 := Vector3(cos(a1), 0.0, sin(a1))
		var p0_bot := corner_center + n0 * radius
		var p1_bot := corner_center + n1 * radius
		var p0_top := p0_bot + Vector3(0.0, height, 0.0)
		var p1_top := p1_bot + Vector3(0.0, height, 0.0)
		# 使用平滑法线 n0, n1 让 3 段折面呈现完美圆柱高光
		st.set_color(color)
		st.set_normal(n0); st.add_vertex(p0_bot)
		st.set_normal(n1); st.add_vertex(p1_bot)
		st.set_normal(n1); st.add_vertex(p1_top)
		st.set_normal(n0); st.add_vertex(p0_bot)
		st.set_normal(n1); st.add_vertex(p1_top)
		st.set_normal(n0); st.add_vertex(p0_top)

## 生成 6 段扇形半圆铁艺阳台（底座扇片 + 弧形石雕托底 + 锻铁护栏，总计 ~96 tris）
static func append_semicircular_balcony(
	st: SurfaceTool,
	wall_anchor: Vector3,
	outward_normal: Vector3,
	radius: float,
	stone_color: Color,
	iron_color: Color,
	arc_span: float = PI
) -> void:
	var base_ang := atan2(outward_normal.z, outward_normal.x) - arc_span * 0.5
	var segments := 6
	var slab_thick := 0.16
	var rail_h := 0.52
	for i in range(segments):
		var a0 := base_ang + arc_span * (float(i) / float(segments))
		var a1 := base_ang + arc_span * (float(i + 1) / float(segments))
		var d0 := Vector3(cos(a0), 0.0, sin(a0))
		var d1 := Vector3(cos(a1), 0.0, sin(a1))
		var v0 := wall_anchor + d0 * radius
		var v1 := wall_anchor + d1 * radius
		# 1) 阳台扇形石板顶面
		st.set_color(stone_color)
		st.set_normal(Vector3.UP)
		st.add_vertex(wall_anchor); st.add_vertex(v0); st.add_vertex(v1)
		# 2) 底部内收弧形石雕托座 (Cul-de-lampe)
		var bot_center := wall_anchor - Vector3(0.0, slab_thick * 2.2, 0.0)
		var n_mid := (d0 + d1 + Vector3.DOWN * 0.6).normalized()
		st.set_normal(n_mid)
		st.add_vertex(v0); st.add_vertex(bot_center); st.add_vertex(v1)
		# 3) 弧形锻铁栏杆顶轨
		var r0 := v0 + Vector3(0.0, rail_h, 0.0)
		var r1 := v1 + Vector3(0.0, rail_h, 0.0)
		st.set_color(iron_color)
		st.set_normal(d0)
		st.add_vertex(v0); st.add_vertex(v1); st.add_vertex(r1)
		st.add_vertex(v0); st.add_vertex(r1); st.add_vertex(r0)

static func _nearest_road_tangent(pos: Vector2, roads: Array, max_dist: float) -> Vector2:
	var best_d2 := max_dist * max_dist
	var best_t := Vector2.ZERO
	for road in roads:
		var pts: Array = road.get("points", [])
		for i in range(pts.size() - 1):
			var a: Vector2 = pts[i]
			var b: Vector2 = pts[i + 1]
			var proj := Geometry2D.get_closest_point_to_segment(pos, a, b)
			var d2 := pos.distance_squared_to(proj)
			if d2 < best_d2:
				best_d2 = d2
				best_t = (b - a).normalized()
	return best_t
```

### 参考代码 4：四层立体透明室内乐调度器（砍掉同频混叠 + 唯一领唱 + 反向对位）
**建议路径**：`scripts/audio/city_creation_layered_orchestrator.gd`

```gdscript
class_name CityCreationLayeredOrchestrator
extends RefCounted

## 四层立体透明室内乐调度器：
## Layer 1 (MIDI 36..50): 大地五度长弓根音垫底 (晚入 22ms 拟人呼吸)
## Layer 2 (MIDI 52..64): 二阶工坊分解琶音与反向/斜向内声部对位
## Layer 3 (MIDI 64..76): 唯一领唱主旋律 (Single Lead Soloist Rule，全城仅焦点街区领唱)
## Layer 4 (MIDI 76..88): 星芒泛音点缀 (每小节最多 2 颗，对齐 16 分音符网格)

const LAYER_FOUNDATION := 1
const LAYER_COUNTERPOINT := 2
const LAYER_SINGLE_LEAD := 3
const LAYER_SPARKLE := 4

const REGISTER_BOUNDS := {
	LAYER_FOUNDATION: Vector2i(36, 50),
	LAYER_COUNTERPOINT: Vector2i(52, 64),
	LAYER_SINGLE_LEAD: Vector2i(64, 76),
	LAYER_SPARKLE: Vector2i(76, 88)
}

## 1. 唯一领唱者选举：镜头焦点所在的最高权重街区担任 Layer 3 领唱，其余街区自动转为 Layer 2 对位伴奏
static func assign_cluster_roles(clusters: Array, camera_focus_xz: Vector2) -> Dictionary:
	var roles := {}
	var best_cluster_id := -1
	var best_score := -1e9
	for c in clusters:
		var cid: int = int(c.get("id", -1))
		var center: Vector2 = c.get("center", Vector2.ZERO)
		var house_count: int = int(c.get("size", 1))
		var dist := camera_focus_xz.distance_to(center)
		var score := float(house_count) * 2.5 - dist * 0.45
		if score > best_score:
			best_score = score
			best_cluster_id = cid
	for c in clusters:
		var cid: int = int(c.get("id", -1))
		roles[cid] = LAYER_SINGLE_LEAD if cid == best_cluster_id else LAYER_COUNTERPOINT
	return roles

## 2. 将任意 MIDI 音高严格折叠进所属声部层的透明八度音区，彻底杜绝中频打架
static func clamp_to_layer_register(midi_note: int, layer: int) -> int:
	var bounds: Vector2i = REGISTER_BOUNDS.get(layer, Vector2i(60, 72))
	var n := midi_note
	while n < bounds.x:
		n += 12
	while n > bounds.y:
		n -= 12
	return clampi(n, bounds.x, bounds.y)

## 3. 反向与斜向对位生成器（告别 100% 满密度的机械平行三度）
static func choose_counterpoint_note(
	prev_lead_midi: int,
	curr_lead_midi: int,
	prev_counter_midi: int,
	scale_degrees: Array,
	phrase_step_index: int
) -> Dictionary:
	# 留白呼吸法则：每 4 步留出 1 步休止或长音延续（30% 呼吸留白）
	if phrase_step_index % 4 == 2:
		return {"play": false, "midi": prev_counter_midi, "delay_sec": 0.0}
	var lead_delta := curr_lead_midi - prev_lead_midi
	var target_midi := curr_lead_midi - 4
	if lead_delta > 0:
		# 主旋律上行时：伴随声部优先保持共同音(斜向)或反向落往低六度(-8/-9半音)
		target_midi = prev_counter_midi if (phrase_step_index % 2 == 0) else (curr_lead_midi - 8)
	elif lead_delta < 0:
		# 主旋律下行时：伴随声部反向温和上托至下三度(-3/-4半音)
		target_midi = curr_lead_midi - 3
	var snapped := _snap_to_scale(target_midi, scale_degrees)
	var final_midi := clamp_to_layer_register(snapped, LAYER_COUNTERPOINT)
	# 小节正拍伴音晚入 22ms，营造真人室内乐呼吸感
	var human_delay := 0.022 if (phrase_step_index % 8 == 0) else 0.008
	return {
		"play": true,
		"midi": final_midi,
		"delay_sec": human_delay,
		"gain_scale": 0.68
	}

## 4. 星芒泛音点缀门控（每小节最多放行 2 颗高八度协和泛音，对齐 16 分音符网格）
static func evaluate_sparkle_ornament(
	active_root_midi: int,
	bar_ornament_count: int,
	current_beat_time: float,
	sixteenth_sec: float = 0.1875
) -> Dictionary:
	if bar_ornament_count >= 2:
		return {"allowed": false}
	var grid_rem := fposmod(current_beat_time, sixteenth_sec)
	var wait_sec := 0.0 if grid_rem < 0.015 else (sixteenth_sec - grid_rem)
	# 仅选用极清澈的高八度纯五度(+7)或大六度(+9)或九度(+14)泛音
	var intervals := [7, 9, 14]
	var pick: int = intervals[bar_ornament_count % intervals.size()]
	var sparkle_midi := clamp_to_layer_register(active_root_midi + pick, LAYER_SPARKLE)
	return {
		"allowed": true,
		"midi": sparkle_midi,
		"quantized_delay_sec": wait_sec,
		"gain_db": -5.5
	}

static func _snap_to_scale(midi_note: int, scale_degrees: Array) -> int:
	if scale_degrees.is_empty():
		return midi_note
	var pc := posmod(midi_note, 12)
	var octave_base := midi_note - pc
	var best_deg := int(scale_degrees[0])
	var best_dist := 99
	for d in scale_degrees:
		var dist := absi(int(d) - pc)
		if dist < best_dist:
			best_dist = dist
			best_deg = int(d)
	return octave_base + best_deg
```
