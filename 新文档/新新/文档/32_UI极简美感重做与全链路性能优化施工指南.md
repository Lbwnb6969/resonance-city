## 一、 整套 UI 怎么重做：兼顾「美感与简洁」的 6 大真实脚本改造清单

经过对最新仓库 `scripts/ui/` 下全部脚本的逐行审计，当前 UI 存在以下 **5 个具体痛点**：
1. **`city_creation_intuitive_guidance.gd`（第 147–149 行）**：虽有羊皮底托，但切换星夜（`light_phase == 2`）时底托依然是刺眼的亮白羊皮纸（`#f6f0e1`），且文字颜色锁死深色，夜晚刺眼、缺乏日夜温润过渡。
2. **`city_creation_roof_ring.gd`（第 108–115 行）**：底部胶囊 `status_caption()` 直接印出 `律动×1.35`、`共鸣 2/3 · 品质 3` 等生硬数字与乘号，像调试面板而非手绘乐谱。
3. **`city_creation_inspiration_draft.gd`（第 23–35、88–95 行）**：
   - 左上角 `HarmonyProgress` 按钮显示 `♪ 河湾共鸣 4 · 120 / 300 · 待选1`，经验值分数冗长啰嗦；
   - 三选一卡片直接印出 `共鸣收益+25%` / `共鸣收益+12%` 及底部 `每次增加2%，至多50%` 的电子表格算术说明，且三阶稀有度卡片缺乏底色层次与流光阴影区分，也没有显示保底进度。
4. **`city_creation_life_capsules.gd`（第 4–18 行）与 `city_creation_ledger.gd`（第 66–99 行）**：左侧 `310px` 账本顶部还没有展示已点亮的「四大虹彩传世奇观冠冕」，且各家工坊缺少一瞥即懂的「`✦ / ✦✦` 供需品阶与 `🕰️` 钟表合拍」星标胶囊。
5. **`city_creation_score_ribbon.gd`（第 70–81 行）与 `city_creation_sundial_hud.gd`（第 64 行）**：每帧无条件调用 `queue_redraw()`，即使画面状态完全没变也在持续触发 Canvas 重绘。
