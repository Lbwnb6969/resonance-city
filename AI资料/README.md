# GitHub 中的 AI 参考资料

本仓库保留三个研究项目的原目录路径，方便现行设计文档直接链接。`tools/prepare_github_references.py` 生成并可暂存这个子集；[精确发布清单](参考资料发布清单.json) 给出每个入库文件的字节数与SHA256，以及本地保留文件的路径/体积/原因。

| 库 | 已入库的主要内容 |
|---|---|
| Tiny Glade | README、全部报告、Python工具、重建伪代码与GLSL/参考实现、文本证据与验证JSON；超大型总表和二进制缓存保留本地 |
| Foundation | 交付入口/报告、玩法语义索引与完整行为图、需求/职业/贸易/地图/建筑引用表、序列化解码表、渲染/音频语义、相关原生分析文本；模型/纹理/声音原件与分析数据库保留本地 |
| Townscaper | README/项目状态、outputs中的生成/拓扑/交互/历史报告、codec、语义JSON、C#/原生反编译研究和证据索引；work数据库与独立备份保留本地 |

Markdown链接指向未发布的大资源时，先看同目录报告/清单及 `local_only`。这些文件不是运行新共鸣之城的依赖；新游戏代码/资产由根项目提供。不要把本地原件缺失解释为整个研究结论已失效，也不要把静态研究当成完整原版可运行工程。

私有GitHub仓库用于项目协作与AI决策/设计；仓库范围没有包含个人用户存档、`.godot/`、机器连接设置、原始素材下载包及本地Git bundle。
