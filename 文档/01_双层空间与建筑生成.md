# 双层空间与建筑生成

## 1. 两层空间规则

| 层 | 玩家看到的空间 | 适用内容 | 生成方式 |
|---|---|---|---|
| 房屋局部层 | 点中房屋后显示轻微辅助线，默认不显示整张网格 | 墙、门洞、屋顶、露台、庭院边 | Townscaper 式局部不规则四边形网格 + 邻接规则 |
| 城市连续层 | 没有格线，鼠标/手柄在地形上连续移动 | 道路、桥、功能区、特殊建筑、植被、地形 | Tiny Glade 式意图输入 + 程序化细节补全 |

**全局坐标永远是连续浮点坐标。** 局部格子只是生成房屋几何的临时坐标系，不能被道路、功能区、声音或存档当作城市格子读取。

## 2. 点社区房子：局部 Townscaper 模式

“社区房子”是玩家选中的已有房屋或房屋小组。点击后进入房屋编辑焦点：

1. 系统在房屋外轮廓上建立局部不规则四边形格，格距随房屋宽度缩放，不向地面铺设全局格网。
2. 玩家点击相邻边、角或上层锚点，表达“向这里长”。
3. 生成器按邻接标签选择墙段、转角、门洞、屋顶、阳台和露台；墙相接时自动补柱、檐口和收边。
4. 空间被围合时优先生成内庭或露台；路径穿过房屋时优先生成门洞；抬高局部时自动生成支撑柱或台阶。
5. 玩家可以撤销、重做、换材质族和改变高度；每次只影响当前房屋局部及与其相接的少量节点。

局部生成器要保证“大形状可预测，小细节可变化”：同一组边界始终得到同一类空间结果，窗、柱、花盆、灯和瓦片允许在固定种子内变化。局部格子上限先定为 12×12 个逻辑单元；超出时分片，不扩大到整城。

## 3. 道路、特殊建筑、功能区、植被：连续 Tiny Glade 模式

- **道路**：玩家拖出一条曲线。系统用连续样条生成路面、路缘、交叉口、台阶和与门口的连接；道路不吸附到房屋格子。
- **特殊建筑**：玩家放置一个轮廓、轴线或占地意图。系统根据地形、道路入口和邻近建筑补齐台基、柱廊、屋顶、平台与灯光。
- **功能区**：玩家用画笔、闭合轮廓或中心点表达住宅、集市、文化、静谧花园等倾向。功能区只影响生成权重、材质和声音风格，不自动刷出任务或人口。
- **植被**：玩家拖出林带、点出树群或沿道路撒播。系统按地形、遮挡、视线和密度散布树、灌木、草簇和石块；避让道路、房屋入口和已确认的公共空间。

这些系统可以在建筑旁边生成门、台阶、矮墙和植被，但不得修改房屋局部格子的身份。房屋生成器也不能为了“对齐”而把道路拉直。

## 4. 连接化学

生成器读取真实几何关系，而不是物件类型的硬编码组合：

- 路线穿过建筑 → 门洞/拱门候选；
- 路线贴近建筑 → 台阶、入口平台或低墙；
- 两座房屋共享墙面 → 连续檐口、共同排水边；
- 高差超过一个台阶 → 支撑、坡道或断开预览；
- 闭合空地 → 庭院、花坛或小广场；
- 建筑与树群重叠 → 树退让或换成攀爬藤本，不穿模。

每条规则都有“可接受的空结果”。生成器宁可留下干净留白，也不塞入不合比例的零件。
