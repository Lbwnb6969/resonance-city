## 现在的问题（实际截图）

依据 `验证记录/Demo/` 下的实际截图——柔和岛台_推近.png、社区绿化_推近.png、风格小景_推近.png、古典建筑小景_推近.png：

1. **四处方向不一致**：建筑朝左下的面亮、朝右下的面暗（光从左上）；岛台阴影偏移 (−12, +18) 落在左下、岛台侧面右前 #CCD8D5 比左前 #C0CFCE 亮（光从右上）；spec.ui U5 写"右上光源"。
2. **没有落地投影**：房子和树都没有投影，接触阴影几乎看不见，像贴在地上。
3. **明暗太弱**：Demo 加工"明暗保留但减弱对比"让三个面和地面明度接近，画面发灰发薄。纪念碑谷式的柔和是"色相柔、明暗清楚"，不是取消明暗。

## 建议本轮范围

统一到"屏幕左上一个太阳"。现有烘焙图与原创 SVG 的受光面已经朝左下，所以不用重做模型；需要改的是岛台、补投影、恢复三面明暗。

| 项 | 建议规则（数值为 `[建议值]`） |
|---|---|
| 太阳 | 屏幕左上：世界方位西偏南约 20°、高度角 45°。全游戏唯一主光；以后昼夜/季节只改颜色、强度与影长，不改方向 |
| 三明度面 | 以 24 槽色板原色为顶面；受光面（朝左下）OKLab 明度 −0.06；背光面（朝右下）−0.16；坡屋顶按法线插值 |
| 冷暖 | 只偏色度、不改明度：背光面色度向 #5B6788 偏 25%，受光面向 #F3C98B 偏 10% |
| 红线 | 同一物体相邻两面 HSL 明度差仍 ≤30 个百分点（既有美学规格 §2.2）；示意图验算暖白墙三面为 92 / 84 / 73 |
| 投影方向 | 沿屏幕右下（太阳的严格反方向，约水平向右下 13°）；影长 = 物体高度 × cot45° 的地面投影 |
| 投影来源 | 离线烘焙：与主图同相机、同 origin 渲染一张影子遮罩（地面只接收阴影的透明材质，Godot 4 `shadow_to_opacity`）；原创 SVG 由生成器把 3D 面片沿光线投到地面，另存影子 SVG |
| 接触阴影 | 占地轮廓外扩约 3 px（默认缩放）、羽化约 4 px，比投影更浓、更小 |
| 影子层 | 投影层与接触层各一个 CanvasGroup：组内纯色 #4A5A78 不透明，组整体透明度分别 0.22 / 0.18，重叠处不加深；位于地面、网格、院落之上，所有建筑之下 |
| 生长同步 | 影子透明度 = 该建筑 growth_progress（读同一可听音频帧），不抢跑；连宅用整图对应的一张整体影子 |
| 岛台 | 阴影偏移改为 (+12, +18)；侧面颜色对调：左前 #CCD8D5、右前 #C0CFCE；其余不变 |
| 树、花坛、路灯 | 同样烘焙投影与接触阴影 |
| 范围 | Demo 主城 9 张建筑整图、2 种原创连宅、2 种树、花坛、路灯；风格小景；古典小景 4 件 SVG。P0 原始整图与 700 栋压力 fixture 不改 |
| 不做 | 不加运行时点光源/3D 光照；不做影子落到其他房子墙上；不改昼夜色板（P0 仍 1 张）；不改镜头、声音、R/V、RNG |

## 最低充分证据

1. 实际 GPU 截图（同一种子、同一镜头）：主城房群全景与推近、风格小景、古典小景，改动前后各一张。
2. 自动检查：每件选件都有影子与接触贴图且 origin 一致；投影方向误差 ≤3°；两影重叠区与单影区像素明度一致；生长中影子透明度 = 进度；B 黑屏仍全黑；城市快照、声音 PCM、RNG 不变。
3. 灰度检查：截图转灰度，每栋三面可分（顶↔受光 ΔL* ≥5、受光↔背光 ΔL* ≥10），建筑底边与地面 ΔL* ≥8；眯眼测试（高斯模糊约 8 px）建筑仍与地面分离。
4. 性能：每栋增加 2 个影子精灵，另做一次当前主城满 27 实体的帧时记录；700 栋 fixture 不加影子、不重跑，不把旧成绩套到新画面。
5. 人工：用户看前后对比图做审美裁定；实现者看图只说明可见效果，不代替用户签核。
