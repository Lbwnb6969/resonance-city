## 表 SP2 · 耦合系数（取代旧权重 w）

两个建筑 i、j 的耦合系数：

```
c(i,j) = A(d) × O(i,j) × T(i,j) × I(i,j)      c ∈ [0, 2.0]
```

| 项 | 定义 |
|---|---|
| `d` | 中心距离 − `r_i` − `r_j`（间隙距离，可为负） |
| **A(d)** 距离衰减 | `d ≤ 0` → **2.0**；否则 `2.0 × exp(−(d/1.8)²)` |
| **有效邻接半径** | `d > 4.0` → `c = 0`（不产生关系） |
| `O` 遮挡 | 无阻挡 1.0；部分（林地/矮墙）0.7；完全（山脊/水体/成路街道）**0** |
| `T` 地形调制 | 平原 1.0；跨水面 **1.15**；跨林地 **0.85**；同地形按 spec.terrain 表 |
| `I` 工业系数 | 任一方为工业 → **×1.3**；在 A 封顶 2.0 之后乘，最终 clamp 到 2.0 上限之外不限制（工业可比 2.0 高，见注） |

**注**：`A` 单独上限 2.0；乘工业 1.3 后 `c` 最大 2.6。这与旧规则"w 先封顶 2.0 再乘工业系数"一致。

**A(d) 参考值**：

| d（间隙，地块） | A |
|---|---|
| ≤0 | 2.00 |
| 0.5 | 1.86 |
| 1.0 | 1.47 |
| 1.5 | 1.00 |
| 2.0 | 0.58 |
| 3.0 | 0.16 |
| 4.0 | 0.02 → 截断为 0 |

## 表 SP3 · 谐振度 R（形状不变）

```
R = 100 × Σ(c_ij · s_ij) / Σ(c_ij)        i,j 遍历所有 c_ij > 0
```

- `s_ij` 取自 spec.harmony.md 表 B（**不变**）
- 纯函数，每乐句边界重算，不保留历史
- **无配对时 R = 100**（保留旧裁定）
- 浮点比较容差 **1e-6**（保留）
- 每条无向对只计一次（保留）

**V 活力公式不变**（见 spec.harmony.md 表 H1）。

## [SPACE-001] 耦合系数的唯一计算路径

状态：重构新增，待实施。

意图：让布局、预览、落定、音频共用同一个连续耦合函数。

规则：按表 SP2；A 的距离参数 σ=1.8、截断 4.0；O 按遮挡采样；T 按 spec.terrain；I 工业系数在 A 封顶后乘。R 按表 SP3。
