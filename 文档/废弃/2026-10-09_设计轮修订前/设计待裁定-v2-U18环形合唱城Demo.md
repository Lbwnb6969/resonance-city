# v2-U18 · 命名形态首个可玩切片：环形合唱城

状态：候选，尚未批准；第52轮形成具体可审阅方案。来源：执行交接-城市生长U18、设计增补v2 §3.4/§7与工作稿§D。与v3-U22稀有分级/声部行为、v2-U21发现池、v2-U19成形演出分别裁定，不因本页而整体批准。

## 建议裁定

采用“自然形成后识别”，不强迫生成器填模板、不提高指定建筑概率。先实现一个有实际声学行为的命名形态，并保留后续梯田赋格镇/双子港及图鉴的原目标。这是CITY-005的首个实现步骤，不能据它宣布全部稀有系统或交接完成。

| 项 | 建议具体规则 |
|---|---|
| 名称与结构 | 环形合唱城；中心为住宅共鸣点，中心周围3×3的8个外围格由同一源点家族的住宅实际占满 |
| 成熟条件 | 8栋均为群/央/腔，允许混合，不强制腔；每栋未处于碴/冻结且真实家族连接可达中心 |
| 声学条件 | 中心及8成员current_midi相同，使用既有系统音级；不改音程/调式/工业规则 |
| 道路条件 | 8成员的环周8条共享边以及中心到4正邻的4条共享边均未成路；未成路足迹仍允许。图外邻居照常参与原和声/冻结判定 |
| 达成 | 以上在连续2个实际乐句边界同时满足；中间不满足清零。仅按真实事件帧解析，不按画面/墙钟 |
| 成形后的声音 | 8栋成员的现有律动分为两组；西北组在偶数小节发声，东南组在奇数小节发声，每小节2秒。两组交替呼应，不新增音高、音源或声音实体，不叠加现有律动 |
| 分组 | 围绕中心按顺时针偏移顺序：北(-1,-1)、东北(0,-1)、东(1,-1)、东南(1,0)、南(1,1)、西南(0,1)、西(-1,1)、西北(-1,0)；西北组索引6/7/0/1，东南组2/3/4/5。名称按当前等距地图屏幕方向解释 |
| 律动包络 | 保留原住宅律动节拍/音色，只乘组门控，最大系数1，组开始/结束各1个十六分音符（0.125秒）线性淡入/出；小节/乐句相位来自同一PCM绝对帧。中心只drone，drone和装饰层均不改；既有duck/mute/solo/迁移静音仍有效 |
| 启用/离开 | 达成边界起，用1小节从普通律动平滑混合到呼应律动；任一判定在下一边界失效，则以1小节恢复普通律动，计数清零。混合系数保持0–1，不做额外响度补偿；后续重新满足仍需连续2乐句 |
| 音量与保护 | 原9校准固定公共gain、新增0.20振幅/27实体上限照旧。未改drone RMS保护和峰值门槛，必须用实际新混音验证，不能以“包络只衰减”推断保护必然通过 |
| 同时多个 | 同时满足的各自家族均可呼应；一个建筑只属一个源点家族，不叠双重门控。中心与成员按稳定ID登记 |
| 可见反馈 | 成形后住宅社区外围出现一条柔和连续环线，选中成员或源点的现有条件区显示“环形合唱城”与真实成员/条件/连续计数。镜头、地图工具和城市计时继续；不新增弹窗、自动镜头或U19卡片 |
| 静音与Solo | 形态身份由城市条件决定，mute/solo不改R/V或成形；条件区须说明当前是否静音/隔离，不能把单边可听说成完整呼应。响应声音也服从既有播放器控制 |
| 断路/调音/迁移 | 道路第三次落定、成员改音或移出环形、中心改音，按同一真实边界取消当前呼应身份；保留建筑/群央腔/永久道路，既有收益代价预览须明确形态与呼应将失去。仅未落定的足迹/预览不改变真实身份 |
| 重开/快照/试听 | 连续计数、活跃成员、启用/离开帧和包络起始值纳入城市/音频快照；独立副本预测/实际落定走同一解析。试听可听到同相位呼应，但不会给真实城发完成事件；重开清空本局记录 |

偏移顺序是世界格的有序环：每对相邻偏移的曼哈顿距离均为1，第7项回第0项也是1，四正邻为1/3/5/7。以此表为执行事实，不用屏幕角度近似判断道路/位置。

## 操作因果示例

玩家释放一个C住宅源点，附近自然长出8栋同家族住宅；它们按既有规则成熟。第一次满足完整环形记1/2，第二次满足成形。此后听到西北与东南两侧律动轮流回应，真实长音继续叠加。

玩家在某一环边踩第1/2次只留足迹；第3次成路切断这条共享边，收益代价预览说明环形和呼应会失去。真实可听边界到达后环线消退，律动在1小节内恢复普通模式，房屋保留；道路永久性沿用原规则。

同音但只排成直线、8栋尚处于胚、来自两个家族凑环、工业填角、任一外围空格或已成路，均不满足。只具有相似轮廓的建筑贴图不决定命名。

## 可行性与范围

中心+8外围共9新增实体，加原9为18，不超过当前27上限。现有密度半径下，同一家族8成员能达到群计数；四角各有2个环上邻居，正邻有环上2邻和中心1邻，所有同音时实际s=1，因此结构无需强制腔或更改已批准阈值。原初始街区/工业占格或道路仍可能使某局不成环，此方案不自动清障、搬家、保底或换种子。

这不是抽卡发现或永久收藏：稀有/史诗/传说概率、三池计数、持久图鉴、City DNA回放、壁纸导出和奖励仍保留后续独立裁定。没有把所有后期音乐改成一种曲风，时代增加可能性的用户修正继续有效。原教堂/斗兽场/神殿SVG资产可另行用于已授权美术，但不会自动替换环上的住宅或作为成形奖励。
