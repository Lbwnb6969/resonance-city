**一句话**：城市第一次长出群、央、腔时，屏幕左边轻轻滑出一张小卡，说清三件事——刚刚发生了什么、它听起来有什么不同、下一步要什么。像一位安静的讲解员，一局只开口三次。

## 为什么改第一版

| 第一版 | 问题 | 第二版 |
|---|---|---|
| 文案"第5乐句 · 住宅（7,8）形成群" | 坐标对玩家没有意义；没说群是什么、下一步是什么。玩家目前只能从条件卡反推胚/群/央/腔的含义，这三张卡本该是最自然的教学时刻 | 三行文案：发生了什么（用画面方位）、这意味着什么、下一阶差什么（读实际缺口） |
| 只庆祝画面变化 | 现行 Demo 里自动建筑从出生起就有长音 + 律动，阶段不改变声音，"成形"在耳朵里没有发生 | 建议同时批准 v4-SND-01（阶段声音分层）；若不批，卡片只写看得见的变化，不声称声音变了 |
| 4 秒 | 三四十个汉字读不完，也不能停下来看 | 6 秒，鼠标悬停暂停计时 |
| 位置未定 | 以后命名形态、地标都要提示，若各自找位置会互相打架 | 定下左缘"通知轨"，以后所有提示共用（v4-NTF-01） |

## 建议本轮范围

| 项 | 规则 |
|---|---|
| 触发 | 本局首次实际形成群、央、腔，各一次；在该事件的一拍揭示完成后的下一拍出现。普通出生不弹卡，同一阶段后续建筑不再打断（同第一版） |
| 位置 | 地图区左上的"通知轨"（标题下方、左对齐，宽 ≤360 px @1440×900），不遮右侧面板与底部条件卡；之后的命名形态、地标提示共用这条轨 |
| 第 1 行 | 阶段阶梯徽记（胚 · 群 · 央 · 腔 四格，当前格点亮）+ 标题"第一次形成「群」" |
| 第 2 行 · 发生了什么 | 来自真实事件：类型 + 画面方位 + 所属源点音级，例："左侧的住宅（C）长成了群"。方位按固定九宫表换算（见下） |
| 第 3 行 · 这意味着什么 | 每阶段固定说明，内容来自 spec.city 表 E 的真实条件。群："它和至少两个邻居协和，社区成形了"；央："群里出现了同音的共鸣邻居，它长成了中心"；腔："它的每个邻居都与它协和——这是一处共鸣腔"。若 v4-SND-01 获批，分别追加"它的节奏加入了合奏 / 装饰旋律开始点缀 / 每个乐句开头它会敲响一声高处的钟" |
| 第 4 行 · 下一步 | 读该建筑当前的实际缺口（沿用表 E4 的条件解析），例："下一阶 · 央：还差 1 个共鸣（同音）邻居；半径 5 内同类 4/6"。央与腔写"央与腔都是成熟形态" |
| 时长与操作 | 6 秒；悬停时暂停计时；点击卡片 = 用已授权的"聚焦选中"看这栋建筑；× 立即收起 |
| 声音 | 可选：卡片出现的拍上一个调内提示音（基音 + 纯五 + 高八度 shimmer，沿用 AUDIO-005 配方，走 UI 总线）；不改变任何城市声部。加入时须复测峰值 |
| 排队 | 同一乐句多阶段时按群 → 央 → 腔依次，每张间隔 1 小节（2 秒）滑入，前一张自动收起；任何时刻最多 1 张 |
| 开关 | "成形提示"默认 ON；关闭后不补播（同第一版） |
| 黑屏/试听/重开 | B 黑屏全部隐藏、不强制退出；未来试听不触发真实卡片；重新开始清空本局首次记录（同第一版） |
| 数据源 | 只读当前可听城市的实际 growth_events 与条件解析，不另算形态条件；不编造城市名、市民评价或未发生的事件，不把同期 R 变化全部归因给这栋房子（同第一版） |
| 不做 | 不停城市与声音、不自动镜头、不改混音增益/R/V/时钟/pending/自动扩张（同第一版）；不做乐章卡帧、稀薄织体、City DNA 回放（属于后续 L3/L4 庆典） |

## 最低充分证据

先做可运行小卡片，用一次针对性实际入口验证：首次触发、一拍揭示后才出现、同阶段不重复、悬停暂停、点击聚焦、关闭、开关 OFF 不补播、B 黑屏隐藏、同乐句多阶段排队、试听不触发、重开清空，以及城市快照/PCM/RNG 不变。截图存一张三行卡片的实际 GPU 画面。不重做真人或压力检查。

## 为什么需要裁定

v2 §6.1 把卡帧时长标为"待裁定U19"，城市生长交接也把时长、可跳过性和字幕来源列为未决。用户授权的方便镜头可以独立实施，但不能由此推定自动演出获批。项目 AGENTS 要求关键需求不明确时先确认。本提案给出位置、文案结构、时长、排队、声音与开关，供一次具体裁定。
