# 旧格边提案规格

仅供追溯，不作为现行规则。

## 表 P5 · Demo引力带（本次用户批准U15）

| 参数 | 值 / 规则 |
|---|---|
| 同时上限 | 1条；新线在同一乐句边界替换旧线，无叠加 |
| 输入 | 在地图拖动从起点到终点，二者为合法且不同的逻辑格；偏向只允许住宅/商业；线可跨已有地块，不占格、不切邻接 |
| 生效 | 复用每乐句1次待提交介入槽，release/调音/迁移/draft互相覆盖；松开鼠标即提交到尚未渲染的下一乐句边界，可取消；无卡拍活力奖励 |
| 重划代价 | 已有引力线且线或偏向改变时，暂停全部自动扩张1乐句；提交边界不产生新建筑，下一边界恢复；已有形态的条件计数/升级与声音继续，不扣R/V |
| 首次及重复 | 首次划线无暂停；同起终点同偏向再次提交不算重划；取消待提交线保留已生效旧线 |
| 影响 | 只影响偏向类别的共鸣点家族，保持原每源点每乐句扩张量与类型继承；不强制生成选定类别，不改变MIDI、音程阈值或R/V公式 |
| 排序 | 先过滤原连通/空格/协和/避碴合法候选；匹配类别先靠近有限线段（平方距离小优先），距离相同时优先向箭头终点方向（沿线投影大优先），再用既有家族邻居数、源点距离、坐标顺序；其他类别沿用原排序；不消耗RNG |
| 快照与显示 | 生效线及暂停终止音频帧纳入城市快照/试听；地图旧线仍有效，待提交线用金色预览，生效线按住宅/商业色区分，箭头显示方向；重划暂停剩余时长读可听时钟 |

### [PROPOSAL-004] 划定引力

状态：本次用户已批准U15建议；几何排序/交互技术由执行方按既有授权补齐。tread/U16已另获用户批准，规则与验收见PROPOSAL-005。

意图：让玩家提供生长方向，城市按已有和声约束回应，增加可玩的间接控制。

规则：表P5。只调整候选位置排序，不直接指定建筑或给数值加成。R/V仍按实际新邻接结算；布局变化导致真实R/V变化属于原公式，不承诺城市永远保持原数值。单槽提交/覆盖/取消和下一乐句生效沿用原介入事务。

数据：表P4/P5、CITY-004、HARM-001/002/003、UI-004镜头。

验收：F5选择引力模式/偏向→拖出方向箭头→下一乐句生效→重划暂停一个乐句后恢复；最小实际场景入口`tests/growth_demo_smoke.gd -- --draft`，同时验证取消与快照保留旧线、合法候选和不改变类别/音级。

反例：不得把偏向当住宅/商业分区或强制生成；不得绕过碴/连通条件；不得立即改已渲染边界；不得重划删房/静音/改活力或反复累计多条引力带；未实现踩路径不得声称街道系统完成。


## 表 P6 · Demo踩路径（用户已批准U16，技术细节授权补齐）

| 参数 | 值 / 规则 |
|---|---|
| 成路阈值 | 累计3次已落定足迹；无需连续，不衰减 |
| 输入 | 地图左键从一格划过到四向相邻格，仅一条共享边；可跨已有建筑/空格，起终点必须在地图内；反向合并为同一无向边 |
| 确认与额度 | 划过先预览，按钮确认后复用每乐句1次介入槽，下一尚未渲染乐句落定；边界前覆盖/取消不计足迹；与release/draft/retune/relocate互相覆盖 |
| 成路 | 第3次落定形成街道，本局不可撤销，重新开始清空；重复标记已成路边拒绝，不额外扣R/V或给卡拍奖励，不删建筑/不改变MIDI/类型/位置/声音实体数 |
| 邻接与连通 | 街道阻断两格共享边的声学邻接、家族连接与向该边扩张；不改变其他边或距离密度计数。R/V与合法调音按实际新图；断开唯一家族路径会停止该部分升级/扩张，保留成熟形态。跨街道连宅拆回单栋 |
| 状态与试听 | 世界格边界/次数/落定帧为权威状态，纳入城市/模型快照；道路是世界边界，不跟随建筑迁移。预测/确认/音频/条件/窗屋选件均读同一图；原P0 fixture默认无道路 |
| 反馈 | 确认前显示次数、成路不可撤销、真实R/V/邻接损益和家族断连数量；地图用浅灰青边界带区分街道与院落步道，未成路显示足迹进度点，待提交为暖色；实际次数显示不得早于可听落定帧 |

### [PROPOSAL-005] 踩路径

状态：本次用户已批准“按3次成路方案执行（建议）”，现行裁定已吸收为表 P6，连续版回退以表 P9 为准。无需重复确认U16；其余未裁定玩法不随本项加入。

意图：玩家通过反复踩同一共享边，引导城市形成永久街道。

规则：表P6。原持续drone和位置保留，道路切的是游戏邻接关系，不宣称物理上消除了全部混音干涉。只有次数达阈值才阻断关系，未成路足迹不改变声学图；批量拖动不等于批量建路。

数据：表P6；CITY-004、HARM-001与AUDIO-002的真实共享图/可听帧。

验收：最小实际场景入口growth_demo_smoke.gd -- --tread，实际划过→预览/确认→两次足迹仍邻接→第三次才成路，验证反向/覆盖/取消、实际R/V、家族断连/连宅拆分与快照；查看实际GPU画面。无需重复700栋压力/声音全套。

反例：未满3次不得切边；反向划过不得算两条街道；不能移动房屋时移动永久路或直接删除房屋/扣活力。
