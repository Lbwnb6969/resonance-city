> 2026-10-09 重构版。本文是**唯一的设计意图入口**。

## 0. 一句话

**你在一片地形上播下声音的种子。城市按和声长出来，长成一座会演奏的城。**

玩家不是建筑师，是**配器师**。城市自己会长，但长成什么和声、在哪个河谷、缺哪个声部，由你的每一次播种与调音决定。

---

## 1. 定位

**声景缺口 → 选一个音 → 播下去 → 城市长出声音 → 你听见它被填上 → 新的缺口在别处出现。**

这不是"修复失谐"的游戏，是**"补齐配器"**的游戏。失谐只是缺口的一种。

> 反支柱对照：旧定位是"城市先响着，你听出哪里不对，然后作一次介入"。新定位是"城市先响着，你听出**少了什么**，然后给它加上"。前者是维修，后者是创作。这个转变是本次重构的核心。

---

## 2. 五条支柱

### 支柱 A · 声音即地形
**地形本身就是声学结构。** 水面隔声、山脊挡声、林地吸高频、平原通透。所以"把工业放在河对岸"不是一个视觉决定，而是一个**物理上真的会改善音景**的决定。

配套：城市的每一栋建筑都是一个发声体，它的音级写在它的位置上，位置写在它的声音里。

### 支柱 B · 配器即玩法
城市演奏时**会缺东西**——缺低音、缺节奏、缺一个五度、缺一段留白。缺口不是错误提示，是**邀请**。玩家的工作是判断"这里该放什么"，而不是"这里哪里错了"。

反例（明确不做）：不投放噪声逼玩家维修；不用倒计时逼玩家处理。

### 支柱 C · 生长即谱写
城市与音乐来自**同一组事件**。你播下 C，长出来的社区就是 C 调家族；你在河对岸播下 G，两岸就形成五度对唱。城市形态与音乐结构是同一个东西的两面。

City DNA 可完整复现形态和声音。

### 支柱 D · 大城即乐队
一座成熟的大城有 **36–48 个社区**、400–600 栋建筑。它听起来**不是 600 条音轨在吵**，而是一支乐队：**只有少数声部同时唱旋律，其余是垫、是脉动、是留白**。规模靠组织，不靠削减。

**但大城是终点，不是起点。** 实现按三阶段推进，**每阶段必须先验证真实玩法再扩规模**：

| 阶段 | 规模 | 验证什么 |
|---|---|---|
| 核心切片 | 20–30 栋、≥3 个可辨认区域 | **完整因果链** + 两条值得选的路线 |
| 中型验证 | 80–150 栋、8–14 社区 | 多社区轮换/应答、音乐角色分配 |
| 最终目标 | 400–600 栋、36–48 社区 | 完整大城音乐组织 |

**每个阶段必须说明"新增了什么真实玩法"**，不能只有数字增长（见 `18_城市规模.md` §5.1）。

### 支柱 E · 柔和直觉
**没有格子。** 你在连续的地形上放置，系统给你柔和的落点吸附。所有操作都有即时的手感反馈：音高滑动、地面涟漪、色温呼吸。

界面默认几乎是空的——城市和节拍。信息在你把鼠标移上去的时候才出现。

## 3. 反支柱（明确不做）

1. **玩家不自由输入音符，不直接作曲。** 音级来自系统给定的音阶集合，且必须与周围形成可听关系。
2. **不做格子、不做 tile 摆放。** 建筑位置在连续空间。
3. **不做交通/经济模拟。** 道路的作用是声学连通与隔断，以及承载移动体做视觉叙事，不产生数值经济。
4. **不做数值碾压。** 元进程只解锁可能性（音源、形态、地形、图鉴），不给永久"R+2"。
5. **不用系统提示音。** 所有 UI 反馈音都是当前调式内的乐器音。
6. **不使用写实渲染、霓虹高饱和、夸张喜剧动效。**
7. **失谐不扭曲几何。** 只用色温偏移、对比微变、阴影变硬、微动效熄灭。
8. **不为"看着热闹"堆常驻 UI。** 信息按需出现。

## 4. 体验目标（三个词，可测试）

| 词 | 测试 |
|---|---|
| **宁神** | 截任何一帧：色相 ≤3 族、对比柔和、无高频闪烁；放置 30 秒画面仍在缓慢呼吸 |
| **生动** | 任意 10 秒窗口 ≥5 处微小运动；每社区 ≥3 个循环微动效（锁 BPM 整数分频）；城市状态变化全部有视觉对应 |
| **丝滑** | 任何可见变化经过缓动；稳定 60fps |

**声音总标准**：任意时刻录 30 秒音频，盲听像一段**作品**，不像游戏音效在循环播放。

## 5. 与旧设计的关键改变

| 项 | 旧设计 | 新设计 | 理由 |
|---|---|---|---|
| 空间 | 16–32 格棋盘，一格一栋，四向共享边 | **连续地形，浮点坐标，距离核耦合** | 用户要求去格子；且地形必须是空间连续体 |
| 邻接权重 | `w = 1 + 0.15×(n−1)`，n = 共享边界格数 | `c = A(距离)×O(遮挡)×T(地形)×I(工业)×M(音乐性)` | 无格子可用；且让地形真正影响声学 |
| 实体上限 | 27 声音实体，到顶停长 | **建筑无上限；实际合成声部封顶 70**（含背景 drone、环境、装饰与交叉） | 27 是"一栋一声部"的产物；按声部组承载后可放开 |
| 邻居计数 | 四向共享边，典型 4–9 个邻居 | **全对集合 `E`（R/V 用）与近邻集合 `N₁₂`（生长/阶段/碴用）** | 密集区实测可达 108 个 `c>0` 邻居，混用会让密集区整体冻结 |
| 社区身份 | 同家族声学连通群 | **稳定规划社区**（ID 不随音级/成熟变化）+ 家族 + 每乐句重算的音乐簇 | 三者服务不同目的，混用会让"社区"指代不清 |
| 核心循环 | 听 → solo/mute 定位 → 判断张力 → 介入 → 再听 | **听 → 想这里该成为什么 → 选有表达差异的候选 → 播下 → 听见它变** | 从维修转向创作 |
| 跨章条件 | 修够 3 条指定失谐边 + R≥70 | **三条路径任一**：修复者 / 建造者 / 配器师 | 奖励建设，不只奖励修理 |
| 多样性 | 靠停谐最优被"不好听"劝阻 | **音乐性权重 `M`**：同音占据率 > 40% 时收益减半，加一个不同音级即恢复 | 直接、可计算、不惩罚 |
| 失谐后果 | 全城 R<40 崩盘 | **局部锈蚀簇 + 全城 R 崩盘双轨** | 大城不再稀释局部问题 |
| 地形 | 名词级提及 | **山/海/湖/河/林/平原为一等系统**；规则层（耦合）与声学层（延迟/滤波）分开 | 用户要求；且"规则上无关"≠"听不见" |
| UI | 常驻右栏 31% 宽 + 底部条件卡 | **默认近乎全空；悬停出卡；单推荐焦点** | 用户要求 |
| 时序 | 一切真实变化等 16 秒乐句边界 | **分层落定**：输入即时 / 声音等 1 拍 / 结构等 16 秒 / 仪式 3 小节 | 不能让每次调音都变成 16 秒等待 |
| 章节 | 固定 7 乐章 @16 秒乐句 | 保留（22–35 分钟中城），新增**自由共鸣长局**达到大城 | 大城需要时间 |

## 6. 必然保留的已批准资产

以下是被反复验证、且不依赖格子模型的资产，**原样继承**：

- **表 B 协和分**：同度/八度 s=1.00 ΔV+8；纯五/纯四 0.90 +5；大三/大六 0.85 +5；小三/小六 0.60 0；大二/小七 0.30 −3；小二/大七 0.05 −8；三全音 0.00 −8。
- **三层声部**：drone（持续，承载和声与拍频）/ 律动（身份与节奏）/ 装饰（偶发彩蛋）。
- **音乐时钟为主**：120 BPM、4/4、小节 2 秒、乐句 8 小节 16 秒。视觉与音乐同步必须用音频帧，不用 Tween 秒数。
- **混音标准**：−16 LUFS 基准、真峰值余量 3 dB、drone RMS ≥ 总混音 25%、equal-power 交叉 2–4 拍。
- **声学测量协议**：小二 7.78±0.5 Hz 峰 ≥6 dB；三全音 3–16 Hz 无慢峰；协和包络波动 <1.5 dB。
- **五时代与音阶生长**：Ⅰ C D E G A → Ⅱ +F,B → Ⅲ +F♯,B♭ → Ⅳ +C♯,E♭,G♯ → Ⅴ 不新增。
- **失谐的视觉表达**：不扭曲几何。
- **无后端**：种子、每日一城、回放全部本地。

## 7. 宣传纪律

可以说的：**听觉诊断 + 有限介入 + 城市生长反馈 + 地形声学**的交叉。

**不得宣称**：市场空白、波形可视化、联觉视觉、音频驱动关卡、音乐城市建造的独创性——这些均有先例。地形→声学的映射也需谨慎表述，不得声称"从无先例"。
