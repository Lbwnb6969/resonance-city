## 已知的数学更正（实证过，不得回退）

| 项 | 曾写成 | 更正 |
|---|---|---|
| 分层 R | "按社区分层可消除局部问题稀释" | **与全城加权平均代数恒等**（实测差 1e-14）。**局部问题由独立社区指标处理**，不得宣称 R 公式本身消除了稀释 |
| 截断跳幅 | "最大影响 0.71 个百分点" | 0.71 pp 只是"其余有一对紧贴建筑"的特殊情形。**最坏在稀疏图**：2 对时跳 50 pp。大城可忽略，**开局小城不可忽略** |
| √k 合并 | "相位归一后保持功率" | 同相 k 份原功率是 `k²P`；`√k` 是**编曲归一化**，不是等价合并的证明（表 A15/A18） |
| 社区分裂 | "41 栋 / 81 栋"含义不清 | 上限 40，故 **41 栋即触发分裂**；81 栋用于验证至少 3 个子区 |
| 平地排水 | "从最高点按梯度流向海" | 平地会停住，必须走 **priority-flood 父图**（表 T2） |

## 状态标记

每条规格含 ID、状态、意图、规则、数据、验收、反例。
- `已裁定`：设计规则已批准，不代表已实现。
- `重构新增，待实施`：本次重构新增，尚未写代码。
