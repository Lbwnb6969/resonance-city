# 提案、试听与介入执行规格

> 2026-10-08 · 最新用户裁定：允许工业改音级；允许迁移时静音一乐句。反支柱仍禁止玩家自由输入音符；音级由系统提案限定。

## 表 P1 · 双轨落点（原样保留）

| 落点与目标音级的关系 | 效果倍数 |
|---|---|
| 命中提案允许的和声音级 | **×1.0** |
| 偏差 1 半音 | **×0.7** |
| 偏差 ≥2 半音 | **×0.4**，且引入一次新张力 |

主轨是和声判断；副轨为距可听乐句边界≤±80ms时的额外泛音层与该街区+5活力。介入输入可在任何时刻，落定只在乐句边界。主轨倍数作用到何种效果、落点音级如何操作未给出，见U06；不能将R乘此倍数破坏其纯函数定义。

## 表 P2 · 介入动词（原样保留；用户已批准两个争议例外）

| 动词 | 内容 | 代价 |
|---|---|---|
| `retune` | 把一个街区的音级改到相邻协和音级（例：工业 F♯3 → G3，与 C 成纯五） | 该街区 −10 活力（改造成本）；与**新**邻居的关系可能不协，必须预览 |
| `relocate` | 把一个街区移到另一格，改变邻接关系 | 移动期间该声部静音 1 乐句；原邻居失去加成 |
| `infill`（P1） | 在两街区之间插入解音声部（公园），取共同协和音 | 占地，降低该处密度上限 |

`retune`允许工业F♯3→G3；industrial类型和工业权重仍按街区类型判定，不把改音级偷偷转成商业/住宅。`relocate`在乐句边界提交新邻接图，同时该声部静音1乐句，下一边界恢复；这是持续drone规则的已批准例外，不增加其他自动静音情形。具体状态提交与活力结算顺序须等U07裁定。P1的infill共同协和音与无共同音时的处理见U06。

## 表 P3 · 提案接口

| 字段 | 规则 |
|---|---|
| proposal_id / source_event | 稳定ID及因果事件，不凭空随机加玩法 |
| verb / district_id / targets | P0只retune/relocate，目标为系统给定选项 |
| allowed_pitches / preview_choice | 提案允许的和声音级集合与当前试听选择，集合算法待U06 |

| before_state / preview_state | 独立副本；取消后真实城状态、RNG与音频相位不受污染 |

| 会导致失效的命名形态 | **≥ 1** | 二次确认（显示是哪个形态） |
| 会失去轮唱 / 对唱的社区 | **≥ 1** | 二次确认 |
| 涉及的规划社区数量 | **> 2** | **拒绝执行**，建议缩小范围 |
| 会覆盖既有建筑 | **任意 1 栋** | **拒绝执行**（不删除、不移位、不浮空） |

**这些是设计值，不是实现细节。** 执行 AI 必须实现阈值判定，**不得由玩家自行调整阈值**。

**预览必须显示**：
- 会消失 / 新增哪些耦合（可视的边高亮）
- 哪个命名形态会失效
- 哪些建筑会被覆盖
- **一个可视的"影响范围"高亮**，不是只给一行文字

**为什么用"拒绝"而非"警告"**：玩家在密集区随手划线时，温和的警告会被忽略。
**硬拒绝 + 替代方案提示**（"缩小范围，或先迁移邻近的两栋"）才是有效的保护。
