## 3. 核心改动（七项）

### 3.1 格子 → 连续空间（最重要）

| 旧 | 新 |
|---|---|
| 16–32 格棋盘，一格一栋 | 连续浮点坐标，占地半径 |
| 四向共享边 = 邻接 | **距离核 `c = A(d)×O×T×I`** |
| `w = 1 + 0.15×(n−1)` | `A(d) = 2.0×exp(−(d/1.8)²)`，4 地块截断 |
| 曼哈顿距离 | 欧氏距离 |
| 点格子放置 | 连续放置 + 柔和吸附 |

**为什么**：这是六条要求里五条的共同前提。地形、柔和、社区、大城都需要连续空间。

**兼容性**：表 B 协和分不变；R/V 公式形状不变；三个紧贴 fixture 结果不变。

### 3.2 27 上限 → 声部组与编曲槽

| 旧 | 新 |
|---|---|
| 一栋 = 一个合成声部 | **声部组 = {社区, 音级, 阶段}**，合成一次 |
| 27 到顶停长 | 建筑无上限；**同时发声封顶 70** |
| 合并是"优化候选" | **合并是编曲的正当手段** |
| 逐栋 Solo/Mute | **按声部组** Solo/Mute |

**为什么**：27 是"一栋一声部"的产物，不是设计意图。600 栋的城 → 40–70 声部，才是"乐队"。

### 3.3 诊断驱动 → 配器驱动

| 旧 | 新 |
|---|---|
| 城市先响，你听出哪里"不对" | 城市先响，你听出**少了什么** |
| 修复失谐 | **补齐配器缺口** |
| 跨章要求"修够 3 条失谐边" | **三路径：修复者 / 建造者 / 配器师** |

**为什么**：旧循环奖励维修，不奖励建设（Q09）；且同音最优导致全城调成 C 是最优解（Q07）。缺口系统同时解决两者。

### 3.4 地形从名词 → 一等系统

| 旧 | 新 |
|---|---|
| 只有固定四点岛台 | 山海湖河林完整生成 |
| 地形只在种子举例里出现 | **地形影响声学耦合（O 与 T）** |
| 岛台四边各扩 2 格 | 边界由地形决定 |
| 无地形动词 | 引水/植树/挖湖/平整/建桥 |

**为什么**：六条要求之一，且旧文档中完全空白。

### 3.5 UI 从常驻面板 → 近乎全空

| 旧 | 新 |
|---|---|
| 右侧 31% 宽滚动控制台 | **无** |
| 常驻底部条件卡 | **无**，改悬停出卡 |
| HUD 主动弹缺口提示 | **声音先行**，视觉柔光 |
| 按钮列表 | **环形菜单** |
| 数字常驻 | **节拍条视觉隐喻**，数字悬停时看 |

### 3.6 单模式 → 三模式

| 旧 | 新 |
|---|---|
| 七乐章固定结束 | 交响曲（7 乐章）/ **自由共鸣**（无终点）/ 聆听 |
| 结束 = 重开 | **结束可"继续经营"** |
| 无导出 | 城市曼陀罗 + 音频 |

**为什么**：22 分钟长不出大城（Q19/Q26）。

### 3.7 生成从撒点 → 六层管线

| 旧 | 新 |
|---|---|
| 锚点周围四邻格挑一栋 | 地形→骨架→社区→街坊→地块→建筑 |
| 家族连通群 = 社区 | **家族 ≠ 社区**（社区有稳定 ID） |
| 道路只阻断 | 道路有正面作用（回声街/连通/移动体） |
| 无街坊/临街面概念 | 完整街坊与地块层 |

**为什么**：撒点长不出城市结构（来自技术调研的核心结论）。
