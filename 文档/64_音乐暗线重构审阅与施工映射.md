## 2. 正式采用的取舍

| 对象 | 施工目标与边界 |
| --- | --- |
| free日常主控 | 由单一调度职责统一母曲、分支与过渡；迁出PhraseTide/CadenceVariation/LongForm的竞争选曲消费者，保留legacy、显式旧谱与已通过接口。模块名UndercurrentDirector是提议，不要求重写已有工作器 |
| 基础与空间染色 | 单屋/未接路/无水/单风貌都有完整简编；空地允许低存在感伴奏或自然留白，不把Lead首次出现当奖励。真实院落、水岸、曲路、作业/文化体量影响音色/织体，不以district才准听Warm/Flowing/Echo |
| 旧空间契约 | `functional_zones()`及证据结构保持，音乐在其外建立独立只读亲和度适配；道路、公共入口、岸路支撑等仍用于物理合法性、真实可达、旧收益/历史消费者。不能为音乐放松真实建造校验 |
| 自动短声 | free退出经营/品质/成区奖励型周期播报，保留真实操作触感及少量有来源、合时宜的近景点景。先迁任务/旧收据/烟气等消费者，legacy不被一刀切停。Lead实际休止、剩余尾音/短槽/用户偏好共同决定留白，不按固定拍位必响 |
| 落笔触感 | 连续笔画合并/节流、收窄刺耳候选音区，与当前已播和声一致；同笔3声、半拍间隔、降低鸟音八度均为试听起点。取消自动成区fanfare与飞章，不取消必要操作确认 |
| 日常HUD与卡片 | 五线谱保留低存在感且可点击到L；卡片可简写真实风景，不常驻stage/缺资格催促；经营开启的品质/库存/进度按65显示。**建造失败、阻挡、保存失败等可操作原因仍明确显示**，不能以诗句掩盖错误 |
| 主动查询 | L合实际曲目/乐器、偏好和必要状态，工程字段折叠；F1/J保历史权益。描述只对应实际已播/真实来源，准备和余韵不冒称新声部已进入；诗意命名不是新建第二套面板的理由 |
| B静听/P侧耳 | B不抢fixed母曲；P作为主动聚焦可温柔抬相应声部、其余退让，保留取消/恢复和原接口。先接真实轨道归因，现有ScoreSolo复用的是领唱，不能把它称作所点房屋的竖琴/木管。不另建播放器/第二layer3 |

音乐暗线不等于强制全程低音量或永不发声。静音、退出、用户音量/偏好与可访问控制优先，不能套慢包络导致静音后仍响。水/森林自然声读取真实环境或明确的底景设计，不凭空宣称无水空城有溪流/鸟群。

## 3. 空间映射的修正契约

采用“全城底色＋焦点局部”的双层感知及围合、流动、呼应、抒情、风貌五类输入；五类影响同曲内预写材料，不建立新的玩家评分条。不能用原稿trait=.45/cluster=.75/district=1直接换皮为另一套接路升级梯度。适配器读真实形态证据，缺路不禁完整简编，道路只提供其真实有意义的贡献。

原公式的focus权重未归一化，近处房屋越多总权重越大，容易把密城所有指数推满；场所W(s)未定义，空间与成员重复累计。施工采用以下确定性基线，可由对照改参数：

1. 每个房屋或规范化空间证据先生成稳定身份与有限特征。按来源集合/几何身份去重，单栋楼层/装饰实例不重复算“多栋”，院落与其成员贡献预算明确。
2. 对实际相关来源计算原候选距离核q；q总和大于0时，local权重为q/Σq，全城权重为1/N，两者按缩放平滑混合。N=0显式采用空地编配；local为空且N>0时使用全城底色，不能除零或把所有轨道静音。原稿额外.35保底没有进公式，不作为已实现特性。
3. 以有界特征的加权平均得到各亲和度；缓存几何/空间特征，镜头只重加权，局部编辑更新相应依赖。不在每帧重新扫全城/重算空间契约，不能从“零新碰撞”推导零成本。
4. 水岸色彩可由真实临水关系产生，无需全城接路；公共可达/遮挡仍决定实际通道、茶座等。内陆曲路可提供流动感；**原稿只有.45曲路项，永达不到.55 Flowing阈值**，不能据此声称内陆已覆盖。为内陆写适配的分支/阈值样板并核正反例，不伪造水岸。
5. 高程与层数先统一为实际米制高度/轮廓，再归一化；不能直接将base_y米数与level层号相加，也不能因此授予civic资格。相邻风貌、作业体量等只影响音乐染色，不新造经营记录。
6. Echo行的公式/输出缺损，不能从碎片反推完整算法。用已有真实作业/相邻关系做最小Echo样板；Canon待补双方来源、空间关系、预写对位及消失/Undo规则。单风貌可以有全部必要表达，但不强制每座城都自动开所有最高档。

离散分支仍需稳定ID、支持矩阵与滞回；不得把连续权重直接用于任意音符插值或随便混四首曲。主/副风貌边界须稳定平局与迟滞，不能在50/50两街来回换器。现有PAN路由不支持逐音独立定位，按63说明原池内可实现的路由与镜头更新/缓存影响。

## 4. 慢过渡与撤销：两层控制、一个播放真相

连续层平滑实际增益/声像/混响，内容层执行“稳定播放→候选观察→准备→预约边界→同播放器预混→稳定”。请求、已准备和实际已播分别维护；同城同曲换器保持乐句/段落位置。自动换曲倾向完整曲末，fixed/quiet及手动选择优先。缺谱、准备超时保留有效旧编配或同曲简编，不把缺支当静默，更不把未就绪内容在UI称作已响。

| 原稿起点 | 采用与修正 |
| --- | --- |

静默与长尾、预混期活跃/旧流/在途资源、所有源/DSP/内容版本纳入预算；不能通过额外AudioStreamPlayer绕过12/4/6/2。新城、新曲、调式、源版本或偏好变化使相应请求失效；删除与Undo用内容签名/真实当前来源重新判定，不因city revision改变就重烘所有PCM。用户取消P/B/面板不丢原偏好与播放恢复点。

旧空间资格不为余韵宽限复活，技术层原子更新仍沿现有ScorePlayback的实际游标与短声和声交接。换曲/换调式预混会同时包含两套和声，选择已写定过渡/兼容边界或先退后入；不能让短声声称同时属于旧新两套权威和声。极短预混的共存只作交接尾音，不引入第二独立领唱时钟/来源。

## 5. 原稿诊断、谱面与时间线校正

- AB1六段Lead占23/32拍确实成立，整体MIDI69—86；但“AB1/旧谱Foundation每小节只有一个1.5拍、Pulse全是.65—.75”不成立。AB1各段Foundation为10/15/8/16/15/8事件，Pulse含.6/.65/.75/.85/1/1.25等时值；按实际声部与段落分析薄的原因，不把旧master2和新AB1混为同一谱。
- AB1 Answer原音范围MIDI55—69，第二谐波对应高一八度，不是原稿所称全在A5—A6；二泛音强也非物理错误。“人耳最敏感频段”“必然单薄”的根因推论未经受控听评，不作为已定位事实。+20.5dB是lift上限，固定+9.5dB与按声部再减1.5—2.5dB是待试方案，不能承诺所有段落自动更均衡。
- `ConstructionWalk range(60,97)`上界是MIDI96/C7，但实际选前6个和弦音，不证明会弹C7；world_tree也要按实际和弦与移调核音，不由`+48`直接断言D7。降音区/换器要同步白名单、预烘与最终发声时和弦校验。
- 原稿P0声部计数16+27+20+6=69、每小节Lead声明合计20拍；P2为16+26+7+3=52、10拍，**只能验证声明自洽**。没有音符不能验证并集、音高/解决、跨界尾音或配器成品。P0声明62.5%也不自动证明“主奏偶现”。仍按63先补逐音稿并独立听评。
- P0第3小节起于6秒；事件6.2后的下一187.5ms网格是6.375，原表9秒Lead具体E4/C#4尚无谱支持。下笔音A3/C#4/E4须按实际已播和弦验证，不能在整个拖动阶段固定复用A和弦。
- 96秒起P4为Bar33，108秒为Bar37，原文“108秒P4 Bar37”时间可对；不得把96秒等同Bar37。Bar47从138秒开始，139.5可为其内部某一拍；最后Lead若按63结束P5 beat27.5，应在140.625秒结束，余3.375秒。原文在139.5“吹完”与4.5拍余韵不相容。
- 27—42秒引水不能直接约定36秒一定安装；只有实际提交、停笔/稳定、就绪及相位条件均满足才成立。院落石板/花丛、条纹布篷仍先验证实际生成来源/净空，不能因放宽音乐门禁就无条件长出装饰。用实录事件生成时间线，原稿示例不是验收证据。

## 7. 施工接续与验收范围

1. 保留旧v2、B1/B2及v3 P0技术基线。当前最小切片按63/本文件补齐田园P0/P2真实逐音谱，先证明伴奏自足和Lead留白的品质。新稿缺谱不阻塞施工AI按已采纳目标作曲，但不得称原JSON已到齐；新写谱注明施工创作与来源修订。
2. 同曲先做一处真实未接路院落或内陆曲路的亲和度适配与慢包络/候选观察；取不换曲、不新建UI的可听样板，证明未接路也完整、镜头掠过不反复切、删/Undo余韵事实分离。必要内部v3扩展随切片落地，不先搭通用平台。
3. 补首曲其余段落/预写分支、完整144秒/首尾及实际空间选择，再按受测范围切free默认和迁旧竞争消费者；L/卡片/HUD、主动P/B及短声与默认接通同批验证，不以隐藏UI等于暗线完成。
4. 单曲品质与空间闭环通过再扩六曲/十调式及内容储备；用户允许音乐、美术、建筑/变体逐步积累，扩库的具体管线已由65续接采用，不以本原稿代作扩库已施工。

验证选择相关CPU/API与旧档/作品、实际OpenGL输入/原图/PCM；锁调式/镜头/版本做等响度A/B与多轮长听，覆盖空地/孤屋、无水/单风貌/混搭、快速掠镜、连续加建、删除宽限内外Undo、缺支/超时/换城/取消加载、静音/P/B及历史来信。记录目标/就绪/实际安装、取消与资源释放时刻，不能以固定秒数或零削波冒充体验通过。
