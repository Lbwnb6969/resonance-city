《共鸣之城》专题D：UI、作品管理与系统整合设计案（工程校准与全系统收口版）

本设计案以**《专题A：完整城建与美术设计案（第二轮工程校正与边界收口版）》、《专题B：音乐系统与音乐资产生产设计案（工程校准与曲库生产版）》及《专题C：成长、居民与数值系统设计案（含最终数值与资产边界修订补丁）》**为唯一产品基线，严格对照
ui_关键源码.txt、PROJECT.md、文档/54、文档/56、文档/60、文档/61、文档/70 与 文档/工程维护.md 编制。

全案恪守以下十二条核心红线：

1.  不新增常驻 HUD 遮挡核心画布（保持 \ge 92\% 3D 视口留白呼吸感）；
2.  不把基础建造工具隐藏在复杂二级菜单（五大画具一级直达，全风貌与基础细部开局可用）；
3.  不把等级、经营、居民或音乐状态做成强制任务或催促弹窗；
4.  不在 UI 中假称候选音乐已正式通过（严格区分 候选 / 技术通过 / 待听评 / 正式曲目）；
5.  不把因结构变化而暂不显示的休眠细部显示成“已丢失”（保留手选高亮并给出具体失配原因）；
6.  不混淆旧城历史权益（growth_cutoff）、当期新账期（cozy_progression）与跨城作品图鉴（AcousticArchive）；
7.  不覆盖作者手选内容（单屋手选优先于聚落默认，成组编辑默认勾选保护手选屋）；
8.  所有悬停与草稿预览绝不写入 State、不递增 _high_watermark ID、不触发自动保存；
9.  所有单笔笔画与多屋批量修改必须合并为单笔可撤销意图（State._commit）；
10. 1024×768 小窗口必须 100% 可读、可点、零控件重叠且不遮挡画布中心；
11. 原作品不可变保护（任何衍生改造、跨版本规则切换、旧档建账均先备份，绝不覆盖原文件，施工隔离会话绝不写入个人 user://）；
12. 全文严格执行 [A] / [B] / [C] / [D] 四级工程事实分类，不编写新的 Godot 代码块，不将设计提案冒充为已实现功能。

      - 在作品外层元数据或 creative_settings 附属只读记录中维护最多 12 条轻量里程碑条目：{"kind":
        "first_bridge", "at_sec": 420, "caption": "双孔青石拱桥跨过河湾"}。

        Ctrl+Z 撤销，未持久化的临时编年条目同步撤回。

        作品文件损坏，当前无法打开；原文件已保留，禁用「打开」与「回放」按钮，绝不污染当前正在游玩的城市（gallery.gd:137

13. 风险分析与必须执行的实机验证清单（对应交付项 13）

13.1 核心 UI 与系统整合风险及防回归对策

1.  1024×768 小窗口下面板重叠与焦点抢占风险：
      - 风险：若玩家同时打开 J 手记、选中房屋展开 HouseDetailSheet、又激活修路子气泡 ToolBubbles，在 1024×768
        下三者会发生水平碰撞并遮挡画布。
      - 对策：强制执行第 2.1 节与第 9.1 节的面板互斥状态机：① 打开 J / L / F1 / 收藏馆 任一记录层面板时，自动调用
        house_inspector.close() 收起房屋详情单；② J 与 L 共用同一个 Scrollbook 抽屉容器，切换页签不双开；③
        ToolBubbles 动态读取 journal.scrollbook.visible 自动右移避让（tactile_dock.gd:153
        [A]）。
2.  成组编辑（BatchEditBar）中途切城或异步重建导致的脏引用风险：
      - 风险：玩家选中 8 栋房屋正处于悬停预览态时，按下 Ctrl+O 切城或按下 Ctrl+Z，若预览残留网格未清理或成组实例 ID
        跨城泄漏，会导致新城市渲染异常。
      - 对策：BatchEditBar 绑定 [state.get_instance_id(), state.revision] 上下文签名（沿用
        window_details.gd:21 模式 [A]）；一旦 state 实例或 revision 变化，或打开任何模态面板，立即清空
        selected_group 并还原预览。
3.  自动化测试脚本因节点改名而断裂的风险：
      - 风险：现有实窗检查脚本（如
        check_creation_progression_ui_live.gd、check_creation_flowering_vines_live.gd）按节点名查找按钮（如
        ChangeProgression、FloweringVines、WindowPennants、WindowDetail_wooden_shutters、DormerChoice_gable_light、GalleryTabs、SaveGalleryVersion）。
      - 对策：遵守文档 61 第 3 节契约，所有既有已通过测试的控件 name 属性 100%
        原名保留；新增折页容器仅作为视觉父节点包裹或通过折叠控制
        visible，绝不删除或重命名既有受测按钮节点。
