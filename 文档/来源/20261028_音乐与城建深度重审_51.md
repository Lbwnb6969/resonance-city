# 《共鸣之城》音乐与城建深度重审：新设计方案与方向总纲

> **核心设计转向（一句话总纲）**：
> **砍掉「同质化点房设店 + 小人跑腿打卡 + 单一预设播全轨」，确立「建筑组合自动长出四大功能区，四大功能区各自执掌一层真实声部，跨区共屏即实时合奏」。**

---

## 一、 核心痛点复盘：为什么现在的「城建」与「音乐」还没完全咬合？

| 维度 | 现有实现（`M75–M82_STEP1`）的深层问题 | 新设计方向（城建即配器 · 空间即总谱） |
| :--- | :--- | :--- |
| **1. 城建与功能区** | **「建筑外观」与「功能用途」两张皮**：<br>20 种建筑原型只管好看，8 种用途（面包/茶座/制琴/钟表/书院）只往普通房子门边贴 `0.4m` 小木牌；且需用专门工具挨个点房指派，自由模式下几乎无体感收益。 | **「形态即功能区，成区即变貌」**：<br>废除逐屋贴标签与抽象街坊画笔。由**「所选建筑原型 + 道路宽度 + 水岸/高差地貌」**自动聚合成 **4 大功能区**，成区瞬间直接改变整条街的建筑构件与天际线。 |
| **2. 城建对音乐的控制** | **「单点决定全曲，跨区毫无合奏」**：<br>目前 `orchestration_plan.gd` 只看镜头中心那 1 栋房子的时代和临水距离，选出 1 套风格后，把 `lead / pulse / answer / foundation` 四条轨全用同一套预设播出来——哪怕玩家精心建了左岸市集、右岸钟楼、山顶卫城，同一时间也只能听到单一风格的独角戏。 | **「分轨归属不同功能区 · 跨区实时室内乐合奏」**：<br>将 4 个音乐职责拆解绑定给镜头视野内的 **不同功能区**——栖居区托底（`foundation`）、市集区走流水琶音（`pulse`）、百工区拉复调对位（`answer`）、卫城/焦点区唱主旋律（`lead`）。**你建出什么功能区组合，耳边就合奏出什么编制！** |
| **3. 音乐本身的耐听度** | **「伴奏单音跳八度 + 应答单音漏音 + 8 小节同型重复」**：<br>`core_scores.gd` 中 `pulse` 逐音孤立调 `Register.plan([pitch])` 导致琶音无方向感；`answer` 在 24 秒内只弹 3 颗孤立单音；`color` 变体只改和弦取音偏移，连续听两圈易腻。 | **「上下句问答曲式 + 整小节琶音浪潮 + 三态织体变奏」**：<br>8 小节严格按「前 4 小节半终止悬停 + 后 4 小节延留解决」写作；`pulse` 整小节规划上下行波浪；`answer` 升级为 3 音级进呼应短句；`color 0/1/2` 切换上行浪/拱形浪/钟摆浪三种织体。 |
| **4. 市民生活定位** | **「模拟人生式的打工算账」**：<br>3,500+ 行代码算小人上下班、揉面读条、买面包凑桌、抢长椅互斥锁，既阻塞音乐触发又拖慢 300 屋编辑（`12.8~21.5s`）。 | **「拓扑连通即共鸣，小人退居视觉音符」**：<br>功能区与音乐完全由**空间几何与道路连通（`component_of`）**即时激活；小人仅作街景漫步与近景触发 16 分音符星芒泛音（`sparkle`）。 |

## 二、 城建新设计：四大功能区「自动成区规则 × 街区视觉质变 × 游戏内硬核收益」

### 2. 城建工具栏的减法与整合（与现有代码平滑衔接）
1. **建造即定性（`derive_natural_role`）**：玩家从底部 `NewHousePalette / PrototypeBook` 选原型建房时，系统自动根据上表写入底层 `house.role`（如选 `clock_turret` 自动记为 `clockmaker`，选 `rotunda` 自动记为 `atelier`，临水建房自动交替配为 `bakery / garden_cafe`），**无需玩家再点第 4 工具手动贴标签**。
2. **弱化并收起旧工具**：第 4 工具（`RolePalette`）与第 7 工具（`DistrictBrush`）不再作为日常必点步骤，仅保留底层接口以兼容 375 项旧档回归测试。
3. **左侧 `L` 键手卷彻底改版为《城市功能区与交响总谱》**：砍掉“柜台 2/6 · 已售出 X”的仓库报表，直接显示当前城市**四大功能区的成型状态、各自点亮的声部轨、以及五大建筑和弦的激活进度**。

## 三、 音乐新设计：「空间多区实时混音」与「六大风格不单调作曲法则」

### 1. 核心革新：从「单风格包办四轨」升级为「四大功能区跨区合奏（Spatial Multi-District Mixing）」

在保持现有 **`12 长轨 + 4 短槽 + 6 总线 + 2 自然声`** 硬件预算与 **24 秒全局共享拍钟** 不变的前提下，升级 `city_creation_core_orchestration.gd` 的声部装配逻辑：

```
                     【镜头视野内的城市空间布局 (Camera Focus & Nearby Districts)】
                                           │
        ┌─────────────────────┬────────────┴────────────┬─────────────────────┐
        ▼                     ▼                         ▼                     ▼
[焦点主导功能区]       [视野内有☕水岸市集区]     [视野内有⚙️百工匠造区]  [视野内有🏡栖居/🏛️卫城]
        │                     │                         │                     │
        ▼                     ▼                         ▼                     ▼
  决定【Lead 领唱轨】    注入【Pulse 律动琶音轨】   注入【Answer 复调应答轨】 注入【Foundation 根音轨】
 (长笛/双簧管/毛毡琴/   (吉他指弹浪潮/竖琴水波/    (拍2.0-3.25 三音室内乐   (大提琴跨小节长弓 +
  手风琴 8小节主旋律)    连续八分分解和弦推进)      对位接腔 + 钢片琴花音)   圆号五度 + P4深流低音)
```

- **玩家立刻能听懂的城建正反馈**：
  - **只建了普通民居（🏡栖居区）**：听到的是宁静温暖的**主旋律独奏 + 大提琴根音托底**（清澈松弛，留白充足）；
  - **在河边加建了一排☕水岸市集与栈桥**：下一小节交界处（`3.0s` 预混边界），**吉他/竖琴的流水分解琶音（`pulse`）立刻柔顺切入**，整首曲子瞬间流动起来！
  - **在街角建起一座⚙️转角铜钟或折顶工坊**：主旋律每个长音停顿的间隙，立刻多出**大提琴泛音/钢片琴的 3 音呼应短句（`answer`）**，从独奏变成室内乐重奏！
  - **在高地建起🏛️爱奥尼柱廊长馆或放置传世地标**：144 秒曲式行进至 `P1/P3/P4` 时，正式解锁**华彩展开段与低音区大提琴深流高潮段**！

### 2. 根治“听久了单调”的三条作曲硬法则（改造 `city_creation_core_scores.gd`）

1. **法则 ①：8 小节旋律强制采用「4+4 上下句呼吸曲式 + 弱拍经过音」**
   - **上句（Bar 0–3 · 呈示与悬停）**：Bar 0–1 动机呈示，Bar 2 加密展开并插入**弱拍级进经过音（Passing Tone）**，Bar 3 落脚在**属音（五级）或二级半终止长音**，产生“话未说完”的期待感；
   - **下句（Bar 4–7 · 模进与归宿）**：Bar 4–5 推向全句音高顶点，Bar 6 回落，Bar 7 通过 **`sus4 → 3` 或 `2 → 1` 延留解决**稳稳回到主音全终止。
2. **法则 ②：`pulse` 伴奏废除单音孤立折八度，改为「整小节三态琶音浪潮」**
   - 将每小节 `4~6` 个琶音音符作为一个整体数组传入 `Register.plan(wave_pitches, Vector2i(52, 72), tones)`，杜绝相邻伴奏音乱跳八度；
   - 利用现有的 `color`（`0 / 1 / 2`）切换三种截然不同的琶音形态：
     - `color = 0`（**上行涌浪**）：`根 → 五 → 十 → 高音五`；
     - `color = 1`（**拱形摇曳**）：`根 → 五 → 十 → 九 → 五`；
     - `color = 2`（**钟摆留白**）：`五 → 十 → 三 → 五`（带附点呼吸）。
3. **法则 ③：`answer` 内声部从“单音漏音”升级为「3 音室内乐接腔短句」**
   - 废除原代码 `([3.25] if bar in [1,3,5] else [])` 的孤立单音；
   - 在第 1、3、5、7 小节主旋律长音留白窗口（拍 `2.0 ~ 3.75`），奏响 **3 音反向/级进呼应短句（`拍2.0(八分) → 拍2.5(八分) → 拍3.0(四分)`）**，让相邻功能区之间产生真正的室内乐对话。
