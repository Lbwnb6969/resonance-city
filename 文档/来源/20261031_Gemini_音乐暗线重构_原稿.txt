1.2 为什么现有系统（含 B2 与 V7 前期设计）仍像“显线”且听感“又尖又抢耳而且单薄”？

结合源码与用户真实听评，问题同时出在底层声学/配器与上层交互/时间结构两个层面：

1.  为什么 B2 听起来“又尖又抢耳而且单薄”？
      - “尖、抢耳”的根源在音域与占用率，不在单纯的音量或起音毫秒数：B2 沿用了 田园晨风_arrangement_ab1.json 的全部 388
        个音符，长笛（lead）依然写在 MIDI 69–86 (A4–D6, 440–1175 Hz)，且在 P0–P5 每一段都占满了 23.0
        / 32.0 拍（71.875%）；同时 answer（cello_harmonic）在
        city_creation_chamber_timbres.gd 中二次谐波高达 0.65（基波仅 0.30），实响窜入 A5–A6
        (880–1760 Hz)。把高音长笛压低 3dB 并削弱泛音，无法改变它在人耳最敏感频段持续吹奏的事实。
      - “而且单薄”的根源在伴奏织体空洞与中频缺失：在 arrangement_ab1（及旧
        master2）中，foundation（bass）每小节只在第 0 拍弹一个 1.5
        拍短音，后半小节低音完全悬空；pulse（guitar）每小节只弹 2～3 颗孤立的 0.65–0.75
        拍单音，没有延音交叠（Let-ring），也没有三度/六度双音或中音区（MIDI 50–66, 146–370 Hz）和声铺底。当 B2
        把长笛压暗、或当 P2 减少长笛音符时，中频段像抽空了一样，只剩干瘪的单音拨弦，听感必然既单薄又突兀。
      - 自动增益抬升（Experience.lift()）制造了“越减法越贴脸”的反常现象：city_creation_music_experience.gd
        第 20–32 行的 lift() 会根据当前活跃轨道的理论峰值和，将所有长轨动态猛抬最高达 MASTER_LIFT_DB = 20.5 dB
        以逼近 LONG_PEAK_BUDGET = 0.56。当单屋开局或进入 P2 减法段、伴奏变弱时，bound 变小，lift()
        反而把仅存的长笛音量大幅推高，导致减法段比合奏段更抢耳！
2.  为什么音乐体验仍像“显线机制”？
      - 底层三套选曲/时间机器并存且切换过急：
          - 旧日常链（HarmonicEmergence + PhraseTide + CadenceVariation）每 3 秒（1小节）或 6
            秒（2小节） 就重新选举一次 lead_track 并在不同聚落乐器间跳切；
          - 短音链（AttentionMixer + ChamberOrnaments + DistrictReply +
            CircularCanon + BakeryCues）在每小节固定拍位（如
            tick 0, 2, 4, 6, 8, 10, 12, 14）高频轮询，把钟声、笛声、问答、轮唱塞进背景；
          - 空间契约链（Courtyard/Waterfront/Artisan/CivicContract）虽已改为只读派生，但前期 V7
            设计将其绑定为 trait → cluster → district 三级硬门槛（必须接通已发布路网 + 满足严格前庭/高差，否则不给
            Warm/Flowing/Echo），甚至设计了“成区瞬间播放先导动机（Fanfare）”和满屏的“门前尚未接路 /
            面水通路受阻”诊断文案——这在体验上把自由造城变成了“为了解锁音轨而去凑几何条件与修路”的显线任务。

三、“显线转暗线”整体方案与明确取舍

3.1 核心设计哲学：什么是《共鸣之城》的“音乐暗线”？

1.  音乐是“空间的体温与光影”，不是“建筑的通关奖励”：
      - 玩家造城的第一驱动力是**“我想在这里摆一排临水小屋、围一座小院、拉一条弯路”**。
      - 只要玩家落下第一间房，哪怕没有修路、没有水、没有凑齐四种功能区，音乐就已经是一首伴奏温暖饱满、旋律松弛有呼吸的完整室内乐。
      - 随着院落合拢、水岸成形、街巷延伸、台地隆起，音乐像水面泛起涟漪一样，在几小节（6～24
        秒）的慢潮汐中悄然增加弦乐的暖意、竖琴的波光或木管的远景回声——玩家不需要知道背后叫 Warm 还是
        Flowing，但当他转头看自己造好的水岸时，耳朵会自然感受到那份温润的流动。
2.  “伴奏常温、主奏偶现、留白有风”：
      - 彻底反转过去“长笛从头吹到尾占 72%、伴奏只有单音点缀”的倒金字塔结构。
      - 底层（常驻暗线）：自然风声/溪流（Ambience）+ 大提琴/低音提琴温润根五度（Foundation）+
        古典吉他/竖琴交叠指弹（Pulse）。它们工作在温暖的 65–392 Hz
        (C2–G4)，全天候自足成立，不尖、不燥、不单薄。
      - 中层（空间呼吸）：单簧管/柔化大提琴泛音/木琴的室内乐应答（Answer），只在主奏停歇的气口轻轻接话。
      - 顶层（偶现微光）：中音区木笛/毛毡钢琴（Lead，D4–D5），唱完两小节或四小节句子后主动退场休止，绝不贴脸抢戏。

四、空间、建筑形态与营造行为的声音映射机制

4.1 连续空间声学场（Continuous Acoustic Field）：告别“凑区解锁”

为了解决“空地到小城、混搭/无水/单一风貌怎样一直完整成立”，我们将底层声音映射从**“四选一/达标解锁”重构为“基础常驻自足层 +
四维连续空间染色（Spatial Coloring）”**。

（1）镜头感知与全城底色的双层融合公式

设当前城市全部建筑集合为 H，镜头焦点为 \mathbf{f}，镜头缩放为 Z \in [9.0, 96.0]。 每一座建筑 h \in H 的空间声学权重
w(h) 由**“近景焦点权重 w_{\text{focus}}(h)”与“全城环境底色权重
w_{\text{ambient}}(h)”**按缩放平滑混合而成：

w_{\text{focus}}(h) = 1.0 - \text{smoothstep}\left(0.25 R(Z),\; 1.15 R(Z),\; \|\mathbf{p}_h - \mathbf{f}\|\right), \quad R(Z) = \text{clamp}(0.85 Z,\; 14.0,\; 36.0)

w_{\text{ambient}}(h) = \frac{1}{\max(1,\; |H|)}, \quad \alpha_{\text{macro}}(Z) = \text{smoothstep}(18.0,\; 48.0,\; Z)

W(h) = (1 - \alpha_{\text{macro}}(Z)) \cdot w_{\text{focus}}(h) + \alpha_{\text{macro}}(Z) \cdot w_{\text{ambient}}(h)

  - 物理与体验意义：
      - 当玩家**拉近镜头（Z \le 18）**细看某片水岸或小院时，\alpha_{\text{macro}} \approx 0，声音细腻地反映眼前这片街景的材质与空间（水岸浮现竖琴、小院浮现暖弦）；
      - 当玩家**拉远镜头（Z \ge 48）**俯瞰全城时，\alpha_{\text{macro}} \to 1，声音平滑融合成整座城市的宏观室内乐交响，不会因为鼠标稍微晃动就忽左忽右；
      - 即使镜头移到远端完全没有建筑的空地（\sum w_{\text{focus}}(h) = 0）：只要城里还有建筑，系统自动保底保留 0.35
        的全城底色权重（或空地本身的田园简编底座），绝不会因为把镜头移向空草地或河面就突然静音断档！

五、柔和慢过渡（Slow Transition）状态机与优先级契约

为了彻底解决“换区、转镜头、加建、拆除、Undo 和换城怎样柔和缓慢地过渡，不靠不断加播放器或突然静音”，我们设计双层慢过渡架构：

5.1 第一层：连续声学包络层（实时帧更新，零换流开销）

在 city_creation_music.gd 与 city_creation_camera_orchestration.gd
中，所有镜头移动、缩放、日夜切换、围合混响偏移均采用非对称一阶低通指数平滑（Asymmetric Exponential
Smoothing），取代原有的快速系数（原 delta * 2.8，约 0.35s 就变完）：

\text{value}(t + \Delta t) = \text{lerp}\left(\text{value}(t),\; \text{target},\; 1 - e^{-\Delta t / \tau}\right)

| 过渡参数                           | 进入/升温时间常数 $\tau_{\text{in}}$ | 离开/降温时间常数 $\tau_{\text{out}}$ | 95% 完成时间 ($3\tau$)                 | 听觉体验设计理由                                                                                 |
| :----------------------------- | :--------------------------: | :---------------------------: | :--------------------------------: | :--------------------------------------------------------------------------------------- |
| **声部目标增益 (`volume_db`)**       | **`3.2s`**                   | **`5.5s`**                    | 渐入 `9.6s` / 渐隐 `16.5s`             | 镜头掠过某片街区或新建房屋时，对应声部如呼吸般在 **8～15 秒**内缓缓浮现或退回背景，绝无突兀跳变。                                    |
| **立体声声像 (`_theme.pan`)**       | **`2.5s`**                   | **`2.5s`**                    | `7.5s`（限幅 `±0.45`）                 | 将长轨最大声像偏移从 `±0.65` 收窄至 **`±0.45`**，平滑速率从 `4.0` 降至 `0.4`（$\tau=2.5\text{s}$），佩戴耳机转镜头绝不头晕。 |
| **总线混响湿度 (`reverb.wet`)**      | **`4.0s`**                   | **`6.0s`**                    | 渐入 `12.0s` / 渐出 `18.0s`            | 进入围合内院或拉远全景时，木石空间感缓慢包裹，离开后余韵自然消散。                                                        |
| **营造编辑让位 (`backing_duck_db`)** | **`0.4s`**                   | **`2.8s`**                    | 压低 `-1.0dB` (`1.2s`) / 恢复 (`8.4s`) | 拖动落笔时背景乐仅极轻微退让 `-1.0 dB`（原为 `-1.2 dB`），停手后用 8 秒缓慢浮回，不产生抽吸感（Pumping）。                     |

5.2 第二层：分谱换流与母曲切换状态机（复用原播放器池）

当空间特征指数跨越阈值（需切换内部 v3 的 tier / color / timbre 分支）或需要切换母曲时，严格运行以下 5
状态有限状态机（UndercurrentTransitionFSM）：

[1. STABLE_PLAYING] (稳定播放当前已落定四职责流)
       │ 空间指数跨越带滞回阈值 (Hysteresis Δ ≥ 0.12) 或偏好改变
       ▼
[2. CANDIDATE_HOLD] (候选稳定观察窗：支撑轨需稳定 6.0s，主奏/母曲需稳定 12.0s)
       │ 若窗口内镜头移开 / 玩家执行 Undo / 拆除来源 ──► 立即取消候选，留在 [1. STABLE_PLAYING]（零打扰！）
       │ 观察窗满，确认真实意图
       ▼
[3. WORKER_PREPARING] (后台线程渲染或命中 LRU 缓存；期间原四轨继续稳定播放，绝不静音)
       │ 若准备期间换城 / 显式换调式 ──► 丢弃过期结果，转入换城柔切
       │ 准备就绪 (authored_score_ready)
       ▼
[4. BOUNDARY_SCHEDULED] (对齐安全音乐边界：支撑轨对齐下一 6.0s 两小节边界，Lead 对齐下一 12.0s 四小节乐句边界)
       │ 后台生成同播放器 450ms 余弦等幂预混流 (Cosine Equal-Power Premix WAV)
       ▼
[5. PREMIX_CROSSFADING] (在安全边界处经过 450ms 平滑交接，完成后切回稳定目标循环流，释放临时过渡流)
       └──► 回到 [1. STABLE_PLAYING]
