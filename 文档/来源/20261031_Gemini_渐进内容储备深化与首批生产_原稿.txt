      - 原稿Lead第2小节[4.0, 1.75, 66]与[5.75, 1.25, 62]合计3.0拍，第6小节[20.0, 1.75, 71]与[21.75, 1.25, 66]合计3.0拍，第8小节[28.0, 1.75, 62]占1.75拍，导致总并集为20.75拍。

2.  P2_cross（Lyrical + Warm + Flowing + Echo）：
      - 原稿Bar 17（beat 0.25）与Bar 21（beat 16.25）的Foundation
        strings演奏MIDI 54（F#3），与beat 0.5 / 16.5进入的Pulse harp
        MIDI 55（G3）形成1.25拍的小二度（半音）重叠。

        cross长音由2.75拍收束为2.5拍，使P2_cross Lead并集严格为10.0拍（31.25%）。
3.  P0_cantabile（Virtuoso级克制歌唱分支）：

B. 独立于 house.seed 的五维细部变体插槽 (scripts/world/city_creation_morphology_variants.gd)

为彻底避免修改house.seed污染旧城，新增可选字典字段house.morphology（缺省时由hash([house.id,
int(house.seed), "morph_v1"])派生只读默认展示，旧作品无此字段时保持100%原几何不变）：

extends RefCounted
## Five-slot building detail grammar. Never mutates house.seed or alters old saves unless explicitly set.
const SLOTS := ["dormer", "chimney", "window_arch", "gable_trim", "porch_clutter"]
const OPTIONS := {
	"dormer": ["none", "pitched_dormer", "eyebrow_vent", "skylight"],
	"chimney": ["default", "single_terra", "twin_stone_flue", "stepped_brick"],
	"window_arch": ["default", "stone_lintel", "round_voussoir", "timber_shutter"],
	"gable_trim": ["default", "corbel_dentil", "timber_bargeboard", "finial_spire"],
	"porch_clutter": ["default", "stone_planter", "timber_awning", "lantern_post"]
}

static func valid(value: Variant) -> bool:
	if not value is Dictionary or value.is_empty() or value.size() > SLOTS.size(): return false
	for k: Variant in value:
		if not k is String or not OPTIONS.has(k) or not value[k] is String or value[k] not in OPTIONS[k]:
			return false
	return true

static func resolve(house: Dictionary) -> Dictionary:
	var result := {"dormer":"none","chimney":"default","window_arch":"default","gable_trim":"default","porch_clutter":"default"}
	if house.has("morphology") and house.morphology is Dictionary:
		for k: String in house.morphology:
			if result.has(k): result[k] = str(house.morphology[k])
	return result

static func cycle_next(city: RefCounted, house_id: String) -> Dictionary:
	var idx: int = city._house_index(house_id)
	if idx < 0: return city._fail("房屋不存在")
	var house: Dictionary = city.houses[idx]
	if house.has("signature"): return city._fail("地标保留专属构件")
	var current := resolve(house)
	var step := posmod(hash([current, int(house.get("seed", 0))]), 11) + 1
	var next := {
		"dormer": OPTIONS.dormer[(OPTIONS.dormer.find(current.dormer) + 1) % OPTIONS.dormer.size()],
		"chimney": OPTIONS.chimney[(OPTIONS.chimney.find(current.chimney) + step) % OPTIONS.chimney.size()],
		"window_arch": OPTIONS.window_arch[(OPTIONS.window_arch.find(current.window_arch) + 1) % OPTIONS.window_arch.size()],
		"gable_trim": OPTIONS.gable_trim[(OPTIONS.gable_trim.find(current.gable_trim) + step) % OPTIONS.gable_trim.size()],
		"porch_clutter": OPTIONS.porch_clutter[(OPTIONS.porch_clutter.find(current.porch_clutter) + 1) % OPTIONS.porch_clutter.size()]
	}
	var before: Dictionary = city.snapshot()
	city.houses[idx].morphology = next
	city._commit(before, "切换建筑细部形态")
	return {"ok": true, "house_id": house_id, "morphology": next, "message": "已切换屋顶天窗、烟囱与门窗细部"}

3.2 标准化制作 Brief 与去重/择优/归档流程

1.  立项 Brief：明确目标槽位（如“deep_flow
    P0/P2暗线分谱”或“clockwork新母型”）、参数边界（拍数/音域/三角形预算/净空包络）及与现有全部ID的差异点。

      - 音乐：每次生成2–3个候选分支，运行静态审计脚本检查：拍位0.25网格、音域边界、同小节半音碰撞（|m_1 - m_2| = 1且重叠>0.05拍）、Lead并集占比（P0
        \le 65\%，P2 \le 38\%），以及与现有母曲的Pitch-Class N-gram重合度（连续8音完全相同则判为重复退回）。

        \le 1）。
3.  等响度听评与三态同景看图：
      - 音乐候选渲染为24s/144s WAV，统一归一化至-23.0 LUFS进行盲听对比（检验是否抢耳、Lead休止时伴奏是否自足）。
      - 美术/建筑候选在固定相机（zoom=22，昼/夕/夜三态，1440×900）下抓拍原图对比轮廓与阴影。
4.  版本化入库、来源许可与淘汰归档：
      - 胜出候选写入正式目录，记录源文件SHA256、作者/AI生成批次、许可证（原创程序化标Original-Procedural，CC0标明具体包名与URL，Foundation/TG研究适配标明本地恢复来源且不进精简库二进制）。
