        (layer 2)：cello_harmonic、celesta、flute、pluck、accordion、wood、bell（音域
        55..74）。
      - foundation (layer 1)：bass（36..50）+ horn（43..55）+ strings /

2.  合成器（city_creation_music.gd _add_note）定点 DSP 听感优化提案（无需新采样资产）：
      - 代码事实：当前 _add_note 中，flute、oboe、strings、horn 的颤音（Vibrato，如 0.018 *
        sin(TAU * 5.1 * t)）从 t = 0.0 起音瞬间就满幅调制，且高频泛音不随音高衰减，在高音区（MIDI
        > 81）容易产生机械电子感。
      - 定点修改提案（待听评 A/B 对照）：
        1.  延迟颤音包络（Delayed Vibrato）：在 _add_note 中引入 var vib_env :=
            smoothstep(0.15, 0.45, t)，将颤音项乘以 vib_env，使长音前 150ms
            纯净起振，随后才浮现自然气息颤音。
        2.  高音区泛音滚降（Register Harmonic Roll-off）：计算 var high_atten := clampf(1.0
            - float(midi - 72) * 0.035, 0.35, 1.0)，对 3 次及以上高次谐波乘以 high_atten，消除
            flute 与 strings 在 A5–D6 的毛刺感。

5.2 十调式（Palette.NAMES mode 0..9）转调策略与问题小节专项修正

  - 代码事实诊断：scripts/audio/city_creation_core_scores.gd 中的 map_pitch(midi, mode)
    采用 index = roundi(float(degree) * (tones.size() - 1) / 6.0) 将 D 大调七声音阶（0..6
    级）映射到目标调式的 KEY_TONES[mode]。

      - 当目标调式为 7 音调式（mode 0, 1, 2, 3, 4, 5, 6, 7, 9） 时，tones.size()
        == 7，一比一映射保留了音程级进与跳进轮廓。
      - 关键问题 1（mode 8：C 宫五声 [0, 2, 4, 7, 9]）：tones.size() == 5！此时 degree 1 (E) 和

        和 degree 5 (B) 均映射为 index 3 (G)！这会导致《田园晨风》第 1 小节的核心动机 D5(deg 0) →

        F#5(deg 2) → E5(deg 1) → D5(deg 0) 变成 D5 → D5 → C5！
      - 关键问题 2（mode 5 B 多利亚、mode 7 F# 小调）：第 4、8 小节原本的导音 C#5(deg 6) → D5(deg 0)
        半音解决，在小调中变成了大二度（A -> B 或 E -> F#）平淡解决，而第 2 小节的 F#5 → D5 → C#5 → B4

7. 曲式接缝、实时交互与短声留白契约

7.1 合法换流边界与状态过渡契约

1.  声部差异化换流边界（保護句法完整性）：
      - 支撑声部（foundation / pulse / answer）：允许在材料后台准备就绪后的下一个 3 秒小节边界（bar_boundary
        = ceil(clock / 3.0) * 3.0），通过同播放器 150ms 预混（StreamTransition /
        ScorePlayback）切入。
      - 主奏声部（lead）：为防止在 4 小节乐句中途（如 Bar 1 与 Bar 2 之间）切档或换乐器导致旋律腰斩，lead
        的档位切换（Simple ↔ Lyrical ↔ Virtuoso）与整句换器严格锁定在 4 小节乐句边界（12.0s
        的整数倍，即段内 beat 0.0 或 beat 16.0） 执行。
2.  后台未就绪、快速连续编辑与换城/换调式：
      - 未就绪保底：若目标高档分谱（如 Flowing 或 Canon）仍在 worker
        线程合成中，当前播放器继续播放已落定的同曲基础档（或上一有效档位），L 页将该声部标为 “准备中 ·
        将在下一小节汇入”，绝不因为等待新分支而静音或回退到无关的旧 8
        小节 original 曲库。
      - 同城连续编辑 vs. 换城/换调式：在建的 city_creation_master_performance.gd 已将
        content_context = [city.music_mode, hash(city.biome_seed)] 与
        city.revision 分离——同城增删建筑/道路只改变空间资格，母曲 144
        秒游标保持连续；一旦发生换城（city.get_instance_id()
        改变）或显式换调式（set_music_mode），立即在当前帧废除旧母曲上下文与在途 worker，防止旧城音乐漏入新城。
3.  静听（B 键）、独奏（P 键）与 quiet / fixed 偏好：
      - P 键屋顶独奏（city_creation_score_solo.gd）：直接锁定并抬升当前母曲正在发声的 lead 播放器至前景包络（0.18
        / pcm_peak），其余三职责让位 -4dB，跨段（如 P1→P2）时保持同一长轨连续播放。
      - quiet 安静偏好：不篡改当前母曲 style（修复 orchestration_plan.gd 强制切 felt_nocturne
        的问题），而是将 pulse 降为 Sparse、answer 降为 Mute、整体伴奏增益 -4dB，让玩家安静听完所选母曲的简编骨干。
