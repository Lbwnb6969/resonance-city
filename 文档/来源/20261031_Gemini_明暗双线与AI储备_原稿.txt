二、明线设计（上）：Tiny Glade 级休闲美学与质感体系

2.1 丝滑直觉营造与“建筑随形化学反应”

玩家在画布上的每一笔操作，都应立刻获得像捏陶土、搭木块一样温润可触的几何与物理回馈：

1.  直接营造与无感切模（Tool 0 筑屋整合）：
      - 单击选屋、表面直拉扩建：在 Tool 0
        下，指向已有房屋侧墙显示水平扩建预览，指向屋顶显示加层预览，按住左键拖动即可一笔拉出连排侧翼或错层高塔；单击屋身则唤出轻巧的屋顶罗盘（SpatialPopover）。
      - 一笔历史与安全回退：预览态仅在独立副本（ChemistryPreview.fork）计算，绝不写 State 或递增
        ID；松开鼠标一笔提交，Ctrl+Z 整笔撤回并带
        animate_house_bounce(id, 0.045) 弹性呼吸动效。
2.  随形生长的建筑微景（Procedural Architectural Chemistry）：
      - 穿堂石拱（Passage）：道路画过底层房间时，实时预览并生成带拱心石与护角柱的穿堂拱洞；
      - 屋谷与转角融合（M83 继承扩展）：相邻或折角（bend_angle_deg）房屋自动织合连续瓦面屋谷，消除生硬穿插；
      - 临水与临街自发点景：房屋靠近水岸（\le 5.2\text{m}）且留有净空时，自动生长木栈桥、折纸水灯（water_lantern.gd）与奶油/陶土条纹布篷（market_frontages.gd）；围合成院时，院心自动铺设青石并生长花丛或涌泉（courtyards.gd）。玩家可通过
        L 页一键开关自动点景，且自动点景绝不锁死后续地形或修路编辑。

三、明线设计（下）：轻量治愈经营与数值成长系统

3.1 设计定调：为什么保留“轻量经营与数值”，又如何避免“打工焦虑”？

玩家喜欢在城建游戏里看到**“我建的面包坊真的烤出了面包、邻居真的去喝了下午茶、工匠把风铃挂上了屋檐、整条街的效率提升了 35%、房屋从 ★1 升到了
★5”——这是城建游戏不可替代的烟火气与正向数值多巴胺（明线）。
过去的问题不在于“有数值”，而在于“用锁工具惩罚玩家”和“用弹窗催促玩家”。因此，我们的轻量治愈经营四原则**是：

1.  建造自由零锁定：四大时代风貌、全部建筑原型、基础配色、调式与地标从开局起 100% 自由可建，绝不用等级去锁住基础画具。
2.  原型即用途，零繁琐指派：玩家无需逐屋打开菜单点选职业——建造水畔敞廊自动开启烘焙/茶座（waterfront_role_seed.gd），建造锯齿花房/双山墙自动开启百工坊，建造圆厅/长馆自动开启书院/礼乐庭（prototype_role_seed.gd）；同时保留屋顶罗盘的一键改用途能力，满足自定义需求。
3.  只有正反馈，没有负惩罚：面包架满了、或者某栋房子没接路，居民只是安静在家歇息或就近散步，绝不扣分、不降级、不弹红字警告、不刷催建任务气泡。
4.  数值成长解锁“美学变种与丰饶效率”：共鸣等级（Lv）与手札（Traditions）不再用来卡脖子，而是提供实打实的生产/通行倍率加成以及全新的建筑外观变种、珍藏色板与街景微景！

4.1 四维连续空间声学场（彻底解耦“接路/成区”硬门槛）

scripts/audio/city_creation_undercurrent_field.gd（<160 行），每 0.5s
从当前城市几何与镜头位置计算以下确定性声学指标：

1.  全城保底与焦点融合权重 W(h)：
      - 设镜头焦点为 \mathbf{f}，缩放为 Z，视野半径
        R(Z) = \text{clamp}(0.85 Z,\; 14.0,\; 36.0)。
      - 每栋建筑的焦点权重
        w_{\text{focus}}(h) = 1.0 - \text{smoothstep}(0.25 R(Z),\; 1.15 R(Z),\; \|\mathbf{p}_h - \mathbf{f}\|)。
      - 融合权重：W(h) = (1 - \alpha(Z)) w_{\text{focus}}(h) + \frac{\alpha(Z)}{|H|}，其中
        \alpha(Z) = \text{smoothstep}(18.0,\; 48.0,\; Z)。
      - 空地保底铁律：若镜头移向无建筑的空地（\sum w_{\text{focus}}(h) = 0），只要 |H| > 0，自动取全城平均特征的
        0.40 权重，绝不因转镜头而切断音乐。
2.  四声部连续映射阈值（带 \Delta = 0.12 滞回区间防止抖动）：
      - Foundation（低音与暖垫）：计算围合与聚落指数 I_{\text{warm}}（闭合院落权重 1.0、半围合/窄巷
        0.70、3屋以上自然聚落 0.45，均不要求道路已接通）。
          - 升档阈值：I_{\text{warm}} \ge 0.42 \implies \text{tier} = \text{warm}；
          - 退档阈值：I_{\text{warm}} < 0.28 \implies \text{tier} = \text{pizz}。
      - Pulse（指弹与流水律动）：计算水岸与曲径指数 I_{\text{flow}}（临水 \le 5.2\text{m} 房屋权重
        0.85、弯曲道路/圆角/折翼/阳台房屋权重 0.50、普通连通街屋 0.35）。
          - I_{\text{flow}} \ge 0.55 \implies \text{tier} = \text{flowing}（竖琴+指弹流水；无水但曲巷丰富的内陆城可通过曲率达到
            0.55 触发内陆微风竖琴！）；
          - 0.25 \le I_{\text{flow}} < 0.55 \implies \text{tier} = \text{sway}（木吉他切分漫步）；
          - I_{\text{flow}} < 0.25 \implies \text{tier} = \text{sparse}（温润交叠指弹基础床）。

            |H| \ge 2）\implies \text{tier} = \text{echo}；
          - 仅在 P2 减法段且 |H| \le 1 或 quiet 模式下

          - |H| \ge 1 且高程/礼乐指数
            I_{\text{lyric}} < 0.35 \implies \text{tier} = \text{simple}；
          - 0.35 \le I_{\text{lyric}} < 0.68 \implies \text{tier} = \text{lyrical}；

            cantabile 抒情重奏伴唱档）。

六、发挥 AI 优势：音乐、美术、建筑种类与变种形态的可持续扩充管线

本项目的核心架构优势在于：所有音乐分谱、建筑原型、立面构件、色彩配方与植物物种均为“声明式数据字典 + 确定性程序生成 + 自动化测试门禁”。这使我们可以将
AI 作为长期的内容扩充引擎，按以下三条标准化管线稳步增加储备：

6.1 AI 音乐储备扩充管线（Music Reserve Pipeline）
