# 《共鸣之城》音乐系统重构方案：预设母曲总谱 × 城建驱动分轨编曲（Pre-Authored Masterpieces & City-Driven Stem Arrangement）

> **核心设计原则**：
> **“作曲家（程序预设）负责保证每一首曲子本身完整、动听、有起承转合；玩家（城建与布局）负责决定这首曲子由哪些乐器演奏、叠入哪几条分轨、绽放哪一段华彩。”**
> 彻底抛弃“用零散算法实时拼凑单音”的做法，改为**「完整预设母曲总谱（Master Score） + 建筑/布局驱动的分轨变奏与配器切换（Stem & Timbre Arrangement）」**。

## 二、 第一层：程序如何预设「大体长什么样」的母曲总谱？

每首内置或通过 `M80` 分析工作流导入的曲目，不再是一段单薄公式，而是一份**预先编好 4 大核心声部、且每个声部自带 2~3 个复杂度档位（Tier）的《完整多轨母谱（Multi-Tier Master Score）》**：

| 预设音轨（Stem Role） | 预设谱面结构（由程序预先精心写定，确保绝对好听和谐） | 预设的 3 个表现档位（供城建行为动态切换） |
| :--- | :--- | :--- |
| **轨 1：主旋律轨**<br>`Lead Stem`<br>*(旋律灵魂)* | 完整写定的 8 小节（24s）× 3 主题（A呈示 / B展开 / C深流对比）：<br>• Bar 0–3 上句半终止悬停；<br>• Bar 4–7 下句推向高点并延留解决回主音。 | • **`Lead_Simple`（纯朴初吟）**：骨干旋律音，温润留白（1~3 栋房时）；<br>• **`Lead_Lyrical`（婉转歌唱）**：自动织入预设好的弱拍级进经过音与倚音（街区成型时）；<br>• **`Lead_Virtuoso`（华彩高潮）**：解锁预设的双音加花与 `P4` 低音区大提琴深流段（建成大型圣殿/地标时）。 |
| **轨 2：律动伴奏轨**<br>`Pulse Stem`<br>*(节拍与流动感)* | 与主旋律和声严丝合缝锁定的 8 小节分解和弦轨（整句规划音域，绝不乱跳八度）。 | • **`Pulse_Sparse`（静谧呼吸）**：每小节 1~2 颗轻拨和弦音（无水岸、道路未成网时）；<br>• **`Pulse_Sway`（摇曳漫步）**：每小节 3~4 音船歌/指弹律动（道路成网或普通街区）；<br>• **`Pulse_Flowing`（深流涌动）**：每小节 6~8 音连续八分/十六分流水琶音（建成水岸市集、宽街或现代水畔时）。 |
| **轨 3：副旋律对位轨**<br>`Answer Stem`<br>*(室内乐对话)* | 预先写定在主旋律长音留白处（第 1、3、5、7 小节后半拍）接腔的 **3 音室内乐问答短句**。 | • **`Answer_Mute`（静默留白）**：单屋或孤立民居时不发声，保持听感干净；<br>• **`Answer_Echo`（街坊接腔）**：在拍 `2.0→2.75→3.25` 奏出预设的柔和三度/六度应答句（建成工坊、茶座或相连街区时）；<br>• **`Answer_Canon`（跨岸赋格）**：完整卡农式反向对位旋律线（跨河桥相连或点亮建筑和弦时）。 |
| **轨 4：和声根音垫轨**<br>`Foundation Stem`<br>*(低频包裹感)* | 跨小节无缝延音（`4.28拍`）的大地根音与五度长垫。 | • **`Found_Pizz`（轻盈拨弦）**：单音低音提琴轻拨（散落小聚落）；<br>• **`Found_Warm`（醇厚长弓）**：大提琴跨小节长弓 + 圆号纯五度暖垫（围合成庭院或高地聚落时）。 |

## 三、 第二层：玩家的「建筑选择与空间布局」如何显著影响音轨与表现？

在母曲总谱已经保证 100% 好听的前提下，玩家的每一次城建决策都会像**调音台推子与乐器编排器**一样，产生立竿见影的听觉变化：

### 1. 不同的「建筑时代与原型」 → 直接切换各音轨的演奏乐器（同曲异器）

当镜头聚焦或街区建造了不同风貌与原型的建筑群时，预设母曲的四条音轨会自动换由对应的乐器家族演奏（底层通过同播放器 150ms 预混无缝换流）：

| 玩家建造的建筑群类型 | 主旋律轨 (`Lead`) 音色变体 | 律动伴奏轨 (`Pulse`) 音色变体 | 副旋律应答轨 (`Answer`) 音色变体 | 听感整体气质变化 |
| :--- | :--- | :--- | :--- | :--- |
| **🏡 古典庭院 / 山墙木屋群** | 清亮木质长笛 (`flute`) | 尼龙弦木吉他指弹 (`guitar`) | 大提琴泛音 (`cello_harmonic`) | 阳光、松弛、吉卜力式的田园微风感 |
| **☕ 水畔圆廊 / 威尼斯连拱街** | 温润双簧管 (`oboe`) | 竖琴水波分解琶音 (`harp`) | 单簧管/竖琴高音水波应答 | 浪漫、优雅、水波潋滟的船歌感 |
| **⚙️ 折顶天窗厂房 / 转角铜钟塔** | 手风琴 (`accordion`) | 轻快木吉他/羽管键琴断奏 | **八音盒钢片琴 (`celesta`)** | 灵动、精致、充满手作机械的巧思 |
| **🏛️ 爱奥尼柱廊长馆 / 罗马巴西利卡** | 高音木管 + 弦乐齐奏 | 开放五度竖琴长琶音 (`harp`) | 跨八度山谷回声弦乐 | 庄重、空灵、卫城殿堂般的开阔感 |
| **🌿 现代生态木构 / 临水慢板街** | 柔音毛毡钢琴 (`felt_piano`) | 中低音毛毡钢琴连续流水琶音 | 醇厚大提琴独奏低吟 | 类似《齐马蓝》的深邃叙事与温暖包裹 |

---

### 2. 不同的「空间布局与修路形态」 → 直接改变音轨档位与演奏技法

| 玩家的空间布局行为 | 对音乐表现与音轨的具体改变 | 玩家听到的直接反馈 |
| :--- | :--- | :--- |
| **① 围合布局（房子围成闭合内院 / 环岛闭合路）** | • `Foundation` 轨从 `Found_Pizz` 升格为 **`Found_Warm`（大提琴长弓 + 圆号五度暖垫）**；<br>• 空间混响湿声（Reverb Wet）微增 `+4%`。 | 围合成院的一瞬间，音乐底部立刻涌起一层温暖醇厚的低音弦乐包裹感。 |
| **② 临水/长廊布局（沿河建房、修亲水木栈桥、铺 `4.8m` 宽街）** | • `Pulse` 轨从稀疏档 `Pulse_Sparse` 直接升格为 **`Pulse_Flowing`（连续八分/十六分流水琶音轨）**。 | 原本安静舒缓的伴奏，随着水岸带与大道成型，立刻变成潺潺流动的琶音浪潮！ |
| **③ 跨区连接（用桥梁连接两岸街区 / 建起钟塔与工坊）** | • `Answer` 轨从静默 `Answer_Mute` 升格为 **`Answer_Echo / Answer_Canon`（室内乐三音对位副旋律）**；<br>• 若两岸为不同建筑时代，左声道主唱用当前岸乐器，右声道 `Answer` 轨直接用对岸街区的代表乐器接腔！ | 真正听到“河左岸的长笛唱上半句，河右岸的毛毡钢琴/竖琴在留白处接下半句”的立体声对话！ |
| **④ 曲线与有机微雕布局（修双点曲路 + 房屋圆角/折翼/半圆阳台）** | • 主旋律与伴奏轨开启 **`Legato`（丝滑连音包络，延长音尾释放 25%）**；<br>• 直路网格街区则保持 **`Crisp`（清脆颗粒感触键）**。 | 弯路与圆角建筑群听起来更加柔和连绵，规整直路街区听起来更加轻快利落。 |
| **⑤ 竖向高差与地标（高地石阶 + 圣殿/四大地面传世地标）** | • 解锁母曲预设中的 **`Lead_Virtuoso`（华彩加花轨）** 与 144 秒第 5 段 **`P4` 低音深流高潮段**。 | 城市拥有制高点地标后，乐曲在推向高潮段时会奏出平时听不到的低音大提琴深情华彩乐章。 |

## 四、 与现有工程（`M78–M86`）的极简对接路径

这套「预设母曲 × 城建分轨编曲」完全复用 `M78–M80` 已建好的底层设施（`score_register.gd`、`stream_transition.gd`、`core_score_cache.gd`、`score_document.gd`），只需在 `M84` 施工时按以下 3 步收敛：

1. **预设母谱分层化（`city_creation_core_scores.gd`）**：
   - 每套预设母曲固定编写好 `Lead`（含基础版/歌唱加花版）、`Pulse`（含稀疏档 `tier=0` / 摇曳档 `tier=1` / 流水琶音档 `tier=2`）、`Answer`（含静默 / 三音接腔短句 / 卡农对位）、`Foundation`（含轻拨 / 长弓五度暖垫）。
2. **城建布局分析器（`city_creation_orchestration_plan.gd`）**：
   - 根据镜头视野内的**① 主导建筑时代/原型、② 水岸与宽街密度（决定 `pulse_tier`）、③ 工坊/跨岸连接数（决定 `answer_tier` 及应答乐器）、④ 庭院围合与地标状态（决定 `foundation_tier` 与 `lead_tier`）**，输出 4 条音轨各自应加载的预设分支键。
3. **跨区异器合奏与有界缓存（`city_creation_core_score_cache.gd`）**：
   - 因为 4 条音轨（`lead / pulse / answer / foundation`）共享同一个 80 BPM、24 秒 8 小节和声时间线与调式 `mode`，**来自不同风貌音色的 `Lead` 轨与 `Answer` 轨天然 100% 严丝合缝同步且和声零冲突**；通过现有的同播放器 150ms 预混换流即可平滑切入切出。
