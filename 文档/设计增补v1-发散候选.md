# 《共鸣之城》设计增补 v1 — 发散候选清单（待评审）

> 工作稿 · 2026-10-08 · v0.1 · **状态：候选，未经批准不得实现**
> 每条标注【成本/收益】与对应解决的弱点。用户圈选后才并入策划案 v3.x。

---

## A. 解决"提案间隙手是空的"（连续动词层）

### A1. 抚琴（The Bow）★ 强推
鼠标即琴弓：按住左键在城市上缓慢拖动，被"抚过"的街区声部会被轻触发声（音量随拖动速度），并获得微量活力加成。
- 本质：把"城市是乐器"从隐喻变成字面事实——策略层之外，城市永远是一件可以直接演奏的乐器。
- 数值上故意做弱（不影响策略平衡），价值全在手感与连接感。
- 【成本：低（合成器触发+少量数值）/ 收益：极高，根除屏保感】

### A2. 光标泛音
鼠标移动本身带一条极弱的热音（theremin）泛音尾迹，音高随纵坐标、音色随悬停街区。
- 默认低音量开启，可关。世界的每一寸都对触摸有回应。
- 【成本：极低 / 收益：中高，"丝滑"与"形象化"的直觉放大器】

### A3. 听诊脉冲
点击任意区域发出一声"声纳"轻响，该区域的隐藏因果链以光波形式显形 3 秒（房租上涨流向、人口迁移路径）。
- 让"主动调查"成为一个动作而不是读面板。
- 【成本：中 / 收益：高，承接 AI 旧案"玩家自己调查城市"的正确直觉】

## B. 解决"没有情感锚点"

### B1. 市民来信 ★ 强推
城市记忆系统 occasionally 生成一封一页信，绑定**真实从玩家选择中长出来的地点**：
> "调音师：我在老钟楼下那家咖啡馆遇见了我妻子。就是您二十年前保留河岸的那次决定。—— 住在北区的林"
- 信在全乐句最强终止式时送达（情感与音乐高潮对齐）。
- 内容模板 × 城市记忆数据填充，成本极低，情感回报巨大——"城市记得"从系统变成了情书。
- 【成本：低（文本模板+记忆数据）/ 收益：极高】

### B2. 指挥风格签名
每局结束生成玩家的"调音师画像"：介入偏早/偏晚（卡拍统计）、协和偏好、留白率、风险胃口，生成一张可分享的雷达图 + 一句命名（如"克制的浪漫主义者"）。
- 游戏版的 Spotify Wrapped，社交传播素材。
- 【成本：低 / 收益：高】

## C. 解决"退化策略"与失败单一

### C1. 留白计分 ★ 强推
终局评分不只看谐振度峰值，还看**动态对比**：全曲最响与最静乐句的差值、留白比例计入艺术分。
- 一句话改变最优解：会"让城市安静"的玩家得分更高——这正是音乐性本身。
- 【成本：低 / 收益：高，堵住退化策略】

### C2. 声部叛离（Tempo Drift）
长期失谐未解决的街区不再只是衰败——它**脱离节拍网格**，开始自由速度演奏（视觉上动效也脱拍）。
- 收服方式不是拆它，而是"带回节奏"：用相邻协和街区包围 + 一次卡拍完美的介入，触发全游戏最爽的"归拍"时刻（偏移的律动被一只看不见的手拉回网格）。
- 【成本：中 / 收益：极高，失败态从"难看"升级为"好玩的难题"】

### C3. 天气干扰
暴雨=本底噪声抬高，失谐更难听清（听觉掩蔽）——天气成为难度修饰器，老手学会"等雨停了再诊断"。
- 【成本：中 / 收益：中】

### C4. 昼夜聆听策略
夜晚城市整体音量下降、掩蔽减少——**深夜是诊断失谐的最佳时段**，但提案在黎明才落定。给"什么时候听"一个策略层。
- 【成本：低 / 收益：中高】

## D. 涌现美学（便宜的大魔法）

### D1. 城市随乐呼吸 ★ 强推
每栋建筑按其所属声部的节拍做 1–2% 的缩放脉冲（底鼓时全城轻颤）——整座城市就是频谱可视化本身。
- Godot 里按 spectrum 频段驱动 modulate/scale，极低成本，极强"活着"感。这可能就是本作截图病毒传播的那个东西。
- 【成本：低 / 收益：极高】

### D2. 赋格应答
两处同类但相距遥远的街区概率触发"问答"：一条街区的乐句在 2 拍后被另一街区复述（卡农），之间拉一道若隐若现的光线。
- 可进配方图鉴："促成一次跨城赋格"。
- 【成本：中 / 收益：高，涌现浪漫】

### D3. 调性迁徙
一整局的调式中心沿五度圈缓慢迁移（商业重心东移→全曲向上纯五度转调）——长线和声叙事，与「转调大师」祝福、城市重心迁移的玩法语义完全咬合。
- 【成本：中 / 收益：高】

### D4. 教学序曲
开局只有一间房子、一个拨弦音。前 5 分钟逐个加入声部——**教程本身就是序曲**，玩家在被教之前先被感动。
- 【成本：低 / 收益：高】

## E. 美术加菜（小而值）

| 项 | 内容 | 成本/收益 |
|---|---|---|
| 水面倒影 | 建筑生成翻转模糊 sprite 倒影，流动错位 | 低/高，夜景翻倍美 |
| 晨光光柱 | 黎明/黄昏定向光束 + 尘埃粒子 | 低/高 |
| 肯·伯恩斯运镜 | 稀有形态/终局回放时镜头缓推慢移（2D 无旋转的替代运镜） | 低/高 |
| 聆听模式 | 隐藏全部 UI，镜头自动游移，城市自我演奏——直播与截图发生器 | 低/高 |
