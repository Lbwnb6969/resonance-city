# U12 / UI-003：Demo失谐边界候选

状态：待用户裁定，不是现行规格。针对当前Demo“声音有诊断，但画面没有抖/刺对应线索”的缺口，先接入可开关的边界诊断；完整视觉优先/E/真人等价验收仍分阶段。

## 建议本轮范围

1. 默认保持现有柔和城市，可勾选“失谐边界”；只画真实四向声学邻接，成路切断的边不显示，未来已渲染状态按可听音频帧显现，不提前透题。
2. “抖”仅用于音程类1/11且真实drone基频差3–16Hz的边，读取合成器同一frequency函数；相位取可听音频帧。把物理频率缩放为`clamp(Δf/8,0.5,2.0)`Hz，并以轻微沿边位移/带宽变化表达，默认不做全屏或建筑明度闪烁。这条诊断缩放例外不宣称是BPM整数分频的装饰动画。
3. 三全音类6显示静止细毛刺，边界形状而不改建筑几何；其他音程保留真实音程名称/关系，不伪称只有两种问题或把商业类型自动叫“刺”。双方当前音级共同决定，不以工业身份单独下结论。
4. 点击建筑，现有卡片增加其真实邻接列表和“抖/刺/其他张力/协和”文字，配同形状图例；不只靠颜色。不会自动选定失谐源、弹窗、隐藏收益或给自动解法。
5. 提供“减弱运动”：抖改为静止双波纹，文字与关系仍完整。沿用柔和色系；边界宽2px，位移/带宽振幅≤2px（1440×900、缩放1基准），最大alpha0.55，整层CanvasItem绘制，不为每栋增加Sprite。
6. 此切片不新增张力债务/E，也不伪造E=0。尚未实现的E在完整视觉优先模式开工时另行裁定；此处标“边界诊断”，不宣称UI-003全项已通过。

## 最低充分证据

沿用当前主场景做一条GPU入口：受控C–C♯抖/C–F♯刺/协和对照、实际道路切断、迁移暂时静音和恢复、真实音级变化在可听帧前后、减弱运动、镜头与选择。边界查询只读且不推进RNG，音频PCM不因显示开关变化；截图与日志记录实际配置和限制，不重跑700栋压力/全频谱/真人听测。

迁移临时静音/mute/solo可能使声音暂时不可听，边界文本应明确“当前不可听/被隔离”，避免说这时仍有可听拍频；关系数值本身仍来自城市。试听期间标明边界来自当前城市，不冒称跟随未来试听副本；完整未来声场可视化另做。
