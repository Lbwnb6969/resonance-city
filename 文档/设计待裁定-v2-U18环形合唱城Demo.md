# v2-U18 · 命名形态首个可玩切片：环形合唱城（第二版）

状态：候选，尚未批准。第二版为 2026-10-09 设计轮修订，取代第 52 轮第一版作为待审方案；第一版原文保存在 `废弃/2026-10-09_设计轮修订前/`。来源：执行交接-城市生长 U18、设计增补 v2 §3.4/§7 与工作稿 §D。与 v3-U22 稀有分级/声部行为、v2-U21 发现池、v2-U19 成形演出分别裁定，不因本页而整体批准。

**一句话**：一圈房子围着它们的共鸣点；当这一圈唱出不止一个音、而且两两和谐，它们开始轮唱——声音沿着环一拍一拍地走，你调过音的每一栋房子都是这段旋律里的一个音。

## 为什么改第一版

| 第一版 | 问题 | 第二版 |
|---|---|---|
| 8 栋同音，西北/东南两组每小节交替 | 同音高；3×3 环通常落在同一个左/中/右声像区，所以交替听起来只是"律动变稀"，几乎听不出呼应。违背 v2 红线"每个命名形态必须有独特且可听的声学行为" | 改为**轮唱**：每栋每 8 拍只在自己的拍子上响一次，按环序走，音高差异让它清楚可听 |
| 源点自然长满一圈就成形 | 按现行扩张排序（同家族邻居最多 → 离源点近 → 坐标序），源点周围 3×3 几乎是默认长法：不稀有，也不需要玩家做任何事 | 自然长满的同音环只是**雏形**；要成为合唱城，玩家至少调出第二个音，且环内邻接全部协和 |
| 成形后只有一条环线 | 玩家不知道发生了什么、为什么 | 环线上有一粒光点跟着正在发声的房子走；条件区写出 8 个音的序列；雏形会提示下一步 |

第二版还顺带回答了用户最早的愿望"让玩家自己创造和改变声音"：不开放自由输入音符，而是用现有的调音动词在和声约束里谱一段旋律——环内邻接必须协和，所以谱出来的旋律总是好听的。

## 玩家体验

```
              0 北（角）
        7 西北（边）    1 东北（边）
   6 西（角）      ◎ 共鸣点      2 东（角）
        5 西南（边）    3 东南（边）
              4 南（角）

   轮唱顺序：0 → 1 → 2 → … → 7，每拍一栋，8 拍（2 小节 = 4 秒）一圈
   四"边"与中心相邻；四"角"不与中心相邻，各与两条边相邻
```

1. 释放一个 C 住宅源点，周围自然长满 8 栋 C。它们成熟后出现淡淡的环线，条件区提示："雏形·齐唱。让其中一栋唱出与邻居和谐的另一个音，环就会开始轮唱。"
2. 选中东北那栋（一条"边"），调音到 E。它的邻居是中心 C 和两个角 C，C–E 大三度 s=0.85，全部协和。收益代价预览写明："将形成环形合唱城（需连续 2 乐句）"。
3. 两个乐句后成形：每 4 秒，一粒光点绕环一圈，你听到 C、E、C、C、C、C、C、C——第二拍那个 E 就是你调的那栋。
4. 再把东南调到 G、西南调到 A：旋律变成 C E C G C A C C。若某次调音让任何一条环内邻接掉到协和以下（例：把一个角从 C 调成 D，D–E 大二 s=0.30），预览会先警告"将失去环形合唱城"。

**一个小谜题**：四个角各贴着两条边。边可以自由选 E/G/A（与 C 都协和）；角要改音，就得同时和两边协和——两边是 E 和 A 时，角可以是 C、A 或 E；两边是 E 和 G 时，角只能是 C。玩家在找"和谐的旋律"时，顺带把音程关系学会了。

## 规则

| 项 | 规则 |
|---|---|
| 名称 | 环形合唱城；声音行为叫"轮唱" |
| 几何 | 中心为住宅共鸣点；周围 3×3 的 8 个外围格由同一源点家族的住宅占满（同第一版） |
| 环序 | 按顺时针偏移：北(−1,−1)、东北(0,−1)、东(1,−1)、东南(1,0)、南(1,1)、西南(0,1)、西(−1,1)、西北(−1,0)，索引 0–7；四正邻为 1/3/5/7。方向名按当前等距地图屏幕方向解释，执行以偏移表为准（同第一版） |
| 成熟 | 8 栋均为群/央/腔，允许混合，不强制腔；每栋未处于碴/冻结，且真实家族连接可达中心（同第一版） |
| 道路 | 环周 8 条共享边与中心到四正邻的 4 条共享边均未成路；未成路足迹允许（同第一版） |
| 雏形 | 满足几何、成熟、道路，但 8 栋只有 1 个音级：环线以一半透明度显示，选中成员或源点时条件区给出上面的提示；**不改声音，不算命名形态** |
| 合唱条件 | 雏形条件 + 8 栋 current_midi 至少有 2 个不同音级 + 12 条环内邻接（环周 8 + 中心–边 4）全部 s≥0.85。只用系统音级与现有调音，不新增音高 |
| 达成 | 以上在连续 2 个实际乐句边界同时满足；中间不满足则清零；只按真实事件帧解析，不按画面/墙钟（同第一版） |
| 轮唱 | 8 拍一圈，每个乐句（32 拍）恰好 4 圈，圈起点对齐乐句第 0、2、4、6 小节。成员 i 只在每圈第 i 拍的拍头发一次律动音，其余时间律动门控为 0。音高 = 该成员 current_midi + 12（即现有律动音高），单音包络沿用住宅律动（起振 0.005 s、尾音 0.25 s、衰减常数 0.075 s）。中心只出长音；所有长音、装饰层和其他声部不变 |
| 轮唱音量 | 原来 8 栋 × 每小节 4 音 = 32 音，轮唱后每小节 4 音。能量相等的上限是单音振幅 ×√8 ≈ ×2.83；建议取 ×2.0 `[建议值]`（总能量约为原来一半，更干净）。公共校准增益、0.20 新实体振幅、27 实体上限照旧；必须用实际新混音复测真峰值与长音 RMS 保护，不以"更稀疏"推断通过 |
| 启用/离开 | 达成边界起用 1 小节从普通律动等功率交叉到轮唱；任一条件在下一边界失效，以 1 小节交叉回普通律动并清零计数；仍满足雏形则回到雏形显示 |
| 可见反馈 | 环线常亮；一粒光点沿环线移动，停在正在发声的成员上（读可听音频帧，拍与拍之间缓动）；选中成员或源点时条件区显示"环形合唱城 · 轮唱"、按环序的 8 个音（例：C E C G C A C C）与连续计数。不新增弹窗或自动镜头；首次形成是否弹成形卡由 U19 第二版决定 |
| 静音与 Solo | mute/solo 不改 R/V 或成形（同第一版）；条件区注明当前是否静音/隔离，不把只听到一部分说成完整轮唱 |
| 断路/调音/迁移 | 道路第三次落定、成员改音或移出、中心改音，按同一真实边界重新判定；失去合唱身份时保留建筑、阶段与永久道路。收益代价预览必须写明"将形成 / 将失去环形合唱城"；未落定的足迹与预览不改变真实身份（同第一版并扩展） |
| 快照/试听 | 连续计数、成员、启用/离开帧、轮唱圈相位与交叉起始值进入城市/音频快照；试听能听到同相位的未来轮唱，但不会给真实城发出成形事件；重开清空（同第一版） |
| 同时多个 | 各自家族独立判定与轮唱；一个建筑只属于一个源点家族，不叠双重门控（同第一版） |

## 可行性与范围

- 中心 + 8 外围共 9 个新增实体，加原 9 街区为 18，不超过 27 上限；不新增音高、音源、声音实体或总线。
- 轮唱门控是"每成员一个拍号掩码"，比第一版的十六分音符包络斜坡更简单；不在每帧重扫建筑。
- 雏形几乎每局都会自然出现，所以玩家一定会遇见这个形态；合唱城需要至少一次调音（−10 活力、占用一个乐句的介入），是一次有意的选择，而不是白送。
- 这不是抽卡发现或永久收藏：稀有度、三池计数、持久图鉴、City DNA 回放与奖励仍由后续独立裁定。梯田赋格镇、双子港等其余命名形态保持后续目标。
- 时代系统获批后（设计增补 v4），环的外观按时代换装——古典井院、中世纪回廊、文艺复兴圆形广场、工业环形公寓、现代圆形集合住宅——轮唱行为不变。
