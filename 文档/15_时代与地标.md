## 1. 五个时代（保留）

| # | 时代 | 副题 | 城市形态 | 新增声音 | 可用音级 |
|---|---|---|---|---|---|
| Ⅰ | 古典 | 石与弦 | 白墙陶瓦聚落 → 城邦 | 里拉琴、奥洛斯、框鼓；单旋律 + 长音 | C D E G A |
| Ⅱ | 中世纪 | 钟与圣咏 | 半木结构、陡坡屋顶 | 摇弦琴、钟、平行五度圣咏 | + F, B |
| Ⅲ | 文艺复兴 | 穹顶与赋格 | 灰泥联排、拱廊、几何广场 | 管风琴、羽管键琴、弦乐；复调卡农 | + F♯, B♭ |
| Ⅳ | 工业 | 蒸汽与管弦 | 红砖联排、烟囱、铁轨 | 管弦乐、钢琴、铜管、蒸汽 | + C♯, E♭, G♯ |
| Ⅴ | 现代 | 电与律动 → 光与合成 | 公寓、玻璃、公园 | 电钢琴、合成器、鼓机 | 不新增 |

**为什么五个**：七乐章放五个时代，中间三个各一乐章，首尾各两乐章。再多每个一闪而过，再少失去"一部城市史"的跨度。

**时代只增加不没收**（保留）：后期仍允许古典、中期与混合音乐——由遗产机制实现。

### 1.1 每个时代给玩家**新增**什么（不只是换皮）

上表只写了外观、音色与音级。如果时代演进只有这些，它就是"换皮 + 换音色 + 全屏提示"。
**每个时代必须同时新增三样东西：一种建造手段、一种音乐组织方式、一种城市形态的拉力。**
下表全部取自已批准内容（`spec.proposal` 表 P8 批量工具、`spec.city` 表 E6 议政链与地标、`12_声音架构.md` §4.4 社区关系），**不新增系统**。

| 时代 | 新建造手段 | 新音乐组织方式 | 新城市形态的拉力 |
|---|---|---|---|
| **Ⅰ 古典** | 播种 / 调音 / 迁移 / 引力带 / 踩路；**社区选择与社区调音**（开局即有）；元老院：第二介入 | **主—从**（一条旋律在长音上）+ **应答**（跨河对唱）；常规五声音阶无半音，包含大二张力与小三中性关系；工坊 F♯ 可形成三全音，叛离另走 U05 | 环形合唱城、双子港、回声街、深流 / 织机；神殿把同音拉到身边 |
| **Ⅱ 中世纪** | 市政厅：**重摇** | **平行进行**：两个社区以五度 / 八度演奏同一动机（圣咏的平行五度）。+F、B 首次带来**半音张力**（E–F、B–C）与音阶内三全音（F–B），张力候选变丰富 | 大教堂让周围可以放心留不协和；行会大厅让商业街成片 |
| **Ⅲ 文艺复兴** | 宫殿：**意志区**；**历史街区**（保留旧时代社区的外观与音色） | **卡农 / 赋格**：同一动机在 ≥3 个社区依次错拍进入 | **梯田赋格镇**（山坡按海拔依次进场）；几何广场 |
| **Ⅳ 工业** | 议会大厦：**整片调音**（调整个家族） | **管弦齐奏**：完满终止时全城多声部齐奏一句；**节奏槽上限 2 → 3**（表 A20 的"2–3"在此生效）；十二音齐，可做半音化和声 | 工业带与铁轨；动力工厂"驯服"三全音 |
| **Ⅴ 现代** | **总体规划**按 P8 作用于多社区；市政中心按 E6 提供修宪（工具解锁边界待 GAP-RUN 闭合） | **自由编曲**：任意组合前代音色（遗产 + 历史街区），电子律动切片 | 中央公园要求提前留出大块空地；超级商业区逼你用道路隔噪 |

**三条约束**：
1. **只增加不替换**：Ⅳ 的管弦不让Ⅰ的长音消失；玩家可以在现代城市里保留一整片古典街区（历史街区）。
2. **新的组织方式是"可用"，不是"必须"**：没有任何跨越条件要求玩家使用本时代新解锁的组织方式。
3. **首批实施范围**：P2 先做Ⅰ–Ⅱ两个时代的完整三列；Ⅲ–Ⅴ 按 P2-β 分期，每做一个时代都要先验证它的"新音乐组织方式"在录音里可辨。

**能力要落在已有作品上**：首次获得一种手段时，在现有候选/详情卡指出它对本城的一种具体用途，例如市政厅的重摇可替换不合当前计划的提案、历史街区可保留玩家已形成的古典主题来源。只在相关对象被选中时出现，不新增科技树或固定教程任务。依照上表和现行规格判定能力是否真正可用；尚未实装的时代内容不得提前显示为已解锁。

地标预影同时回答“我的布局如何使它觉醒、哪些作品会被转写、落成后我能换一种什么做法”。神殿附近可以尝试同音生长，圆形剧场可以组织道路与家族关系；使用已定 E6 效果，不另发邻接分数或研究加速。能力卡引用实际受益范围和失去的机会，后续演奏仍服从角色槽与遗产合同。前期留地兑现按 [P10](01_执行规格/spec.proposal.md#表-p10--留地与后续兑现)，它只保住场地，不代替地标觉醒条件。

### 1.2 昼夜与时代夜光

昼夜是全城共享的一条连续表现时间轴，时代只提供这一条时间轴上的**夜光词汇**。它不为每个时代再造一套时间规则，也不在跨越时重置；具体相位、曲线和色板变换见 [17·美术规格](17_美术规格.md) §7.1–§7.2，声音只进入现有环境声床见 [12·声音架构](12_声音架构.md) §6.1。

- `spec.run.md` §2.8 的“夜光”行是时代身份：古典用油灯/火盆，中世纪用火把/灯笼，文艺复兴用烛台街灯与窗烛，工业用煤气灯，现代用电路灯与大片窗光。它们决定形状、密度和暖色材料，不决定昼夜的时间长短。
- 时代换代按 R10 从局部向整城蔓延，保留当前 `day_phase`。灯具与建筑按局部进度更新，全局时代环境缓慢收束，完成后才确认新时代；“天空先变、城市晚一拍”仍用于日常昼夜 LUT，不用于提前把整城换代。
- 地标和历史街区保留落成时代的灯具与窗光形状；亮度仍受全城昼夜曲线控制。时代遗产因此在夜间有可辨的来源，而不是被统一的现代霓虹覆盖。
- 实现顺序固定为“时代基础色板 → 昼夜 LUT → 时代夜光统一层”。任何失谐、锈蚀、缺口和地形识别信号都优先于装饰性暖光。

## 2. 跨越（修正 Q09）

**旧条件**：每乐章 ≥3 次协和解决 + 末乐句 R≥70。
**新条件**：三条路径任一。**数值权威是 `spec.run.md` 表 R7**，本文不再复制具体阈值（旧稿此处的"建造者 ≥6 栋"已过时，现为随规模变化的 `max(6, ceil(0.04 × N))`）。

| 路径 | 一句话 |
|---|---|
| 修复者 | 本乐章解决了足够多的失谐 |
| **建造者** | 本乐章和谐地长出了足够多的建筑（阈值随城市规模放大） |
| **配器师** | 本乐章填上了足够多的**不同**声景缺口 |

三条路径都要求末乐句 R ≥ 70；**任一满足即跨越**。

| 终止式 | 条件 | 结果 |
|---|---|---|
| 完满终止 | 任一跨越路径满足 | 若已满最短停留 → 跨越；否则"辉煌"：多揭示 1 座地标候选 |
| 半终止 | 部分满足 | 不跨越；下一乐章"悬"（首次协和解决计 2 次） |
| 阻碍终止 | 都不满足 | 不跨越；下一乐章"小调乐章"（关系小调色彩）；小调乐章以完满终止收尾才可走"皮卡第跨越"；仍须满足 R7，奖励映射待 GAP-RUN |

- **最短停留**：Ⅰ 2 乐章，其余 1 乐章
- **保底跨越**：Ⅰ 第 3 乐章末、Ⅱ–Ⅳ 第 2 乐章末
- **第 7 乐章永远是终章**
- **交响曲失败**仍只有 R<40 连续 3 乐句崩盘；自由共鸣不结束、不累计失败计数

## 3. 时代在城中逐渐蔓延

**玩家先发现城里一处变了，随后听见、看见一个时代慢慢接过整座城；正式提示是最后的确认。** 2026-10-10 用户更新替代原16秒全屏庆典。时长与工程权威只在 [spec.run 表 R10](01_执行规格/spec.run.md#表-r10--渐进时代过渡)，本文说明演出意图。

| 过程 | 玩家感受到什么 | 制作方式 |
|---|---|---|
| 一处萌发 | 熟悉的古典合奏中，一栋建筑突然开始带有中世纪音色 | 从真实起点声部换演奏音色，仍唱原来的音；不播报新时代、不换整城背景 |
| 沉入与重生 | 原建筑缩下去、沉入地面，新建筑沿同一地基长出来 | 地面裁切、垂直收缩与回升；保留建筑身份，换成同用途/阶段/朝向的新时代版本 |
| 逐渐蔓延 | 新旧街区并存，近处回应远处，波前慢慢抵达城市角落 | 城市坐标驱动稳定批次；音色与建筑共用局部时间轴，河对岸和远端都有完整换代过程 |
| 整城落定 | 最后一片新建筑站稳，原合奏已成为新时代织体 | 等最后交叉与重生结束，保留遗产的旧音色；不用音量暴涨制造高潮 |
| 正式提示 | “原来我已经走到中世纪了” | 此时才显示“正式进入中世纪”，揭示新能力/候选/来客并进入章首祝福 |

首版按 R10 排成一分多钟的城中演出。画面不定格、不盖全屏卡片；玩家可平移、缩放、聚焦和独听，尤其能拉近看一栋如何沉下去再长出来。城市规则计时沿既有过门保持语义，建造提交稍后恢复；不是边播电影边偷偷推进成长或扣活力。完整传播不能用一个全局淡入或同秒换皮代替。

音色先提示变化，视觉随后给出来源；原屋的体量收拢到地面，新屋沿同一锚点舒展。动效克制、有重量、接地，不做爆炸碎片、夸张弹跳或吞噬土地的特效。远景看成街的转换，近景看清地面裁切、材质与朝向；减弱运动保留时序，改用原地交叉。

**这不是把旧作品拆掉**：ID、音级、主题来源、阶段、活力、道路和庭院关系都保留。地标与主动保留的历史街区不沉降换代，让新城中仍看得见、听得见自己的过去。新增土地仍按地形条件从雾中显现，统一在正式入代边界揭示，不因演出额外生成规则方形地图。

## 4. 遗产与时代混音（保留，强化）

- 普通建筑跨越时换外观与音色
- **地标保持落成时代的外观与声部**，成为遗产
- 结果：现代城市里能同时听到古典合唱与中世纪钟声

**强化（回答 Q24）**：玩家可**主动保留一个历史街区**：

| 新动词 | 时代 | 作用 |
|---|---|---|
| **历史街区** | Ⅲ 起可用 | 指定一个社区保留旧时代外观与音色，不随跨越换装 |

这让"我想留住古典"从被动（只有地标）变成主动（整个社区）。

保留旧乐器、玩家主题、前代编曲语法和整片社区是四个不同承诺。遗产地标保持音色只覆盖其中一部分；历史街区的完整实现已列 P2 任务 7；保留范围仍见 GAP-LEGACY，不能用“已有遗产”宣称整片古典社区已能持续经营。后期保留与混合仍受现行角色槽/预算约束，完成范围见 GAP-LEGACY。

## 5. 地标

### 5.1 地标是什么（保留）

- 时代特有的大型公共建筑（占地连续区域，不是格子矩形）
- **从城市生长中觉醒**，不从菜单购买
- 有城市级规则效果、标志性声部，之后成为遗产
- 生长阶梯第五阶：胚 → 群 → 央/腔 → **地标**

### 5.2 生命周期（修正空间部分）

| 阶段 | 规则 |
|---|---|
| 候选揭示 | 时代开始时公开本时代候选 |
| 觉醒 | 条件在连续 2 个实际乐句边界满足（只用现有可测量） |
| 选址预影 | 觉醒后计算落点：占地为**连续圆形/矩形区域**，须含"锚点"；按"吸收最少 → 协和邻接最多 → 离家族重心最近"排序，最多 3 个备选 |
| 确认 | 玩家用本乐句介入槽确认 |
| 落成 | 下一乐句边界：1 小节 4 拍分段揭示 |
| 生效 | 下一边界起；若邻居 s≤0.05，效果"沉默"（不拆） |
| 遗产 | 跨越后保持原时代外观与声部 |

**空间修正**：地标占地从"2×2 到 3×3 格"改为"半径 1.0–1.5 地块的连续区域"，**地标按中心间隙距离、占地半径和 SP2 距离核参与耦合，不额外按共享边界面积计权**。这一修正**简化**了旧设计（旧的 `w = 1+0.15(n-1)` 需要多格扩展，新的距离核天然支持任意形状）。

当前 Demo 已接入生命周期、首批效果和连续时代音色切片：城市第一次形成群后，时代Ⅰ显示元老院、神殿、圆形剧场三项及其连续世界条件；条件在两个实际乐句边界连续满足后进入觉醒，点击候选生成稳定连续场地预影，按 Enter 使用同一 pending 槽确认，下一句以 4 拍分段揭示几何地标。落成会吸收预影半径内的成熟建筑，按稳定顺序把其音级写入地标动机，并把地标作为独立长音声部加入合奏；同时记录被吸收建筑的来源社区，社区主题以地标动机为骨架、让幸存建筑继续应答，避免吸收造成主题静默。分段揭示完成后，神殿缩短同音建筑形态连续句数，圆形剧场放宽附近家族生长连通并提高附近活力，元老院公开第二政令槽。连续河谷时代Ⅱ–Ⅴ已用受限谐波表做4拍等功率长音交叉，地标声部保持落成时代；完整三落点排序、时代专属律动/遗产视觉和全时代内容仍按本节继续推进。

### 5.3 地标目录（保留 27 座；首批只做六座）

完整名单、觉醒条件与作用参数只取 [spec.city E6](01_执行规格/spec.city.md)。首批为时代Ⅰ的元老院、神殿、圆形剧场和时代Ⅱ的市政厅、大教堂、行会大厅。

这些地标分别提供议政、同音成长、道路与活力、重摇、可承担的张力和商业优先等取舍；它们改变真实关系，不发放通用全城加分。隐世候选与依赖净空/区域边界的地标另按目录推进，时代Ⅲ–Ⅴ沿 P2 分期。

### 5.4 地标的声音（修正吸收的技术口径）

- 地标 = 三层声部（长音 + 律动 + 装饰）
- **标志动机用落成时城市的实际音级写成** → 每座城的神殿唱法都不同

**吸收不是"释放性能预算的技术操作"，而是"作品的转写"。** 这一条决定了地标能否承担"城市历史的一部分"。

| 项 | 旧稿 | 修正 |
|---|---|---|
| 振幅 | "功率守恒合并：吸收 k 栋 → 振幅 `a·√k`" | **"功率守恒"这个词取消**。同相 k 份的原功率是 k²·P，`√k` 是**编曲归一化**，不是守恒证明（与 `spec.audio` 表 A18 同口径） |
| 被吸收的建筑 | "声部合并，为后续生长腾出预算" | **作品转写**：见下 |
| 音高信息 | "不销毁" | **强化为四条明确的保存规则** |

**吸收时被吸收建筑的命运（四条，逐项必须实现）**：

1. **音级进入地标动机**：被吸收建筑的实际 MIDI 按**稳定几何序**排入地标动机数据源。
   地标演奏的标志动机**包含这些音**；保留音级是必要条件，不独自证明玩家原来的旋律仍可辨认。
2. **社区主题重写**：若被吸收的建筑属于某个有社区主题的社区，该社区主题**重新生成**，
   新版本以地标动机为骨架。**不得让社区主题静默消失。**
3. **记录与可查**：地标的详情卡（悬停）必须列出**被吸收的建筑数与它们的音级**，
   以及落成时间。这是"地标是城市历史的一部分"的具体落实。
4. **遗产后仍可听**：跨越后地标保持原时代外观与声部，其动机继续包含被吸收的音级。

**为什么必须这样做**：如果吸收只是"吃掉几栋房子腾出预算"，玩家精心调出的一个社区会凭空消失，
而他只会看到"地标落成"的庆祝动画。**那是把玩家的作品当资源回收。**
本作的承诺是"城市会记住你做过什么"——吸收是这条承诺最容易被违背的地方。

**作品转写的待验证边界**：选一个已有多音轮唱/主题的社区，记录落成前的成员 ID、位置/空间音序、实际 MIDI、节奏与形态，连同落成后的地标动机、幸存成员应答和来源社区对照。预影要让玩家知道哪些房屋和命名形态会消失、哪些内容转入地标；新旧片段能否让玩家认出自己的作品需实听，不能用音级列表或全同音 fixture 代替。既有稳定几何序、环成员重判和遗产规则继续有效；若转写后的轮廓/节奏失去辨识度，记入 GAP-LANDMARK，不默认为已保存完整作品。

### 5.5 地标界面（保留，符合极简原则）

- 地图区左上：**通知轨**（落成提示，6 秒后收入）
- 左缘：**地标栏**（一列圆形图标，已落成实心 / 候选空心+进度环 / 隐世 `？`）

## 6. 终局体验（回答 Q26）

**问题**：七乐章固定结束 + R<40 崩盘，与"几十社区长期养成"并存，未说明投入的回报。

**新方案：三种模式共用同一座城。**

| 模式 | 长度 | 规模 | 结束后的去向 |
|---|---|---|---|
| **交响曲** | 7 乐章 ≈ 22–35 min | 120–180 栋 | 结算 + 图鉴 + 可"继续经营"（转自由共鸣） |
| **自由共鸣** | 无终点 | 目标 400–600 栋 | 随时保存/继续；可导出"城市曼陀罗"壁纸 |
| **聆听** | 无限 | 任意 | 纯听，不做操作 |

**关键**：
- **交响曲结束后可以"继续经营"**——跨越完成不等于城市终结，玩家可以选择把这座城养大。
- **失败也保留作品**：崩盘局仍可"继续经营"（只是没有跨越奖励）。
- **导出**：终局可导出城市曼陀罗（全城和声结按布局排成一幅图）+ 音频。

**为什么这样回答**：投入建设后的回报是**"这座城市还在，还能听，还能长大"**，而不是"重开"。
