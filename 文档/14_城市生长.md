# 05 · 城市生长

> 2026-10-09 重构版。旧生长模型建立在四向格子邻接上（"每源点每乐句从四向边界空格选一栋"）。
> 本文把它迁移到连续空间，并回答旧问题单 Q14/Q15/Q16/Q17/Q18/Q28。

---

## 1. 生长的心智模型

**你播下一颗种子，城市自己长。你只能决定种子在哪、什么音，以及给它什么方向。**

玩家不摆放每一栋房子。这是本作"配器而非建造"的必然结论。

---

## 2. 生长规则（连续空间版）

### 2.1 候选位置

每乐句边界，每个共鸣点为它的家族尝试长出一栋新建筑。

**合法候选先来自19的临街地块**。以下连续环带用于在地块内生成或排序候选，不得越过道路/地块管线直接撒建筑：

1. 以共鸣点家族的所有成熟建筑为源，向外取**环带采样点**：
   - 在距离现有建筑 `[0.9, 2.4]` 地块的环带内，按黄金角螺旋均匀采样（每建筑 12 个候选方向）
2. **过滤**：
   - 地形不可建（海/河/湖/陡坡）→ 剔除
   - 与已有建筑占地重叠 → 剔除
   - 被成路街道隔断（连线穿过成路）→ 剔除
   - 与最近邻居的最大耦合音程为"碴"（s ≤ 0.05）→ 剔除
   - 不在家族引力方向（若有引力带）→ 降权
3. **评分排序**（取代旧的"同家族邻居数 → 近源点 → 坐标序"）：

```
score = w_grav × 引力匹配
      + w_harm × 该位置的和声收益（新建筑与邻居的 s 加权和）
      + w_dens × 局部密度适配（社区自己的目标密度）
      + w_terr × 地形适宜度（平地/缓坡加分，水边可加分）
      + w_seed × 到源点距离（近者优先）
      + jitter（极小，按种子确定，避免机械重复）
```

4. **取最高分**，生长一栋"胚"。

### 2.2 与旧规则的对应

| 旧 | 新 |
|---|---|
| 四向邻接格 | 连续环带采样 |
| 至少 1 协和邻居 | 新位置与最近邻居的最大耦合 s ≥ 0.60 |
| 无 s≤0.05 邻居 | 保持不变（"碴"剔除） |
| 优先同家族邻居数 | 和声收益 + 密度适配 |
| 近源点 | 保留（w_seed） |
| 坐标序 | 黄金角螺旋 + jitter（避免规则网格感） |

**关键改进**：旧模型只能长成"格子团聚"（因为只能在四向长）。新模型可以长成**有机形状**——沿河弯曲、绕山盘旋、填满湖湾。这直接回答 Q18。

## 3. 道路（回答 Q16）

### 3.1 道路的双重作用

旧设计中道路**只有负面作用**（阻断邻接）。重构给它正面用途：

| 作用 | 效果 |
|---|---|
| **隔声**（保留） | 成路的街道阻断两侧的声学耦合（O=0） |
| **连通成形**（新） | 沿路两侧的建筑形成"街"，**街道本身是一条声学通道**：沿街的建筑彼此产生**延迟耦合**（每 1 地块延迟 1 拍）——形成"回声街" |
| **承载移动体**（新） | 行人/车辆/牛车沿路行走（旧 U24b 保留），密度绑定 V |
| **社区边界**（新） | 道路自然划分社区；玩家可主动用路划出社区边界 |

### 3.2 "回声街"

沿一条成路排列的 ≥4 栋建筑，形成：
- 音频：沿街建筑按顺序，每 1 拍延迟一次应答（像一排钟）
- 这是**道路的正面收益**：它产生音乐结构，而不只是切断关系

### 3.3 踩路径（保留旧机制，补回退规则）

- 在两点之间划一下，重复 3 次成路
- 成路后**不可自由撤销**，但有**明确的回退额度**（见 §7）：每条成路每乐章可"消解" 1 次，恢复到踩路前的耦合状态
- **新**：成路后可以在路上"加桥"（跨河成路 = 桥），桥允许跨河耦合

**为什么加回退**：旧稿"成路不可撤销"＋"每乐句可踩 1 次"意味着玩家在一局里可能无意间切断了
几十处耦合，而每一处都是永久损失。**试错必须有意义，但一次普通探索不该毁掉已经塑造好的作品。**

## 4. 命名形态（回答 Q18）

**命名形态 = 空间图案 + 独特声学行为。** 全部保留旧设计，但改为在连续空间判定。

| 形态 | 空间条件 | 声学行为 |
|---|---|---|
| **环形合唱城** | 一个中心 + 周围环状排列的 ≥6 成员（按角度均匀分布） | 8 拍轮唱（旧 U18 保留） |
| **双子港** | 河两岸各一片协和社区，距离 < 8 | 卡农式对唱（新，见 `13_地形与自然.md` §3.1） |
| **梯田赋格镇** | 山坡 ≥3 个高度层，每层 ≥4 栋 | 按海拔依次进场的赋格（新） |
| **深流** | 河谷低音社区 ≥8 栋 | 低音槽锁定，全城地基 |
| **织机** | 密集商业区 ≥12 栋 | 节奏槽锁定，推进力 |
| **回声街** | 一条成路 + 沿路 ≥4 栋 | 延迟应答 |
| **独奏岛** | 湖心岛 1–2 栋 | 独奏 +3 dB，声像清晰 |

**判定要点**：
- 在**连续空间**判定几何（角度分布、高度层、距离），不再用格子偏移表
- 仍要求"连续 2 个实际乐句边界"满足（保留旧规则，防抖）
- 仍"不改声音不算命名形态"（同音环只是雏形）

## 5. 批量工具（回答 Q14/Q15）

**问题**：旧设计中，管理工具（意志区、整片调音）解锁很晚，且逐栋操作在几十社区规模下不可行。

**新方案：管理工具分级解锁，且早期就有基础批量能力。**

| 时代 | 工具 | 作用 |
|---|---|---|
| **Ⅰ（开局即可用）** | **社区选择** | 点一栋 → 选中稳定规划社区（spec.space表SP6），与家族/音乐簇分开 |
| Ⅰ | **社区调音** | 把整个社区调到同一音级（每栋 −5 活力，比逐栋便宜） |
| Ⅰ | **引力带**（保留） | 定向生长 |
| Ⅱ | **重摇**（保留） | 重抽提案 |
| Ⅲ | **意志区**（保留） | 涂一片区域指定偏向 |
| Ⅳ | **整片调音**（保留，升格） | 调整家族，每栋 −5 |
| Ⅴ | **总体规划**（新） | 一次指定全城多个社区的偏向 |

**核心改变**：**"社区选择"与"社区调音"从开局就有**。旧设计把它们放在文艺复兴/工业时代，导致"做大之前必需的工具，做大之后才有"。现在它们是基础能力。

## 6. 生长阶段（保留）

| 阶段 | 连续乐句 | 条件 | 声音 |
|---|---|---|---|
| **胚** | 1 | ≥1 邻居耦合 s ≥ 0.60 | 只有 drone（0.20 倍） |
| **群** | 2 | ≥2 邻居 s ≥ 0.85，局部 R ≥ 60，半径 4 内 ≥3 同类 | + 律动层 |
| **央** | 3 | ≥3 邻居 s ≥ 0.85（含 ≥1 个 s=1.00），半径 5 内 ≥6 同类 | + 装饰层（每 2 小节 1 音） |
| **腔** | 2 | ≥3 邻居且**全部** s ≥ 0.85 | + 每乐句边界共鸣钟（+24 半音） |

**迁移到连续空间**：
- 阶段、生长与碴冻结的"邻居" = spec.space表SP5的N12；R/V结算用全对集合E
- "半径 4 内 ≥3 同类" = 曼哈顿距离改为**欧氏距离**，半径不变
- 阶段阈值不变

**碴**：N12内任一 `s ≤ 0.05` 的邻居 → 冻结升级与该建筑向外扩张（保留）

## 7. 永久操作与试错（回答 Q28）

**问题**：道路永久、地标不可迁移 → 玩家因一次普通探索就轻易失去精心塑造的作品。

**旧方案的不足**：旧稿的答案是"不可撤销 + 补偿手段（桥、摆渡）"。这保住了决策重量，
但**没有防住"无意间毁掉"**——玩家在密集区划一条路，可能一次性切断几十处耦合，而他并未打算这样做。
补偿手段只能救特定情形（跨河），不能救"切断了密集区"。

**新方案：三档可逆性 + 明确的毁坏上限。**

| 操作 | 可逆性 | 回退成本 | 说明 |
|---|---|---|---|
| 播种 | 落定前可撤销 | 无 | 落定后不可删除（保留旧规则） |
| 调音 | 可反复 | 每次 −10 活力 | |
| 迁移 | 可反复 | 静音 1 乐句 | |
| **踩路** | **可消解** | 每乐章每条路 1 次 | 恢复到踩路前的耦合状态 |
| **引水** | **不可撤销**，但有上限（见下） | — | 引水前必须通过全屏确认 |
| **挖湖 / 平整** | **不可撤销**，但有上限 | — | 同上 |
| 植树 | 可移除 | −5 活力 | |
| 地标确认 | 落定前可取消 | 无 | 3 个备选（保留） |

### 7.1 毁坏上限（防止"一次探索毁掉作品"）

**裁定：任何单个不可撤销操作，其影响范围不得超过以下阈值；超过则必须拒绝或要求二次确认。**

| 指标 | 阈值 | 超过时 |
|---|---|---|
| 被切断的耦合边数 | **≤ 6 条** | 拒绝执行，并提示"这会切断 N 条关系" |
| 受影响的成熟建筑数（群/央/腔） | **≤ 8 栋** | 拒绝执行 |
| 会导致失效的命名形态 | **≥ 1 个** | 二次确认（显示是哪个形态） |
| 会失去轮唱/对唱的社区 | **≥ 1 个** | 二次确认 |
| 与之相关的规划社区数量 | **> 2 个** | 拒绝执行，建议缩小范围 |

**这些是设计值，不是实现细节**。执行 AI 必须实现阈值判定，**不得由玩家自行决定阈值**。

**预览必须显示**（保留旧规则并扩展到地形）：
- 会改变哪些耦合（哪些边消失、哪些新出现）
- 哪些社区会失去命名形态
- 哪些建筑会被覆盖（覆盖一律拒绝）
- **一个可视的"影响范围"高亮**，不是只给一行文字

**为什么用"拒绝"而不是"警告"**：玩家在密集区随手划线时，一个温和的警告会被忽略。
**硬拒绝 + 明确的替代方案提示**（"缩小范围，或先拆除邻近的两栋"）才是有效的保护。

## 8. 生长的时间推演（回答 Q19）

| 时间点 | 建筑数 | 社区数 | 说明 |
|---|---|---|---|
| 开局 | 9（保留旧开局 9 街区） | 3 | 住宅/商业/工业各 3 |
| 5 分钟 | 25–35 | 4–5 | 约 3 个乐章 |
| 中局（15 分钟） | 80–120 | 8–12 | 约 5 个乐章 |
| 交响曲终局（30 分钟） | 120–180 | 10–15 | 7 乐章完成 |
| **自由共鸣 40 分钟** | 250–350 | 20–28 | |
| **自由共鸣 90 分钟** | **400–600** | **36–48** | 终局大城目标 |

**每个源点每乐句最多长 1 栋**（保留）。40 分钟 = 150 乐句 → 若有 15 个共鸣点，理论上限 2250 栋，实际受地形/密度/和声限制，落在 250–350，合理。

**若玩家停滞**：缺口系统会引导（不是强制）。停滞不会失败，只是城市长得慢。
