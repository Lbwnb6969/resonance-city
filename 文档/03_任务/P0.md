# P0 · 连续世界地基与可玩河谷

## 目标

交付能连续操作、听见因果并保存继续的河谷。空间基础与所需画面/供音一起接入；实现进度只取 [PROJECT](../../PROJECT.md)，不恢复旧格子视觉。

## 依赖

按 [spec.space](../01_执行规格/spec.space.md)、[spec.terrain](../01_执行规格/spec.terrain.md) 与 [19·管线](../19_城市生成管线.md) 的对应合同推进。P1/P2 只依赖所需地基，不等待整期真人验收。

## 任务与完成条件

| 任务 | 依赖 | 完成条件 |
|---|---|---|
| 连续空间与邻接 | SP2–SP4/SP9 | 连续投影、空间索引、距离/遮挡/地形权重正确；E 与 N₁₂ 各按所属用途工作 |
| 河谷与道路 | 地形、空间 | 两岸可建地、缓坡、主街、合法桥、临街地块与稳定规划 ID 可用 |
| 操作与声音 | 空间、音频时钟 | 播种/调音、区域独听/静音、成长声音、试听；拍点改声与乐句结构分开，可听帧揭示一致 |
| 快照与继续 | 事务、随机流 | schema 2 浮点快照、命名随机流复现；存档/DNA 与试听/后台快照边界一致 |
| 社区衔接 | 可建邻接图 | 分裂后成员互斥、局部连通、父 ID 保留；规划社区不随改音改变 |

社区主题、编曲、通用地块与完整模式/时代分别沿 P1/P2 推进。建筑样本数不构成游戏上限，规模目标只取 [18·规模](../18_城市规模.md)。

## 验证

按 [DOD](../02_验收/DOD.md) 选择最低充分检查。空间/事务改动复用 `tests/continuous_valley_contract.gd` 的对应 case，交互改动再做实际窗口操作；基础与含 M 的样例分开验，不重复历史全套。命令、结果、剩余范围写验证记录和 PROJECT。
