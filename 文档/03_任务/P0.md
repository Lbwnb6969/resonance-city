# P0 · 房屋点击与道路接合

目标：在已有古典河湾中，第一次点击就好看，第一条路就接得自然。

| 工作 | 结果 | 最小验证 |
|---|---|---|
| 房屋局部拓扑/命中 | 平墙、转角、上层、露台的候选明确 | 点击位置/面 ID、删除后稳定命中 |
| 点击驱动生成 | 单次和笔画增/减模块；停手不增殖 | 无输入推进后拓扑不变 |
| 邻接造型 | 墙、屋顶、露台、支撑自然重组 | 混型高差、庭院与移除对照 |
| 连续拉路 | 曲线、路口、门前平台/台阶，跨水需桥 | 道路不量化到局部格，无穿模/捷径 |
| 撤销/保存 | 原样恢复局部形态、身份和种子 | 编辑→保存→恢复，撤销/重做对照 |
| 风格与性能 | 古典小街坊达到统一视觉方向 | 同场景截图、连续编辑延迟和帧时 |

复用现有输入、WorldDelta、道路、资产与作品格式；旧自动成长和声音门槛必须在此切片中关闭。状态写 PROJECT，验收入口见 [DOD](../02_验收/DOD.md)。

第一可评审切片只需一处高差连宅、一个露台、一段连续路到门和统一撤销。同时迁移原子建设提交，场景自然时间与音频设备解耦；旧作品先用明确版本读取。完成后交付实际点击/删除/撤销片段和同镜头风格对照，不先制作全部目录。
