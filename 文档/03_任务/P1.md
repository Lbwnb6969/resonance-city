# P1 · 地形、社区、声音规模与极简界面

> 2026-10-09 重构版。按P0的可交付切片推进；空间基础接入后可同步制作必要的画面/供音，不用“全部规格完成”阻挡河谷试玩。完整P0进度见PROJECT；数值样例改见SP9。
> P1 的目标是让**新世界模型第一次产生新体验**：地形影响声音、大城按声部组发声、界面近乎全空。

---

## P1 达成的体验

- 在河谷/海岸/山地上开局，**地形明显改变城市形态与听感**
- 城市长到 **80–150 栋（中型验证阶段）**时，**听起来是一支乐队**，
  不是音轨堆。**200–400 栋是下一阶段**，不是本阶段目标（三阶段见 `18_城市规模.md` §5.1）
- 界面默认只有城市 + 一条节拍条；信息在悬停时出现
- 玩家能一次操作**整个社区**，不必逐栋
- **听见自己做的动机**：≥6 栋的成熟社区生成社区主题，改其中任何一栋的音级，主题就变

## 推荐切片的顺序（不并行）

当前第63轮已有街坊/路网设施覆盖、社区合奏主题槽、两层落定与公交切片；不等于整行验收完成。设计依赖按 [待裁定与依赖](../待裁定与依赖.md) 定位，实施及已测范围见 ../../PROJECT.md。

**按"能看见、能听见"的顺序做，每步都可玩：**

1. **河谷切片**（任务 1 + 3 + 4 + 11 的最小版）——**第 62 轮已有可玩首片**
   一条河、一个缓坡、两岸可建地；主街 + 一处合法桥；几个用途不同的社区。
   **证明**：沿街建、沿岸留、沿坡转；一次操作同时改变城貌与声音。

1b. **核心乐趣切片**（任务 12 两层落定 + 20 候选分组 + 19 社区主题，**规模仍 20–30 栋**）——**下一步从这里开始**
   调音下一拍可听；候选跨 ≥3 种表达类型；≥6 栋社区唱出用玩家音级写成的主题；
   在同一河谷里能走通**深流（低音）**与**织机（节奏）**两条路线（`11_核心循环.md` §4）。
   **证明**：HUMAN-EXPRESSION（候选听得出差别）、HUMAN-AUTHOR（玩家说得出"这是我调的"）、
   HUMAN-DIFF（两条路线盲听可辨）。**这三项不过，不进入切片 2**——扩规模救不了不成立的核心玩法。

1c. **落点与连片切片**（任务 21 + 22 + 23 + 24，**规模仍 20–30 栋**）
   **任意合法陆地能点**；沿街的一串房子共享山墙、屋顶连成一片；
   散落与成街在截图里读得出差别。**证明**：HUMAN-TIER（点之前说得出会长成什么）、
   HUMAN-FABRIC（两张同建筑数截图，说出哪张更像社区）、FABRIC-005（连片不进 R/V）。
   **为什么排在切片 2 之前**：这是"好看"与"这片是我盖的"的直接来源，
   而它**不需要扩大规模**就能验证——属于小规模高价值切片（`文档/废弃/2026-10-09_历史执行与研究/玩法改进评审-涌现与五个方向_2026-10-09.md` §10
   的"先用当前 20–30 栋创作范围完成关键选择的因果"）。

2. **声音规模切片**（任务 6 + 7 + 8 + 9）
   把城市推到 **80–150 栋（中型验证）**，验证声部组 + 编曲槽 + 留白 + 社区轮换 / 应答。
   **证明**：听起来是乐队；40→55 声部组无下溢。

3. **界面归零切片**（任务 11 + 12）
   删掉所有常驻面板，只留标题 + 城市 + 节拍条，逐个加回悬停卡。
   **证明**：够用且干净。

4. **地形动词切片**（任务 14 + 15）
   引水成河、建桥、植树。
   **证明**：玩家能用地形配器。

## 最小验证

每个切片只跑：
1. 该切片的合约 case
2. 一次实际启动 + 截图/录音
3. 音频相关切片加一次真峰值与 skips 检查

**不重跑**历史全套；**不建**庞大压力矩阵。

## 风险

| 风险 | 应对 |
|---|---|
| 声部组在 70 时下溢 | 小步 40→55→70；参考旧 64 实体下溢教训 |
| 地形生成产生不可玩布局 | 可建面积 ≥45%；R≥65 保护；最多重采样 8 次 |
| 资产朝向不匹配连续街道 | **先只选资产支持的朝向**；需要自由方向时先补资产（见 `19_城市生成管线.md` §2⑤） |
| 编曲槽让玩家失去控制感 | 槽位竞争规则对玩家可见（悬停时显示谁在唱）；聚焦可覆盖 |
| UI 归零后信息找不到 | 保留"视觉优先模式"作为完整信息后路 |
