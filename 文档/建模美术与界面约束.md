# 建模、美术与界面约束

适用于营造主场景里的建筑、街景、地貌和操作界面。玩家在常用镜头下应能辨认自己刚建了什么、它与周围怎样相接，以及手里选着哪个工具。改动前先记录挡住这件事的具体画面或操作。

## 建模与材质

建筑模型优先。模型、UI、草地和道路都可以从头制作，直接替换默认实现。替换前保留原件与 Git 备份；用同一座旧城、同一机位和光照对照新旧画面。换模型要保住建造与拾取，换 UI 要走通原操作，换草地和道路要核对地形衔接及道路连通。按模块验收，不为每次换版另建文档。

| 检查对象 | 制作取舍 | 在游戏里怎么看 |
| --- | --- | --- |
| 建筑轮廓 | 先定墙身、屋面、开间的比例，再做凸窗、檐口和压顶。重复构件按实际屋面和外露边界布置。 | 拉到日常营造距离看轮廓，再转到背面看穿插、悬空和邻屋共墙。 |
| 构件连接 | 玻璃嵌进框，框落在窗台，屋檐伸过墙面。同一构件的比例和局部变换由一处定义，渲染、拾取和净空按同一几何核对。 | 给房屋旋转或调坡。从两侧点窗，核对命中房屋、窗框遮挡和屋面接缝。 |
| 材质和照明 | 通过色相、粗糙度和细部尺度区分灰泥、木、石、陶瓦与金属。窗灯取真实玻璃面，檐口与墙根用接触阴影交代厚度。 | 同一机位切昼夜。看瓦纹尺度、背光面层次、亮窗是否压住窗框。 |
| 草地、水岸与街道 | 常态草地以叶绿为主，阴处偏冷，向阳草梢略暖。远看草地与土路有色相区别，近看草根融入地面。地表、路缘和浅岸共用地色。 | 同一机位对照白天与夜间，再从木屋门前看向河岸，检查是否泛黄灰、出现亮边或草叶闪点。 |

材质、交互、地形的专题依据分别见[质感与光影](59_美术质感光影续稿审阅与施工映射.md)、[自由营造](60_自由营造交互与玩家体验审阅及施工映射.md)、[道路与水岸](62_地形道路与水岸创作审阅及施工映射.md)。

## 界面与操作

选屋式时，若面板已占到画面中线，选定后收起，画具仍可直接落笔；再次展开保留选中屋式。宽窗留面板供连续选型。

- 保留营造画面的中心区域。常用画具固定位置，当前画具的次级选择跟随对应入口展开。收起面板后，玩家能回到刚才编辑的位置。
- 命令名用玩家熟悉的动作或对象，例如“筑屋”“修路”。同时提供可辨认的图标和文字。选中态用形状或底色与文字对比共同表达，悬停、禁用和选中各自可辨。
- 在同一张实窗图里看工具栏、提示条、镜头与建筑的关系。窄窗口优先核对文字裁切、面板碰撞和点击区域。房屋详情和用途面板展开时为屋名栏优先留位，侧栏需要下移时保留可点击的间隔。快捷键、撤销和重做沿用已有操作路径。
- 界面层级与入口的专题依据见[UI 与冗余系统清理](61_UI与冗余系统清理审阅及施工映射.md)。

## 验收示例

改一扇山墙窗时，在同一座房、同一镜头、同一光照下各留一张改前和改后原图。先看常用距离下檐口能否读出来，再确认窗玻璃可点、夜灯落在玻璃内。如果只改工具栏，直接切换画具、展开选项并撤销一次，记录窗口尺寸与结果。其他改动按实际影响选证据。

构件和界面有操作问题时记下“看到了什么、如何重现”。风格取舍记下“采用哪一版、判断依据”。工程通过和主观评价分别登记。记录位置与原件管理见[工程维护](工程维护.md#文档和产物各归其位)。
