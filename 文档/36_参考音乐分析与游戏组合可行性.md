# 参考音乐分析与游戏组合可行性

2026-10-27，按用户提供的本地 `mIDDLEFILE/music` 工作流，对《Youzee Music - 齐马蓝》的已有结果与游戏当前原生组合做同口径对照。结论：**游戏已有柔和琴音、低音铺底、声部呼应和长段落留白，能做相近的音色方向；当前造城选项尚不能组合出参考的节奏密度和整曲发展。**

## 参考结果能告诉游戏什么

参考的12秒窗口显示：约0～24秒逐步铺开，24～48秒能量提高，48～72秒回落，72～96秒再次增强；约96～120秒能量维持较高但频谱质心降至约250～280Hz，141秒后逐步收尾。这里是能量和明暗分区，不将它们命名成主歌、副歌或判定具体乐器。

游戏可以借鉴的是**段落之间改变音区、节奏密度和配器重心**。参考并非单纯越来越响：96秒后的暗化与此前高频较多的段落形成对比。现成全曲统计不能推导出原旋律、逐和弦时间表或各乐器分轨；需要这些内容时应另做音符/和弦转录与听觉核对。

## 当前游戏的实际组合配方

使用正常API在隔离城市造5栋普通住宅，坐标从`(-30,-20)`至`(-18,-20)`，间距3m；其前方修一条路。日常保持行板、昼景、26m视距；候选将这5栋屋设为慢板，切夜景，将镜头移到14m。夜景确实把原主声部切成`*/nocturne`，没有直接指定轨道音量、替换游戏总线或加载参考歌曲。

实际音色来自[夜曲谱材](../scripts/audio/city_creation_chamber_pcm.gd)的柔音钢琴与大提琴泛音应答，配合既有[分层乐谱](../scripts/audio/city_creation_chamber_score.gd)、低音与和声底层；[镜头配器](../scripts/audio/city_creation_camera_orchestration.gd)减少伴奏并保留同一声部池。慢板会影响生活生产、混音倾向等，**不改变全局BPM**。夜曲循环只有11次主旋律起音/24秒；这与检测器的音头次数不是同一个量。

实录夜曲质心比日常降低约68Hz，向参考的暗色方向靠近；音头密度仍仅为参考的约36%。它更稀疏，不能把“柔和音色接近”解释成已经能演奏出参考的推进感。

| 要达到的效果 | 当前能力与缺口 |
|---|---|
| 低中频为主、柔和持续的音色 | 夜景已有合成柔音钢琴/泛音应答，实际频谱比日常更暗；仍比参考亮，未核对具体参考乐器 |
| 多层组合、主次有序 | 低音、和声、主旋律、应答和短音已有；12长轨、4短槽、6总线、2自然声保持 |
| 参考约125 BPM的推进 | 当前共享拍钟固定80 BPM；需统一参数化小节、短音网格、PCM生成与切换，不能只调某个播放器速度 |
| 更密的分解和弦、动机变化 | 现有夜曲刻意稀疏；需要在原创音符事件层增加分解织体、应答变化和真实休止，不能只加音量或叠更多相同循环 |
| 约两分半钟的起伏与音色换区 | 已有72秒呼吸、144秒六段曲式与换调/变体；实录覆盖六段，但主体仍复用24秒谱材，不具备参考那样的分区展开 |
| 与原曲同调、同旋律、同乐器 | 此次特征分析不能确认或复原；做相似风格也不要求复刻原曲旋律或固定E调 |

据此，后续最有收益的开发顺序是：先增加原创音符织体与音区对比，再让长段落改变谱材和密度，最后把统一速度选择接入既有拍钟。把整首音频作为背景播放无法验证城市组合能力，本次没有采用该方式。
