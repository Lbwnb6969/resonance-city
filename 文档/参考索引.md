## 取用方式

先查原代码/字段/纹理，再用小型证据核参数及单位；恢复报告用于定位，关键语义回到原件。Godot适配按当前接口实现，区分原算法/原资源与本作几何、调度和参数。资源保来源与许可记录，不标为CC0或本作原创，原件只读。

旧临时考据与运行验证不随当前 GitHub 成品发布；本地仍按项目规则保存在 `废弃/` 与 `验证记录/`。资料内部历史链接不作为新施工契约；当前动作以主蓝图第二代Stage I～X、PROJECT、产品源码和本索引中的四库入口为准。

其他技术资料按需查 [城市生成](../参考资料/城市生成深化_2026-10-09/阅读入口.md)、[系统技术参考](../参考资料/系统技术参考_2026-10-09/README.md)、[全项目补充研究](../参考资料/全项目补充研究_2026-10-10/README.md)。当前音乐由 [共享PCM声部](../scripts/audio/city_creation_music.gd) 与 [预编译声部库](../scripts/audio/city_creation_bank_cache.gd) 驱动，旧原生音频扩展已归档。

Foundation远山已适配：[素材记录](../资源/自然参考/远山/README.md)。原1014顶点/1875三角网格按共享实例形成外围山谷；原文件与三库目录保留，原作材质绑定由本项目草石/空气透视着色替换。

## 调度与CPU优化的当前落点

已核对CS2的 [车辆分组生产端](../参考资料/Cities%20Skylines%20II逆向分析-六项底层机制-2026-10-17/03-time-code/Game.Simulation.CarMoveSystem.decompiled.cs#L418)、[显示插值](../参考资料/Cities%20Skylines%20II逆向分析-六项底层机制-2026-10-17/03-time-code/Game.Rendering.ObjectInterpolateSystem.decompiled.cs#L4321) 与 [来源说明](../参考资料/Cities%20Skylines%20II逆向分析-六项底层机制-2026-10-17/03-time-code/CarMoveSystem_来源.md)。借鉴权威状态/稀疏更新/连续显示的分工；本作近景保持完整动作，远处普通采购、生产和送装用错峰或到期事件结算，不引入严格宏观经济。

Phase12已适配：`city_creation_life.gd`按个体搭车需求分档，`city_creation_citizen_schedule.gd`用下一拐点/桥拱侧阈值截止时间堆调度隐藏长路段；`city_creation_citizen_motion.gd`按生活时钟连续推算位置，回镜/编辑/保存结清，过桥沿用原观察器结算，赴演完整观察。`city_creation_tram.gd`只逐帧验证候车与在车票，负决策按行程缓存。300屋带真实电车的最新900帧实窗Life均值.780ms/p95 .946ms，作为实测参考；28471次道路高度查询与原最近段解算一致。`city_creation_worker_lod.gd`复用同一移动采样，隐藏面包师/工匠的烘焙、制作、安装、休息按完成时间唤醒；库存/委托/开关/加成变化唤醒原状态机，回镜、编辑与存档结清。继续处理旗舰品质/生态与编辑尾帧，验证更大规模经营。音乐拍钟独立，奖励只结算一次。原生路网队列与茶座座椅路线预热已接入：独占Network持有Godot AStar2D零启发队列，精确保留原边权；三席进出路线在载入/后台准备，原城重绑后直接复用。

缺少关键静态证据时可继续使用REA技能定向分析本地CS2文件，复用原件和已有导出。只发布必要源码与精简结论，大型证据留本地。本次REA达到元数据表示预算，后续生产端C#由已有ILSpy只读导出；分析结果与性能实测分开记录。

## 桥头与轻量光照

本地Tiny Glade恢复源码`reconstruction/shaders-source/glsl/country-core/compiled/terrain_lighting_texture/000.comp`区分日/夕阳光与indirect_light_tint；Foundation恢复`packages/engine/shaders/glsl/light_ambient.fragment`按法线从天空辐照度采样。2026-10-20适配为本作柔暖直射/天空补光与昼夕夜参数，保留现有墙面微法线/屋檐AO。

[Godot灯光与阴影](https://docs.godotengine.org/en/stable/tutorials/3d/lights_and_shadows.html)、[DirectionalLight3D](https://docs.godotengine.org/en/stable/classes/class_directionallight3d.html)、[环境与后处理](https://docs.godotengine.org/en/stable/tutorials/3d/environment_and_post_processing.html)：用两级联太阳减少重复绘制，曝光与normal bias以本作Compatibility实窗校准。桥头过渡写入已有路面顶点，木桥沿弧长纹理、石桥保持世界相位；单路面避免共面叠层。细颗粒按像素足迹淡出，板缝用fwidth平滑。入口city_creation_bridge/renderer/environment与creation_road/era_road/promenade_pattern；验证见PROJECT。

2026-10-20继续依[渲染器能力表](https://docs.godotengine.org/en/stable/tutorials/rendering/renderers.html)补Compatibility可用的短距离SSAO（0.75m、强度1.1、直射影响0.10），及两级联阴影混合。本地Tiny Glade原terrain_lighting_texture/000.comp中的直射/间接光分工继续沿用；不添加本后端不支持的PCSS。环境入口city_creation_environment.gd，实际release三态截图与纹理验收见PROJECT。
