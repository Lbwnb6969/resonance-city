# M76 · 自由创作政策与版本化存档

> 已完成的M76实现快照与验收记录。“本轮/后续”均指M76当时；当前规格及下一项以[V7.1施工总案](54_V7_最终施工改造总案.md)和根backlog为准。地标/音乐偏好的后续实现分别见48、46，不再受当时预留字段限制。

本轮基于源提交`8c808d526`，按文档39/40/41接续。用户要求连续逐轮完成，每轮独立验收、提交和双库同步后立即进入下一项。

## 实现与规则

- 正式新城默认为空地，入口`State.initialize_free()`、作品集新地貌入口`CreationPolicy.initialize_biome()`创建free城；四时代普通风貌、八种普通用途、五大画具从开局可选。`era_unlocks`、实际问答、手札与库存不因开放权限被填充。
- `initialize()`/`initialize_empty()`保留为legacy配方构造API，保护历史样例与回归夹具；正式产品的新建入口均改为free。旧档restore缺少扩展时确定为legacy，不自动转换或重写格式。
- 时代/用途权限由`CreationPolicy.can_build_era/can_assign_role`统一；State、画笔、时代轮换、两套用途/时代UI、道路电车门槛使用相同规则。
- 首次启动不再催促三屋目标。F1手册中可单独开启/收起教学提示；无论是否开启，free城的画具始终可用。旧城保留原引导与六项可见用途，free菜单新增原本被排除的演奏庭/交响厅。
- 手册按当前政策解释可用性；自由创作中的时代成长条件显示为真实纪念，避免仍写“画具陆续解锁”。批量用途画笔不再吞掉手册/作品集/账本的Esc。

## Schema20

`city_creation_creative_save.gd`集中校验/读写扩展；原Schema1～19的既有字段与校验路径保留。新字段只在明确版本20内合法，读入后规范化整数，未知版本与非法数据原子拒绝。

| 字段 | 规则与作用 |
|---|---|
| `creative_settings.version` | 扩展契约版本1 |
| `creation_policy` / `migration_version` | legacy或free；0为新建/原策略，1为显式转换；与永久成长分开 |
| `guidance` | 可撤销的教学提示偏好 |
| `music` | mode、受限字符串style、确定性seed；为后续配器计划提供持久承载，本轮不暴露尚未接入的音乐控制 |
| `presentation` | 自动装饰、旧冠冕展示偏好承载，实际装饰/冠冕整合由M81接入 |
| `placed_landmarks` / `next_landmark_id` / `landmark_high_watermark` | M76当时预留为空/1/0；M81现已接入实际实体与身份高水位，当前校验见[地标记录](48_传世地标与真实留白.md)，未知蓝图仍拒绝 |

建造权限不替代成就真实性：历史解锁顺序、已声称获得的现代时代仍须有原本的真实共鸣证据。free城可保存尚未获得时代纪念的普通房屋/用途与有效跨时代完成记录；无效枚举、占地、重叠、非法原型继续拒绝。地标蓝图、时代铭牌和手札候选仍按既有已赚取权益处理。

## 转换与历史

旧城通过F1的“开启自由创作”显式转换。先在独立转换目录保存可冷读的转换前城市；若目标已有原档，同时逐字节保留其原文件，再调用既有临时写入/校验/原子发布链。写入失败恢复政策、revision与dirty状态。

正常继续模式保存到当前继续存档；非持久试玩保存独立转换副本并加入现有作品集，不写个人继续存档。转换不占地、不生成蓝图、不伪造采购/问答/奖励。已有Schema20经典策略的作者偏好在转换中保留。

创作偏好进入Undo/Redo；转换后的free政策与迁移版本不被旧几何撤销收回。颜色快捷撤销也核对新作者内容，避免绕过偏好恢复。后台渲染/预览副本复制政策，避免主城free、worker误判legacy。
