# 07 · 界面与反馈

> 2026-10-09 重构版。本文回答"极简 UI + 悬停出信息"与"不断视听正反馈"。
> 这是用户最明确的诉求之一，也是与旧设计冲突最大的一块（旧设计有常驻右栏 31% 宽 + 底部条件卡 + 主动弹窗缺口提示）。

---

## 1. 核心原则

**默认状态：屏幕上只有城市、地形和一条极细的节拍条。**

一切信息在**鼠标移上去**的时候才出现。一切反馈在**发生的那一拍**出现。

三条约束：

1. **常驻元素 ≤ 4 个**（当前：顶部标题栏、左缘地标栏、底部节拍条、可选的左上通知轨）
2. **悬停出卡**，离开即收；卡片带 300 ms 淡入 / 200 ms 淡出
3. **单推荐焦点**：任意时刻只高亮 1 个建议动作，其余可用但不显眼

---

## 2. 即时反馈（回答 Q20）

**关键洞察**：本作有多个时间层，玩家必须**同时**感到"跟手"和"有分量"。

时间分层只取 [U20](01_执行规格/spec.ui.md#表-u20--即时反馈层回答-q20)：输入与预影先回应，局部声音在下一可写拍点进入，结构在乐句边界提交。声音延迟是需测量的体验目标，不由队列存在自动证明。

首作选择声音方向立即播放同源四秒片段，结束恢复城市；停止、再听与 Space 按住试听保留。公共/公交比较沿各自三秒分支。打开菜单不代选，试听不提交，确认才进入正式事务。

### 2.1 第一次播种的完整反馈序列（标准动作）

| 时刻 | 反馈 |
|---|---|
| 悬停合法空地 | 该位置出现**半透明预影建筑**；按 U20 提供轻量音高预览；地面柔光 |
| 悬停时界面 | 只在鼠标旁出现一行极小文字："C · 预计与西侧形成 C–E 大三度" |
| 点击 | 涟漪从落点扩散；一声完整的调内音；预影加强但仍与真实建筑可辨 |
| 落点等待 | 预影缓慢脉动（呼吸感），随节拍微亮 |
| 乐句边界 | 真实建筑弹出（squash & stretch，1 拍）；声部淡入；镜头轻推；地面微光；一声调内木质轻击 |
| 稳定后 | 该建筑参与合奏，界面无任何提示（不弹窗、不出卡） |

**没有任何一步是"系统提示音"。全部是调内乐器音。**

## 3. 界面构成

### 3.1 常驻元素（全部）

```
┌──────────────────────────────────────────────────────┐
│ 共鸣之城                        ○ ○ ◐ ○ ？          │ ← 标题 + 地标栏（极小）
│                                                      │
│                                                      │
│                    城  市  与  地  形                │   ← 100% 的画面
│                                                      │
│                                                      │
│                                                      │
│                                                      │
│  ▏▎▍▌▋▊█▉▊▋▌▍▎▏          ♪                           │   ← 底部极细节拍条
└──────────────────────────────────────────────────────┘
```

- **标题栏**：只有标题（可点击收起）
- **地标栏**：左缘一列小圆点（隐世是 `？`）；悬停出详情卡
- **节拍条**：底部一条极细的横向进度条，显示当前乐句的 16 秒进度；当前活跃声部以不同色调的小块显示（**这是唯一的"数据"常驻显示**，且是视觉隐喻不是数字）
- **通知轨**：只在有 L1+ 事件时出现，6 秒后自动收

### 3.2 悬停出卡（信息层）

| 悬停对象 | 卡片内容 |
|---|---|
| **待落点**（2026-10-10 新增） | **"会长成什么"**：落点层（沿街 / 临街一侧 / 孤屋）+ 预计音程 + 可达阶段。例：`沿街 · 预计与东侧形成 C–E 大三度 · 可达群/央`；`孤屋 · 无临街 · 每 2 乐句最多出生 1 栋，阶段停在群` |
| 一栋建筑 | 类型、音级、阶段（胚/群/央/腔）、活力、属于哪个社区、与邻居的音程关系（**用颜色和音程名，不用数字**）；**若是连排成员，注明"连排 N 栋"** |
| 一片区域 | 缺什么声部、该区域的和声健康度（色温条） |
| 地标栏图标 | 效应 / 代价 / 声部 / 落成时间 / 状态 + "▶ 单独聆听" |
| 节拍条 | 当前乐章数、谐振度、下一跨越条件进度 |
| 社区轮廓 | 社区名（若已命名）、成员数、**成形档（萌芽/成熟/完整，用词不用数字）**、社区主题旋律的"曲谱"小图 |

**待落点卡是本作"选择"能否成立的关键**：玩家必须能在**点下去之前**知道自己在做什么选择。
**只显示"合法/不合法"是不够的**——那是二值判断，不构成设计选择（`spec.fabric` 表 FB1 §1.2）。

候选/落点卡按 [P11](01_执行规格/spec.proposal.md#表-p11--判断预览与条件机会) 在原卡内补“当前变化 / 取舍 / 后续机会”，主卡各保留一句，条件明细按需展开。例：“低音加入河岸 / 节奏仍空 / 对岸成熟后可尝试应答”；具体条件由真实世界生成，示例不是无条件承诺。预览分别标识下一边界能兑现的结果与尚缺条件的方向，试听只播前者的实际副本。

空地菜单提供“留地”，已留地区提供“释放 / 规划用途”；额度、提交与转换仍走 P10/P7。作者家族的活动留地可直接点“你留下的空地”短标记；菜单首屏提供保持留白、公园、文化馆三项动作，释放与局部兑现等高级工具保留在折叠区。悬停时画真实范围和相关对象，局部公共目标足迹预影同时画出目标到真实道路入口的连线，并显示入口道路、目标社区、下一乐句落成和剩余留地数量；取消选中后收起操作描边，以地面/植被保留空间辨识。留地不播放虚构设施声，不常驻预测进度、不加待办计数；B 黑屏隐藏全部辅助轮廓与卡片。输入等价和减弱运动继续沿用既有协议。

“自由分块公园/自由分块文化馆”沿用同一预影：左键绘制当前组件，Tab 收束组件并继续绘制，Enter 提交全部组件。每个组件显示独立边线与填充，预影合并显示所有目标组件、真实道路入口、目标社区和剩余留地；组件重叠或接边时只显示明确原因，不生成虚假设施声。单组件自由局部入口继续使用原有提示。

“自由内院公园/自由内院文化馆”先绘外环，Tab 收束后进入内院绘制，Enter 提交外环与全部内院；未完成、过小或自交的当前草稿保留并提示原因。预影与排队显示实际实心范围、内院边界、真实入口和残余留地；落成地面、步道、水池与摆件避开内院，内院仍能点选并继续规划。分块/搬迁预影与落成画面遍历全部组件；公共操作菜单按宽度换行。

局部、分块和内院目标接入三分支比较：画好合法范围后按住空格，按钮选择不建/公园/文化馆，Enter 提交同一范围；松开只结束声音，继续点图或 Tab 修改会丢弃旧比较，Esc/右键取消草稿。固定矩形局部目标也可先空格固定范围，再比较、Enter 确认。局部面板并列显示三方案摘要，只展开当前方案的条件；当前三秒合奏相同时直接说明声音仍需条件。落成反馈提供真实公建、剩余留地和已服务房屋入口，不以预测出生冒充真实对象。

同样的简洁比较用于普通公共选址：三方案保留栋数、文化服务与主题摘要，详细角色条件只展开当前方案。多个受影响社区时显示名称按钮，点击只切换查看社区的机会行，不改完整合奏、范围或试听源；单社区隐藏该行。查看与确认使用同一社区目标，实际对象出现后仍按真实社区重新绑定；关闭或比较失效清除查看选择。按钮按宽度换行，不常驻规划之外。

**所有卡片**：

- 悬停卡在鼠标旁并避让屏幕边缘；首作选择卡与作者调音卡放在目标另一侧，保留真实落点或选中房屋的可见空间
- 300 ms 淡入，200 ms 淡出
- 悬停提示使用暖纸底与细边框，保持文字可读且不截获点击；选择卡只占必要空间，状态文字使用浅底保持昼夜可读
- B 黑屏时全部隐藏

### 3.3 动词菜单（按需出现）

**默认不显示任何按钮。** 选中一栋建筑后，鼠标旁出现一个**环形菜单**（4–6 个图标：调音/迁移/单独聆听/静音/聚焦/查看），离开即收。

这取代旧的右栏一长串按钮列表。

### 3.4 需要输入时

需要选择（选音级、选落点、选地标落点）时，从屏幕底部**滑上一条窄带**（不是全屏对话框），列出 3–5 个选项，每个带即时试听。

选择完自动收起。

当前首作三方向为深流、织机、暖庭，使用地图旁的三张声音卡。每张卡共用第一时代真实生产建筑缩略图，展示路线名、住宅/商业用途、声音听法、城市后果和当前试听状态；低音慢拍、高音短拍、中音长和声另有简短图形节奏标记。卡片与实际试听预影共用真实道路朝向模板，缩略图不制造未来房屋。暖庭是声音路线，公共规划“留地 · 呼吸”仍表示不发声的真实空地。主卡不堆音频测量和公共/城市工具。打开时无默认方向；点方向立即听四秒，切换可比较，结束自动恢复城市，停止/重听和按住Space仍可用。“确认种下 · 下一句生长”与停止/再听、返回河湾位于独立底部操作区。Enter或确认才提交；未等试听准备完成就确认时，地图以真实事务位置、表达色占地和可听倒计时标记待落成，不虚构未来房屋，直到已听边界、撤回或实际失败才清除。

推荐声音落点优先选择已有房屋附近、道路交汇处的合法地块，让新家族从可见街坊接续；玩家仍可亲自换到另一处合法陆地。

首作轻入口位于标题下，避开底部状态。实际可听序曲五秒后出现“塑造第一段 · 选择发展方向”，P可提前进入；选择章程、变化卡和社区后，玩家在合法位置亲自选择公园、文化馆、留地或暂不建设。暂不建设不新增公建或保留地，同一真实章程在可听边界落定后仍进入声音选择；反馈面板收起后，轻入口和P恢复同一步骤。真实作者根屋听见后，轻入口显示“你的深流/织机/暖庭 · 改音与继续”，定位原房屋菜单；其中可开始“下一段 · 街坊 / 公共空间 / 声音”，不以改音或成熟数量锁住继续。进入下一段前先结束当前独听和主题聚焦，再重新打开既有章程、变化卡、社区范围与公共规划选择，不代选；作者调音卡也提供同一入口。第二次规划结果实际揭示后，反馈面板和 `P` 都能恢复尚未完成的第二片社区声音选择，再由玩家亲自选择合法落点和路线。菜单按各自真实根屋保留已有作者段，分别定位社区与路线。跨岸房屋满足合格音级、距离与真实来源条件时，以实际连线加入合奏，Reply 在 Lead 后延两拍出现；已听见改音不会让继续创作的入口消失。有真实活动留地时，原房屋菜单可定位并打开该留地的三动作菜单。

2026-10-12 的入场采用深松绿标题牌、暖纸色面板与明确的主要动作。开局镜头按实际街坊投影 bounds 与窗口尺寸适配，缩放上限 1.65。章程/变化卡加入街坊方向小图，标题、倾向、取舍分层；首作声谱先介绍三条声音路线，已有两段作品后显示各自真实社区、路线和已听音级。小窗口保持原生字体像素与内容滚动，不把整个画布缩小后压成细字。声音菜单按实际面板宽度将真实落点移到旁边的地图净空，并给地块/门面留出完整范围；800×600 也按真实目标避面板，面板打开时收起重复的地图说明。

## 4. 视听正反馈分级（保留旧 NTF-01，扩展）

| 级别 | 触发 | 视觉 | 听觉 | 频率 |
|---|---|---|---|---|
| **L0** | 每次生长 / 介入落定 | 一拍揭示 + 微光 | 调内轻音（一声） | 随时 |
| **L1** | 首次群/央/腔、首次命名雏形 | 该建筑/社区一圈柔光 | 已有声部的实际成长声音；不自动另加提示音（U15） | 每局每类一次 |
| **L2** | 命名形态达成、地标觉醒/落成 | 通知从屏幕边缘滑入 + 悬停详情 | 该形态/地标的标志动机 | **每乐句最多 1 个** |
| **L3** | 时代跨越 | 城内逐批沉降/重生；完成后短横幅确认，时序见 R10 | 局部新音色向整城蔓延，原城声连续 | 每次跨越 |
| **L4** | 终章结算 | 城市曼陀罗展开 | 全城齐奏 | 一局一次 |

成长短提示优先反馈真实作者出生，以“你的深流/织机/暖庭第N栋…”说明路线、家族次序与实际用途。普通房屋只说明社区和用途，避免把背景住宅叫作作者路线；玩家通知不显示建筑内部ID，实际演奏标记仍跟随真实来源。

**硬规则**：
- 任何通知都**不停音乐时钟**
- L2 每乐句最多 1 个
- L3 期间不弹其他提示
- **L0 必须每次都发生**——这是"不断正反馈"的基础，也是最频繁的一层

## 5. 视听同步纪律（保留）

- **音乐同步的视觉必须按音频帧插值**，禁止用 Tween 秒数控制生长/入场
- `t = (audio_frame − start_frame) / STEP_FRAMES`，STEP_FRAMES 代表**一拍**
- 普通建筑生长 = 精确 1 拍；常规场景级过渡 = 1 小节；时代沉降/重生与整城传播专用 R10 时序，不套普通出生动画
- 微交互 150–300 ms；UI 300–450 ms；镜头 600–900 ms
- 缓动：入场 ease-out cubic、状态切换 ease-in-out sine、回弹 ease-out back（overshoot ≤1.1）

## 6. 聆听模式与尺度切换（保留 + 扩展）

**用镜头缩放自动切换尺度**（回答 Q21）：

| 缩放 | 尺度 | 听到 | 看到 |
|---|---|---|---|
| 拉远（≤0.8） | 全城 | 编曲全景（40–70 声部） | 城市轮廓、社区色块、地形 |
| 社区（全城进入≥0.85，回到全城≤0.8） | 社区 | 该社区 + 跨社区邻居 | 建筑细节、微动效 |
| 拉近（≥1.8）或选中 | 单栋 | 该建筑三层频谱 | 该建筑 + 直接邻居连线 |

**连线可视化**：拉近时，与选中建筑有耦合的建筑之间出现极细的**声学连线**，颜色表示协和度（暖=协和，冷=不协和），线宽表示耦合强度。

这是"诊断"的视觉等价物，且**符合"不扭曲几何"**（连线是叠加层，不改建筑形状）。

**B 键黑屏**：保留旧的纯黑聆听模式。

## 7. 无障碍与等价性（保留）

- **视觉优先模式**：关闭音频时，等价信息完整可读（保留旧 UI-003）
- **减弱运动**：时代保留局部传播顺序与完成时点，取消沉降/重生和自动运镜，改为原地交叉（R10）
- **失谐不靠颜色单一表达**：连线既用颜色也用**线型**（虚线 = 不协和）
- 文字对比度、色弱可读（保留旧规格）

## 8. 与旧设计的差异总结

| 项 | 旧 | 新 |
|---|---|---|
| 常驻面板 | 右侧 31% 宽滚动控制台 | **无** |
| 底部条件卡 | 常驻，高度动态变化 | **无**；改为悬停出卡 |
| 缺口提示 | HUD 主动弹出 | **声音先行**，视觉柔光，绝不弹窗 |
| 动词入口 | 按钮列表 + 下拉 | **环形菜单**（选中后出现） |
| 数据展示 | R / 声部数 / 乐句 / 倒计时的数字 | **节拍条视觉隐喻**，数字在悬停时 |
| 通知 | 常驻通知轨 | **只在有 L1+ 事件时出现** |
| 试听 | 选方向、再听或按住 Space | 首作点声音方向立即听四秒并自动恢复，另有停止/再听，也支持按住Space；公共/公交比较保留3秒，悬停轻音作为补充 |

## 9. 当前实现入口
