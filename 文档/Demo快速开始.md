# 城市生长 Demo

在项目根目录双击 `启动Demo.cmd`，或在 Godot 按 F5。

滚轮以鼠标位置缩放，中键拖动地图；Home或右侧“复位视角”恢复全图。

1. 在右侧“地图工具”选择“释放共鸣点”，从 C/D/E/G/A 选择系统音级，再点击地图空格。
2. 源点在下一乐句边界落定，城市随后每16秒尝试长出一栋连通建筑。右侧有下一次回应倒计时。
3. 将“地图工具”切回“浏览与选择”，点击建筑选中；右侧下方显示邻居、密度、连续乐句与缺口。已满足条件会形成群/央/腔；有失谐的碴会冻结生长，保留建筑。
4. 用 solo/mute 辨认声音。调音或迁移可长按试听3秒，再确认；迁移模式可点击空格选目标。释放、调音、迁移共享一个待提交槽，后选覆盖前选。
5. B 全黑聆听，Esc 恢复；“重新开始”回到本日原始城市。正式人测在“详细信息 / 设置”展开“聆听设置 / 正式听测”，再点专用按钮，仍使用原标准协议。

这版完成 release + 自动扩张 + 条件升级的 P1-α 体验。工业不会被自动生成；新增声音有振幅预算，当前最多27实体。踩路径已按用户批准接入；图鉴、稀有命名形态与卡帧演出留后续。主观好玩与艺术效果等待实际游玩反馈。

当前集群混用紧凑、庭院、侧翼住宅，以及连续坡屋顶/阶台露台两种统一连宅；小幅错位和尺寸变化让社区更自然。配对住宅保留两个逻辑格和独立声部，点击各自地块可分别选中。形态升级沿整组外侧显示状态边界；当前图片由柔和CC0副本与项目原创连宅组成，原件保留。已授权2.5D素材可按需加工。

引力带：从“地图工具”选择“划定引力”，选择住宅/商业偏向，在地图按住左键拖出箭头。下一乐句生效，只影响合法生长位置的优先级；重划时暂停扩张一个乐句，声音和已有建筑继续。释放/引力/调音/迁移共用一个待提交槽，取消新线会保留已生效旧线。辅助与正式听测在“详细信息 / 设置”内展开“聆听设置 / 正式听测”。

画面已使用柔和建筑加工副本、浅色背景和淡白网格；滚轮/复位采用平滑镜头，中键拖动可立即接管。按B仍是纯黑聆听。

协调房群.png是实际GPU场景在12个模拟乐句后的画面；正常游玩按每16秒一次回应生长，不使用这段快进作为实时性能成绩。

释放模式下，鼠标悬停会说明当前位置是否可用；确认后的共鸣点用暖色地块与圆标记显示，地图下方显示剩余时间。误点占用格会保留之前的待提交项，取消会清除标记。选中建筑时，地图下方直接显示其实际生长条件；可释放不保证附近一定能长出建筑。

调音/迁移目标选择后，按钮上方会立刻显示同一副本的预期谐振度、所选活力和代价；完整邻接/其他声部变化可向下查看。长按试听用于听未来，确认才实际提交。

踩路径：从右侧“地图工具”选择“踩路径”，按住左键从一格拖到四向相邻格。先查看谐振度、邻接和家族断连的收益/代价，再点击“确认足迹”；下一乐句落定一次。对同一边界分3个乐句确认，前两次留下足迹点，第三次形成街道，无需连续；反向拖动算同一边，长拖不能一次铺多条。

未落定足迹可取消/覆盖，并与释放、引力、调音、迁移共用一个待提交槽。成路后本局不可撤销，重新开始清空。街道切断该共享边的声学邻接与家族扩张，不删房、不直接扣R/V；成熟房屋保留。连宅跨边时拆回两栋，声音与各自选择保留；迁移房屋不会移动街道。第三次确认前务必查看永久代价。

条件与缺口：点击建筑，地图下方和右侧条件区会直接说明还缺多少邻居、共鸣、密度或局部谐振度，以及失谐冻结/家族断连。条件满足时显示正常连续乐句进度；连续2个完整乐句既未升级、下一阶段计数也未推进，选中它时会强调“已等待N乐句”。不会弹窗或自动给答案；新生当乐句、成熟央/腔、工业和共鸣点不计升级停滞。更新后重新启动Demo/F5可载入新版，重开会清空本局。

美术小景可单独打开“启动风格小景.cmd”，操作滚轮/中键/Home，G切换白网格。当前用于审阅整体比例、连宅和自然元素，详细图与来源见风格小景审阅.md；与本局城市的生长/声音状态独立。

历史建筑样稿可双击“启动古典小景.cmd”：神殿、教堂、古典公共建筑、斗兽场同框；滚轮/中键/Home，G开关淡白网格。可编辑源图和说明见古典建筑样稿.md。当前用于美术观察，音乐时代和解锁规则尚未接入。

地图、活力/条件与乐句提示现在跟随实际可听边界，音频预填不会提前显示生长/迁移。已经排入声音的介入会标明等待可听；其PCM已生成，取消按钮只取消后续尚未生成的待提交项。

失谐诊断：在右侧Solo/Mute下方打开“失谐边界 · 看见抖 / 刺”，再点击房屋看地图下方的真实邻接关系。轻微灰青波纹代表基频差在3–16Hz内的小二/大七，暖灰短齿代表三全音；没有对应关系时不会凭空出现。道路已切断的邻接不再画。

“减弱运动”把抖改成静态双波纹；静音、Solo隔离、长音关闭或迁移静音时也停止动态并说明原因。诊断默认关闭，随时可收起；未来试听期间文字提醒边界仍来自当前城市。B仍隐藏整幅画面。此功能不改变声音或生长规则，也不代表完整视觉优先模式已经完成。

操作面板已整理成紧凑布局：从“地图工具”切换浏览、释放、引力和踩路径，只显示当前工具的参数。浏览时可调音/迁移；踩路径保留收益代价与确认。切换工具会结束未来试听，保留已提交的介入。取消按钮始终可用。

完整生长条件、提案明细、重新开始及听测设置放在“详细信息 / 设置”中，展开后可向下滚动；收起不会清空选择或改动城市。空格仅在试听按钮可见且可用时用于试听；下拉框获得焦点时空格交给该菜单处理，可点击地图后使用试听快捷键。B黑屏、Esc返回保留当前工具和展开状态。

房屋点选已按可见轮廓处理：透明角落不再抢走空格点击，屋顶/立面可直接选中；生长动画未露出的部分不拦截点击。统一连宅仍保留两个逻辑地块，点击各自地块可分别选中、试听或调音。
