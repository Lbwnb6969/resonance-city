# 城市生长 Demo

在项目根目录双击 `启动Demo.cmd`，或在 Godot 按 F5。

1. 打开右侧“释放共鸣点”，从 C/D/E/G/A 选择系统音级，再点击地图空格。
2. 源点在下一乐句边界落定，城市随后每16秒尝试长出一栋连通建筑。右侧有下一次回应倒计时。
3. 关闭释放模式，点击建筑选中；右侧下方显示邻居、密度、连续乐句与缺口。已满足条件会形成群/央/腔；有失谐的碴会冻结生长，保留建筑。
4. 用 solo/mute 辨认声音。调音或迁移可长按试听3秒，再确认；迁移模式可点击空格选目标。释放、调音、迁移共享一个待提交槽，后选覆盖前选。
5. B 全黑聆听，Esc 恢复；“重新开始”回到本日原始城市。正式人测另点专用按钮，仍使用原标准协议。

这版完成 release + 自动扩张 + 条件升级的 P1-α 体验。工业不会被自动生成；新增声音有振幅预算，当前最多27实体。draft/tread、图鉴、稀有命名形态与卡帧演出留后续。主观好玩与艺术效果等待实际游玩反馈。

当前集群以地面占地排列：紧凑屋顶、开放院落与共享通道；形态升级沿整组外侧显示状态边界。已授权2.5D素材可按需用于后续选件，本轮图片仍是现有CC0烘焙整图。
