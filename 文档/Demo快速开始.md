# 新共鸣之城 · 快速开始

默认入口是新的 3D 河湾创作切片，基于 Foundation 的建筑生活、Tiny Glade 的连续空间和自然接合、Townscaper 的局部点击生成重新构建。当前实际完成状态见 [PROJECT](../PROJECT.md)。

## 打开河湾

| 入口 | 行为 |
|---|---|
| [启动Demo](../启动Demo.cmd) | 从六座房屋开始，不读取已有作品；可手动保存 |
| [继续我的河湾](../继续我的河湾.cmd) / Godot F5 | 恢复新存档，编辑停手三秒后自动保存 |
| [打开创作样例](../打开创作样例.cmd) | 已有高差房屋、露台和跨河桥的实窗编辑样例 |
| [旧河谷对照](../启动旧河谷对照.cmd) | 保留旧 2.5D 城市、声音/规划和作者系统 |

## 一次试玩

用工具 1 点中间长房的右墙扩出一个房间，点它的顶面再加一层；用工具 2 点相邻屋顶留下露台。按住右键转动镜头能看到不同墙面。工具 3 沿空地拉路到门前，横跨两岸会补桥。工具 5 选房，改名或安排面包坊/演奏庭；居民沿接通的小路去采购和小聚。

红色候选说明当前位置被道路、河水、别房或支撑规则占用。点其他墙面继续；所有实际建设立即发生，不等待乐句，也不检查协和资格。

| 操作 | 行为 |
|---|---|
| 1 / 房屋 | 点墙扩展、点顶加层、空地新房 |
| 2 / 露台 | 点墙延伸露台、点顶建屋顶花园 |
| 3 / 道路 | 按住左键自由拉路，松开提交；Esc 取消 |
| 4 / 移除 | 移除单元，失去支撑的附属层一起收回；最后一块保留 |
| 5 / 用途 | 逐栋选房、输入名字后 Enter；居所/面包坊/演奏庭 |
| 6 / 植被 | 选橄榄/柏/灌木和笔刷大小，拖动左键画树群；Shift 擦除，Esc 取消；整笔撤销 |
| 7 / 水岸 | 选池塘或引水渠与宽度；池塘在空地起笔，引水从已有水域起笔拖向干地；Shift 点击填回自建水域，Esc 取消，整笔撤销 |
| Ctrl+Z / Ctrl+Shift+Z / Ctrl+Y | 撤销 / 重做，一条道路一次恢复 |
| 保存 / Ctrl+S | 保存新作品；原存档版本保留 |
| 滚轮 / 右键 / 中键 | 缩放 / 转动 / 平移镜头 |
| H / 全景 | 恢复河湾镜头 |
| F | 隐藏界面拍照 |
| 音乐 / 光线 | 静音与开启 / 白昼与暖夕光 |

新作品保存于 Godot 用户目录 `city_creation_v1.json`，不覆盖旧 City DNA。坏档保留原文件并禁止当前试玩自动覆盖；读取成功才替换城市。窗口关闭完成已有编辑保存，未确认道路草稿不写入。

植被自动避开完整房屋足迹、门前、道路与河岸；新建筑覆盖树木时保留植物真值并隐藏冲突实例，撤销建设后原树恢复。居民不会因为植树、改名或加层重新回家；正常继续入口自动保存累计采购/小聚，重新打开后累计次数继续。

水岸可以合流、围出小岛，新增道路完整横跨后自动搭桥。红色水岸预影会列出冲突房屋/道路；调整路径后继续，当前工具不覆盖这些结构。水域覆盖树群只隐藏植物，撤销后恢复原树。基础主河暂不能填回。

本轮已验证真实输入、删除/撤销、水岸/植被笔画、保存与居民可达；美术统一以本地 Tiny Glade 参考库为基础。区域画笔、完整经营进展、五时代与视野声场尚未完成。实现与证据见 [新城切片](21_新城创作切片.md)。旧 Demo 操作说明完整保留在 [旧入口说明](../废弃/文档/2026-10-14_新城入口前/Demo快速开始.md)。
