用Godot 4.7.2打开 `project.godot` 后F5，或双击下方入口。默认3D河湾，Compatibility，1440×900。

## 先玩五分钟

1. 新城会出现三枚虚线屋基，按地面引导点下三栋屋，再沿门前画路。五个主画具会逐步点亮：筑屋、修路、烟火、林水、地形。
2. 点屋打开悬浮罗盘，设置生活用途、风貌和颜色；「更多」展开墙面/屋顶色盘。「加建」后点墙扩房、点顶加层，露台与拆除在筑屋子圆章中。
3. 接路后按屋顶气泡一键设面包坊、茶座与制琴坊，保留居所，观察居民真实到岗和采购。三栋近邻或同街房屋自动组成街坊，新屋继承邻居风貌，不必先涂街坊。
4. 修路圆章中，每种道路都能选曲线/直线及宽度；林水圆章中选择树木、池塘或溪渠。七种植物支持精确单株和成片摆放；地形可抬高、压低、平顶或柔化坡地。
5. 在烟火浏览态掠过成形聚落的屋顶、树冠或水面，可以拨出轻音并看邻居回应。屋顶心愿会提示真实缺路、缺水等需求，点气泡切工具并显示落点；六种地标可主动奏24秒乐章，末两乐句齐奏。

J看成长手记，L看生活账本，Ctrl+O收藏完整作品；左上五线谱与右上日晷保留画面，详细手札用F1打开。

红色预影表示本笔与结构、水域或支撑规则冲突；调整位置再落定。建设立即提交，不等待音乐资格。

## 成长与地标

居民实际买面包、品茶、收到木饰/画作并参加演出，会让各户从1级逐步长成5级名宅；门前花盆与暖灯、窗台花箱、铜铃、连廊、花架、金色风向标和彩绘圆窗随级别出现。已获得的等级会保留。

左上角「地标名胜」列出里程碑。10屋加跨河桥解锁古钟瞭望塔（步行+15%、聚焦范围+3m）；累计烤出24份面包解锁水车磨坊（所有面包坊每炉+1、烘焙耗时缩短20%）；文艺复兴开启、两个街坊实际完成器乐问答后解锁圆顶音乐院（38m演出与自动接力）。选「免费选址」后点击有效预影放置，Esc取消；点击地标（或兼容键5）可移动或整体回收，Ctrl+Z可恢复。水车磨坊须沿岸落位，再接路让工人来开炉。

## 声学和弦与开拓

面包坊、茶座与附近池塘组成田园和弦；四栋1m高地房屋、钟楼与石阶组成高地共鸣；书院、制琴坊和两栋实际连拱楼组成赋格；钟表坊、一座玻璃花房与轨街组成圆舞曲。两个不同时代的成型聚落位于两岸或高低台地时，用桥梁或共鸣音弧联结，可点亮古今对位。左上徽章可查看当前配方。

第二片独立五屋聚落起，每片增加12%全城工坊与木饰成长效率，最高60%；同一条真实街道连成一片后按一个聚落计数。空涂街坊不计奖。音乐院可按自然聚落翻倍工艺批量；总站相通轨街6m内的工坊/茶座效率增加30%，屋顶卡片会显示。

## 手绘传世乐章

有两座地标或四片至少五屋的大聚落后，点地标罗盘的「绘巡游」。按住左键依次划过2～8处聚落与地标，松开邀请街坊；Esc或右键取消绘制。居民先沿路赴约，再提灯巡游，八乐句按手绘顺序接力，末两句齐奏。参与地点须有相通街道；普通房屋仍专注生活用途。演出中可保存，也可点地标停止，取消不领取完成奖励。

## 五个主画具与兼容快捷键

默认坞只显示五个主画具，露台/拆除并入筑屋，水岸并入林水，旧手绘街坊保留在兼容入口。下表的1～9为既有键位，不代表九个可见按钮。

| 键/工具 | 操作 |
|---|---|
| 1 房屋 | 点屋打开用途，选「加建」后点墙扩展、点顶加层；拖动同一宿主/楼层建整笔，空地起笔建新屋；邻屋自动贴齐，Alt自由放置 |
| 2 露台 | 点墙伸出、点顶留花园；可连拖同层，系统补栏杆与支撑。工具4点布篷也能移除原露台 |
| 3 道路 | R/UI切自由曲线/直拉，Alt起笔临时直拉；按住左键画，直拉时空格/右键锁段，松开提交；各样式均可选原宽/窄/标准/宽，圆章显示米数；Shift点击擦除整条路 |
| 4 移除 | 点单元，附属失去支撑层一起移除；面板选整栋或Shift点击；撤销恢复 |
| 5 选房（兼容快捷键） | 与直接点屋相同：改名、生活用途、风貌、四配色或展开墙面/屋顶色盘；用途不再占一个画具。地标保留庆典入口 |
| 6 植被 | 选橄榄/柏/灌木/金叶树/粉白黄花，单株模式点击精确种植，成片模式选笔刷大小拖左键画；Shift擦除；自动避开房、路、水，建设冲突时保记录并隐藏 |
| 7 水岸 | 选池塘/引水渠与宽度；池塘空地起笔，引水从已有水边起笔；Shift点击填回自建水，主河保留 |
| 8 街坊 | 拖动划区、点击选区；起名、选五主题，可选已解锁时代风貌并连接两区共鸣，面板可开用途配器/邻里对答；Shift移除整区，后画区域覆盖成员归属 |
| 9 地形 | 抬高/压低/还原/露岩草丘/平顶台地/柔化缓坡，2/3.5/5m笔刷；自然轮廓开关、Shift起笔临时压低，一笔一次撤销 |

Esc取消未落定笔画；切工具也会取消。鼠标在UI上松开不把草稿误建到世界中。

|---|---|
| 滚轮 / 右键 / 中键 | 缩放 / 转动 / 平移镜头 |
| H / F | 恢复全景 / 隐藏界面拍照 |
| Ctrl+Z / Ctrl+Shift+Z / Ctrl+Y | 撤销 / 重做 |
| Ctrl+S | 保存当前继续作品 |
| Ctrl+O | 打开作品收藏，保存完整可编辑版本；“示范河湾”页签可切换18座内置样例，首张为127屋四时代六地标旗舰城 |
| F1 / 手札 | 打开四页营造与乐理手札：营造手势、烟火与进化、声学与时代、快捷键；Esc返回 |
| J / L | 河湾手记 / 生活账本；Esc返回 |
| 按住 P / 鼠标侧键 | 临时轻拨成群屋顶、树冠和水面；松开回到原画具，期间点击空地不建造。拖拽中不抢画笔，Esc取消临时拨奏 |
| 5 / 烟火浏览 | 持续浏览用途与试听；移动光标轻拨成形聚落，点屋开罗盘；不改作品或撤销历史 |
| V / 漫步按钮 | 进入街头透视视角；WASD/方向键行走、右键转头，再按V恢复原镜头 |
| F10 | 保存截图、城镇、相机与生活现场到 `user://render_diagnostics/`；发现纯色异常时短暂停住画面自动隔层定位，随后恢复 |
| F12 | 拍下带纸框和日期的明信片，保存在 `user://postcards/`；创作或漫步视角均可使用 |
| 音乐 / 光线按钮 | 静音或开启音乐 / 晴昼→夕照→星夜循环 |
| 四时风物圆章 | 日晷旁点击轮换花吹雪、太阳雨、秋金与萤火；分别延长茶聚余韵、加快临水烘焙、工坊制作及扩大星夜问答距离，支持撤销 |

继续档位于Godot `user://city_creation_v1.json`；作品收藏在 `user://city_creation_works/`。收藏可同名留新版本，打开另一作品前先保留当前作品，恢复房路、居民行程、库存、演出进度及镜头光线。关闭窗口保存已有编辑，未落定草稿不写入。从隔离样例启动不自动写个人继续档。游戏内切换示范会先把当前河湾留在“我的作品”，可随时回开；正常继续模式下，选中的示范及后续编辑作为当前继续作品。

工具8的跨区共鸣连线可以隔河连接两片街坊；音乐按双方实际时代与当前乐句一问一答。近处房屋清晰演奏，连线伙伴轻声回应，远方钟声保留方向，其余远处街坊安静。解锁新风貌后，老街坊会保留原来的样子，由你选择哪一片升级。

Ctrl+O顶部选择「开启新河湾 · 选择声学地貌」可开始晴翠双岸、三级台地、环水沙洲、林间秘境、星夜或每日组合开局。原河湾先自动留存；每日地标免费赠送且实际放入地图，普通时代仍需正常解锁。台地生产、沙洲活水、保留森林、星夜声域的加成可在屋顶罗盘查看。晴翠为D大调，台地为G吕底亚，群岛为B多利亚，森林为A大调，星夜为F♯小调；每日种子固定选择其中一套。背景、落笔、屋顶、对答与地标乐章共用当前调式。台地真实石阶带浅深石质琴键，用烟火画具拂过或居民实际踩过会奏出琴音并亮起；居民脚步不会持续压低整城伴奏。
