# 快速开始

使用Godot4.7.2打开project.godot后按F5，或运行根目录三个启动器。启动Demo为隔离新城，继续我的河湾读取个人继续档，打开创作样例为隔离示范。

正常新城从free空地开始，可选择普通风貌和核心画具。经典旧作品保持原规则；F1中显式转换先备份，不伪造库存、手札或历史成就。

| 操作 | 作用 |
| --- | --- |
| 下方五键画具 | 筑屋、修路、烟火用途、林水、地形；点建筑打开上下文微调 |
| Q / E | 建筑每次转90度；自由角使用既有上下文控件 |
| 右键 / Esc | 取消当前候选或笔画；修路可锁段 |
| Tab | 修路直线/曲线切换 |
| 鼠标滚轮 | 默认缩放；上下文编辑按控件提示处理 |
| Ctrl+Z / Ctrl+Y | 撤销/重做建设 |
| Ctrl+S / Ctrl+O | 保存当前作品 / 打开作品收藏 |
| J / L / F1 | 手札 / 当前城市账本 / 操作手册 |
| V / B | 漫步切换 / 附近道路长椅或有效阳台静听；Esc退出恢复镜头 |

个人存档和作品在Godot user://目录。验证带--isolated-session并禁用persistence，不覆盖个人作品。

当前已实现能力与待办见[PROJECT](../PROJECT.md)。功能区自动用途、新L城市总谱、预设母曲多档编配仍按[54整合规格](54_V7_最终施工改造总案.md)施工，不能把未来设计当作当前操作条件。
