## 云端接续

克隆完整库、安装Godot4.7.2，先重建导入缓存：

```text
godot --headless --editor --path . --import
godot --headless --audio-driver Dummy --path . --script tests/test_city_creation_legacy_roundtrip.gd -- --isolated-session
```

跨平台施工检查入口（Python 3.10+、Git、Godot4.7.2，无额外Python包）：

```text
python tools/check_creation_cloud.py --godot godot
```

接续几何验证时加`--geometry`，会在上述八步后运行屋谷69项、屋面非上升檐口路径32项、坡地路口27项、桥面9项、桁架桥6项、相邻异风貌桥72项及桥岸55项CPU回归，共15步。2026-10-29已在Linux/Godot4.7.2实际运行；报告仍区分CPU、图形与录音范围。

无桌面/音频设备的Linux可安装Godot4.7.2、Xvfb、xauth和PulseAudio后，用同一个进程环境启动隔离实窗验证：

```text
python tools/run_creation_linux_live.py --godot godot --script tools/check_creation_roof_slope_live.gd --out-dir 验证记录/linux_roof_slope
python tools/run_creation_linux_live.py --godot godot --script tools/check_creation_roof_valleys_live.gd --out-dir 验证记录/linux_roof_valleys --timeout 600
python tools/run_creation_linux_live.py --godot godot --script tools/check_creation_bridge_banks_live.gd --out-dir 验证记录/linux_bridge_bank --timeout 1200 -- --verify-banks --case=diagonal
```

输出目录必须为空，失败取样也保留。包装器建立带私有授权的Xvfb和仅监听回环的PulseAudio虚拟输出，等待服务就绪后运行探针；GDScript运行错误及时中止；超时或引擎错误返回非零，音频回落Dummy不能算成功，退出清理两个服务。自定义安装可给`--xvfb`、`--xauth`、`--pulse`及`--pulse-module-dir`，依赖库按该安装的环境配置；工具不安装软件或写机器配置。探针额外参数放在末尾`--`之后；隔离会话和本轮输出目录由包装器统一追加。

这条路径使用Mesa软件OpenGL和虚拟音频。能回读实际渲染像素与实时混音PCM，不代表物理设备输出、硬件GPU性能或主观听评。`linux_live_report.json`保存命令、引擎版本、耗时、回退/错误与验收范围；具体原图/PCM仍由原探针生成。

引擎不在PATH时给--godot完整路径，或设置GODOT_BIN。该入口记录引擎版本、Harness/链接/资源与来源审计、首次导入、隔离旧档及屋面UV回归，任一步失败返回非零，日志和report.json写入本地验证记录。Linux/Windows共用此命令，不依赖D盘、WASAPI或本机缓存；CPU检查不替代GPU实窗与实际录音，云端有显示/音频设备后按工程维护补验。历史Windows干净树记录不代表Linux实测；2026-10-29的Linux实测范围见本段与[本轮记录](52_画面连续性修补与证据.md)。
