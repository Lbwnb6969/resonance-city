## 发布步骤

先提交本地改动，然后：

```text
python tools/sync_github_all.py prepare
python tools/sync_github_all.py push
```

两条命令之间审阅验证记录/GitHub完整库同步/plan.json和omitted.json、验证记录/GitHub完整同步/plan.json。核对删除旧路径、保留输入、字节及远端父提交。完整库独立索引，不污染精简工作树；普通快进、不强推，保留历史备份。push后重新获取远端并核对Git树，证明在verification.json。

## 云端接续

克隆完整库、安装Godot4.7.2，先重建导入缓存：

```text
godot --headless --editor --path . --import
godot --headless --audio-driver Dummy --path . --script tests/test_city_creation_legacy_roundtrip.gd -- --isolated-session
```

跨平台施工检查入口（Python 3.10+、Git、Godot4.7.2，无额外Python包）：

```text
python tools/check_creation_cloud.py --godot godot
```

引擎不在PATH时给--godot完整路径，或设置GODOT_BIN。该入口记录引擎版本、Harness/链接/资源与来源审计、首次导入、隔离旧档及屋面UV回归，任一步失败返回非零，日志和report.json写入本地验证记录。Linux/Windows共用此命令，不依赖D盘、WASAPI或本机缓存；CPU检查不替代GPU实窗与实际录音，云端有显示/音频设备后按工程维护补验。当前本机无Linux运行环境，Windows干净树通过不能表述为Linux实测。

读取根AI_START_HERE、PROJECT、AGENTS和backlog，按[工程维护](工程维护.md)接续。正常启动直接使用轻量音库；合成器变更后依次重烘PCM与轻量库。缺少外部分析数据时查省略清单，不能误认为运行依赖缺失。

完整库克隆首次双库发布前配置ai-sync为上述精简库URL。工具从完整库清单恢复精选范围，保留源HEAD/工作索引；历史和剩余任务不因发布切换重置。
