# 美术与性能

## 1. 目标风格

以 Tiny Glade 的“暖、软、会自己补细节”作为生成和交互参考，以纪念碑谷的“简化几何、清楚轮廓、像模型盒子一样的构图”作为画面约束。最终不是复制任一游戏，而是形成自己的古典童话城市：奶油石材、低饱和蓝绿、少量珊瑚色点缀、圆角屋顶、厚檐口、干净的阴影和可读的留白。

## 2. 资产原则

- 先做 8–12 个可重组的墙、屋顶、门、柱、路缘、树和公共设施模块；每个模块有明确轮廓和 2–3 个材质变体。
- 使用低多边形、手绘渐变、顶点色和烘焙环境遮蔽；默认关闭昂贵的实时光追。
- 屋顶、道路和植被优先使用实例化网格、共享材质和分层 LOD；近景才显示瓦片、藤蔓和窗内光。
- 镜头采用轻微等距/倾斜 2.5D 构图，允许旋转但限制极端角度，保证道路和房屋入口始终可读。
- 色彩与轮廓必须在灰度截图中仍能区分：道路、房屋、公共建筑、功能区、植被至少有明度或形状差异。

## 3. 性能预算（第一版目标）

| 项目 | 目标 |
|---|---:|
| 目标帧率 | 60 FPS，生成时允许短暂降帧但不阻塞输入 |
| 单帧生成预算 | 主线程 ≤2 ms；复杂网格放入后台任务并分片提交 |
| 近景详细实例 | ≤300 个；远景用合批/简化层 |
| 可见植被实例 | ≤2,000 个，按簇实例化 |
| 同时活跃音乐声部 | ≤32 个，事件音效共享池 |
| 房屋局部逻辑格 | 单房屋最多 12×12；超出分片 |
| 存档 | 只存玩家意图、稳定 ID、种子和必要几何；不存渲染缓存 |

这些是首个垂直切片的测量起点，不是永远不能调整的教条。任何提高上限的改动必须附带同场景帧时间、内存和生成延迟对比。

## 4. 视觉验收

用同一镜头做“无装饰、基础装饰、完整装饰”三张对照图：轮廓、连接、入口、留白和视觉焦点都能一眼读出；远景不闪烁，近景不穿模，生成前后光照方向一致。风格问题优先修轮廓、比例、材质和色彩，不用增加更多小物件掩盖问题。
