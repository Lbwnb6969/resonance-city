# 版本整合说明

本版以整个对话中的最新需求为准，综合首次修改前的 31 份原稿。需求发生冲突时直接修正所属正文/spec；开发不需要先读日期裁定再猜哪一版有效。

| 旧内容 | 保留与更新 |
|---|---|
| 连续空间、路网、地形、庭院与公共留白 | 保留；社区房屋新增局部墙格，其余城市连续无格 |
| 自动成长、播种/章程驱动城市演化 | 改为点击扩房与手绘城市意图；系统补连接/细节，停手不新增建筑 |
| 五时代、渐进传播、历史街区、27地标 | 完整回收；首版换代约80秒、局部音色先行、最后提示；新版地标提供工具能力 |
| 14功能区、7命名形态、深流/织机/暖庭 | 全部回收为形态/用途/声音词汇，不设音乐达标门槛 |
| 三层声音、主题、轮唱/应答/卡农、全城演出 | 保留为可选正反馈；视野内优先、远端偶发、特殊全城参与 |
| Sound/AudioPlan、可听帧、稳定来源、签名、响度与预算 | 保留技术价值；建设与自然时间不等待设备乐句 |
| 公共留地、多组件/孔洞、部分兑现、搬迁/改用 | 回收真实几何、来源与面积合同；取消旧额度/不可撤销规则 |
| 作者容器、WorldDelta/快照、作品/DNA、种子 | 回收字段和旧档迁移；新增局部拓扑、撤销和音乐意图 |
| 轻交通、换乘、用途配额、章程/卡牌 | 保留已有对象/来源；章程/卡牌可选，不驱动自动建房，不扩展经济前置 |
| 资产源、古典四向、石街/夜光/联合屋顶 | 保留制作链，重新按 Tiny Glade/纪念碑谷收敛画面，不把旧图当最终签核 |
| 400–600阶段、3,000–5,000后期、120FPS目标 | 保留；先达到真实完整切片60FPS，再推进后期120FPS |
| 日常/手选种子、作品收藏、图鉴、来信、导出 | 回收为可选作品价值，不加每日压力/债务 |
| R/V冻结、修复跨越、叛离/债务、七章/崩盘、音乐次数额度 | 从默认玩法退出；原文及旧夹具完整保留供版本追溯 |
| 固定四元素HUD、固定三色相、每栋动效数、12×12/32声部等 | 取消无必要的产品限制；几何/艺术/性能参数按同场景原型确认 |

首次原稿和本次修改前文档逐字节保留在 [全量来源归档](../废弃/文档/2026-10-14_全量复核/README.md)。完整独立备份是 `备份/文档全量复核前_20261014_104427/`，Git 备份分支是 `codex/backup-audit-20261014_104427`。更早整理前的目录也原样保留，没有删除重要设计、模型或证据。

现行 [开发接口](20_开发接口与迁移.md) 收拢有效技术合同，[覆盖记录](需求与旧稿覆盖.md) 对应每项用户要求和每份旧文件；哈希/标题清单保存原稿的来源信息。旧参数移到 `数据/兼容规格/`，生成器同步改读取路径；运行值与旧 spec_values 保持原样。游戏代码/资产行为没有被本次文档修改实现，差距仍在 PROJECT/P0–P2 记录。

旧音频校准/拍频与存档夹具是已有实现的回归工具，按变更风险复用；自动成长/冻结/额度等旧期望不能拿来验收新默认玩法。声音生成、风格与后期目标需要实际原型/真人验证，不能以完整文档或历史 PASS 宣称完成。
