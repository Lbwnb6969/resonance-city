本版按 2026-10-14 最新授权综合旧设计与新信息：新需求与旧条款冲突时，直接更新正文和执行规格，不要求开发者另读日期裁定解决矛盾。

## 详细资料没有丢失

综合优化前的整个目录及 PROJECT 按原名保留在 [完整原稿](../废弃/文档/2026-10-14_综合优化前/README.md)。旧版和此前精简版也仍在 `废弃/文档/`。独立备份另存于 `备份/文档综合优化前_20261014_101721/`，含哈希清单。

执行规格保留当前程序需要的数值表，标成兼容参数；完整声学公式、详细地标目录、每个旧规格 ID、测试命令和资料版本可从原稿读取。旧原稿描述当时实现，不能据其重新引入已取消的玩法限制。

开发迁移时先找同名旧 spec 的对象/字段、合约 ID 与既有测试，再按新 spec 的行为更新。存档与音频相位/来源等完整性测试继续复用；自动生长、音程冻结、债务与修复进度的旧期望需改写，不能为通过旧测试恢复旧设计。

代码与资源没有随文档迁移而改变。工具只更新合并阅读入口；参数生成校验要求运行数据除来源哈希外保持一致。需要重新实现的方向在 PROJECT/P0/P1/P2 中列明。
