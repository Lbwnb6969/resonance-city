# 共鸣之城 · 模块设计与文档导航

玩家画下房屋、路和水岸，建筑从空间关系长成街区，音乐随城市变化。营造、观看、聆听是同一座城的三种玩法。

## 模块设计

按**这次要改变的行为**选一行。先读主文档里对应的小节，再顺着源码核实实现。第三列给出扩读条件；同一个物件可以涉及不同任务，例如池塘的颜色归美术，改变水域边界或桥头净空则归地形。

## 施工记录的使用

施工记录保留在文档中，按专题查证，不作为每轮必读或并行进度。52/53保留短摘要与章节定位，完整历史原文在各自链接的来源TXT中；原始日志、截图和PCM仍在验证记录。新增记录只写变更、命令/结果/耗时、证据路径及未覆盖范围，PROJECT只留当前首步、能力边界与链接，不再复制逐轮计数。
