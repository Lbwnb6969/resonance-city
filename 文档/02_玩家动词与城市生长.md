# 玩家动词与城市生长

## 1. 主循环

**观察 → 画出意图 → 预览 → 确认 → 局部生长 → 看到和听到反馈 → 撤销或继续。**

城市不会因为时间流逝自动扩张。所谓“长”是玩家一次确认后的可观赏生成过程：墙面、露台、道路边缘、植被和灯光分几步出现，但生成不替玩家做下一次决定。

## 2. 玩家动词

| 动词 | 输入结果 | 可撤销范围 |
|---|---|---|
| 点房子 | 进入局部房屋格子焦点 | 当前房屋的本次扩展 |
| 拉路 | 连续曲线预览，自动接入口 | 这条路及其装饰 |
| 画区域 | 功能区权重预览 | 该区域的生成权重和风格 |
| 放特殊建筑 | 占地、朝向、入口预览 | 建筑及连接件 |
| 撒植被 | 密度和避让预览 | 这次散布的实例 |
| 连声音 | 将两个或多个区域加入同一音乐网络 | 声音连接，不改几何 |
| 试听 | 临时播放预览合奏 | 不写入城市、不消耗随机种子 |

## 3. 社区规则

“社区”是房屋的内容和风格容器，不是行政模拟单位。玩家点选社区房子后，局部房屋生成器可以长出墙、屋顶、露台和内庭；社区不会自己在空地上增殖。系统只在玩家已确认的房屋边界内补细节，不偷偷增加一整片房子。

玩家可以给社区指定一种建筑气质（紧凑、临水、庭院、坡地等）和一种区域音乐风格。风格改变颜色、装饰权重和配器，不改变已经确认的建筑身份。

## 4. 提交与撤销

预览层必须与正式层分开：预览可以显示半透明建筑、道路连接线、区域影响和声音波纹，但不能写存档、正式随机流或世界状态。确认时生成一个带稳定 ID 的操作记录；撤销按操作记录回滚，失败的后台生成不留下半成品。

大操作采用短暂的“生成演出”（约 0.3–1.2 秒，按复杂度分段），期间允许取消；取消回到操作前快照。生成结束后才播放完整的正反馈音效和区域主题变化。
