## 1. 纪念碑谷式精致感：能落实，但第一条是光（v3-U21 修订）

**结论不变：能，而且 2D 固定视角路线比 3D 更接近那种观感。** 但要补上原稿漏掉的第一条。纪念碑谷的精致感来自四件事：

1. **明暗结构清楚，色相柔和。** 每个体块的顶面、受光面、背光面一眼可分；柔和来自色相与过渡，不来自取消明暗。现行 Demo 色相已经柔和，但明暗被压平，所以看起来"灰、薄"而不是"柔"。
2. **元素少，每个都打磨到位。**
3. **所有运动服从缓动纪律。**
4. **色彩纪律**：每屏一主色族、辅色同类、点缀色只一个（美学规格 §1）。

### v3-U21 · 风格帧制度（修订版）【待裁定】

1. 主参照纪念碑谷（光、色、几何）；Townscaper 只看房群如何连成片，Dorfromantik 只看温度。不从三作混提色板。
2. 起点用已有的"梦岸·小景01"（风格小景，7 种资产 8 处摆放），不另起炉灶。
3. 对这一帧反复迭代：先光影（v4-LIT-01，一个太阳、三明度面、投影与接触阴影），再色板、缩放基准、纸感噪点。
4. 通过条件：壁纸测试 + 灰度测试 + 眯眼测试（v4 §4.5），由用户审美裁定。
5. 冻结为视觉基准帧。此后**新**资产须过"与基准帧同框测试"；P0 已有的三格人工记录照旧保留，不追溯作废。

**资产来源统一规则**：Kenney CC0 负责现代（时代Ⅴ）；原创参数化 SVG 负责历史时代（古典四件已验证可行，生成器可直接按光向算面色与影子）；已授权 2.5D 素材按需补充，但必须能重新服从"一个太阳"，做不到就不用。"敢扔"原则保留：凡是与基准帧不同框的，宁可不用。

精致预算 80/20 保留：打磨时间花在光影、缓动、对齐、色彩上，而不是资产数量上。

## 3. 音乐史 = 城市史（原 v3-U23，已由 v4 取代）

原稿最好的洞见保留并写进 v4：**调式（每局）× 编曲语法（随时代）× 音源组（音色家族）三层分离**，以及"风格即 build"的祝福（时间胶囊、未来碎片、熔炉，见 v4-ERA-10）。

修正后的结论：

- 五个时代：古典 / 中世纪 / 文艺复兴 / 工业 / 现代，一局七乐章，跨越由完满终止赢得（v4-ERA-01/02）。
- 时代只增加可能，不没收可能；旧时代的声音通过遗产地标留在城里（v4-ERA-06）。
- 渐强来自织体密度、亮度与律动，不来自响度；终章欣快而不刺耳；锯齿音色只给工业（v4-ERA-08）。
- 可用音级随时代从五声走向十二音，新的张力由历史供给（v4-ERA-04/05）。

## 5. 玩家掌控感（v3-U25 系列，本稿最重要的一章）

### 5.1 原则（保留）

**掌控感 ≠ 放置权。掌控感 = 玩家随时能感到"我的手正在改变可感知的结果"。** 直接摆建筑给的是"权力感"，我们要给的是"在场感 + 定向感"，两者叠加同样满足，并且保住"系统生成城市"的灵魂。

### 5.2 已有的掌控（更新盘点）

已批准并已实现：释放共鸣点、划定引力、三次成路的踩路径、调音、迁移、3 秒同源试听、单 Solo/Mute、条件与缺口查看、失谐边界诊断、整栋聚焦镜头。这已经比原稿写作时多了一倍。

### 5.3 新增动词（修订）

| 提案 | 修订后内容 | 状态 |
|---|---|---|
| v3-U25a 意志区 | 改为时代Ⅲ宫殿解锁的"规划"：每乐章 1 次涂 ≤5×5 区域，住宅/商业/留白偏向；仍须过协和、连通、避碴；**永不生成工业** | 并入 v4-LMK-06 |
| v3-U25b 指挥台 | 改为纯监听台：各街区音量/声像只影响你听到的，不改城市、不限次数；诊断用的 Solo/Mute 规则不变 | 待裁定 |
| v3-U25c 否决与重摇 | 否决删去（不提交即否决）；重摇改为时代Ⅱ市政厅解锁，每乐章 2 次 | 并入 v4-LMK-06 |
| v3-U25d 地标钦定 | 由 v4 地标系统取代：地标从生长条件中觉醒，玩家用一次介入确认落成，可在最多 3 个落点中选择 | 取代 |
| v3-U25e 时间控制 | 不做倍速；暂停 = 延留（城市时钟保持、音乐退到柔和的等候小节，可试听不可落定） | 由 v4-ERA-09 取代 |
| v3-U25f 抚琴 | 保留修订版：抚过街区只触发该声部既有乐句的轻触采样，不产生新音符 | 待裁定 |

### 5.4 构筑多样性（四条轴）

1. **时代路径**：走得多快、在哪个时代停留（v4-ERA-02/11），本局抵达哪个时代。
2. **主配方**：围绕哪组和弦协同展开（原稿保留）。
3. **乐器背包**（v3-U26）：开局从已解锁音色中装备 3 个进入本局出现池（原稿保留）。
4. **地标组合**（新增）：本局落成了哪些地标，决定城市的性格——神殿 + 大教堂 + 歌剧院是"圣咏之城"，圆形剧场 + 体育场是"欢呼之城"。

局末"本局构筑卡"（v3-U27）在原稿基础上加入：抵达时代、地标列表、终止式记录。

### 5.5 掌控感时间尺度（按现行时钟重写）

| 尺度 | 玩家手上的动词 |
|---|---|
| 随时 | Solo/Mute、查看条件、镜头、试听；听觉镜头切换（若 v4-LNS-01 获批） |
| 每乐句（16 秒） | 1 次介入：释放 / 调音 / 迁移 / 引力 / 踩路 / 确认地标落成 |
| 每 64 秒 | 提案刷新（时代Ⅱ市政厅之后可重摇） |
| 每乐章（约 3.2 分钟） | 祝福三选一；政令 / 意志区 / 整片调音各 1 次（若已解锁）；终止式结算 |
| 每个时代 | 跨越仪式、新音级、时代来客、新的地标候选 |

判定标准保留并补一句："玩家任意时刻停下来问'我现在能做什么'，答案不少于 3 个；**但界面同时只突出 1 个推荐焦点**"——防止工具栏浏览吞掉注意力（反支柱 B）。
