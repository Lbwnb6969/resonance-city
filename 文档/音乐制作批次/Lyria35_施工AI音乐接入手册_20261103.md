# 给施工 AI 的音乐接入手册

目标：让城市空间缓慢改变一首完整作品的表情，保留呼吸和留白。2026-11-03最新设计：简单城以稀疏背景织体为默认，多数普通营造不突出主旋律，不开局铺满；完整作品不要求持续领唱。详见[专题B的背景优先设计](../专题B_音乐系统与音乐资产生产设计案_工程校准与曲库生产版_20261103.md)。现有core含原曲主奏，降低颜色层不能消除旋律；此类候选不自动作为简单城默认。旧尖薄合成bank退出正式默认及自动回退；下文保存/恢复旧bank是当前接口事实，正式路由仍须后续按此目标改造与验证，不据文档宣称已修好。分轨是制作材料，声部数量不作为品质。2026-11-03用户已授权整库制作及隔离接入；正式默认、听评与循环验收仍独立。

## 从设计到资产的两条施工路径

当前授权是先完成本期可玩接入、再集中用户Play Test。技术实现和隔离测试不等待逐曲签批，主观品质仍标待评；以下流程不改变这一点。

| 目的 | 读取顺序与使用范围 |
| --- | --- |
| 将已有曲目接入游戏 | active_game_music → catalog → 按source_id选manifest → bundle的layers/timeline → GameMusic.request。只使用该包声明的层，不重跑分离、不按原始乐器轨数量创建播放器。 |
| 对原曲/原始分轨重新编配 | 从[原曲目录](../../数据/音乐制作/音乐库目录_20261103.json)按source_id取source；从active_curation指向的curation.songs按source_sha256取同一作品的full_mix及groups[所选方案].kept。只取一个同源分离方案，读取groups[所选方案].safe_mix_gain等约束；不把coarse_six和woodwind_plus_remaining_six当独立可全叠声部。 |
| 新编配成为游戏包 | 原曲和现用包不覆盖，另建版本，验证共同起点/帧数/增益和音频预算，再按现有打包接口生成catalog、bundle与timeline，进入独立可玩测试入口。新版本技术通过不自动获得listening_approved。 |

原曲source_id、curation的source_sha256和bundle的source_id必须相同；曲名仅用于显示，不作为关联键。原始分轨用于制作，core/body/motion/detail用于运行，二者不是一一乐器映射。groups[所选方案].excluded是原始近空候选，不是运行层，也不因本次整理重选入池。

清理后旧制作目录中的delivery/report保留历史路径，当前读取以active_curation和当前bundle为准。42首旧stage WAV已归档，原曲与正式交付音频保留。不要因历史stage缺失判定当前曲库损坏；重做分离用新版本输出目录或按本地归档映射恢复，不能凭旧report原地续跑。

专题B的flow/craft方案先对照本页真实接口，再实现几何消费者与包络；专题D只展示实际包/层状态，不另建一份曲库。跨曲交接、循环和短音切片按本期设计开发独立版本并技术验证，待用户整体Play Test确认听感；不要把当前不支持的操作当成已存在API，也不要把待听评当作停止实现的理由。

## 音乐怎样保持完整

| 声部 | 制作依据与用途 | 约束 |
| --- | --- | --- |
| core | 原混音减去三条有限染色层；保留完整音乐骨架与前景主题 | 始终1，不能把它当只剩低音的foundation或另加第二领唱 |
| body | 从实际连续度、低频比例、峰均比选的支撑颜色 | 围合暖度候选，不认定某个真实乐器 |
| motion | 实测能量起伏/起音特征的流动颜色 | 流动/内陆摇曳候选，不伪造固定鼓拍 |
| detail | 实测稀疏度与亮度的点缀颜色 | 手作呼应候选，不将Other自动当lead |

三条颜色来自同一首、同一分离方案；按数值回加残差选方案，未将低残差当成更好听。先抗混叠降采样，再测色彩描述。每条只缩小原始比例，绝不单轨拉响补响；三个颜色的任意下降组合，其逐样本绝对值上界RMS不超过原曲18%。所有层全开与原混音的差只到PCM16量化误差；任意允许推子组合的绝对和峰值上界≤0.8202。

这些界限证明数值与同步，不证明听感。串音、相位残影、分离毛刺、某个乐句是否更好听，仍须在工坊逐曲对照。core并非已分离的纯伴奏；不要删掉它后宣称音乐仍完整。

## 实际 Godot 接口

[容器读取器](../../scripts/audio/city_creation_game_music_bundle.gd)校验SHA、44.1kHz/双声道/PCM16/共帧数/允许增益，损坏颜色层回退完整混音。容器独立于旧M80/schema1、内部v2/v3和24秒网格。

[播放器](../../scripts/audio/city_creation_game_music_player.gd)后台准备文件，期间旧音乐继续；准备完成后复核城市与相关音乐设置，再借用现有foundation播放器，以AudioStreamSynchronized播放最多4条同源流。每次只后台准备一包，不一次加载全部曲包。原12长轨/4短槽/6总线/2自然声池不扩充；派生流也计入真实音频预算。

```gdscript
const GameMusic = preload("res://scripts/audio/city_creation_game_music_player.gd")
# manifest_path来自施工包目录中的manifest字段，先核目录签名。
var ticket = GameMusic.request(demo.music, manifest_path)
if ticket.ok:
    var conductor: Node = ticket.node
    # 可以在后台准备期间先暂停；实际开播仍停在0。
    conductor.set_paused(true)
    while is_instance_valid(conductor) and not conductor.active:
        await demo.get_tree().process_frame
    if not is_instance_valid(conductor):
        return # 失败、取消或换城，旧音乐保持
    # 只有已经由真实空间消费者派生的0—1值才能用于正式空间映射。
    # 工坊/隔离测试可手动试配，不记录成城市事实。
    conductor.set_expression(flow_weight, craft_weight)
    if conductor.seek(50.0): # active后调用；全体同步，不是乐句切点确认
        conductor.set_paused(false)
    # conductor.stop() 释放借用并恢复接管时保存的旧音乐状态。
```

目前warm自动读取既有MusicAffinity的真实围合/焦点/缩放，观察6秒后慢入、来源消失最长6秒退回开放基线，暂停冻结观察和所有包络。flow/craft默认自动读取真实水距、内陆曲路与匠造前庭几何；`set_expression`仅供显式手动对照，并在该播放器会话保持手动模式。高差/茶叙等剩余表达未接。几何来源复用[水域距离](../../scripts/world/city_creation_water_distance.gd)、[水岸契约](../../scripts/world/city_creation_waterfront_contract.gd)和64中的来源去重规则，不按房屋数量、用途标签、XP或经营门槛假造资格。1表示该颜色回到原混音比例，不是添加新旋律。

使用空间来源的稳定source_ids、删除/Undo和revision重新采样；几何无关的编辑不重烘音乐。单屋、无水、无路仍有完整core，不把音乐做成必须凑齐的任务。镜头掠过不立刻换歌，不让每栋新房都抢前景；先稳定表达，再在实际乐句/留白里调整较大的变化。抒情展开优先保持原作呈现，减少流动与点缀竞争，不叠另一首主旋律。

新旧Lyria试听互斥；留声机先释放试听所有权，再采集要恢复的旧bank，结束不能复活失去控制节点的adaptive流。接其他音频拥有者时也先显式释放旧拥有者，再保存恢复状态，不能仅覆盖AudioStreamPlayer.stream。

## 时间线、循环、短音和自然声

每包timeline.json包含实际时长、每秒RMS、最多6个相距至少12秒的能量变化候选，以及源SHA匹配的librosa/Essentia节拍CSV。能量边界不是主副歌，两个引擎的BPM不是人工确认的节拍图。新曲不强制80BPM、D大调或24秒，禁止按固定秒数硬切。

当前允许：同源颜色增益、同步暂停/跳转、固定共同音量、同位置原混音对照及坏层回退；短音按当前候选可信音集落音，未标定或未明时改物理木质触感；隔离候选入口另支持完整曲终后3秒自然声续播（fixed重复本曲）。当前不允许自动：跨曲叠加、移调、独立拉伸某层、切片、拼乐句、无缝循环。可先依据实测段落/和声/余韵制作隔离loop/edit候选版本及新签名并技术验证，主观听评集中到用户Play Test；正式采用需另记确认，所有层同起点同切点共同处理，保留原始全长。切换不同作品的乐句时机与过渡还须独立验证，现有API不承诺跨曲无缝。

2份自然声意图可供2自然声池后续选材，但先确定合适循环和响度；2份孤立采样意图须测实际音高、起音和释放切点，再转入既有4短槽。背景播放器会拒绝这4份的自动背景接入，61份均可在工坊听原源，不能把99秒采样会话当成一个短音。

原始模型候选仍可用于更深配器探索，但必须按完整上下文听评。需要纯lead/纯bed时重新制作/合并声部，不把统计角色名当作纯净分离的证据。新算法或重分离另建版本，不覆盖原件。
