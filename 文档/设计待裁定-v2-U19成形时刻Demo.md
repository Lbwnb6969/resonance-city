# v2-U19：成形时刻 Demo 提案

状态：候选，尚未批准。来源为设计增补v2 §6.1–6.3与城市生长交接U19；不混同v3时代或稀有机制。本页是具体审阅方案，获批后才吸收入执行规格。

## 建议本轮范围

1. 城市在本局首次实际形成群、央或腔时，各显示一次4秒的“成形时刻”小卡片；只在可听事件完成现有一拍揭示后出现，不在音频预填时提前展示。普通出生不弹卡，同一阶段后续建筑不反复打断。
2. 卡片只引用真实街区类型、位置、形成阶段与乐句。示例：“第5乐句 · 住宅（7,8）形成群”。不编造城市名、市民评价或未发生事件，不将同期R变化全部归因给该房屋。
3. 保持城市与声音继续运行，卡片不遮地图操作，不改变混音增益、R/V、时钟、pending或自动扩张。该方案是成长反馈片段，不把它当完整乐章卡帧/稀有命名演出或稀薄织体实现。
4. 玩家点击卡片可使用已授权的选中聚焦查看真实建筑；点击关闭立即收起。提供“成形提示”开关，默认ON。关闭不补播旧通知；同一乐句多阶段按群→央→腔依次展示，每阶段仍只一次，取消/黑屏期间不排队补打断。
5. B黑屏时全部隐藏，不强制退出黑屏。重新开始清空本局首次记录；未来快照试听不触发真实卡片。提示完全由当前可听城市的实际growth_events驱动，不另算形态条件。
6. 先做可运行小卡片，验证首次触发/一拍后/跳过/关闭/黑屏/多事件与状态不变。完整乐章结束、8秒定格、声音稀薄、City DNA短回放和分享导出仍需后续独立方案。

## 为什么需要裁定

v2 §6.1明确把长度标为“待裁定U19”，城市生长交接也把时长、可跳过性和字幕来源列为未决。用户授权的方便镜头可继续独立实施，但不能由此推定自动演出获批。用户提供的AGENTS.md要求：“不可逆操作或关键需求不明确时，先请求确认。”

本提案给出默认开关、次数、时长、音频/时钟语义和字幕依据，供一次具体裁定；它不要求重做真人或压力检查。
