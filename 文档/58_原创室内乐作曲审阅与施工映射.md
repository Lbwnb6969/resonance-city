## 4. 首曲候选的具体使用方法

候选共388事件：Foundation72、Pulse106、Answer72、Lead138。每个事件仅记录`[beat, beats, midi]`，beat是段内0起点，`start=beat*.75`秒；`section`取P0—P5，C4=MIDI60。默认D大调，不推断其他调式的音符。gain、最终音色/演奏法、tier/color与运行签名未定，不伪造缺失字段。

| 段落/全曲小节 | 候选保留与发展 | 必须复核 |
| --- | --- | --- |
| P0 / 1—8 | D5—E5—F#5呼唤、Bar2附点回落；低音10/拨弦19/回答12/主奏26事件 | 这是一套四role草案，不自动定义为Simple；简编也需完整主题。Answer入口前的谱面休止不等于DSP/混响无掩蔽 |
| P1 / 9—16 | 主奏重心上移，弱拍起句与低音第二落点；15/19/12/28事件 | 检查切分与旧弱拍的实际区别；增音量不能替代展开 |
| P2 / 17—24 | 减少低音与拨弦，延长主奏、留环境声；8/9/12/15事件 | 表格仍有四role与12个Answer事件，不能宣称已完成二重奏或Mute分支；段落密度由实际音乐决定 |
| P3 / 25—32 | 低音每小节两落点、拨弦三音型推进；16/24/12/27事件 | 两落点以根五度为主，不等同已写出连续Walking Bass；走句需另作明确音高设计 |
| P4 / 33—40 | 向Bar37 D6高点集中，低音更长、后半回落；15/22/12/25事件 | 不能把这套全谱直接叫Virtuoso；Simple也有P4，真实华彩及支撑避让另写 |
| P5 / 41—48 | 回首主题后减密度，D5长句收束；8/13/12/17事件 | 31.75拍后余0.25拍；P5→P0从接缝两侧实际录音，不凭同和弦同频判断连续 |

表格有31个相对当前小节和弦构成音的非和弦音事件；它们不自动算错，也不自动算“优美延伸”。逐处检查经过/邻音的节奏地位、解决及伴奏遮蔽，保留音乐判断。四role组合可以复音，唯一layer3主奏与播放器池预算不变。

## 5. 施工AI接入顺序与待补材料

1. 当前首步仍按[PROJECT](../PROJECT.md)：完成在建连续播放、六段144秒与P5→P0、跨段短声、退出/独奏/换城。先用旧受测谱建立技术基线，不把本次作曲改写捆进播放故障定位。
2. 连续基线通过后，复制候选为独立新内容版本，保留原master2/旧池作A/B。先固定母曲、mode0、Lead和空间，明确选择基础可听编配、gain及音色；用相同输出响度比较主题、呼吸、P2减法、P3推进、P4高点与长听疲劳。原稿“可直接替换”不进入施工指令。
3. 按54接专用内部v3校验与选择接口，独立定义Pizz/Warm、Sparse/Sway/Flowing三color、Mute/Echo/Canon、Simple/Lyrical/Virtuoso。给出各段分支覆盖和允许静默；保留缺省v2读取与M80外部schema1。总事件388分属六段，不代表8小节M80越过256限制，也不证明所有多档合法。
4. 一次只改一处真实空间做同曲A/B：固定Lead，合法水岸改变Pulse，真实百工改变Answer，再围合/跨岸/礼乐。按54记录来源、资格、目标、准备、实际进入与撤回；原稿没有这部分实例，不能据六曲定位表自动生成空间阈值或新增成长门槛。
5. 分支接通后分别写十调式与乐器整句音域，检查重排后主题轮廓、非和弦音解决、深流低音主奏及极端组合。不得把`map_pitch/Register.plan`成功当作完成十调式作曲；新音色先接通再做等响度听评，更新DSP/内容缓存签名。
6. 首曲闭环通过后补后五首：每首先交独立8小节实际主题，再48小节和声/句法路线、多档与空间实例。新和声Em7/F#m7/属持续音需一份权威时间线联动长轨/短声/实际游标，不能只改某条PCM；新ID注册随可用内容一起验收。

**继续委托所需清单：** 首曲各档完整分谱及三color；十调式改写；同曲跨区完整8小节实例；一份真正完整的M80示例及真实哈希来源；其余五曲主题和全曲路线；接缝/混音试听记录。可直接用已收到的完整表格补齐新候选，无需等截断JSON才能继续；补写内容必须注明作者与修订，不冒充原稿已交付。
