## 3. 直接营造：先确定输入与事务，再画控件

Tool0采用“首击选屋、同屋表面继续加建、点另一屋切换”的目标。未选中屋面拖动可直接进入扩建；原稿6px仅为拖动起点候选，需适配缩放与窗口。按下时只暂存意图，越过阈值才进入笔画，释放后才判定单击；同一事件不得既选屋又重复提交房间。

| 输入阶段 | 处理约定 |
| --- | --- |
| UI、文本、弹窗、拾色、旋转、修路已有捕获 | 由现有输入所有权先处理，画布不得穿透；按键帮助与实际路由同时更新 |
| 命中另一屋/同屋表面 | 另一屋切选；同屋沿真实局部法线与现有候选合法性预览。不把屏幕拖动方向直接当世界格轴 |
| 连续加建/移除 | 复用现有State与笔画历史语义；一笔可整体撤销，取消不遗留部分提交，非法格不留代理实体或消费ID |
| Shift移除、Alt吸取与整屋删除 | 先盘点原有修饰键与选取；整屋删除必须为明确操作，不能把快速加建和整屋删除交给同一含糊点击 |
| Esc、右键、换工具、换城、忙状态 | 明确提交/取消边界，收回预览、鼠标捕获和后台请求；旧城异步结果不得发布到新城 |

`city_creation_house_direct_edit.gd`是原稿提议的新模块，不是现成入口。新增模块按职责拆出，demo只加短委托；不把整套输入状态机塞回主文件。选择环留出房屋操作空间，随真实包络更新；小窗碰撞、长名称与高缩放下可读即可，不固定368×42或“画布92%”为门槛。

free房屋说明只由一处读模型生成：忙/路网未就绪优先，其次真实未满足条件，再显示已连接/可查看空间。上下文操作优先复用“到门前接路/看功能区”，点击只定位与选工具，修路/整平仍由玩家明确落笔；不能一键暗改地形。历史+35%说明和legacy业务状态分支保持。

## 4. 修路与空间预演：必须和提交结果同源

门阶提示读取真实`city.house_entrances(id)`、局部朝向与高程评估；该API确实存在。6m提示半径、朝向点积.72是显示候选，不能成为新的空间资格。`Frontage.HALF_DOOR=.35`是现有几何参数，不等于任意门前都能接通。

原位升级复用`city_creation_road_upgrade.gd`：双向覆盖、端点及误差约束共同判断，不能只用“重合90%”；交叉笔画不能误升级。穿堂、桥梯、保护地形和门阶都读真实预览结果。道路ID及Undo按现有事务保持。

四类空间为庭院/街巷、水岸、百工、礼乐；庭院/窄巷是第一类内的两种几何，不能一边称“四类”一边另建五种顶层资格。仅展示本次编辑相对发布前真实变化的轮廓、阶段与原因，保留原有微景预演。

`city_creation_chemistry_worker.gd`已有分离副本与160ms级悬停设计可复用；主线程仍承担快照捕获、发布和绘制，不能宣称“线程化即零阻塞”。扩展副本须覆盖实际资格需要的身份/修订与路网数据，不能直接信任未准备的网络或共享可变缓存。道路重描在副本中也要执行真实升级语义，不能一律追加`preview_road`后宣布预演一致。

预览不得写正式State、Undo、历史权益、存档、迁移文件；可在独立副本计算。结果带城市身份、revision与候选键，过期丢弃。路网未就绪时显示“预计形成/连接待核对”，提交并发布后才确认成区；不能在hover承诺正式权益。160ms是防抖起点，不是计算完成时限。

## 5. 声音归因：计划、准备、安装、实际播放分开

沿用现有谱线与L页，用简短解释回答“改了哪里、何时听见、哪里在贡献”。原稿`plan.waiting`不是现成通用字段；`entry.at`是入口几何坐标，不能在任意zone对象上取；`eligibility.reason`确有空间诊断用途，不能当音频已播放凭据。现有全局`audible`也不能证明某个新来源声部已响。

| 真状态 | 可显示内容与边界 |
| --- | --- |
| 几何/路网重建中 | “街巷正在更新”，保留旧的真实播放信息；不把未发布空间计入新声部 |
| 空间已发布、分支未准备 | 显示真实空间来源和“声音准备中”；目标声部只列候选，不承诺下一小节 |
| 分支已准备、等待安全入口 | 从实际播放器/编配决策解释等待；有可靠入口时才显示下一拍/小节/段落，撤回或改城清除旧提示 |
| 已安装/播放到目标事件 | 用实际内容版本、role/layer、来源ID与播放游标映射确认；休止或无事件时不能把“已安装”写成“正在响” |
| 静音/安静模式/无合法来源/候选撤回 | 区分主动安静、尚无来源与准备失败；空间存在不强迫音乐加层，不将安静模式等同系统静音 |

L页分当前实际与目标/等待即可，来源定位按稳定ID解析并处理源已删；原用途调试可折叠，但原人工意图与历史权益不能删字段。原稿“3秒下一小节/150ms预混/竖琴流水或钢片琴必定加入”只在对应内容与播放器确实支持时成立，不提升为全局契约；stage与tier不是一对一映射。音乐数据适配优先接58的单首闭环，不先铺满新HUD。

## 6. 静听、收藏与切城

B保留鼠标明确目标优先；无命中时可尝试镜头关注范围内的合法空座，但不得穿墙、抢占或跨城复用座位。无座只说明原因或提供显式低角欣赏操作，不自动把玩家切进陌生漫步模式。Tab换座与新增静听条属于候选，先核输入冲突。退出恢复镜头/工具/选择；删椅、换城、占用变化按现有生命周期处理。

| 作品体验 | 校正后的施工约定 |
| --- | --- |
| 当前城与继续档 | 区分未保存/写入中/已成功/失败；只在真实写入回执后提示完成，不因State改变便写“已实时同步” |
| 收藏与自动备份 | 优先按真实`reason`分组manual/before_open，未知旧值仍可找到；不删除原备份。四页签与常驻当前城大卡待UI精简评审 |
| 封面 | `_capture`截取的是当时实际视口；`_view`元数据不会把截图自动变成俯视。若要换封面镜头，须显式切镜/等待绘制/恢复，不覆盖旧原件 |
| 列表与弹窗 | `open_panel→_refresh→library.entries()`确有磁盘读取，也没有保证背景Life静止。暂停、预览与音频恢复应按真实状态处理，不写“零I/O/零等待” |
| 不可变版本 | 沿用`city_creation_collection.gd`临时写入/回读校验/JSON最后发布，保留旧版本；PNG与JSON两次rename不是跨文件原子事务 |
| 切城 | 先校验候选与当前城的有效恢复点，再发布隐藏新城；检查点失败保留当前城。候选迁移准备本身会有备份I/O，不能笼统承诺校验阶段无磁盘变化；取消/失败须释放隐藏上下文和音频预览 |
| 坏档与坏封面 | JSON/SHA失败不得替换当前城；封面有效标记实际叫`preview_valid`，不是`_preview_valid`。单独封面失败不等于城市损坏，原文件保留 |
| 回放与对比 | 留声机是既有重建/混音语义，不是精确WAV、全144秒事件相位或任意城市A/B还原；按54先保存城市/镜头/偏好，精确回放另评估 |

`city_creation_city_load.gd`现有`STAGING_SLICE_MS=65`不代表无可感知阻塞，也不作为新硬门槛；记录实际捕获、组装、发布与首次可操作等待。原稿“几帧完成/零等待/100%安全”均不作施工结论。

## 7. 两条旅程的可执行修正

空地旅程保持任意工具开局：选屋/加建/Undo，画一处可解释的连接或水岸，分别核对预览、提交后资格与实际音轨，最后收藏与重开。不要求三屋、指定摆放顺序或必须凑齐四区；未接通就显示真实原因，不用金光或水灯替代资格证明。

百工旅程可用`sawtooth_atrium`，它确在`ArtisanContract.BODIES`中，但“双格”不是该契约统一硬前置。用确定的相邻建筑/模块制造阻挡，再验证净空与入口高差；现有`PublicSpaceObstacles.collect`收集建筑包络/柱脚及地标，不把橄榄树`p9`当已实现阻挡证据。普通合规道路也能形成前庭，不必升级tram才成区；tram2.10m是道路样式值。撤销升级回窄路后资格是否撤回取决于真实几何，不能写死撤回。+35%保持56的旧正式权益，不生成新的free刷奖励闭环。

按键表必须从实际输入审计后统一：原稿新1—5槽与保留旧1—9不能同时原样成立，工具内1/2/3、Tab与全局快捷键也需优先级。R当前按鼠标增量`.008 rad/px`连续旋转，`%.1f°`只是显示，不是0.1°吸附；P与独奏按现有事件路由，不把示例“12秒”写成固定时长。文本焦点、组合键和减弱动态同时检查。
