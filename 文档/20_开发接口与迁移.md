# 开发接口与迁移 · 接上现有工程

本文收拢旧稿中仍有价值的字段、数据完整性与实现入口。标为“现有”的内容可查代码；标为“新版目标”的字段/行为尚需实现。设计规则取各 spec，当前完成范围取 [PROJECT](../PROJECT.md)，不能因为接口已写明就记成已交付。

## 1. 复用与迁移落点

| 子系统 | 当前入口 | 新版工作 |

| World、快照、差量 | `scripts/world/continuous_world.gd` 与相关 WorldSnapshot/WorldDelta | 保存局部房屋拓扑，建设提交与配乐时钟解耦 |
| 连续路网/空间规划 | `city_road_network.gd`、`city_spatial_planning.gd` | 接玩家拖拽，保留共享节点/入口/完整足迹查询 |
| 公共空间 | `partial_public_conversion.gd`、`public_site_relocation.gd`、`public_site_reuse.gd` | 保留多组件/孔洞、残余留地、设施移动与改用 |
| 房屋形态 | `fabric_relations.gd`、`scripts/visual/joined_classical_roofs.gd` | 用局部模块拓扑驱动，缓存真实接缝和高差 |
| 章程/旧成长 | `development_charter.gd`、`authored_street_growth.gd` | 章程转布局预设；关闭无输入出生和音乐门槛 |

## 2. 对象与版本

现有 schema 2 连续世界使用稳定对象 ID、连续位置/占地、时代、音级与作者来源。新增局部拓扑后提高对应对象/作品 schema，不能把结构不同的数据仍标成旧版本。

| 对象 | 新版目标的最小内容 | 来源与更新 |
|---|---|---|
| Building | ID、transform、footprint、era/style、作者来源、local_topology | 普通新房独立 ID；加层/露台引用宿主 |
| HouseTopology | schema、稳定 cell/face/module ID、占用/邻接、层高、模块类型、局部变换、生成版本 | 编辑单元，不保存派生三角形作为唯一真值 |
| RoadSegment | ID、端点节点、连续中心线、宽度、高程层、桥信息、revision | 端点/交点对齐；不量化到房屋格 |
| Lot/PublicSpace | ID、外环/孔洞/组件、实际临街边、入口、用途、设施 ID、来源链 | 多组件一致布尔，残余可继续编辑 |
| FunctionalArea | ID、轮廓/权重、用途倾向、style、revision、作者意图 | 生成标签和连续范围，不自动刷房 |
| VegetationIntent | ID、范围、密度/族、种子、排除区域、玩家修改 | 实例可重建；镜头不改种子 |
| MusicRegion/Connection | 稳定范围 ID、显式成员或明确空间范围、revision、风格、连接、控制 | 默认静态成员；动态范围须明确自动归属规则 |
| CityProfile | 地形族、中心层级、街块尺度、路断面、密度、混合用途、绿网、交通、建筑语法、历史倾向 | 生成倾向和样例参数，不替玩家决定放置 |

`Building ID`、局部单元 ID、内部 CID、作者街坊 ID、音乐区域 ID 与实例槽号互不替代。已有代码的建筑稳定键叫 `district_id`，迁移时映射到建筑实体含义，不能把它误当内部 Community 的 CID。几何连片后的单栋仍能选择、改造和追溯。

## 3. 事务、撤销与后台

新版目标数据链：输入 → Preview → Intent → 几何/依赖校验 → WorldDelta → 一次发布 → UndoEntry → 派生画面/声音更新。

Intent 至少含 `operation_id/tool/source_ids/target/parameters/seed/base_version`；WorldDelta 记录 `created/modified/removed` 对象和影响范围；UndoEntry 保存前后状态、来源链及重新生成所需版本/种子。字段可沿现有类型实现，避免为同一真值再造平行容器。

预览读取不可变快照，拖动改变预览参数；确认才分配正式操作身份/随机计数。连续笔画是一项事务。取消没有世界写入，大型替换由本次预影确认，失败保持原版本。后台任务携带世界/对象依赖版本和选区修订；迟到任务丢弃或局部重算，不覆盖后续点击、载入或作者改名。

主线程提交世界和场景树；后台生成候选、几何与离线 PCM。结构、细节与动画可以分片完成，但世界不能发布半个失效事务。撤销还原几何与作者数据，已经输出的 PCM 无法倒放；在下一可写帧接回恢复声音。撤销不能被旧每乐句单槽或 −5V 成本拦住。

规划关系保留六类用途：reserve 保净空、connect 接真实入口、support 提供基础/公共服务、attract 选择模块倾向、focus 设置视觉/音乐关注、pressure 只描述空间拥挤或冲突。它们通过查询和候选权重工作，后两者不制造维护惩罚，任何关系都不自行增加建筑。

## 4. 公共空间与留地几何

现有 `planning_reservations`、`target_polygons/footprint_components`、`hole_polygons/target_holes` 等字段保存完整范围；旧单 `polygon` 只作兼容读入，不截掉第二块或内院。目标组件不重叠，孔洞严格位于所属外环，拒绝自交；入口须能从真实道路接入。

部分兑现时进行同一布尔运算：原留地 = 本次目标 + 残余（扣除孔洞并在几何容差内比较面积）。残余组件保留 `root/parent/source` 链和独立 ID，可以再次规划；预览、提交、保存、JSON 与后台副本使用同一组范围。孔洞保留为空间，不能被植被/装饰画成已建公园。

设施搬迁保持设施 ID、用途、等级和历史来源；原位同用途不隐式升级，扩容是另一个动作。只取消关联待提交改造，不清空其他操作。服务容量是空间表现/工具配置，旧每级 18、三级等参数不成为所有新版功能的硬限制。当前服务与客流不能自动新增住宅。

## 5. 玩家作者容器

现有容器：`authorship={schema:1,next_neighborhood_id,neighborhoods}`。单项包含 `id/name/revision/member_ids/selection_kind/created_audio_frame/modified_audio_frame`。当前 `selection_kind=explicit_buildings`；成员是实际存在且已出生的建筑稳定 `district_id`，去重并排序。名字去首尾空白后非空，编辑保留 ID/创建帧并增加 revision。

作者数据独立于 World 后台交换和内部 CID。作品二进制中的 `city.authorship`、可读 DNA 的 `runtime.authorship` 真值及顶层可读投影沿现有保存路径保持一致；加载使用权威真值，不分别造两份作者名单。未知作者 schema 明确拒绝，缺字段旧档为空，不从系统分桶名称补造玩家街坊。

历史成员暂时失效时保留原 ID，详情可说明对象已改造；改名不静默删除来源。新增成员由玩家明确操作；删除/改造的来源通过可撤销事务记录。未来空间范围选区另标 schema/selection_kind，与现有显式成员区分。默认扩展只有 Intent 明确归属时才加入街坊，不因为同音或共墙自动认领。

## 6. 音频技术合同

世界建设时间、场景自然时间和设备音频时间有不同职责。新版建筑/道路立即提交；昼夜在关闭音频/暂停设备时照常工作。声音同步用实际 PCM 采样帧：不要用每帧 delta 累积音乐节拍，也不要回写预填缓冲。

现有基线为 120 BPM、22050 Hz、0.12 s 模型缓冲与 70 实际 RenderVoice；部分大城实际供音队列有 0.24 s 下限。边界由绝对拍序号乘采样率取整，避免半拍 5512/5513 的累积漂移。实际可听帧 = rendered − queued + 设备混音时间补偿，限范围并保持单调。新采样率/队列配置须和缓存、事件/存档版本一起迁移。

AudioPlan 至少记录计划/世界版本、提交帧、来源事件/对象、role/pitch/timbre、起止、增益/声像/包络/滤波和签名。排程按帧切块并稳定排序。可听活动行保存 `event_id/source_event_id/source_id/receiver_id/generation/source_onset/onset/end_frame/pitch/strength`；只查询实际渲染、当前可听的有界窗口，不能从未来资格画演奏标记。活动缓存是运行时数据，不进 DNA；静音/黑屏/停播按实际控制隐藏。

河岸 Reply 保存真实接收者与来源，延两拍、generation=1，不递归复制。来源进退有 `born_at/retired_at`，新入场不补播历史事件；改音的 A→B→A 是新生命周期，不复活旧 Reply。签名包含来源音级与接收身份，连续交接保留相位、当前淡化电平和已发生尾音。

精确共享波形只在音高、相位、包络、滤波、控制与来源签名一致时成立，逐声道累计原增益。`√k` 是改编归一化；不同控制状态不能合并。当前精确路径保留 PCM/功率相对误差 ≤2e-5 的旧测试，重新编曲另验响度。节点计数包括降电平背景、环境、装饰与交叉尾音，全城参与不等于解除预算。

现有初始完整混音校准约 −16 LUFS、公共增益固定、真峰值留 3 dB；mute/solo/镜头不重新校准。明确静音最高优先，独听/聚焦与自动视野调度其次，恢复时回到保存的显式控制。旧 25% Drone RMS 保护和“抖/刺”诊断 fixture 属旧合成器回归，新的音乐编制不强制每首曲保留同样 drone 比例，也不要求玩家辨别拍频才能操作。

## 7. 同源试听

沿用现有私有 Model、连续相位和同一版本城市快照，比较不改造/留地/公园/文化馆或不同风格。副本保留待提交项、控制和来源；监听只输出一个比较分支，原城相位继续，不把新旧音轨叠加伪造差异。

世界版本、候选几何、目标/选区修订、来源、控制或排程边界变化使旧试听失效。取消恢复控制，不消耗正式 RNG。服务/空间有差异而主题尚未实际变化时 PCM 可以相同，面板按真实后果说明，不增造声部强行让分支不同。“后续机会”是条件描述，不是已经发生或保证得到的结果。

## 8. 保存、种子与作品版本

现有 terrain/mode/boons/form/events 五条命名随机子流与计数器保留供旧作品复现；每日种子沿旧 UTC 日期 + 版本派生，自选根种子与生成器版本一起保存。新房屋/植被 Intent 派生局部子流，悬停、选房、镜头和装饰增减不重排整城。相同操作重做用同一种子和规则版本。

保存世界、作者真值、用户意图、拓扑/资产/生成版本、历史区、时代传播进度和必要音频状态；不保存线程、设备句柄、网格索引、临时焦点或可听标记缓存。旧档新字段为空/明确默认值，未知 schema 或损坏档不清空后覆盖。大整数 JSON ID/计数按现有安全精度路径或字符串编码处理。

临时写入、回读校验、替换正式文件并保留上一有效档；同时覆盖二进制作品、JSON DNA 与载入继续。可继续编辑、同版本确定回放、跨版本重新合成是三种验收，不能互相代替。日常/手选种子、具名快照、图鉴和来信使用实际事件来源；录音导出单独记录格式/采样率/素材权利，不把实时设备循环录下当作可重放作品格式。

## 9. 交通和自然表现

路线、站点、路径 legs、步行接驳、换乘、需求分别保存身份。端点与图节点一致，不以最近距离把两岸无桥站点连上。改线时车辆完成旧路段或到下一合法节点再接新线，不跳过河面或瞬移到新站。时代Ⅰ–Ⅲ马车、Ⅳ电车、Ⅴ公交/汽车仍是表现素材，可在低画质按区域分频调度。

风、水、昼夜使用持久的场景自然时间，音符标记使用可听帧。既有昼夜从 audible_frame 派生，在迁移时用保存相位桥接到场景时间，避免设备停播冻结自然或载入跳天色；两个时钟不重复写同一真值。季节后置，不改地形拓扑或建设资格。

## 10. 资产与派生缓存

现有 manifest schema 2 包含 `id/category/texture/era/origin/pixels_per_world/plot_span/image_bounds/model_bounds/source/license` 等，新增模块支持接口标签、层高、真实足迹、朝向、LOD 和命中代理。旧资产 metadata 与玩家历史分别保存；`voice_tag` 可以提示素材，不锁功能与乐器一一对应。

2.5D 真实四向对应世界北/东/南/西，不旋转 PNG 伪造门向；主图、阴影、窗光各带 origin 与尺度，并由真实几何烘焙。现有 2048 主图/512 检查图等是制作配置，新模板按显示尺寸调整。索引色纹理不直接线性混合槽号：先解析色板成 RGBA 再做过滤/mip，或使用明确的离散采样路径。

稳定地表、街面、屋顶、阴影/夜光按对象/几何版本和材质状态缓存。重绑作品即使几何相同也检查来源与夜光注册，避免复用缓存漏灯。实例槽回收和 dirty 上传按空间块/真实变化范围做，删除后的 GPU 数据及时失效。镜头移动只变换/裁剪，单栋编辑不全城重烘焙。原始模型/素材保持可恢复，源代码许可与纹理/音频许可分别登记。

## 11. 验证与证据复用

本次只有文档与兼容参数输入路径变化，不修改游戏行为。完成证据：原稿/备份哈希、31份来源覆盖、当前链接、合并稿、world_v2 除 sources 外一致、spec_values 字节不变。

后续开发先选一个新行为合约和一次真实操作。涉及声音再测削波/真峰值/欠载，涉及保存覆盖旧档/损坏档/来源恢复，涉及美术做固定场景三尺度对照。Round150–152 公共空间/规划、173–174 来源连续与公共活动、180 表达、206–218 资产/UI/作者/自然等旧证据在原 `验证记录/` 可查，旧 PASS 不证明新墙格或新声场完成。精确入口按现有代码与原稿目录定位，不把所有历史脚本改成每次必须运行的清单。
