# 作品与进度执行规格

保存 WorldSnapshot、玩家编辑/局部拓扑、生成版本/种子、时代、独立 authorship、区域音乐意图和必要声音恢复状态。线程、网格缓存、临时输入和播放器不入作品。

临时写档回读成功后替换，并留上一份有效档。未知 schema 拒绝覆盖；旧档缺新字段默认空，已有名字/来源保留。稳定 ID 和 JSON 精度沿旧合同。

自由建设默认；城市史与聆听为可选组织。时代由空间进展揭示、玩家选择，地标能力不要求 R≥70 或修复数。历史街区和地标保留原风格/作者；替换记录可撤销。

验证编辑→保存→加载→继续，未知 schema/损坏文件保护，时代转换/撤销、来源转写及音乐连断恢复。跨版本重渲染另测，不能把可继续存档当作完整声音回放证明。

完整旧参数、公式和合约 ID 见 [迁移前 spec.run](../../废弃/文档/2026-10-14_综合优化前/文档/01_执行规格/spec.run.md)。
