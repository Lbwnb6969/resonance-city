# 单局、随机、祝福与城市记忆执行规格

> 2026-10-08 · P0不实现Roguelite；本文件定义后续阶段。未知项有编号，禁止自行填齐。

## 表 R1 · 时长（原样保留）

| 单位 | 长度 |
|---|---|
| 小节 | 2 s |
| 乐句 | 8 小节 = **16 s** |
| 乐章 | 12 乐句 ≈ **3.2 min** |
| 一局 | **7 乐章 ≈ 22 min**（含祝福与结算停顿，实际 25–35 min） |
| 祝福选择 | **每乐章边界 1 次 → 一局 7 次** |

## 表 R2 · 种子与City DNA（原样保留裁定内容）

```
City DNA = { seed: uint64, mode: string, charter_id: string,
             decisions: [{bar:int, proposal_id, target, choice}] }
所有随机来自 hash(seed, 子流名)
子流固定：terrain / mode / boons / form / events
seed = hash("daily:" + UTC日期 + 版本号)
```

禁止无子流来源的`randi()`。地形及初始布局使用terrain；调式/音源/宪章使用mode；祝福用boons；命名形态用form；提案及城市记忆事件用events。2026-10-08用户批准P0 U02方案，执行定义见R2a；每日一城无后端，不暗含排行榜、账户或云存档。

## 表 R2a · P0种子执行方案（用户批准U02）

| 项 | 规则 |
|---|---|
| 根种子 | 16位小写hex文本，表示原uint64位串，避免JSON整数精度/有符号转换损失 |
| 子流派生 | SHA256(根seedhex+":"+子流名)，UTF-8，五条命名子流各自独立 |
| 随机字 | SHA256(子流hashhex+":"+计数器十进制)前8位hex作为uint32；计数器从0递增 |
| 有界取样 | uint32拒绝采样，丢弃≥floor(2^32/上界)×上界的字，再取模，不引入模偏差 |
| 快照 | 根seed与五子流计数器；试听只深拷贝不推进真子流 |
| daily | SHA256("daily:"+UTC YYYY-MM-DD+ProjectSettings application/config/version)前16位hex |
| P0版本 | p0-1（执行方案版本，写project.godot）；改变生成/子流语义必须升版本 |
| P0决策 | 保留原bar/proposal_id/target/choice；追加verb、district_id、输入requested_audio_frame与commit_phrase_frame；音级/格子来自系统选项，不丢失输入时刻 |

P0只实现种子/生成/选择可追溯接口；完整Run、祝福、图鉴重放内容仍不进入P0。daily失败固定原种子安全布局见CITY-002 D2。

## 表 R3 · 终止式与祝福

| 参数 | 人类裁定 |
|---|---|
| 乐章完成条件 | 本乐章达成3次「协和解决」（一处大二/小三提升到协和）且末乐句R≥70 |
| 进入祝福 | 达成即三选一 |
| 基础权重 | 普通70 / 稀有22 / 史诗7 / 传说1 |
| 连续普通软保底 | 每次稀有+3、史诗+1；出稀有或以上重置 |
| 硬保底 | 连续5次普通后下一次必定稀有或以上 |
| 元进程 | 仅扩展音源、街区、提案与图鉴可能性，不给永久数值碾压 |

12乐句长度与“达成即推进”的关系、未达标如何续章、第7次祝福是否用于终局、三选一按抽取还是选择计数见U08/U09，不擅改7乐章/7祝福。

## 表 R4 · 张力债务（P1）

| 参数 | 裁定 |
|---|---|
| 故意保留失谐额度 | N = 1 + 已获祝福数 ÷ 2，上限4 |
| 期待值E | 每乐句+1，上限6 |
| 延迟解决奖励 | 爆发加成 = E × 落点精度 |
| 记忆 | E转化为城市图鉴条目 |

N整数化、精度定义、加成目标、标记/撤销/重连后的债务归属未定（U10）。不把债务自动从R公式中豁免。

## 表 R5 · 跨局与来信

| 项目 | 阶段 / 规则 |
|---|---|
| 市民来信B1 | P1，文本模板填充真实玩家选择产生的地点/事件，于终止式送达 |
| 音色/形态/配方三册 | 可发现可能性；稀有概率与解锁具体条件未裁定 |
| 崩盘保底 | 每局至少新样本或图鉴线索；池耗尽策略待U09 |
| 作品回放 | 同事件路径重渲染；City DNA可复现，不以视频录制替代 |
