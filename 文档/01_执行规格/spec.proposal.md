# 编辑事务执行规格

输入：工具类型、来源/目标、局部或连续几何、参数、编辑种子和依赖版本。输出：Preview、Intent、WorldDelta、UndoEntry。

Preview 不修改正式 World/随机流/存档。小点击直接形成 Intent；连续笔画合成一次操作，大型放置先预览。提交检查依赖，失败不发布部分世界；过期后台结果丢弃或重算。

UndoEntry 保留前后差量和受影响对象，撤销覆盖房屋、道路、区域、植被、时代改造和音乐连接。旧每乐句单槽、固定 −5V 和不可撤销地形动作取消。

声音已写 PCM 不回写；城市撤销与下一可写声音淡化分开。验证预览取消不写真值、同种子重做、迟到任务、组合操作和损坏存档。

完整旧参数、公式和合约 ID 见 [迁移前 spec.proposal](../../废弃/文档/2026-10-14_综合优化前/文档/01_执行规格/spec.proposal.md)。
