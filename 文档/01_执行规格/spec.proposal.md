# 提案、试听与介入执行规格

> 2026-10-08 · 最新用户裁定：允许工业改音级；允许迁移时静音一乐句。反支柱仍禁止玩家自由输入音符；音级由系统提案限定。

## 表 P1 · 双轨落点（原样保留）

| 落点与目标音级的关系 | 效果倍数 |
|---|---|
| 命中提案允许的和声音级 | **×1.0** |
| 偏差 1 半音 | **×0.7** |
| 偏差 ≥2 半音 | **×0.4**，且引入一次新张力 |

主轨是和声判断；副轨为距可听乐句边界≤±80ms时的额外泛音层与该街区+5活力。介入输入可在任何时刻，落定只在乐句边界。主轨倍数作用到何种效果、落点音级如何操作未给出，见U06；不能将R乘此倍数破坏其纯函数定义。

## 表 P2 · 介入动词（原样保留；用户已批准两个争议例外）

| 动词 | 内容 | 代价 |
|---|---|---|
| `retune` | 把一个街区的音级改到相邻协和音级（例：工业 F♯3 → G3，与 C 成纯五） | 该街区 −10 活力（改造成本）；与**新**邻居的关系可能不协，必须预览 |
| `relocate` | 把一个街区移到另一格，改变邻接关系 | 移动期间该声部静音 1 乐句；原邻居失去加成 |
| `infill`（P1） | 在两街区之间插入解音声部（公园），取共同协和音 | 占地，降低该处密度上限 |

`retune`允许工业F♯3→G3；industrial类型和工业权重仍按街区类型判定，不把改音级偷偷转成商业/住宅。`relocate`在乐句边界提交新邻接图，同时该声部静音1乐句，下一边界恢复；这是持续drone规则的已批准例外，不增加其他自动静音情形。具体状态提交与活力结算顺序须等U07裁定。P1的infill共同协和音与无共同音时的处理见U06。

## 表 P3 · 提案接口

| 字段 | 规则 |
|---|---|
| proposal_id / source_event | 稳定ID及因果事件，不凭空随机加玩法 |
| verb / district_id / targets | P0只retune/relocate，目标为系统给定选项 |
| allowed_pitches / preview_choice | 提案允许的和声音级集合与当前试听选择，集合算法待U06 |
| gain / cost / changed_edges | 预览副本按同一模拟计算收益、成本、失去/新增邻接 |
| requested_at / commit_boundary | 可听时钟输入时间与尚未渲染的合法乐句边界 |
| before_state / preview_state | 独立副本；取消后真实城状态、RNG与音频相位不受污染 |

### [PROPOSAL-001] 诊断向的有限介入

状态：P0已按本次用户裁定U06/U07明确；P1误差/公园待另裁定。

意图：让玩家修改和声关系并承担取舍。

规则：P0两个动词按表P2执行；禁止增建住宅替代。基础每乐句一次介入；用户已裁定P0固定每64秒刷新（原60–90范围内且对齐乐句）。retune只提供C大调五声C/D/E/G/A并与至少一个邻居达到表B协和或共鸣的系统选项，迁移只给合法空格。成本如实显示，不虚构新张力。误差倍数/新增张力/公园留P1。

数据：表P2、P3；UI-002。

验收：DOD PROPOSAL-001：`& "D:\GODOT\Godot_v4.7.2-stable_win64.exe" --headless --path . --script res://tests/proposal_contract.gd -- --case verbs`；工业retune、迁移静音/恢复、原邻居加成变化断言。

反例：不得限制工业retune为非法；不得通过mute修改R/V；不得把+5卡拍糖变为强制输入门槛。

### [PROPOSAL-002] 试听未来与逐样本对照

规则：长按试听3s，以城市状态/RNG/音乐相位快照模拟同一选择；取消不改变真实状态。预览与落定使用同一模拟/事件混音路径。在相同起始相位、相同状态与标准增益下比较PCM，监听强调/ducking另测。提交时间必须是尚未渲染乐句边界。

## 表 P5 · Demo引力带（本次用户批准U15）

| 参数 | 值 / 规则 |
|---|---|
| 同时上限 | 1条；新线在同一乐句边界替换旧线，无叠加 |
| 输入 | 在地图拖动从起点到终点，二者为合法且不同的逻辑格；偏向只允许住宅/商业；线可跨已有地块，不占格、不切邻接 |
| 生效 | 复用每乐句1次待提交介入槽，release/调音/迁移/draft互相覆盖；松开鼠标即提交到尚未渲染的下一乐句边界，可取消；无卡拍活力奖励 |
| 重划代价 | 已有引力线且线或偏向改变时，暂停全部自动扩张1乐句；提交边界不产生新建筑，下一边界恢复；已有形态的条件计数/升级与声音继续，不扣R/V |
| 首次及重复 | 首次划线无暂停；同起终点同偏向再次提交不算重划；取消待提交线保留已生效旧线 |
| 影响 | 只影响偏向类别的共鸣点家族，保持原每源点每乐句扩张量与类型继承；不强制生成选定类别，不改变MIDI、音程阈值或R/V公式 |
| 排序 | 先过滤原连通/空格/协和/避碴合法候选；匹配类别先靠近有限线段（平方距离小优先），距离相同时优先向箭头终点方向（沿线投影大优先），再用既有家族邻居数、源点距离、坐标顺序；其他类别沿用原排序；不消耗RNG |
| 快照与显示 | 生效线及暂停终止音频帧纳入城市快照/试听；地图旧线仍有效，待提交线用金色预览，生效线按住宅/商业色区分，箭头显示方向；重划暂停剩余时长读可听时钟 |
