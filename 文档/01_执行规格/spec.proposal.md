# 提案、试听与介入执行规格

> 用户已允许工业改音级与迁移静音一乐句。新版空间/可逆性分别取 P7–P9 与 spec.space；引力与踩路的连续规则见P5/P6/P9；旧格边输入已移出。两层落定取 spec.ui U20 / spec.audio A26，音级仍由系统选项限定。

## 表 P1 · 双轨落点（原样保留）

| 落点与目标音级的关系 | 效果倍数 |
|---|---|
| 命中提案允许的和声音级 | **×1.0** |
| 偏差 1 半音 | **×0.7** |
| 偏差 ≥2 半音 | **×0.4**，且引入一次新张力 |

主轨是和声判断；副轨为距可听乐句边界≤±80ms时的额外泛音层与该街区+5活力。介入输入可在任何时刻；城市真值/成本在乐句边界落定，局部可听声音按 U20 的拍点层落定。P0 系统音级已在 P4 裁定；P1 主轨倍数的作用目标与误差输入方式仍见 U06；不能将R乘此倍数破坏其纯函数定义。

## 表 P2 · 介入动词（原样保留；用户已批准两个争议例外）

| 动词 | 内容 | 代价 |
|---|---|---|
| `retune` | 把一个街区的音级改到相邻协和音级（例：工业 F♯3 → G3，与 C 成纯五） | 该街区 −10 活力（改造成本）；与**新**邻居的关系可能不协，必须预览 |
| `relocate` | 把一个街区移到另一合法连续位置，改变耦合关系（旧 P0 fixture 仍用格坐标） | 移动期间该声部静音 1 乐句；原邻居失去加成 |
| `infill`（P1） | 在两街区之间插入解音声部（公园），取共同协和音 | 占地，降低该处密度上限 |

`retune`允许工业F♯3→G3；industrial类型和工业权重仍按街区类型判定，不把改音级偷偷转成商业/住宅。`relocate`在乐句边界提交新邻接图，同时该声部静音1乐句，下一边界恢复；这是持续drone规则的已批准例外，不增加其他自动静音情形。P0 结算顺序已由表 P4 裁定，连续世界叠加 M 时按 spec.space SP4 计算每端 ΔV；新动词的额外奖励/额度冲突不由旧 U07 自动裁定。P1的infill共同协和音与无共同音时的处理见U06。

### 表 P9-a · 毁坏上限（新增，防止"一次探索毁掉作品"）

**任何单个持久拓扑操作（含可消解踩路，以及不可撤销引水 / 挖湖 / 平整）必须先按本表判定；超限则拒绝或要求二次确认。**

| 指标 | 阈值 | 超过时 |
|---|---|---|
| 被切断的耦合边数 | **≤ 6** | **拒绝执行**，提示"这会切断 N 条关系" |
| 受影响的成熟建筑数（群/央/腔） | **≤ 8** | **拒绝执行** |
| 会导致失效的命名形态 | **≥ 1** | 二次确认（显示是哪个形态） |
| 会失去轮唱 / 对唱的社区 | **≥ 1** | 二次确认 |
| 涉及的规划社区数量 | **> 2** | **拒绝执行**，建议缩小范围 |
| 会覆盖既有建筑 | **任意 1 栋** | **拒绝执行**（不删除、不移位、不浮空） |

**这些是设计值，不是实现细节。** 执行 AI 必须实现阈值判定，**不得由玩家自行调整阈值**。

**预览必须显示**：
- 会消失 / 新增哪些耦合（可视的边高亮）
- 哪个命名形态会失效
- 哪些建筑会被覆盖
