# 城市与街区执行规格

> 现行实现规格。空间/邻居以 spec.space 为准；生长见 E-grow，环形见 E5-b，地标见 E6/E6-b。P0 固定音级与黑屏 fixture 独立保留，当前进度见 ../../PROJECT.md。

## 表 A · 街区声部（P0 版）

每个街区 = **drone 层**（持续音，承载固定和声与拍频诊断；其他层也有物理干涉，不能替代 drone 验收）+ **律动层**（承载节奏签名 → 产生节奏对比）+ **装饰层**（偶发音，彩蛋）。

| 街区 | 音级 | **八度（MIDI）** | **频率** | drone 音色 | 律动层签名 | 设计意图 |
|---|---|---|---|---|---|---|
| 住宅 residential | C（主音） | **C3 = 48** | **130.81 Hz** | 木琴/拨弦 pad 化，暖 | 稳定 4/4 中速 | 城市锚点 |
| 商业 commercial | E（大三度） | **E3 = 52** | **164.82 Hz** | 明亮键盘/铃铛 | 十六分律动 | C–E 大三，天然协和（+5） |
| 工业 industrial | **F♯（调外音）** | **F♯3 = 54** | **185.00 Hz** | 锯齿脉冲，保留185Hz基音 | 不规则切分；**300Hz高通仅律动层** | C–F♯ 三全音 = 「刺」，天生需重排 |
| 公园/绿地（P1） | 无固定音级 | 动态 | 动态 | 正弦 pad，长音 | 长音留白 | **解音声部**：自动取相邻声部的共同协和音 |

表A保留初始音级/MIDI/频率；工业可retune。2026-10-08工程轮用户明确裁定U04：300Hz高通只用于工业律动，drone保留基音；此前高通作用域冲突已解决。

## 表 C2 · CITY-003 P0人工叛离fixture（既有测试授权的技术落实）

仅用于DOD已列的`city_contract.gd -- --case rebellion_fixture`，不能从本表推定正式叛离规则。初始声部不自动叛离，听测真值/主城生长/邻接/工业属性不改。无需编造包围判据或新触发时长。

| 项 | 测试技术协议 |
|---|---|
| 音高偏移 | +1半音，相对注入前的当前音高；只在人工指定且恰等于当前渲染游标的尚未渲染乐句边界注入，不重置振荡相位 |
| 律动偏移 | ±5–12%，沿CITY-003原值；覆盖正负两端，速率乘数为1+偏移。仅更改律动节拍包络的采样位置，不改变其载波音高/drone音高，禁止独立警报或LFO |
| 漂移时基 | 每个显式测试声部保存start_frame、start_grid_frame、speed、original_midi；包络索引floor(start_grid_frame+(sample_frame−start_frame)×speed)，对既有小节包络长度取模。注入时start_grid_frame等于真实frame，不使包络突然跳到0 |
| 人工归拍 | 由fixture在恰等于渲染游标的指定合法乐句边界撤去漂移并恢复原current_midi；律动重新读真实样本帧，振荡相位继续。这里只证明显式恢复，不宣称玩家包围/卡拍自动触发已实现 |
| 隔离 | 注入/撤去函数仅在tests/rebellion_fixture.gd；软件混音仅识别显式PCM测试状态键。常规state无键时仍走原包络索引/混音，UI/生成器不会写此键 |
| 快照 | 测试键与PCM状态一并深拷贝；分块与逐样本路径同义，恢复不依赖Tween/画面delta |
| 判定 | 与同音高的未漂移对照比较drone逐样本完全一致；与正常声部对照实际律动能量分布不同；无关声部逐轨PCM不变；恢复后同相位drone/律动与普通路径完全相同。两种采样率及端点含义由既有时钟和本表推导，不新增游戏数值 |

此切片不包含正式触发、包围判定、卡拍收服、归拍奖励或新音色。原主城/听测状态不会注入fixture；已有初始gain、显式mute/solo、保护和道路规则保持有效。

**为什么邻居口径必须显式限定**：密集区（六方最密堆积）里每栋建筑有 **108** 个 `c > 0` 的邻居，

- "≥2 邻居 s ≥ 0.85"极易命中 → 所有建筑同时升级
- "任一邻居 s ≤ 0.05"极易命中 → 所有建筑同时冻结
**两个方向都会让城市在密集处停止有意义的分化。** 用 `N₁₂` 后，判据只看"听得清的那 12 个"。

### E7-a · 文化设施容量与扩容（第117轮切片）

文化设施仍是稳定 `public_sites.id` 的独立公共规划对象，不把住宅改成文化建筑。每栋房屋请求一个文化服务名额；先按 E7 的真实入口步行覆盖过滤设施，再按空间距离、设施 ID 和建筑 ID 确定性分配，首选满载时尝试另一座可达设施。重叠覆盖、跨社区服务和社区分裂都不能重复计算同一服务对象。公园覆盖与文化容量分开统计。

| 参数/字段 | 当前合同 |
|---|---|
| `service_level` / `service_capacity` | 一级至三级；每级服务18栋，即18/36/54。旧快照缺字段按一级恢复 |
| `service_demand` / `served` | 前者为首选请求数，后者为实际分配的建筑 ID；实际分配不超过容量 |
| 社区 `pressure` | `(成员数−实际文化服务数)/成员数`；无成员为0，只作服务反馈，不改 R/V |
| 扩容提交 | 点击已建文化设施，选择“公共设施”；复用 `civic` 操作，在下一乐句扩一级，保持位置、占地与 ID。重复待播操作替换同一设施意图；三级请求拒绝并返回明确提示 |
| 成长反馈 | 同一落点层级、用途优先级内，有剩余容量且步行可达的设施提供0–50分偏好；不强制播种、不跨河、不降低原有合法性和协和条件 |
| 交通/音乐反馈 | 可达文化服务且压力≥0.5的站点增加1名需求；既有节奏槽压力≥0.5时，深流由每4拍改为每2拍，晴岸由每拍改为每半拍。节点按压力档位进退，复用现有淡化与70声部预算 |

## 表 E8 · 规划锚点关系与范围语义（2026-10-10）

本表把公共设施、重要建筑和发展章程接入现有连续城市。它不改变 E7 的道路服务数值、不改变 SP2 的声学耦合公式，也不把范围内建筑逐栋变成手动建造对象。

| 锚点类型 | 规划作用 | 音乐接口 |
|---|---|---|
| 公园/绿地 | 保留净空、降低局部填充偏向、为边缘成长留下空间 | 留白、主题退让和既有公共节奏入口 |
| 文化设施 | 按真实入口服务并受容量约束，偏向形成文化中心 | 实际服务社区的主题/装饰资格，服从 A20 |
| 商业节点 | 偏向临街和交通可达的连续成长，形成中心压力 | 竞争节奏槽，密度过高时仍需保留留白 |
| 桥/交通节点 | 改变真实道路可达和跨社区连接机会 | 满足既有条件时形成对唱/连接，不直接奖励声学分 |
| 地标 | 使用自身觉醒条件和局部规划影响 | 使用实际城市音级写成动机，服从遗产与吸收合同 |

范围语义分三类：服务范围按道路最短路和容量，规划范围按连续空间影响配置与衰减，声学范围按 SP2 的 c。三者必须在预览中分别说明；跨河近距离不等于可服务，桥接通也不自动等于产生声学耦合。
