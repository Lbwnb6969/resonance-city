# 执行规格索引与状态

> 本目录加`../02_验收/`是唯一实现细节来源。顶层阅读稿和`90_存档/`不产生规则；不要混读多个版本。

| 文件 | 管辖范围 |
|---|---|
| spec.city.md | 街区schema、三层、初始音级/八度、生成/叛离 |
| spec.harmony.md | 音程分、R/V公式、初值、结算与迟滞 |
| spec.audio.md | 路由、时钟、持续信号、ducking、辅助 |
| spec.asset.md | 许可与来源、离屏管线、整图、导入隔离 |
| spec.proposal.md | 介入、试听、落点、代价 |
| spec.run.md | 乐章、种子、祝福、债务、记忆 |
| spec.ui.md | 推子、HUD、等价视觉、换色与性能 |

每条规格均含ID、状态、意图、规则、数据、验收、反例。“已裁定”指设计规则已批准，不代表功能已实现。`待裁定Uxx`只阻止依赖该缺口的实现，不阻止其他任务。所有Uxx与冲突记录在`../修订记录-2026-10-08.md`。

表格是参数事实源。下一阶段先从表格产出单一数据配置并在测试中核对；本轮不生成运行时代码，也不把未给出的默认值补进数据。
