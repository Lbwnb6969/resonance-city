## 兼容性声明

**原样保留的数值**（不得改动）：
- 表 B 全部协和分与 ΔV
- V 公式、灰噪化迟滞、崩盘、开局 R≥65
- 三层声部的全部谐波权重/包络/滤波
- 混音标准（−16 LUFS、真峰值 3 dB、drone RMS 25%）
- 声学测量协议（A6）
- 卡拍窗口 ±80 ms、介入槽每乐句 1 次、64 秒提案刷新
- 种子五子流、City DNA 格式
- P0 黑屏听测协议与 fixture

**被取代的条款**（旧值不再有效）：
- 表格空间的一切（16×16 格、四向共享边、曼哈顿距离）
- `w = 1 + 0.15×(n−1)` 权重公式 → 表 SP2 耦合系数
- 27 声音实体上限 → 表 A18 声部组 + 表 A21 密度预算
- 三段量化声像 → 表 A19 连续声像
- 常驻右栏与底部条件卡 → 表 U16 常驻 ≤4 元素
- 单一跨越条件 → 表 R7 三路径
- 固定 7 乐章为唯一模式 → 表 R8 三模式

## 状态标记

每条规格含 ID、状态、意图、规则、数据、验收、反例。
- `已裁定`：设计规则已批准，不代表已实现。
- `重构新增，待实施`：本次重构新增，尚未写代码。
- `待裁定Uxx`：只阻止依赖该缺口的实现。
