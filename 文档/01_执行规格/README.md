## 实现与验证范围

当前主线是连续河谷。旧格子Demo的27实体、第62轮24栋、第63轮30栋是不同切片预算；70是当前合成器配置硬上限，满预算供音/响度/性能尚未验证。18栋制作开局与14个RenderVoice也不能换算成最终城市规模。完整进度只在PROJECT维护。

`已裁定`表示设计批准；`已有切片`表示局部代码接入；技术PASS只覆盖注明的版本、路径和样本；真人听感与好玩单独验收。旧AUDIO-007三档定位不覆盖AUDIO-G4连续声像，历史静态700栋不覆盖动态大城与完整音频。

剩余设计缺口及局部任务依赖见 [待裁定与依赖](../待裁定与依赖.md)。工程细节按已批准边界自主补齐；不能把待实施、待验证或已闭合旧问题写成全项目阻塞。

## 必须保持的边界

- 表B协和分/ΔV、活力/迟滞/崩盘、初始R≥65、卡拍±80ms、每乐句介入槽、64秒刷新、五命名随机子流与P0黑屏测量协议保持。
- 全对集合E用于局部R/V求和，N₁₂用于阶段计数/碴冻结；按M前c₀稳定排序。
- 分层R与全城加权平均代数恒等，局部问题靠社区指标呈现。截断跳幅不存在固定0.71pp上界，唯一失谐配对被移除时可从0跳到100。
- 同相k份原信号功率为k²P；√k是编曲归一，不是等价共享的证明。A15精确共享与A18合奏响度目标分别验收。
- 41栋触发规划社区分裂；调音不改变社区ID。分裂尚未完成。
- 平地排水走priority-flood父图；规则耦合消失不代表混音中的物理拍频消失。
- **任意合法陆地都能落点，L1/L2/L3 由后果分层，不得拒绝 L3 空地**（spec.fabric 表 FB1）。
- **形态关系（共享山墙/连排/庭院）不进 R/V，也不合并建筑身份**；连片是视觉层，声学耦合只在 spec.space（spec.fabric §0）。

## 数据生成

在项目根目录运行：

```powershell
python tools/build_spec_data.py
python tools/build_spec_data.py --check
```

生成器读取现行 spec（含 [spec.fabric](spec.fabric.md)），输出 `数据/world_v2.json` 并记录源文件哈希。旧 `数据/spec_values.json` 是独立P0音频合约，生成器不会覆盖它。只改文档作用域时，运行参数应逐项保持，更新的只有来源哈希。
