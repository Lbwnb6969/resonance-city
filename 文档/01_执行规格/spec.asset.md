# 美术资产与性能执行规格

模块交付 mesh/贴图、轴心/地脚、尺度、朝向、接口标签、材质族、时代、LOD、碰撞/命中代理和来源许可。资产与可重建制作脚本、manifest 同存。

第一时代保持古典材料与庭院/柱廊词汇；房屋墙格只决定生成，最终墙体不描棋盘。模块有端部/转角/高差/屋顶接口，装饰服从入口和净空。

2.5D 四向从真实几何烘焙，不能旋转贴图冒充视角；3D/混合原型按同场景测量取舍。共享材质、空间分块、实例化与 LOD 保留轮廓/连接优先；不限定 Blender 或唯一建模路径。

验证接缝/高差/路接门/灰度可读/昼夜、同镜头三档细节、帧时/编辑延迟和素材许可。数量与预算按实测确定。

完整旧参数、公式和合约 ID 见 [迁移前 spec.asset](../../废弃/文档/2026-10-14_综合优化前/文档/01_执行规格/spec.asset.md)。

## ASSET-JOIN · 生产交付

资产至少带 ID、schema、用途/时代、源文件/制作脚本、材质族、真实尺度/足迹、地脚/朝向、接口标签与许可。3D 模块提供端部、角/T 接、高差、屋顶、开口和支撑；2.5D 主图/窗光/阴影有各自 origin/pixels_per_world，四向来自真实几何。

manifest 是部署入口，不扫描目录猜来源和尺度；工作素材、源模型与生成缓存分别存放，原件可恢复。模型/代码/纹理/音频分别查许可。索引色 mip 不混合槽号；遮挡窗光由真实孔洞/可见性输出。风格、画质级别与缓存粒度不改变逻辑房屋身份。

同一场景验证全景/街坊/墙面三档、白昼/夜景、高差/路门/桥岸接头与删块后重建，随后测完整有声连续编辑的帧时和内存；单件渲染或静态700图不代替新玩法完整场景成绩。[制作合同](../20_开发接口与迁移.md)
