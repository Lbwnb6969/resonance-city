# 操作与反馈执行规格

地图状态使用命中候选和就地工具；房屋编辑显示局部格提示，城市其余不显示网格。面板输入优先于地图，Esc 取消当前草稿/关闭面板，不撤其他已提交操作。

显示真实影响范围、空间冲突和工具能力；不显示 R/V 作为建造门槛。音频静音时轮廓、预影、接头和动画仍足以操作；减弱运动保留信息。

音乐独听显示真实选区/CID 作用域，退出可恢复自动视野声场。镜头/文字避让以实际选中成员为准，名字不跟旧 CID 扩张。

验证鼠标/键盘同意图、文本快捷键隔离、小窗口候选可读、取消、镜头移动和真实可听事件显示。

完整旧参数、公式和合约 ID 见 [迁移前 spec.ui](../../废弃/文档/2026-10-14_综合优化前/文档/01_执行规格/spec.ui.md)。

## UI-INPUT · 焦点与模式

状态区分浏览、墙格编辑、连续工具草稿、参数面板和文本输入。局部格只在房屋编辑焦点出现；道路/区域笔画显示连续轮廓。面板消费快捷键，文本 Tab/Enter/Space 与地图快捷键不同时触发；Esc 依焦点退出一层。

小点击直接执行，大动作预影列影响对象。音乐独听/连接显示真实作用集合，选中不自动修改风格。缩放只换显示/声场候选，名称的避让不改作者记录。通知依真实事件出现，不盖满地图或反复强制聚焦。

无声音可完成相同工具链，灰度/减弱运动保留命中、范围和冲突信息。最小检查包括文字输入隔离、800×600 工具避让、透明角落命中、连续笔画取消和缩放前后成员集合一致。
