# 房屋局部与连接执行规格

输入：房屋 ID、墙面/单元 ID、添加/移除或露台模式、模块风格、局部种子。输出：变化拓扑、结构模块、接缝和局部碰撞/命中数据。

单次点击或笔画创建一次编辑事务，更新受影响邻接。结构→开口→屋顶/露台→支撑/台阶→装饰；大形状确定，小细节固定种子变化。不强制每格一栋，不把房屋锁死在原有轮廓。

道路交叉可形成门洞/入口；相邻屋顶不兼容时使用清楚断点，不生成覆盖庭院的大斜棚。共同檐口不合并房屋 ID 或作者。庭院保留真实可达净空。

验证：平墙/角/T 接/高差/上层/露台/移除；单栋选择；撤销、重复种子与完整占地。尺度、拓扑和接缝容差按美术原型确定。

完整旧参数、公式和合约 ID 见 [迁移前 spec.fabric](../../废弃/文档/2026-10-14_综合优化前/文档/01_执行规格/spec.fabric.md)。
