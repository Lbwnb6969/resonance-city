# 音乐协调与兼容执行规格

和声规则用于让区域风格连接后好听，提供调性/节拍兼容、声部疏密与过渡，不用于建设正确答案。

优先使用设计好的素材族、stem 和有限动机组合；保留深流/织机/暖庭及时代音色来源。听觉诊断和拍频公式是音频工具，不产生冻结、崩盘、债务或解锁门槛。

旧 R/V 与音程表仅供运行配置生成和历史 PCM 复现。代码还未迁移时仍有旧行为，具体差距见 PROJECT。验证音乐连接不改几何/进度、换风格不改房屋身份、响度控制和真实来源。

完整旧参数、公式和合约 ID 见 [迁移前 spec.harmony](../../废弃/文档/2026-10-14_综合优化前/文档/01_执行规格/spec.harmony.md)。

旧运行数值独立保留在 [兼容数据](../../数据/兼容规格/README.md)，由参数生成器读取；不作为本规格的建造条件。

## MUSIC-STYLE · 协调职责

风格预设包含音色族、节奏密度、动机长度、调性/节拍适配与可用素材；地域用途、房屋体量与音乐风格分别保存。连接两个风格时用同源对照试听，匹配拍点、淡化或轮换；张力可以是正当表达，不变成建设错误。

长音/律动/装饰是素材层，Bass/Pad/Lead/Rhythm/Ornament/Bed 是角色。混音预算和响度控制防止素材叠到一起遮蔽，限输出密度，不缩减玩家城市方案。随机事件可复现，持续固定音高不随机抖动。

旧声学诊断、音程分和迟滞 fixture 仅用于旧合成器回归。新版验证风格有辨识度、连接过渡好听、静音控制真实生效、声音修改不写建设状态。真人听感与自动波形检查分开登记。
