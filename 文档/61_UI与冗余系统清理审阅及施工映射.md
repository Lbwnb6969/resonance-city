## 4. 不能按原稿立即切断的六条边界

1. **旧来信仍须能真实完成。** `scripts/world/city_creation_poem_features.gd`有池塘面包坊新景且`produced>=1`条件，Vignettes另有workshop/clockmaker等角色要求。停止种子/生产后，保留原条件和原历史的同时要提供历史页显式继续原任务所需的有限兼容行为/人工用途入口；不自动恢复全城经营、不补造出炉，不改成点一下即完成。逐原ID证明可达后再关闭该消费者。新free无此兼容任务。
2. **冻结余韵不是只跳过倒计时。** `resonance_afterglow`还影响渲染、倍率、校验和新发放。free旧数值保留作为历史，运行消费者改读清晰的空间/播放状态，不能永久发光或重新加速；原值超过180秒的合法来源/倍数校验不放宽。legacy照旧计时。
3. **停品质不能丢外观。** 保存的building_quality、house_improvements、彩窗/花箱等保持；新自动表现依实际几何且可关闭，不继续后台改变作者配色。茶座桌椅、座位合法性与旧买面包喝茶状态机分开；长椅/阳台不是任意茶椅，不能假定B已支持全部茶座。
4. **收据休眠须显式唤醒。** 不以`set_process(false)`一行结束：城市切换、正式打开/转换、旧来信兑现、旧章程、选卡/翻卷、Undo/Redo均需刷新余额、覆盖状态和入口；已截止普通事件不得被重新采集成新XP。是否仍需维护非XP历史计数按消费者审计，不凭“XP=0”停所有账本。
5. **基础权限不能冒充已接通。** 四风貌/六饰色/两个额外调式/两类地标及两种微景已有子步；石阶琴键与9m云廊不在该已验收清单。`scripts/world/city_creation_tradition_rules.gd`的bridge_distance仍按cloud_gallery卡区分7.2/9m。可纳入待迁目标，须逐项贯通真实几何/碰撞/净空/Schema/Undo和旧作者内容；不能同时把所有stair_rise/tree_radius等奖励条件全部放开。
6. **后台裁剪有图和生命周期前置。** 保留公共路网、入口、真实高程、区域分量、活动路线/座位、在途居民/电车、当前演出与旧收据；移走所有经营状态机前先处理当前动作的退出、恢复和原checkpoint。不得用清库存、清行程或重生成市民规避迁移。

母曲/调式UI只列真实注册并能播放的内容；原稿“准备中=下一小节”沿60纠正，安装与实际发声分开。新曲未默认接通、actual role/tier未可读时，不用固定示例文案伪装总谱已实现。
