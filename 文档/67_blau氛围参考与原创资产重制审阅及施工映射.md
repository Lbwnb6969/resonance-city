## 2. 转成《共鸣之城》的原创暗线资产

将参考气质压缩为一套可选 `blue_underflow_v1` profile，默认关闭、不可锁住基础音乐，不增加播放器和总线。运行时只允许审定的原创事件和合成参数：

| 参考机制 | 原创游戏层 | 接入边界 |
| --- | --- | --- |
| 毛毡钢琴近景 | 中音区 `felt_keys`：短起音、轻机械噪声、3–4.5 s 暗混响、3 kHz附近柔化 | 写入 `lead` 或 `answer` 的少量事件；保持暗线低存在感，不复制原曲动机 |
| 温暖弦垫呼吸 | `breathing_pad`：慢 Attack 0.8–1.2 s，和声变化跟随空间亲和度 | 只在跨区或高亲和度时渐入；每条总线有峰值和释放上限 |
| 水下低通拨弦 | `muted_pluck`：低通 400–900 Hz 的原创合成，慢衰减与轻磁带漂移 | 作为 `pulse` 的稀疏替代；不把 16 分音符密度固定成全城节拍 |
| 深海低频/闷脉冲 | `warm_sub` 与极轻 `filtered_pulse` | 只提供呼吸参照，不能成为鼓点或经营反馈；动态侧链 ≤1.5 dB 候选 |
| 气泡/水下底噪 | 复用现有自然声池；新增内容用程序化噪声或自录授权素材 | 归 `nature`，不从原 MP3 分离；可在静谧模式关闭 |
| 反向钢琴/吸气转场 | 原创短声或合成噪声包络 | 只用于慢过渡，禁止硬切和“进入新区域”宣告；hold/尾音按64等幂约束 |
| 宽阔声场 | profile 内的窄→宽滤波和混响发送 | 使用现有 6 总线/12 长轨/4 短槽/2 自然声预算；不以固定 ± 声像宣称真实空间定位 |

参考曲约 124 BPM 的十六分音符推进可以转成“当前母曲 BPM 下的 1/8 或稀疏 1/16 事件密度”，不能直接把游戏 Transport 改为 124 BPM。优先保留《共鸣之城》已有 80 BPM 母曲的呼吸与跨段安全换流；新 profile 只改变织体、滤波、混响和层密度。

和声采用“关系色彩”而非原曲复制：在现有 `harmony_mode` 中选择 E/B/G♯m 邻近的开放五度、sus2、add9、maj7 色彩，避开连续高音与同音域堆叠。每个候选必须给闭合事件 JSON、音域、休止、层级、来源签名和回退；不把 Gemini 的 `Emaj7→F#6→G#m7→D#m7` 直接写入正式母曲。

## 3. stem 与资产的处理规则

1. 原 MP3 与任何从它分离出的钢琴、Pad、低频、脉冲、气泡或混响尾音只保存在本地参考目录，记录源哈希，不进入 Git、发布树、运行时数据或 2MB AI 参考包。
2. 若用户取得原作者/发行方的改编、同步、再发行和 stem 授权，另建许可记录，逐个文件记录授权范围、期限、地域、署名和 SHA；授权前仍按“仅参考”处理。
3. 可发布资产采用原创重制：程序化 DSP、原创 MIDI、原创噪声/水声录制，或许可证明确允许再分发的 CC0/兼容样本。参考原曲的音色参数可以写成技术 Brief，旋律、录音指纹、原始混响尾和逐样本波形不能复制。
4. 在游戏里只保存审定的 profile/事件/缓存版本；stem 试听文件和对照 WAV 放在本地验证记录，不由运行时动态读取。

## 4. 生产与验收顺序

1. 先做 16 小节原创 `blue_underflow_v1` P0/P2 对照：felt_keys、breathing_pad、muted_pluck 三个分支，保留现有 `pastoral_comfort_p0_p2_v1` 与旧 A/B/B2 对照，不切默认。
2. 运行 24 s/144 s 渲染，分别测峰值、RMS、频谱质心、过渡尾音和缓存签名；同一批导出 -23 LUFS 对照 WAV，再人工长听，重点检查尖锐度、低频遮蔽、Lead离场后伴奏自足和硬切真空。
3. 做一处未接路庭院/内陆曲路样板：亲和度只控制滤波/Pad/短声比例，slow transition 期间保留源层尾音，不因接路/经营/等级解锁音乐。
4. 只有听评和空间样板通过，才接入正式内部 v3.1；新 profile 必须更新 BankCache 来源签名、预混、loop 和回退。失败候选移入本地废弃批次。
