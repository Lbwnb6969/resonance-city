# 背景音乐柔和配器与长听：审阅及施工映射

2026-10-31审阅（10月30日原稿） · 采用目标、校正材料；本轮未修改运行音频、未合成或试听。产品主规格为[54](54_V7_最终施工改造总案.md)，既有作曲材料见[58](58_原创室内乐作曲审阅与施工映射.md)，当前首步只在[PROJECT](../PROJECT.md)/backlog维护。

## 1. 结论与来源边界

**采纳中音区、真正休止、互相让位、伴奏自身成立的背景室内乐方向。不能据此判定现有音乐已经好听，也不能把降低高频、降低Lead增益当作全部解决方案。** 用户已评原A/B“B略好但两版仍不足”、B2“又尖又抢耳而且单薄”；这些反馈优先于原稿的乐观推断。新v3首段混编技术通过但听感未评，详见[53](53_功能区与母曲编配施工记录.md)。

已提取[部分谱与参数候选](../数据/作曲候选/Gemini柔和长听_部分谱与参数_v1.json)：P0/P2逐音事件、原始和声单元、来源行号和7行音色参数；`runtime_ready=false`，不是内部v3，也不是外部M80导入文件。P2简写角色的音色仅继承P0作为目录上下文，正式配器仍须写定。原稿代码不执行、原表错误不静默改写。

用户进一步明确音乐是随时随地存在的暗线，由玩家自己发掘和感受。该方向已记入54；具体建筑/空间声音映射、换区/加建慢过渡及显线退场重构交下一轮Gemini方案，本文件不先写死机制。

## 2. 正式采用的音乐目标

- Lead以可辨的中音区句子为主，长音后真正离场；高潮来自旋律方向、和声和音色层次，不靠持续升八度、加音符或加响度。Virtuoso保留接口身份，可以写成克制的cantabile分支。
- P2/P5安排真实减法，不能用零gain音符伪造休止。Lead休止时伴奏仍有完整和声与方向；Answer接句而非与Lead争前景，低音、暖垫和内声部避免同音域堆积。
- Warm、Flowing、Canon是预写互补分支；档位提高不必提高密度或整体响度。不同曲目保持身份，不统一成低通后的同一种音色。
- 和声使用带拍位的权威时间线。悬留/经过音有准备与解决，不能把长音逐拍吸附到当前和弦来掩盖配器问题。短反馈服从真实留白和前景操作。
- 音域、占比、gain、起音与混响数值是A/B起点，按完整编配及真实设备听评决定，不把原稿百分比升级为普适质量门禁。

## 3. 谱面复核：施工前必须校正

按原表事件计算，Lead占比取音符时值区间并集，不含混响尾音；“无Lead事件小节”也不自动等于实际PCM静默。

| 项目 | 实际表格 | 施工处理 |
| --- | --- | --- |
| P0 | 53事件、21 Lead、6 Answer；Lead 21/32拍=65.625%，MIDI61—74 | 原文16.5拍/51.6%与5 Answer不成立；若要更疏朗，另写修订谱并重算 |
| P2 | 24事件、7 Lead、2 Answer；Lead 11.5/32拍=35.9375%，MIDI61—67；18/20/22小节无Lead事件 | 原文22事件/6 Lead/9.5拍不成立；表格第23小节也有Lead，不能照抄“仅17/19/21/24” |
| 声明音域 | P0有MIDI61，P5有59，P4末有62 | 不符合原稿某些“最低62/P4最低66”的文字；新v3分支明确整句音域，不放宽旧接口来迁就未审谱 |
| P2和声 | 摘要第22小节F#m7，表格为Bm7；24小节写A6sus4→A6但只有一个和弦数组 | 先写定和声及解决拍位，再编Lead/伴奏；F#m7数组[42,49,52,57]本身正确 |
| P0第7小节 | 标Gmaj7，却有G2→A2、A3和E4等运动 | 分清低音移动/转位与和声变化，不以单一标签证明整小节和谐 |
| P2第24小节 | Lead C#4与Pulse D4悬留同时存在 | 写明张力意图和解决，不能只贴sus4名称宣布不冲突 |
| P5收束 | Lead最后从25.25延至27.5，剩4.5拍=3.375秒 | 不是原文5.5拍/4.125秒；第48小节A系伴奏与摘要Dadd9不一致，须明确接缝A→D时间线 |
| P5越界音 | E4从30.25延2.25拍，至32.5 | 保留跨界意图；真实衰减、wrap与预混决定尾音可闻性，不能仅凭越界事件宣布无缝 |
| Warm音程 | D2/MIDI38至A3/MIDI57相差19半音 | 是复合纯五度，不是十度；不要按错误音程评价浑浊来源 |
| Canon偏移 | .022拍在80BPM为16.5ms | 不等于22ms；如保留演奏偏移，独立于谱面量化字段版本化，不放宽M80网格 |
| P4密度 | 2小节15/16事件分别为2.5/2.667事件每秒 | 7.5事件/小节只能是平均数；事件、同时音数与实际响度分别统计，不以单个总量保证轻盈 |

Deep主题D2/MIDI38降到B1/MIDI35是小三度；旧稿32.25拍跨界音是合法尾音候选，改短属于新作曲取舍，不是修复非法格式。Construction Walk的`range(60,97)`不等于实际必响MIDI90—96：还要看筛选后的和弦音数组和step索引，按实际输出核对。

静态复核命令：`python tools/review_music_comfort.py --report 验证记录/音乐长听方案提取.json`。它校验原稿哈希及确定性提取结果，不验证和声审美、DSP或听感。

## 4. DSP、混音和路由：采用方向，修正因果

| 原稿论断/数值 | 审阅结论与落地要求 |
| --- | --- |
| `sin(phase+.018*sin(2π*5.1*t))`是强烈音高颤音 | 这是相位调制；瞬时频率偏移幅度.0918Hz，A5约.18音分。t=0内层sin为0，不能称起音即最大位移，更不能凭公式确定眩晕原因 |
| cello_harmonic二泛音高于基音是物理错误 | 泛音音色可以如此；先区分光谱峰与听觉基音。新暖Answer独立音色/profile，不覆盖旧音色来“修错误” |
| bell的3倍频是非谐波 | 是第三谐波。437/683Hz弱瞬态是否刺耳须实听；换成142/218Hz也不自动和谐 |
| 新长笛42ms起音能解决尖薄 | 旧原值55ms，B2已有更软起音/滚降仍被用户否定；先改完整音区、旋律和伴奏，再定音色。新bass二泛音.18反而高于旧.14，不能统称全面减泛音 |
| 线性bandlimit/Hermite能彻底消除混叠 | 逐谐波衰减与插值不等于完整抗混叠；相位/幅度调制、噪声和采样移调另查，保留高音/单声道实际PCM |
| MASTER_LIFT或active_roles预算代表感知响度 | 它们是幅度/峰值策略，非LUFS；MASTER_LIFT为上限，不是每次必跳到该值。随角色数增预算仍会改变电平，要测实际增益轨迹、稀疏段与满编切换 |
| 混响hipass=.22代表220Hz | Godot接口值归一化0—1，文档没有这种Hz换算。用独立滤波器或核实实际实现后再写截止频率；共享总线影响范围如实说明 |
| 把各声部写到不同声像即完成跨岸定位 | 现有空间路由不提供逐音独立声源。可评估原池内立体声PCM或现有声源路由，但先说明跟随镜头/空间的更新方式与缓存签名；不能加播放器绕过预算，缺失声像表不代写成已收方案 |

DSP/混音改动用独立内容或profile版本标识，缓存及预烘签名随实际参数更新；不全局改变旧曲增益来制造新版本更好听。旧A/B/B2与最新v3首段均保留作比较基线。

## 5. 微采样与公开参考

微采样是待评估分支，不是本轮新增资产任务。根音50/57/62/69、每根±4半音合计覆盖MIDI46—73，覆盖不了A5/81、B5/83；标准长笛的D3样本也不能假定存在。逐乐器列实际文件、根音、奏法、可用音域、许可、来源与哈希，再决定混合合成或补根音，不强行挪八度掩盖缺样本。

原建议12个1.2秒拨弦加4个1.3秒笛声，22,050Hz/16bit/mono裸PCM为864,360字节（WAV头另计），解码float32约1.73MB。QOA约175KB不是固定保证；发布总预算、解码内存、活跃/缓存/预混流分别实测，不能只报压缩包大小。

- [VCSL官方仓库](https://github.com/sgossner/VCSL)与[VSCO 2 CE官方仓库](https://github.com/sgossner/VSCO-2-CE)标CC0；具体乐器、奏法和裁样覆盖仍要核对实际文件，仓库许可不等于每种目标乐器都有可用样本。
- [Tiny Glade官方原声专辑](https://noknokaudio.bandcamp.com/album/tiny-glade-original-video-game-soundtrack)曲名为“Tiny Flowery Glade”，署名Oda Tilset并列长笛演奏者Bente Borge；不能把原稿的错误曲名当精确引用。
- [Martin Kvale开发者声音访谈](https://www.youtube.com/watch?v=0tSr74_p23c)标题为Save & Sound Festival 2023，不是AirCon 2025。[官方声音开发日志](https://steamcommunity.com/games/2198150/announcements/detail/3887232108503707092)支持自然/触感声音方向，不足以证明原稿逐曲音域、响度和配器结论。另一个未提取出内容的视频链接不作证据。
- [Dorfromantik Vol.2官方商店页](https://store.steampowered.com/app/1981960/Dorfromantik_Soundtrack_Vol_2/)可作作品参照，不把发行描述冒充实际听析。[Godot 4.7混响文档](https://docs.godotengine.org/en/4.7/classes/class_audioeffectreverb.html)用于核对参数语义。

## 6. 施工切片及验收

沿用已接通的内部v3首段/真实Mute与旧v2技术基线，先制作独立的P0/P2共16小节柔和修订：修正逐音统计、和声时间线和音域，写出Lead离场时仍成立的伴奏；必要的v3音域/和声/profile能力与内容同批落地，不先铺全部六曲或22种音色。保留原表候选，不把它直接宣布为修订完成。

同调式/段落/设备，比较现有v3首段与修订P0、现有B/B2的P2与修订P2；固定总增益做等响度对照，保留未归一化原录音。记录版本、路由、实际四轨/静默、短声与换段、峰值/削波、可闻尖锐/薄/糊的时间点；-23LUFS仅是已有对照数据，不是默认播放目标。

真实听评回答旋律是否愿意再听、Lead是否抢耳、休止后伴奏是否空薄、低中频是否混浊、操作声是否突兀。参数或频谱改善不替代这些答案。该切片通过后完成P1/P3/P4/P5与首尾、Warm/Flowing/Canon等空间选择；再接默认编配及其余母曲。具体当前次序以PROJECT/backlog为准。

每个子步记录实得证据，整首和长听仍需多轮真实播放。原稿缺页不阻塞已明确的16小节切片；缺页内容不得臆造。M84～M86状态、历史验收、个人作品和12长轨/4短槽/6总线/2自然声预算保持。
