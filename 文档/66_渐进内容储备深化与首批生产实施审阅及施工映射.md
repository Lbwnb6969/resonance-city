## 2. 源码缺口核对与首批范围

原稿盘点与当前源码一致的缺口如下：内部音乐 v3 仍是受控 ID/分支/音色白名单；增加曲名、音色或 DSP 必须更新来源签名、缓存和校验；建筑声明 ID 不会自动生成网格、碰撞、入口包络、预览和序列化；玻璃、材质、植物字典和 Shader 不是即插即用；新经营必须有单一版本化政策和独立账期，不能绕过旧截止。

首批只做有真实差异、能单步回滚的样板：

1. **音乐暗线**：`田园晨风` P0/P2 的 `base/cross/cantabile` 受控切片；修正 P0_cross 实际 Lead 并集为 20.0 拍、P2_cross 的 54/55 半音重叠为 0，并补齐低六度延迟伴唱。`undercurrent_warm_v1` 作为独立 profile，需重新计算来源签名和预混缓存。它仍不是完整 48 小节母曲，也不改变默认母曲。
2. **美术质感**：四层内凹窗样板（玻璃、窗套、上楣/窗台、微旋百叶）和独立玻璃批次；墙体高光、树冠重复乘色修正；`tuscany_ochre` 色板与 `weeping_willow` 垂柳候选。真实墙洞、遮挡、AO、LOD、共享风和冷算/增量一致性必须单独验证。
3. **建筑**：`stepped_guildhouse` 阶梯山墙行会与 `cantilever_tea_deck` 悬挑亲水茶台两个几何差异明显的母型；五类细部插槽（天窗、烟囱、窗拱/百叶、山墙檐口、门廊微景）。悬挑、船坞、吊臂和外阶改变净空或碰撞时必须接 `Frontage`/场地校验，不得只改外观。
4. **明线经营**：只设计一个版本化 `cozy_progression` 权威契约和新账期；旧档缺省保持旧静谧/截止语义，新作品或主动启用才建立新账期。原稿的 XP、等级、品质和奖励数字先当候选，必须映射真实事件、收据和小数余量。

## 3. 采用规则与必须修正的原稿断言

- 完整曲、16 小节分谱、主题种子、替代配器和音色/DSP profile 分开计数；建筑母型、结构变体、细部构件、材质、配色、植物和微景分开计数。改名、换色或复制参数不算新内容。
- `P0_cross` 的旧 20.75 拍统计必须在修谱后重新核验；`P2_cross` 的半音碰撞检查使用事件真实重叠，不能只看和弦表。`cantabile` 伴唱仍受唯一 `layer=3` 约束，不增加播放器。
- 玻璃 `z=-0.042m`、窗台/上楣外挑、百叶 14—18° 只是候选尺寸；未切出真实墙洞时不能称立体窗。共享玻璃材质不保证 DrawCall 不增加，`COLOR.a` 不会自动写 AO。
- 原稿所谓 Blinn-Phong 片段不是 GGX；`SPECULAR_LIGHT`、roughness、metallic、背光和半角向量必须按当前 Godot Shader 实际编译。树冠少面数不等于摩尔纹、侧视、风或 GPU 时间已解决。
- 不执行 `house.seed += 1` 重掷细节。新变体必须有独立稳定 ID、版本、变体 seed 和作者覆盖；旧房屋保持旧配方，显式重掷才写 Undo/快照。
- 12 个原型、6 个色板和五维插槽都是候选池，不能自动注册为可用、自动赋予场所/声音/品质或声称有 1024 个有效组合。每个组合需有风貌、屋顶、开口、净空、LOD、碰撞和作者覆盖矩阵。
- `cozy_progression` 与旧稿 `prosperity_enabled` 是同一政策的两个草案名，只保留一套正式字段；不能按 headless 与实窗分叉，也不能用新开关回放历史 XP。

## 4. 候选生产管线

离线候选放在本地验证记录/内容储备目录，带 `runtime_ready=false`、源文件 SHA、作者/批次和许可证；运行时只加载通过静态校验、人工听评/看图和预算检查的定稿。每一批按以下顺序：

1. 写 Brief：目标槽位、与现有 ID 的差异、拍数/音域/几何包络/材质和预算。
2. 生成 2—3 个候选，静态检查 0.25 拍网格、音域、半音重叠、Lead 密度、AABB/退化三角形、UNORM8 歧义和单屋 DrawCall 变化。
3. 音频渲染 24 秒/144 秒，统一到 -23 LUFS 做盲听；美术/建筑固定机位 1440×900 做昼/夕/夜三态原图。
4. 选择后写正式版本、来源许可、SHA、支持矩阵和回退；落选项移入本地废弃批次并写归档说明。
5. 先接一项并回滚验证，再横向增加数量。音乐首曲品质闭环优先于同时铺六曲；明线经营、窗材质、建筑和储备批次分片验收。

## 5. 施工顺序与最低充分验证

施工 AI 按依赖执行：

1. 音乐 P0/P2 修谱、内部 v3.1 受控读取、独立 profile 和 -23 LUFS 实录/听评；保留旧 A/B/B2 与 v3 对照，不切默认。
2. 四层窗、独立玻璃、墙/树 Shader 样板、色板/垂柳；检查真实墙洞、材质路由、三态原图、增量/冷读几何和缓存。
3. 两个母型与五维插槽；检查入口净空、Jolt 拾取、LOD、Schema/Undo/冷读和旧房外观。
4. 单一 `cozy_progression` 新账期；检查旧 Schema1—20/legacy/growth_cutoff、重复发奖、关闭/再开、J/UI 和真实收据。
5. 通过后才从候选池扩展下一批，不把“候选数量”写成已开放内容。
