# 声画合一设计融合：室内乐总谱箱庭

2026-10-30 · 用户方案审阅与采纳定稿 · V7.1 增补

用户在本轮提供《从机制叠加走向声画合一》整体方案并要求判断、融入项目。本文记录审阅结论、采纳后的产品目标和施工边界；是对用户方案的融合整理，不冒充原稿全文。与[文档54](54_V7_最终施工改造总案.md)共同使用；本文明确更新自由模式成长方向，其余空间、数据、谱面与验证契约沿用文档54。唯一任务进度仍为[根backlog](../ai_feature_backlog.json)的 holistic_integration。

## 1. 判断：采纳方向 A，吸收 B/C 的局部体验

主干定位为“室内乐总谱箱庭”：玩家塑造建筑、道路、水岸、地形与植被，真实空间关系选择同一首完整母曲的配器、织体和演奏法；通过即时反馈、静听和收藏感知自己的创作。

方向 B 的物理装置沙盒保留为触感即兴的灵感，不引入全局流体/风道声学模拟，不推翻现有母曲架构。方向 C 保留居民生活点景、长椅与阳台静听，不以等待 NPC 偶遇作为基础音乐前置。二者后续可独立探索，不成为本轮必做系统。

此方向与 V7.1 大体同向，主要新增价值在于：明确取消自由模式数值成长驱动的长期目标、强化操作归因、将探索与欣赏组织成完整体验。不是另一套空间分类与音频框架。

### 必须校正的判断

| 用户方案中的表述 | 融合结论 |
| --- | --- |
| 母曲保证任何时候好听、绝不拥挤或跑调 | 同曲同和声提供结构约束；音域、节奏、尾音、换器与密度仍需实际听评。不能以零削波代替品质 |
| CueGrid 零延迟、即时 0.18 秒 | 当前 GRID=.1875，向未来网格吸附；理论量化等待为0至187.5ms，实际还含帧调度和设备缓冲。视觉立即确认，声音记录实际延迟 |
| 小节就是乐句，每3秒可换全部材料 | 3秒是小节，乐句可跨多小节；伴奏在合法小节换流，领唱按谱面句法保持完整 |
| A/B/C 复用率90%/40%/70%，最小资产成本 | 没有依赖审计和工时测量，不采用百分比。A最贴近现有结构；喷泉、车船、印章、录音回放仍有内容和工程成本 |
| 空间几何是唯一音乐决定因素 | 几何是自由模式的主要空间表达来源；最终发声还由实际播放段落、和声、谱面留白、用户偏好和预算决定 |
| 好看空间必然对应高档音乐 | 空间赋予表达上限；简单、稀疏、安静均是完整作品，不建立造景评分或满编最优解 |
| 模块都已验收即可兑现整套体验 | M75～M83是受测技术基座，M84连续母曲/多档未完成；未提交施工修改不当作已验收能力 |

本轮依据为当前入口、日志、backlog、文档54、CueGrid源码及工程边界；没有新增实窗、音频听评或外部调研。用户引用的外部游戏经验仅保留为论证背景，不扩写成已验证的普遍规律。

## 2. 产品主循环与自由模式减法

主循环为：**塑形 → 看见空间关系 → 听见有来源的变化 → 驻足欣赏 → 收藏或继续修改。**

城建深度来自体量、界面、围合、高差、连通与留白。居民提供尺度和生活气息。库存、送货、采购、信誉、茶聚次数、住宅等级、稀有度与倍率不再作为 free 音乐和基本美术的资格中介。

### 成长方向的明确更新

自由模式的最终目标改为非数值创作与探索：退出新自由城默认的 XP/等级条、三选一抽卡、稀有度/保底与收益催建。原18张手札和5类建筑和弦按真实ID梳理为已有表达、历史权益和未实现提案，不再新增一套奖励经济。此目标覆盖文档54第1节“保留可选三选一”的长期产品选择；实施须先完成下列迁移闭环。

- 经典 legacy 继续正式运行经营与历史规则。
- 已有 free/legacy 的等级、credits、邀请、收据、稀有度、已获+35%和人工意图完整保留；旧手札与题签提供主动继续/领取入口，不因隐藏UI或停轮询消失。
- 当前正式+35%仍按现规则运行。退出其自由模式新增长路径前，明确哪些新事件不再计点、旧余量与未领取奖励如何处理、旧效果如何展示及跨模式转换规则；用隔离旧档和真实入口验收后切换。不能直接删倍率或冻结旧权益冒充减法完成。
- 新自由城基础工具、基础母曲与基础声部不通过印章、图鉴或任务解锁。未来母曲/材质/风貌也先提供自由选择；探索记录可帮助发现和推荐，不强制刷条件。
- 住宅品质仅在 free 退出默认考核与催促，旧等级保留读取。装饰改接真实空间来源后再停止旧消费者，不用填假库存或假茶聚维持表现。

目标是自由模式少一条数值任务链。收藏发现本身若变成凑齐12枚的新任务链，就偏离了本次改造。

## 3. 营造：四类工具入口与作者控制

“屋、路、水、自然地貌”作为默认入口组织方向；自然下仍可区分植被与地形操作。合并入口不删已有能力、快捷键或外部API。完整原型目录和细节编辑放入进阶层，常用工具优先可见。

四风貌共享美术语言；玩家可直选少量原型并显式微调。随形推荐优先提供候选，不强制所有建筑自动变为同一种空间最优形态。

| 行为 | 采用规则 |
| --- | --- |
| 小屋、长屋、L/U屋与高差台基 | 复用已有几何；沿实际高程与净空生成支持结构，不能以外观掩盖门槛断路 |
| 贴弯路折翼、自动阳台/飘窗 | 作为可选候选；有原型、净空与拾取证据后开放，不改写作者已选形态 |
| 道路穿屋形成穿堂、跨水改桥、空中连廊 | 涉及实体、道路结构、高程和通行的改变必须预览并由玩家提交；禁止后台自动挖穿或抬桥 |
| 庭院石铺、花箱、茶伞、浮灯 | 合法范围内派生、依附来源、可关闭；保留树、预留广场和水岸留白。装饰不能反过来证明成区 |
| 喷泉、栈桥、石琴键面、轨街电车 | 逐项核对现有资产和消费者后做可选内容；不作为成区必然生成或本期完成承诺 |
| 化学反应预览 | 优先复用现有候选/预览入口，仅显示真实可提交结果，提示冲突与来源；取消不写State，一笔一条Undo |

“围院清泉、临街连拱、跨岸双拱”可用作反馈语汇，不固定三字文案，也不以金色特效替代施工结果。一次操作产生多个变化时，首先解释最重要的一项，避免多次音效和弹窗叠加。

## 4. 空间契约：保持真实关系，避免新硬门槛

沿用文档54的 courtyard/waterfront/artisan/civic 与 trait/cluster/district。三级是派生描述，不向玩家推出三级升级任务。

- 庭院允许合法闭合、半围合与窄巷界面；不强制每院必须新造穿堂或喷泉。
- 水岸必须有真实水域、面水公共界面与可达入口；单栋复合长廊也能成区，不强制多栋连续走廊。
- 百工看作业体量、真实前庭/街面和入口；跨岸卡农另需双方来源及有效连接，不能把桥头存在当百工资格。
- 礼乐允许平地公共前场，不把高台、长台阶或主干道作为必需项。
- 5.2m水距、2.0～3.2m窄巷等是既有候选/样本参数，不是美学公式或所有空间唯一标准。闭合、围合、曲率和高差须与实际几何及通行匹配。

现有庭院、现代入口、水岸、百工、礼乐和独立地标已受测的范围保持；外置露台、穿堂、复杂界面仍按真实边界扩验。断路、删水、外伸柱脚阻挡与Undo必须同步改变相关资格。

## 5. 音乐：完整母曲、空间编配、克制即兴

### 5.1 宏观连续性

保持六首144秒母曲目标、每首48小节与P0～P5结构；先把首曲两段、完整六段和P5→P0实际播放接通，再放开多档和六曲。内部version3、旧version2和M80外部schema1按原契约各自校验。

单屋可以听完整简编，未接路不锁首次音乐。foundation/pulse/answer/lead是编谱职责，唯一layer3领唱；空间只选择各职责的可用上限，母曲段落决定实际分支。保留12长轨、4短槽、6总线、2自然声预算，不能把四职责误当四个固定新增播放器。

真实播放游标驱动短声和声、L页与声画事件。请求、准备、已播放状态分开；不能旧PCM仍在发声而UI和短声已经使用下一段和声。

### 5.2 空间表达与偏好

庭院Warm、水岸Flowing、百工Echo、跨岸Canon、礼乐/地标Lyrical或P4华彩继续作为预写分谱方向，不承诺每次成区立即播放最高档。各段保留合法静默；不规定所有P2/P5都只有独奏。

“同曲异器”需要逐句核对音域、节奏和音色可用性，风貌提供配器倾向，不能任意替换所有乐器或使每栋建筑独立发声。曲路Legato尾音×1.25、围合混响+4个百分点和空间声像是待听评初值，不是听感保证。

fixed优先于自动选曲，quiet优先控制密度；夜景与B静听可以改变混音和环境感，不自动把用户固定母曲换成毛毡夜曲。声像依实际世界位置与相机转换，沿既有PAN_LIMIT，不写死“西岸必左”。

### 5.3 即时反馈与装饰短声

建造反馈复用已有Construction Walk、World Strum和CueGrid，按实际发声小节取和弦并处理跨段尾音。先量化反馈、节流与前景让位，密集落笔时不逐节点堆叠音符。

“每小节第12/14格必为空隙”不成立。生活短声只在实际谱面有留白、真实事件发生且预算允许时播放；找不到空位就不补，禁止生成假生活历史。居民不承担必须等到才能发声的前置。

硬质屋顶、石墙不随手势弹跳或随音乐变形。即时动效放在候选代理、选择反馈、水、光和气；不得影响正式网格、碰撞、拾取及作者结构。

## 6. 美术与欣赏：统一气质，先复用

采用暖石、陶瓦、水彩植物与微缩手作质感的共同方向，四风貌共享明度、材质和细节密度控制。作者palette优先，不强制统一暖色；roughness 0.88～0.96仅是提案参考，各材质按实际光照表现确定。

沿用微法线/接触AO、世界风、实际坡地台基、连续屋谷与桥岸接续。日/夕/夜都须可辨空间界面，不用金光或夜灯掩盖白天轮廓问题。

声画联动优先水、光、气，读取实际播放事件、低幅平滑、可减弱，静音/换城恢复基线。喷泉呼吸、浮灯色温、金色音弧和夕照薄纱先做单项对照；无来源、遮挡操作、引起疲劳的效果不采用。

B静听、长椅/阳台、现有巡礼与作品收藏优先复用。漫步V键、第一人称微距、全新景深模式只是候选，核对现有输入和舒适性后再决定，不在文案先宣称可用。

L页先展示正在发声的曲/段落/分支及真实来源，目标计划标为等待。点击声部定位来源作为待办交互，镜头跳转不改变作者偏好或立即截断母曲。

## 7. 发现记录与黑胶明信片的范围

“声景乐思图鉴/印章”合并进现有手札和收藏入口。先梳理18卡、5和弦与已有样板的对应关系，再决定是否需要新目录；不固定12枚，不另造货币、抽池或条件计数。发现记录可持久保留，实际空间效果随当前资格撤回，用户可以关闭装饰或选更安静编配。

若新发现语义需要持久化，核对Schema及稳定来源/收据映射，不能直接把旧卡重命名覆盖或用撤销反复刷记录。历史权益保留不等于把所有旧卡强行加一个新特效。

“黑胶明信片”作为作品馆的呈现方向：先复用城市快照、封面、昼夜、音乐偏好和不可变收藏版本。精确音频回放需另外设计母曲内容版本、实际游标/分支、随机状态、DSP版本与资源可用性；12条轨的某刻状态本身不能重建完整录音。无上述能力只称保存城市与音乐设置，不称已经封存声音。WAV导出或长录音不阻塞当前母曲闭环。

### 三个受控体验样本

1. 空地首屋→修路→院落：从真实free空地起步，不固定开局自带河流或D大调；锁定母曲/调式/段落，围合前后对照Foundation，检查有无听出变化及自动装饰是否占用留白。
2. 单岸→两岸→接桥/断桥：锁定Lead与母曲，检查Pulse/Answer资格与安全边界，跨岸Canon不得只因任何一座桥存在而授予；使用Undo检验恢复与解释。
3. 台地或平地礼乐→夕照→B静听→收藏重开：分别检查公共入口、P4实际到达、固定母曲偏好、当前城市和收藏版本差异；不编写“造完桥恰好P3”的必然剧情。

## 9. 本轮证据与未解决项

这是文档融合轮，只做入口/链接/Harness与发布树核对；不更改游戏代码、不写个人作品、不更新功能passes/verified_by。修改前Git锚点及既有脏工作区快照保存在本地备份目录，原文件保留。

待解决项：自由模式数值退场的逐权益迁移；母曲全局连续游标及多档实际听感；复杂空间几何覆盖；自动装饰的密度与作者控制；准确音频回放成本；长期创作动力是否成立。以上通过对应施工与实玩判断，不以提案中的复用率或绝对听感承诺代替证据。
